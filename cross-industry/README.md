# 发达国家创新者与跨行业研究

[返回研究计划总图](../PROGRAM-MAP.md)

本区研究两件互相关联但层级不同的事：

1. **Innovation Formation**：一个创新者怎样形成，他如何获得技能、判断、资本、决策权与错误窗口。
2. **Industrial Revolutions Comparative Lab**：技术机会本身怎样出现、跨过成本线、扩散，并最终被新的组织或产品形态吸收。

这两条线不能混成“伟人创造技术”或“技术自动创造伟人”。

---

## 1. 从游戏业进入跨行业：PUBG 是桥梁

根目录 [CASE-032](../cases/CASE-032-pubg-brendan-greene.md) 已经给出一个关键中间态：

> mod / community 中的个人规则发明 → 可玩的公共 artifact → 商业组织合作 → 大型公司资源放大。

它避免两个极端：

- 伟大创新都是一个天才凭空想到；
- 大型公司只要投入更多资源就能买到创新。

PUBG / Brendan Greene 因此连接了 indie production 与 industrial-scale innovation。

## 2. Innovation Formation / 创新者形成

### Builder / 创业者

首批：Steve Jobs、Elon Musk、Jensen Huang、Jeff Bezos、Edwin Land、James Dyson。

观察：
- formative hobbies / early work；
- first artifact；
- non-consensus decision；
- capital allocation；
- hiring / decision rights；
- vertical integration；
- customer feedback；
- failure portfolio；
- founder control 的正负效应。

### Organizational innovator / 工程组织者

候选：Kelly Johnson / Skunk Works、John Carmack 等。

重点不是个人魅力，而是组织怎样让小团队获得 clear owner、short feedback loop、protected autonomy、direct user / test data、low coordination tax 和 escalation discipline。

### Theorist / 理论工具

首批：Clayton Christensen。

理论家不等于成功 builder。disruption、value network、incumbent incentive、overserving、resource dependence 应作为可被案例支持或反驳的解释工具，而不是先验定律。

### 当前综合节点

- [001 — Innovation Survival, Selection & AI Funnel](001-innovation-survival-selection-ai-funnel.md) — 将 Craft / Search / Selection、Innovation Rights、创新熵增、异类存活漏斗与生成式 AI 的 bottleneck migration 合并为可证伪研究地图；只作为跨案例综合与待证假说，不把 Jobs / Christensen / Grove / Nintendo / Pixar 个案提前写成已证普遍规律。

### 统一分析模板

每个跨行业人物 / 组织至少回答：

1. Formation：童年、家庭、教育、兴趣、早期工作形成了什么能力与世界模型？
2. First artifact：第一次无需职位授权就能证明能力的作品是什么？
3. Non-consensus bet：真正逆共识的判断是什么，当时为什么不是常识？
4. Runway / capital：谁为试错付钱？失败一次会怎样？
5. Decision rights：谁有 kill / pivot / ship 权？
6. Feedback architecture：多久能获得外部真相？
7. Escalation：什么时候从小下注升级为大规模投入？
8. Residual value：失败留下了什么人才、技术、渠道、品牌或认知？
9. Institutional amplifier：公司、资本市场、大学、政府、供应链承担了什么放大作用？
10. Dark side / boundary：这种模式制造了什么组织代价、错误和不可复制条件？
11. Technical opportunity：当时刚刚成熟 / 扩散到可用的技术是什么？本人是否明确意识到这一窗口？

## 3. Industrial Revolutions Comparative Lab / 工业革命比较实验室

正式入口：[industrial-revolutions/](industrial-revolutions/)

这里研究的不是“最新技术新闻”，而是：

> **一项技术怎样从“已经存在”变成“值得采用”，再变成“产业基础设施”。**

强制区分：

invention → engineering maturity → economic viability → diffusion → complementary fit / killer application

以及：

frontier availability → professional diffusion → small-team / indie diffusion → mass availability

研究案例包括：

- Newcomen → Watt / Boulton：效率、通用化、商业组织与蒸汽动力扩散；
- 电气化：发电 / 电网 / 电机已经存在后，工厂为什么还需要组织重构才能吃到生产率收益；
- Diesel：从早期固定 / 船舶 / 潜艇应用，到不同运输和军用场景找到优势组合；二战苏联装甲应用只作为其中一个高价值候选，不写成“战争才第一次证明柴油机有用”；
- 计算机 / 微处理器 / PC / 网络：frontier capability 与普通开发者可调用能力之间的扩散时滞；
- 通用引擎、数字发行、众筹、Early Access、UGC 平台：它们怎样改变最低有效团队规模和反馈路径；
- 生成式 AI / agent：哪些成本项真实下降，哪些互补组织、数据、判断、验证和专业能力仍构成瓶颈。

### 技术决定论禁令

禁止：

> 技术没到位，所以以前的人什么都做不了。

也禁止：

> 技术到位，所以现在一个人什么都能做。

正确研究对象是：

> **在一个时代真实可获得的技术集合里，当事人看到了什么新可行解；同代其他人为什么没有采用、不能采用或不愿采用。**

## 4. “技术→体验转换”的研究归属

技术→体验转换不进入“游戏设计方法论”专区。

在本项目里它只作为历史与产业问题处理：

- 某项尖端技术哪年出现；
- 哪年工程成熟；
- 哪年成本降到商业可接受；
- 哪年扩散到大厂；
- 哪年扩散到普通专业团队；
- 哪年小团队也能负担；
- 哪一批产品最早证明它能创造玩家真正重视的体验 / 市场价值；
- 哪些技术曾经长期存在，却因为缺少 complementary system 而低利用；
- 哪些“先进技术”没有形成有竞争力产品，为什么。

对应框架见 [Technology Absorption Framework](industrial-revolutions/001-technology-absorption-framework.md)。

## 5. “中国从美国学到了什么 / 没学到什么”必须拆开

已大量学习、需要具体量化的部分：
- 大规模工程管理；
- 软件与互联网组织；
- 风险资本形式；
- 全球供应链；
- 平台商业；
- 用户增长与广告；
- 标准化职业体系；
- 大规模制造与成本控制。

待检验是否仍存在差距的部分：
- problem selection / product thesis；
- 对非共识个人的早期容忍；
- artifact-first credential；
- 创始人 / 小团队的真实 decision rights；
- 在证据出现前保持小下注、证据出现后快速加码；
- 对失败项目的 residual-value accounting；
- 跨组织的人才流动和创业再组合；
- 长周期资本；
- 从本土 benchmark 跳向全球前沿问题的能力；
- 把“怪人”留下来而不是只筛掉。

这些都必须用中美公司史、创业者人生史、招聘 / 资本 / 组织制度和失败案例验证，不能用文化印象完成。

## 6. 当前边界

本区现在建立研究框架、来源池和桥梁案例，不批量生成英雄传记。

跨行业材料尤其容易受创始人自传、授权传记、公司公关、投资者成功学和事后“伟人早知道一切”污染。正式结论必须同时有同期材料、反方材料、失败节点和制度背景。

同样禁止把本区研究转写成私人项目的具体游戏设计、数值、系统、关卡或竞争方案。这里研究历史发生了什么；私人商业应用留在仓库外。
