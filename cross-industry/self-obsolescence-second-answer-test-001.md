# Self-Obsolescence / Second-Answer Test — 成功公式处决、自我过时与第二答案测试

- **Status:** CROSS-INDUSTRY RESEARCH NOTE / HYPOTHESIS FRAMEWORK / 2026-10-08
- **Program:** D — 发达国家创新者与跨行业研究；与 Program A 的 DOOM 纵向案例交叉引用。
- **Primary game anchor:** [DOOM 组织老化与再年轻 043](../book/research-notes/doom-organizational-aging-rejuvenation-043.md)
- **Core question:** 一个人或组织第一次创造出有效答案以后，能否在该答案仍然赚钱、仍然有声望、仍然有大量历史证据支持时，主动撤销它的“默认正确”地位？
- **Evidence rule:** 本文件提出的 SELF-OBSOLESCENCE、SECOND-ANSWER TEST、ORTHODOXY HALF-LIFE 等均为本项目 H 级分析框架，不属于 Grove、Christensen、Jobs/Cook、Iwata 或 id Software 的原始术语。跨行业案例只用于压力测试机制，不能用少数成功者证明总体分布。

---

## 0. 核心命题：真正稀缺的不是创新一次，而是让自己的成功重新接受审判

“创新能力”经常把性质不同的东西混成一个词。至少应拆开：

| 能力 | 主要问题 | 典型输出 |
|---|---|---|
| SUSTAINING INNOVATION | 已有产品怎样继续变好 | 性能、内容、成本、质量持续改良 |
| HETEROMORPHIC / RECOMBINATIVE INNOVATION | 已知范式还能怎样重组 | 新组合、新实现、新市场表达 |
| ORIGIN INNOVATION | 现有范式外还有没有新解 | 新产品语法 / 新品类 / 新工作方式 |
| SELF-OBSOLESCENCE | 我最成功的旧答案是否仍应拥有默认统治权 | 主动重写产品、组织、资源配置或评价函数 |

第四项不是前三项的“最高等级”，也不能由前三项自动推出。一个创始人完全可能第一次创造新范式，随后把该范式变成二十年的组织正统。

### SELF-OBSOLESCENCE CAPACITY / 自我过时能力

> **一个人或组织在既有成功模式仍然有效、仍然拥有资源与组织合法性时，主动撤销其“默认正确”地位，使新的问题定义、能力组合或产品形态能够重新与现实竞争。**

关键不是“经常改变”，也不是“追新”。关键是：

1. 旧答案仍有真实证据支持；
2. 组织仍从它获得收益、身份或声望；
3. 新答案尚未被市场完全证明；
4. 旧答案不再拥有免于重新验证的特权。

## 1. DOOM 2016 → Eternal → The Dark Ages：成功理论也会硬化

043 已记录 Doom 4 → DOOM (2016) 的 BENCHMARK CAPTURE 与 PROBLEM SOVEREIGNTY。2016 之后出现第二个更难的问题：

> 一个刚刚从旧 benchmark 中逃出的团队，会不会把自己刚发现的新原则迅速变成下一套 benchmark？

### 1.1 Eternal：从宽原则到强语法

Game Developer 2019 对 Hugo Martin / Marty Stratton 的同期访谈显示，Eternal 明确延伸 2016 的 push-forward combat：Martin 说“解决所有问题的办法都是 aggressive”，并强调玩家应在需要资源时主动从恶魔身上取得资源。

这说明 Eternal 不是简单“多加系统”，而是把 2016 的行为原则进一步制度化：

- Glory Kill → health；
- Chainsaw → ammo；
- Flame Belch → armor；
- 更明确的敌人弱点和武器工具关系；
- 更高频的移动、切枪、资源维护。

### DOCTRINE HARDENING / 理论硬化

> 一次有效发现从直觉 → 原则 → 系统 → production grammar → “正确玩法”的过程。

理论硬化本身不是错误。多人生产必须把隐性判断转成可教导规则。风险在于：

> **帮助组织发现真相的原则，开始获得免于玩家现实重新审判的权力。**

### MANDATORY ACTION TAX / 必修动作税

不是“游戏有多少机制”，而是：

> **玩家为了维持基本有效状态，在单位时间内必须正确调用多少种动作、资源循环和系统接口。**

机制数量与必修动作税不是同义词。一个系统很多的游戏可能允许大量工具保持可选；另一个系统较少的游戏却可能把大部分动作变成基础毕业要求。

该概念目前是 H；不能仅凭部分玩家对 Eternal 的批评证明总体“过度规定”。Martin 2020 也明确反驳过“过度 prescriptive”的说法，并列举了同一敌人的多种有效解法。因此应把问题写成 **action-surface / compulsory loop 的压力测试**，而不是“Eternal 只有唯一玩法”的事实判断。

## 2. The Dark Ages：不是失败后的 pivot，而是成功后的主动改写

2025 Developer_Direct 中 Hugo Martin 明确说：

- 2016 是 “run and gun”；
- Eternal 是 “jump and shoot”；
- The Dark Ages 是 “stand and fight”；
- Shield Saw 的 block / throw / parry / deflect 被压到一个 contextual input；
- 团队希望每一代 DOOM 都能作为独立体验成立。

同年采访中 Martin 又把 Eternal 的问题区分为 **complexity rather than simple difficulty**：玩家应该“和恶魔战斗，而不是和控制器战斗”。这不是证明 Eternal 设计失败，而是开发者公开承认上一代成功语法存在可被重新优化的接口成本。

### INTERACTION-SURFACE COMPRESSION / 交互表面积压缩

> **减少玩家必须显式管理的输入/API 表面积，同时尝试保留甚至增加底层状态、战术与反馈深度。**

The Dark Ages 把 Shield、Melee、Guns 作为更集中的动作族；同一 Shield input 根据语境承担多个动作。其假设不是“更少按钮 = 更浅”，而是：

> **Decision depth 不必与 button count / subsystem count 同比例增长。**

但这不是免费午餐。压缩显式动作表面积可能同时减少：
- explicit agency；
- expression granularity；
- 玩家对具体动作触发的可控感。

PC Gamer 的后续评测就把 Dark Ages 视作对 Eternal 复杂度反馈的某种 overcorrection。这类评价只能作为反方压力，不可作为设计优劣的客观裁决。

## 3. SUCCESS-FORMULA KILL CAPACITY / 成功公式处决能力

Doom 4 → 2016 更接近：

### FAILURE-TRIGGERED PIVOT
旧方向已经积累明显负证据后，组织有能力处决沉没成本。

Eternal → Dark Ages 更接近：

### SUCCESS-FORMULA REVOCATION
旧方向仍有强市场与口碑证明，但组织主动取消其“下一作默认模板”资格。

因此：

### SUCCESS-FORMULA KILL CAPACITY

> **组织在旧公式仍然赚钱、仍被认可、仍未明显失效时，能否主动撤销其默认优先权。**

这比一般 pivot 更难，因为失败会天然制造改革联盟；成功会制造：
- 预算合法性；
- pipeline；
- KPI；
- 用户预期；
- 内部专家权威；
- “为何不复制上一作”的风险规避压力。

DOOM 现代三作目前只能作为一个强案例，不能证明 id 已形成永久稳定的元能力。

## 4. ORTHODOXY HALF-LIFE / 正统半衰期

定义：

> **一次成功形成的方法论，在组织内部拥有无需重新证明自己的默认权威多久。**

这个变量不是简单“多久改版”。真正要测的是：

1. 成功经验被引用为 evidence，还是被引用为 veto？
2. 哪一种新证据可以迫使它重新测试？
3. 是只有市场失败才会降权，还是 prototype / user behavior / technology shift 就能降权？
4. 谁拥有发起 revalidation 的权限？
5. 谁拥有 kill / rescope 权？

健康组织不是“没有传统”，而是：

> **传统是高权重先验，不是永久 oracle。**

## 5. Intel / Andy Grove：战略拐点与“滞后证据陷阱”

Andy Grove 1998 年 Academy of Management 演讲为该框架提供了很强的一手管理证据：

- strategic inflection point 会要求 business strategy 的 fundamental change；
- senior management 往往是最后意识到重大变化的人之一；
- 公司历史数据主要描述过去，在拐点期可能无法证明正在形成的小趋势；
- 较低层级、接近市场或技术变化的人可能更早成为“Cassandras”；
- Grove 明确主张先允许 experimentation / “let chaos reign”，再在证据成熟后重配资源；
- 更关键的是，他强调新投入必须与旧投入的 “no” 配对，组织不能只增加新项目却不停止旧承诺。

这支持：

### LAGGED-EVIDENCE TRAP / 滞后证据陷阱

> **真实、精确、历史上高度有效的数据，因为生成于旧状态空间，被误用为新状态空间的否决证据。**

这不是反数据主义。恰恰相反，它要求把数据的**生成制度与时间有效期**也当成数据的一部分。

Intel 官方回顾 Gordon Moore 的材料还保存了 memory → microprocessor 转向的经典“走出办公室再作为新人走回来”故事。该材料属于公司多年后的机构回顾，应按 P1 / institutional retrospective 看待，而不是当同期会议记录。

### ARTIFICIAL OUTSIDER TEST / 人工外部人测试

> **如果今天没有历史职位、沉没成本与组织身份，我第一次看到这个资源组合，会继续做同样的配置吗？**

这是降低 SUCCESS-PATH LOCK-IN 的一个认知工具，不证明采用它就一定做出正确战略。

## 6. Christensen：优秀管理为什么可以自动产生春登化

Bower / Christensen 1995《Disruptive Technologies: Catching the Wave》以及 Christensen 1996 资源依赖研究的关键价值，不是“所有创新都应追逐 disruptive technology”，而是证明：

> **成熟公司的资源分配过程可以在每个局部参与者都做出合理决定时，系统性过滤掉小市场、低性能、当前客户不需要的方向。**

所以“春登化”不必依赖一个保守老板。

组织可以通过：
- ROI；
- 当前客户需求；
- 市场规模；
- milestone；
- pipeline compatibility；
- forecast confidence

自动把还不能用旧指标证明自己的探索饿死。

这支持 043 的 PROTECTED HERESY，但也给出重要边界：

> Christensen 的经典模型针对特定 disruption / resource dependence 问题；不能把任何失败创新都解释成 Innovator's Dilemma。

## 7. Apple：自我蚕食作为明确的组织原则，但必须区分 Jobs 与后续 Apple

2007 年 Apple 对 iPhone 的官方定义本身就把 “widescreen iPod” 吸收入手机。仅凭这一事实不能证明管理层有明确的“自我过时哲学”。

更强的一手管理证据来自 Tim Cook 2012 Goldman Sachs 会议：他明确说 Apple 对 cannibalization 的看法是，宁愿自己做，也不要让别人做；公司不应因为新产品会夺走旧产品销量，就阻止团队做“the absolute greatest thing”。

因此 Apple 可作为 SELF-CANNIBALIZATION 的强组织样本之一，但证据归属要准确：
- iPhone 2007 产品事实：P0 corporate source；
- Cook 2012 对 Apple 原则的直接表述：P1 / contemporary executive retrospective；
- “Jobs 一直这样想”若引用 Isaacson 等传记，则另按 P1/S1，不把 Cook 的话反推成 Jobs 原话。

## 8. Nintendo / Iwata：反 benchmark 文化本身也必须可被推翻

Nintendo 2007 investor Q&A 中 Iwata 明确说：

- 如果 Nintendo 满足于 DS / Wii 的成功、不再追求新挑战，别人最终会复制其成功；
- Nintendo 必须持续寻找其他平台无法做到的体验；
- 其硬件与软件团队紧密协作是一项应保留的 capability。

这非常接近：

> **保留 capability，撤销 current solution 的永久权威。**

但 Nintendo 同时提供反面提醒：

> “不要和别人一样”本身也可能硬化成 doctrine。

因此任何所谓 Anti-Benchmark Constitution 都必须递归适用：

> **组织连自己的“创新哲学”都不能拥有永久免责权。**

Nintendo 多代硬件的长期表现、Wii U 等反例应作为该理论后续压力样本；不能用 DS/Wii 一代证明 Nintendo 永久拥有 self-obsolescence。

## 9. Pocketpair：目前更强地证明“低教条组合搜索”，不是长期自我过时

Pocketpair / 溝部拓郎 2024 回顾 Craftopia → Palworld 时明确说：

- Craftopia 的“anything goes”很适合扩展，但游戏本身已经很复杂；
- 继续增加功能会拖慢开发；
- 当新概念已经足够不同，新开一款游戏反而更快；
- Palworld 的 Early Access 方式也吸收了 Craftopia 的失败经验。

这说明它有很强的：
- product-boundary recognition；
- low-dogma recombination；
- artifact / user-feedback orientation。

但它尚不足以证明：

> Pocketpair 能够在多个周期里持续主动处决自己最成功的核心公式。

所以它目前应归：
### COMBINATORIAL HERESY / 组合异端能力
而不是直接归：
### LONGITUDINAL SELF-OBSOLESCENCE

至少需要第二、第三个成功周期和清晰的旧公式退位证据。

## 10. 中国商业游戏：现阶段只能立“纵向公司审计问题”，不能提前定性

本文件不以单个《原神》《Marvel Rivals》或其他项目证明某家中国大公司已经具备完整 SELF-OBSOLESCENCE。

原因：

1. 单个项目最多证明 project-level innovation；
2. 新团队 / 新 IP / 新品类不等于公司主动削弱旧利润机器；
3. 同一商业底层、同一组织评价函数下的产品重组，可能很强，但性质不同；
4. 需要比较多个产品周期中：
   - 旧业务是否仍成功；
   - 新业务是否真实竞争同一资源；
   - 是否允许新 objective function；
   - 谁能推翻旧 KPI；
   - 是否有主动 cannibalization；
   - 失败后是否留下 residual capability；
   - 成功模式的半衰期是否随组织规模增长而延长。

所以目前最安全的命题是：

> **中国头部公司已经存在大量 sustaining / recombinative / project-level heteromorphic innovation；是否在数量级上形成稳定 SELF-OBSOLESCENCE 机制，仍是 OPEN QUESTION。**

禁止：
> 找到一两个创新案例 → 推出整个体系不存在问题。

也禁止：
> 找到一两个保守失败 → 推出整个体系没有创新能力。

## 11. SECOND-ANSWER TEST / 第二答案测试

单次成功很难区分：
- 能力；
- 技术窗口；
- 资本；
- 团队组合；
- 运气；
- 市场时点。

因此研究长期创新能力时，增加：

### SECOND-ANSWER TEST

> **当第一次伟大答案已经变成身份、流程、利润和组织权力来源以后，当事人能否在新的状态空间中产生第二个不同答案？**

最低审计：

1. **First Answer**：第一次异常成功的具体机制是什么？
2. **Lock-In Assets**：哪些人、流程、品牌、资本和职位因此与旧答案绑定？
3. **Contradictory Signal**：什么新事实开始与旧解释冲突？
4. **Revalidation Trigger**：什么事件有资格迫使旧答案重新接受测试？
5. **Kill Right**：谁能停止/缩减旧承诺？
6. **Protected Search**：新方向在未证明前靠什么活到验证？
7. **Second Answer**：新解是否只是旧解改良，还是 objective function / product grammar / resource allocation 已发生实质变化？
8. **Counterfactual Cost**：若旧答案继续复制，当时是否仍可能赚钱？如果是，则 self-obsolescence 证据更强。
9. **Failure Pressure**：转向主要由失败逼迫，还是在旧公式仍成功时发生？
10. **Recurrence**：这种能力出现一次还是跨周期重复？

## 12. 可操作审计量：把“创新文化”变成可比较变量

后续跨公司研究优先记录这些变量，而不是给公司贴“创新/保守”标签：

### A. ORTHODOXY HALF-LIFE
成功方法多久需要重新证明？

### B. REVALIDATION TRIGGER
什么证据能迫使旧答案降权：销量？prototype？用户行为？技术变化？一线员工信号？

### C. KILL-RIGHT ACCESS
谁真正有 kill / rescope / budget reallocation 权？

### D. INTERNAL EXIT
团队能否退出旧路线而不必退出整个组织？

### E. SUCCESS-FORMULA RETIREMENT
是否存在旧方案仍成功时被主动降级的案例？

### F. FEEDBACK LATENCY
异端假说多久能转成 artifact 并获得现实反馈？

### G. EVIDENCE TEMPORALITY
组织是否给历史数据标注 regime / cohort / platform / market 状态，还是默认跨时代有效？

### H. SECOND-ANSWER RATE
在多个成功周期里，组织产生了多少次真正改变 problem definition 的第二答案？分母必须是可比周期，不能用英雄案例计数。

这些变量可以与 043 的 PROBLEM SOVEREIGNTY、REALITY ARBITRATION、PROTECTED HERESY、SUNK-COST KILL CAPACITY 联合使用。

## 13. “春登 / 农民发明家”在这里的严格化

### INCUMBENT EPISTEMOLOGY / 春登

不再定义为“年长/保守”，而定义为：

> **把过去成功产生的知识，从高权重可修改模型升级成无需重新验证的前提。**

### REALITY-FIRST SEARCHER / 农民发明家

不等于“没知识”“反专家”，而是：

> **在可靠知识到达边界后，仍愿意通过低成本 artifact 搜索现实，并允许新证据修改自己。**

因此同一个人可以在不同阶段切换角色。真正的反春登能力不是“永远反对传统”，而是：

> **让自己的传统也服从相同的现实审判程序。**

## 14. 与先发 / 后发问题的连接

后发者：
> 外部世界已经有大量答案，因此“找答案—吸收—工程化”长期收益很高。

先发者：
> 没有答案，被迫训练搜索能力。

但成功的先发者会不断制造自己的答案，于是**内生地产生后发化**：

> “为什么重新探索？我们自己就有 successful formula。”

所以国家 / 公司最终更有解释力的分类未必是“先发 vs 后发”，而可能是：

### ANSWER-DEPENDENT SYSTEM
旧答案拥有高默认权，探索必须先证明自己符合既有评价函数。

versus

### REALITY-REVISABLE SYSTEM
旧答案保持 evidence 权重，但可以被新 artifact / 新市场 / 新技术状态重新降级为 hypothesis。

这是 H 级上层框架，必须继续用失败样本、非明星公司和跨国分母压力测试。

## 15. 证伪条件与禁止外推

以下证据会削弱 SELF-OBSOLESCENCE 框架：

1. 长期高创新组织并不表现出更短的正统半衰期；
2. 大多数所谓“主动自我过时”其实都发生在旧业务已经明显失效以后；
3. 主动 cannibalization 与长期创新表现没有稳定关系，甚至系统性降低组织存活；
4. 第二答案主要由关键个人偶然迁移造成，组织机制不能复现；
5. “内部退出 / protected search”在大样本中并不提高新方向存活到验证的概率；
6. 不同产业的资本强度、监管、技术周期差异过大，使该框架无法跨行业比较。

禁止外推：

- Grove / Intel 一例 ≠ 所有美国公司都有自我过时能力；
- Nintendo DS/Wii ≠ Nintendo 永远反 benchmark；
- DOOM 2016 / Dark Ages ≠ id 已永久解决创新老化；
- Apple cannibalization ≠ 所有主动蚕食都正确；
- Pocketpair 的低教条组合 ≠ 已证明长期组织更新；
- 中国找到创新项目 ≠ 数量级与制度条件已与美国/日本相同；
- 中国存在 benchmark capture ≠ 中国创作者缺乏原创能力。

## 17. 下一轮研究

优先级：

1. **失败型自我蚕食样本**：主动杀成功公式但转向失败，防止全是幸存者。
2. **第二答案失败者**：伟大创始人第一次成功后再也无法产生第二答案的公开纵向案例。
3. **组织 vs 个人**：Jobs / Grove 离开后，机制是否继续存在；区分个人元能力和公司制度。
4. **Nintendo 长周期**：FC/SFC→N64/GC→DS/Wii→Wii U→Switch，测 ORTHODOXY HALF-LIFE 而不是挑成功代。
5. **游戏公司数量级**：至少建立 20–30 家成熟工作室的 longitudinal product-grammar 转向表，再谈国家差异。
6. **中国公司纵向样本**：以同公司多周期资源配置、旧业务 cannibalization、prototype authority、kill-right 为单位，不再用单作“创新性”替代公司能力。
7. **AI 范式转换**：观察 incumbent 的旧 production grammar 是否变成新一轮 LAGGED-EVIDENCE TRAP；这里只做公开行业研究，不导入私人项目执行方案。
