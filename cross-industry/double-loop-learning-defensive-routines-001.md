## 0. 核心问题

组织最常见的“学习”并不是没有反馈，而是：

> 收到反馈后，只调整行为，不允许产生行为的目标、规则、假设和评价函数进入审判。

Chris Argyris把这种差别概括成：

- Single-loop learning：修正行动，使既定目标重新达成；
- Double-loop learning：如果必要，连产生目标、政策、规范和假设的 governing variables 一起检查和修改。

Primary:
- Chris Argyris, “Double Loop Learning in Organizations,” HBR, 1977:
  https://hbr.org/1977/09/double-loop-learning-in-organizations
- HBR Store summary:
  https://store.hbr.org/product/double-loop-learning-in-organizations/77502

## 1. Single-loop不是低级错误：它是成熟系统的必要能力

很多现实问题本来就是：
- bug修复；
- 参数调整；
- performance tuning；
- balance patch；
- production optimization。

若目标本身稳定，single-loop非常高效。

问题出现于：

> 组织把所有坏结果都预设成“执行没有达到正确目标”，从不允许目标函数本身被质疑。

因此新增：

### LOOP-DEPTH MISMATCH / 学习回路深度错配

> 本应修改governing variable的问题，被长期当成行动层误差处理。

## 2. Governing Variables：真正难改的不是feature，而是“什么算成功”

产品组织中，governing variables 可能包括：
- “D7必须是第一指标”；
- “必须做长线运营”；
- “这个品类用户核心需求就是X”；
- “大项目才值得投入”；
- “senior判断天然比junior可靠”；
- “创新必须证明ROI后才能获得prototype资源”。

当这些前提保持不动时，组织可以做大量“创新动作”，却没有double-loop learning。

### GOVERNING-VARIABLE LOCK / 治理变量锁死

bad outcome
→ feature changes
→ process changes
→ people changes
→ metric changes
while governing assumption remains immune

这与 Representation Lock-in、Self-Sealing Orientation、Metric Regime Dependence 直接相连。

## 3. “Good Communication”也可能只制造Single-loop Theater

Argyris 1994《Good Communication That Blocks Learning》直接反驳一种现代管理常识：

> 更多员工调查、focus group、management-by-walking-around，并不自动产生组织学习。

这些工具可以提供大量single-loop information，但也可能建立一种角色分工：

employees criticize
→ management fixes
→ employees' own assumptions remain outside inquiry
→ management's governing assumptions also remain largely intact

HBR概括：
- 新沟通技术帮助获取简单信息；
- 但可能强化defensive reasoning；
- 员工被暗示自己的角色是批评管理层；
- 管理层角色是“修好问题”；
- 双方因此都避免审视自己怎样参与制造问题。

Source:
- Chris Argyris, “Good Communication that Blocks Learning,” HBR, 1994:
  https://store.hbr.org/product/good-communication-that-blocks-learning/94401

### FEEDBACK THEATER / 反馈剧场

不是“没有反馈”，而是：

> 反馈不断发生，却被结构性限制在不威胁governing variables的层级。

## 4. Grove解决Voice，Argyris追问“Voice进来以后会发生什么”

Innovation Constitutionalism已经提出：

> Voice without Decision Effect is theater.

Argyris进一步追问：

> 即使员工真的说出了问题，组织会不会把信息重新解释成不威胁自己理论的形式？

所以两层必须区分：

- Voice Access：信息能不能说出来？
- Inquiry Depth：信息进来以后，哪些假设有资格因此改变？

### VOICE ACCESS ≠ DOUBLE-LOOP CAPACITY

组织完全可能非常开放、每周retro、人人能发言，却仍然只允许：

> 怎样更好执行既定战略。

而不能问：

> 为什么战略本身是这个？

## 5. Espoused Theory vs Theory-in-Use：真正信什么，要看行为

Argyris / Schön长期区分：
- espoused theory：人声称自己遵循的理论；
- theory-in-use：从实际行动中可推断出的行动规则。

Argyris 1966对六家公司高管决策会议的研究指出：

> 高管实际行为经常与他们自己关于“有效管理”的主张不一致，这种差距会损害开放、信任、替代方案搜索、创新和灵活性。

Source:
- Chris Argyris, “Interpersonal Barriers to Decision Making,” HBR, 1966:
  https://hbr.org/1966/03/interpersonal-barriers-to-decision-making

### ESPOUSED–ENACTED GAP / 宣称—行为鸿沟

创新文化审计不能问：
> 公司是否说“鼓励失败”“鼓励挑战权威”？

而要问：
- 最近一次junior挑战senior以后发生了什么？
- 最近一个失败prototype是否影响绩效？
- 谁因为杀掉自己的项目得到奖励？
- 有没有真实资源因异议重新分配？

### BEHAVIORAL CONSTITUTION > DECLARED VALUES

## 6. Defensive Routines：组织会保护自己免受尴尬和威胁

Argyris后来把大量阻碍double-loop learning的行为概括为 organizational defensive routines。

典型目的：
- 避免尴尬；
- 避免威胁；
- 避免公开暴露自己的推理可能错误；
- 维持控制；
- 避免失败身份化。

常见形式：
- 外归因；
- 模糊措辞；
- 私下抱怨、公开同意；
- “大家都懂”的暗示；
- diplomatic easing-in；
- 把真正危险问题改写成安全问题。

更危险的是：

> 这些routine常常同时阻止人公开讨论“我们是不是正在防御”。

因此可以把它视为一种 SELF-SEALING DEFENSE / 自封闭防御。

## 7. Skilled Incompetence：越熟练的人，越可能熟练地制造学习失败

Argyris 1986提出 Skilled Incompetence。

核心并非“高手其实无能”，而是：

> 人可以非常熟练地执行一种社会上奖励的行为模式，而这个熟练行为恰好持续产生自己并不想要的组织后果。

HBR例子强调，管理者擅长：
- 避免正面冲突；
- 显得理性；
- 保持礼貌；
- 控制谈话风险。

这些都是skill。

但长期后果可以是：
- 真实分歧不进入会议；
- 关键假设不被挑战；
- 每个人知道有问题却无人公开重构问题。

Source:
- Chris Argyris, “Skilled Incompetence,” HBR, 1986:
  https://hbr.org/1986/09/skilled-incompetence

### SOCIAL COMPETENCE CAN BECOME EPISTEMIC INCOMPETENCE

## 8. “聪明人不会学习”：长期成功也可能让失败处理能力欠训练

Argyris 1991《Teaching Smart People How to Learn》明确把矛头指向 well-educated, high-powered, high-commitment professionals。

HBR总结指出：
- 这些人通常很擅长成功；
- 恰因长期很少真正失败，没有发展出反思自己推理方式的习惯；
- 当失败终于出现时，更容易把原因投射到外部，而不是检查自己如何参与造成结果。

Source:
- https://hbr.org/1991/05/teaching-smart-people-how-to-learn
- https://store.hbr.org/product/teaching-smart-people-how-to-learn/91301

### SUCCESS-SHELTERED LEARNING / 成功庇护型学习

clear task
+ strong ability
+ repeated success
→ little need to inspect own governing assumptions
→ failure-handling skill remains undertrained

这与“中国高学历做题家”的讨论只能作为机制类比，不能直接当因果证明。

Argyris研究的是专业人士 / 管理者，不是中国考试制度。

但它提出一个可验证问题：

> 长期在明确评分器里持续成功的人，是否获得了足够多“自己定义问题、公开预测、承担错误、修改深层假设”的训练？

## 9. Model I：为什么高能力组织会自然制造防御推理

Argyris所谓Model I常被概括为：
- 单方面定义目标和控制局面；
- 最大化“赢”、最小化“输”；
- 压低负面情绪；
- 以单方面定义的“理性”行事。

这些倾向甚至很像 competent professional。

问题是遇到高风险错误时，它们可能自然产生：

need to look competent
→ avoid exposing uncertain reasoning
→ advocate strongly
→ minimize inquiry into own assumptions
→ others reciprocate
→ public agreement / private doubt
→ no double-loop learning

所以创新失败未必来自“大家没有批判性思维”，而可能来自：

> 每个人都在非常理性地保护自己的competence identity。

## 10. Model II：不是“温柔沟通”，而是让主张可检验

Argyris的替代方向不是简单“多倾听、多同理”。

更接近的是：
- valid information；
- free and informed choice；
- internal commitment；
- public testing of reasoning；
- advocacy 与 inquiry结合。

因此新增：

### TESTABLE ADVOCACY / 可检验主张

不是：
> “我觉得你错了。”

而是：
> “我的判断是X，因为A/B/C。如果D出现，我会降低对X的置信度。你看到的证据是什么？”

这与Lakatos的 Prediction-Before-Outcome、Programme Accountability，以及Reality Arbitration完全兼容。

## 11. Double-loop 与 Goodhart：不要只优化proxy，要允许目标函数进入审判

前面Goodhart / Proxy Capture研究的问题是：

true value
→ metric proxy
→ proxy becomes target
→ organization optimizes proxy
→ proxy decouples from original value

Argyris给出的组织学习语言是：

Single-loop：
> retention下降 → 加签到 / reward / event。

Double-loop：
> 为什么retention是这一阶段的主要目标？我们原来认为retention代表什么？现在直接优化它以后，这个proxy还代表原价值吗？

### PROXY DECAPTURE REQUIRES DOUBLE-LOOP LEARNING

没有governing-variable review，Goodhart问题往往只能被更多metric暂时覆盖。

## 12. Double-loop 与 Lakatos：修改理论，不等于无限修改理论

Double-loop不是：
> 每次失败都重新发明公司使命。

Lakatos提供边界：

- governing variables可以被质疑；
- 但核心programme不必因单一异常立即死亡；
- 修改后必须改善预测与解释能力。

健康组合：

single-loop
→ fix local errors when model still predicts well

double-loop
→ re-open governing assumptions when anomalies persist

Lakatos
→ judge whether revised programme becomes more predictive

## 13. Double-loop 与 Christensen：有些governing variable不是靠会议就能改

Argyris可能让人产生错觉：

> 只要大家推理更开放，组织就能学会新范式。

Christensen提醒我们：
- current customers；
- margin structure；
- P&L；
- sales incentives；
- organization size；

本身就可能是结构性governing variables。

因此有些double-loop learning必须以组织重构体现，而不能只停在认知层。

例如：
- 建独立事业部；
- different P&L；
- prototype fund；
- independent selection system。

所以区分：

### COGNITIVE DOUBLE LOOP
认知上承认旧规则有问题。

### STRUCTURAL DOUBLE LOOP
预算、scope、P&L、Decision Right真的随之改变。

否则：
> 人都承认旧规则有问题，但资源系统仍然自动复现旧答案。

## 14. Defensive Routine Audit

遇到一次项目失败，逐项问：

1. 谁可以公开描述自己当时的预测？
2. 当时预测是否有记录？
3. 失败解释主要归因外部，还是包括自己可控变量？
4. 是否有人能质疑目标本身？
5. 是否能质疑当前metric？
6. senior的判断是否与junior同样接受证据审判？
7. 哪些话题大家只在私下说、不在正式复盘说？
8. 哪些措辞看起来专业，实际让判断无法被验证？
9. 复盘以后，下一轮有哪些事前预测真正改变？
10. 资源配置有没有随模型更新发生变化？

如果只有 action correction，没有 assumption correction / resource correction，那很可能只有single-loop。

## 15. Learning Rights Stack

Innovation Rights Stack可以补一个组织学习侧：

1. Error Naming Right — 可以说发生了什么错误；
2. Causal Challenge Right — 可以挑战官方原因；
3. Assumption Challenge Right — 可以质疑governing variables；
4. Self-Implication Duty — 提出批评者也必须检查自己如何参与结果；
5. Prediction Right — 可以提出与主流不同的可检验预测；
6. Resource Consequence — 学习结果可以真的改变预算、scope和Decision Right。

前3项防沉默。
第4项防“所有问题都在别人”。
第5项防纯评论员化。
第6项防反馈剧场。

## 16. 与个人主义主线：独立判断也必须允许别人检查你的决策逻辑

低质量个人主义：

I own my judgment
→ therefore my reasoning is private
→ outcome bad
→ external blame

成熟的Judgment Sovereignty：

I own my judgment
→ I expose action-relevant reasoning
→ others challenge assumptions
→ reality adjudicates
→ I revise

所以 Judgment Sovereignty 必须配 Reasoning Accountability。

这里不要求公开全部私人心理过程；真正需要公开的是：
- 可行动假设；
- 可检验预测；
- 关键决策逻辑；
- 会让自己改观的证据条件。

## 17. 对中国“高学历做题家 / 模糊决策”研究的严谨接口

Argyris最有价值的不是给“中国人不行”提供外国权威。

恰恰相反，他研究的是美国高学历、高投入、高成功professional，说明：

> “强专业训练 + 持续成功 → 防御性学习风险”不是中国专属机制。

可验证的跨国问题应是：

- 哪类教育 / 职业路径让人长期只需single-loop就能成功？
- 哪些环境要求学习者公开预测并承受自己错误？
- 哪些组织允许junior质疑governing variables？
- 各国从业者第一次真正承担模糊决策是什么年龄？
- 高credential和强身份投入是否让失败更威胁自我形象，从而增加defensive reasoning？

因此本节点用于 MECHANISM COMPARISON，而不是 CULTURAL ESSENTIALISM。

## 18. Reader-facing Debugger

遇到“我们已经复盘过”：
> 复盘修改的是动作，还是修改了我们定义问题的方式？

遇到“开放沟通”：
> 哪一次员工反馈真正推翻了一个领导层governing assumption？

遇到“非常聪明、总能解释问题”的人：
> 他最近一次事前预测错误以后，具体修改了自己的什么假设？

遇到“数据驱动”：
> metric不达标时，我们会改产品；metric本身什么时候可以被改？

遇到“主人翁文化”：
> 员工是否既被要求承担结果，也拥有质疑目标函数的权利？

## 19. 当前最值得继续验证的问题

1. 游戏公司postmortem里有多少真正修改governing variables，而不是feature/process；
2. 强团队的design review是否存在可观察的Model II式testable advocacy；
3. 高credential人才在首次重大失败后是否更容易出现外归因；
4. 哪些组织制度最能降低defensive routine而不制造无休止争论；
5. Grove Cassandras进入高层后，哪些case真的改变了组织底层假设；
6. 中国商业游戏公司的“复盘文化”更偏single-loop还是double-loop；
7. AI总结会议是否会强化漂亮一致的事后叙事，还是能帮助暴露espoused–enacted gap；
8. 能否把Judgment Trace与Prediction-Before-Outcome结合成低负担double-loop工具。


## 20. Learning Depth Ladder：把“复盘”拆成五层

为了避免所有review都自称“学习”，新增：

### L0 — Outcome Description
发生了什么？

### L1 — Action Correction
下次动作怎么改？

### L2 — Causal Model Correction
我们原来为什么判断错？因果模型哪里有误？

### L3 — Governing Variable Correction
目标、metric、成功定义、风险语言本身是否需要改？

### L4 — Structural Learning
预算、P&L、Decision Right、团队边界、晋升激励是否真的随新模型改变？

因此：

> 说得更深 ≠ 学得更深。

真正组织学习的强证据，是后续行为和资源系统发生可追踪变化。

## 21. Competence Identity Trap：身份越依赖“我是会做题的人”，失败越可能变成身份威胁

Argyris关于高能力professional的观察可进一步提出H级机制：

### COMPETENCE IDENTITY TRAP / 能力身份陷阱

当一个人的地位长期建立在：
- 我聪明；
- 我专业；
- 我判断准；
- 我总能给答案；

那么模糊失败不只是一次任务失败，
还可能被体验为：

> “我到底是不是那个聪明、专业的人？”

于是最理性的自我保护方式可能变成：
- 把失败外归因；
- 强调执行偏差；
- 找数据证明自己原本仍对；
- 避免公开不确定性。

因此高credential并不自动提高double-loop learning，
甚至可能增加“承认我的representation错了”的身份成本。

该假说必须单独实证，不能从Argyris直接推出跨国总体结论。

## 22. AI风险：总结器可以让single-loop变得极其漂亮

AI会议纪要 / postmortem agent 很容易：
- 聚合意见；
- 生成一致故事；
- 列行动项；
- 自动归纳“根因”。

这可能提高L0–L1效率，
却同时制造：

### SYNTHETIC CONSENSUS / 合成共识

> 多个互相冲突、尚未被检验的解释，被LLM压缩成一个流畅、专业、貌似已经达成共识的因果叙事。

所以AI复盘工具应该反过来保留：
- 分歧模型；
- 未解决冲突；
- 每个解释的证伪条件；
- 谁在结果发生前预测过什么；
- 哪些governing variables无人质疑。

AI最有价值的角色不是：
> 帮组织把故事说圆。

而是：
> **防止组织过早把冲突压平。**
