## Purpose

本区研究技术与产业之间最容易被简化的一段：

> **一项技术从“已经有人发明”到“普通生产者可以可靠、经济地使用”，中间究竟发生了什么？**

它不是未来学专区，也不是“新技术必然颠覆一切”的论证库。

本区尤其反对两种对称的技术决定论：

- “旧时代技术不够，所以当时的人什么都做不了”；
- “新技术已经出现，所以现在一个人什么都能做”。

更符合历史的研究对象是：

> **技术改变可行解空间，但能否被吸收，还取决于成本、可靠性、基础设施、组织、技能、市场、资本和使用者是否识别出了新的用途。**

## Core distinction

所有案例强制区分：

1. Invention — 原理/设备第一次出现；
2. Engineering maturity — 可靠性、可制造性与工具链达到实用门槛；
3. Economic viability — 成本/效率跨过真实业务阈值；
4. Diffusion — 供应链、人才、标准、基础设施让更多主体可用；
5. Complementary fit — 新组织、新流程、新市场或战争等场景终于把技术优势放大；
6. Absorption — 使用者不只是“买了技术”，而是重构自己的生产方式去吃到收益。

## 与《独立游戏英雄传说》的接口

工业革命区研究“机会怎样出现”。

人物 Profile 研究：

> **这个人当时拿到了什么技术条件，他看见了什么别人没有看见的可行解，又有哪些事情仍然做不到？**

因此每个重要人物可以有 Technical Opportunity Window，但技术史 canonical material 留在这里，人物篇只链接。

## Source rule

作者文章、旧博客与历史类比可以作为 H / author-origin source。

正式历史判断仍应优先补：
- museum / archive；
- contemporaneous technical documents；
- academic economic history；
- company / patent / standards records；
- participant testimony。

作者自己的历史解释不得因为“写得早”自动升级为外部证据。
