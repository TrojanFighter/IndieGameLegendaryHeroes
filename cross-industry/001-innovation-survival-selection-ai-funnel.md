## 0. Boundary

本节点把 Christensen / Grove / Jobs / Catmull / Nintendo / early id 与生成式 AI 讨论压缩成一个可检验的共同框架。

它不是：
- “天才人格学”；
- “个人主义必然创新”的文化本质论；
- “AI 会自动民主化创新”的技术决定论；
- “有品味的人一定成功”的成功学；
- 对任何私人项目的具体设计、发行、融资或组织建议。

当前目的只有两个：

1. 把分散讨论改写成可以被案例支持、削弱或证伪的机制；
2. 明确下一轮需要补什么公开证据。

## 1. 主框架：Innovation is a pipeline, not an idea

暂定把创新链条拆为：

**Variation → Selection → Retention → Scaling**

并进一步拆成九个实际 gate：

**Potential Heterodoxy → Formation → Expression → Prototype → Ownership → Funding → Market → Retry → Amplification**

这里通过漏斗的不是抽象“天才”，而是：

> **人 × 异常判断 × artifact × 权利 × 资源 × 时机**

任何一层都可能使潜在创新在进入市场验证前死亡。

因此国家、公司或时代比较不能只数“最后出了几个名人”。必须尽量测：
- 有多少异常方案形成；
- 有多少能被表达；
- 有多少能获得 prototype right；
- 多少拥有作者权 / IP / decision right；
- 失败后多少人还能继续做第二次；
- 成功后多少能得到工业化放大。

**个例只证明可能性；分母、频率、分布和路径容量才决定结构性。**

## 2. 三层个人能力：Craft / Search / Selection

创新教育与创新人物研究必须至少区分：

### Craft
能不能把东西做出来。

包括工程、设计、美术、写作、制作、商业等领域技艺。

### Search
在巨大可能空间里去哪里找候选答案。

不同创作者可能形成完全不同的 search prior：
- 技术边界；
- 成熟技术重组；
- 日常行为；
- 类型历史；
- 亚文化经验；
- 市场缺口；
- 组织约束。

### Selection
在多个可行方案中，什么值得继续、什么应该杀掉。

本项目已有 Taste Capital 审计表明，selection 不能被理解为单一 scalar。至少要拆成：
- product / interaction selection；
- scope selection；
- representation selection；
- onboarding judgment；
- audience / market judgment；
- business-model judgment；
- feedback integration。

Brigador 是重要反压力：强产品 / 美学 /技术 selection 可以与弱 market legibility / onboarding judgment 同时存在。

因此禁止：

> “X 很有品味，所以 X 更可能商业成功。”

更精确的问题是：

> **X 在哪些 selection domain 上有可观察优势？这些优势是否正好覆盖当时真正的瓶颈？**

## 3. Taste 的工作定义：early-signal ranking

Taste 暂不神秘化为审美天赋，而定义为：

> **在信息极不完全、最终结果尚未出现时，对候选方向未来价值进行排序的预测能力。**

可观察代理包括：
- 是否能把“喜欢 / 不喜欢”翻译成规则与取舍；
- 是否能从多个 prototype 中区分潜力；
- 是否能删掉“做得出来但不值得做”的内容；
- 是否能区分核心不可妥协项与通往核心的可修改接口；
- prototype / playtest / market evidence 出现后是否真正更新。

这一定义与现有 Taste Capital Audit 兼容，也允许失败案例存在：判断力是概率优势，不是预言能力。

## 4. 六种创新动作不是一回事

“创新”至少拆成以下不同操作：

1. **Capability Creation**  
   创造过去不存在或不可用的能力。early id / Carmack 是强候选锚点。

2. **Capability Reinterpretation**  
   对成熟、便宜、可靠的既有能力重新找用途。横井军平路线应单独取证。

3. **Behavioral / Rule Abstraction**  
   从行为、感觉、因果与决策关系中抽象新交互。Nintendo / 宫本路线应继续取证。

4. **Product Synthesis**  
   把技术、交互、工业设计、商业、分发和用户接口组合成一个完整产品命题。Jobs 是候选研究对象，不在本节点直接写成已证定律。

5. **Resource Reallocation**  
   让尚无成熟市场证据的新方向获得资源。Christensen 提供理论工具。

6. **Self-Obsolescence / Strategic Reorientation**  
   组织能否否定曾经使自己成功的答案。Grove / Intel 与 DOOM reboot 提供不同层级的候选材料。

这套拆分用来避免“已有组件 = 没创新”以及“用了新技术 = 有创新”两种对称错误。

## 5. Innovation rights stack

一个组织是否“鼓励创新”，不应主要靠口号判断，而应观察真实权利：

1. **Idea Right** — 谁能提出偏离 roadmap 的问题；
2. **Prototype Right** — 谁能在完整立项前把东西做出来；
3. **Critique Right** — 谁能公开说核心方向不成立；
4. **Decision Right** — 最终产品判断属于谁；
5. **Resource Right** — 谁决定增加人、钱、时间；
6. **Kill Right** — 谁能处决已有沉没成本的方向；
7. **Persistence Right** — 一次失败后，作者还能否继续搜索。

相关现有机制：
- DOOM 043：Problem Sovereignty / Reality Arbitration / Sunk-cost Kill Capacity / Protected Heresy；
- Creator Exit 044：失败后的项目、职业、作者性、资产是否可逆；
- Pixar Braintrust：批评权与命令权分离的高价值候选；
- Nintendo prototype tradition：把认知问题尽早转成可玩 artifact 的高价值候选。

真正有效的“心理安全”在这里不是气氛友好，而是：

> **讲真话、做异端实验、失败一次之后，会不会失去职业资本与下一次下注权。**

## 6. Innovation Entropy：成功组织怎样把搜索算法变成答案复制器

本节点提出 H 级上层概念：

### INNOVATION ENTROPY / 创新熵增

> **组织仍在专业地生产“新东西”，但发现过去未知之物的能力逐渐下降。**

可能的子机制：

### Solution Knowledge replacing Generative Knowledge
把“上次正确答案长什么样”误当成“怎样找到下一次答案”。

### Identity Lock-in
“我们就是做这种东西的公司”。

### Asset Gravity
成功 IP /业务越大，允许探索的空间越小，逃离既有答案需要更高政治和财务能量。

### Scale Burden
项目必须一开始就证明足够大，导致小市场 / 弱信号实验无法竞争资源。

### Decision-right Calcification
判断权逐渐集中到维护旧成功函数的人。

### Measurement Capture
指标从辅助判断的仪器，升级成“什么值得存在”的最终裁判。

### Cultural Succession Failure
继任者模仿前辈的外在行为，而不是继承其搜索、验证和纠错机制。

此框架与 Christensen 的 incumbent resource-allocation 问题、Grove 的 strategic inflection point / Cassandra 问题以及 DOOM 043 的 benchmark capture / selective institutional amnesia 相互兼容，但目前不能把三者写成同一理论已经被证明。

## 7. 两种创新生态：Genius Cluster 与 Innovation Institution

### Genius Cluster
特点：
- 极高人才密度；
- 高自主权；
- 极低协调成本；
- 大量隐性接口存在于少数人之间。

优势：
- 决策快；
- 创新振幅大。

风险：
- “人本身就是 API”；
- 关系破裂后能力组合不可复制；
- 规模扩大后 founder stack 失效。

early id 是高价值锚点。

### Innovation Institution
目标不是“制造天才”，而是把部分创新行为制度化：
- cheap prototype；
- peer critique；
- reality arbitration；
- decision / critique rights 分离；
- kill / rescope；
- residual knowledge retention；
- intergenerational craft transmission。

Nintendo / Pixar 是候选锚点。

二者不是简单优劣关系。真正研究问题是：

> **哪些判断必须保留在人，哪些反馈与权利结构可以制度化，从而不需要每次等待救世主？**

## 8. 异类存活漏斗：从民族叙事转向可观察变量

跨国研究禁止直接写：
- 美国人更创新；
- 日本人更从众；
- 中国人更模仿；
- 斯拉夫苦难产生创意。

应该比较同一组 gate：

- 家庭 / 教育是否允许异常兴趣长期形成；
- 同侪环境是否允许真实异议；
- artifact 是否能先于 credential 出现；
- 是否存在低成本 prototype substrate；
- 不被组织认可时是否有 exit；
- 失败一次后能否 re-entry；
- 创作者能否保留作者性 / residual assets；
- 资本是否只跟随已有市场证据；
- 全球市场接口是否可直接触达；
- 成功后是否存在强 amplification；
- 玩家 /媒体 /发行商是否具备识别异质产品的 selection capacity。

现有研究已分别触及：
- early id 的 outside option / strategic disloyalty；
- creator exit & re-entry；
- China creator constraints / taste institutions；
- Japan comparator；
- Slavic team fission。

下一阶段应寻找 cohort / denominator，而不是继续堆名人个案。

## 9. Artificial Wild Habitat / 人工野生生境

成熟产业职业化会提高平均能力，同时也可能提高异常者进入成本。

因此提出 H 级概念：

### ARTIFICIAL WILD HABITAT

> **成熟产业刻意保留低许可、低成本、低职业门槛的实验生态，让不符合标准职业路径的人仍能制造 public artifact。**

候选载体：
- mod / UGC；
- game jam；
- hobby tooling；
- open source；
- direct digital distribution；
- low-cost engines；
- creator platforms；
- small prototype grants；
- generative / agentic production。

判断其价值不能只数参与人数，应继续测：
- artifact → first revenue；
- artifact → employment；
- artifact → founder formation；
- failed artifact → second attempt；
- hobby creator → durable authorship。

## 10. AI：不是自动民主化创新，而是改变下注资格

与 [Game Industry Technology Regimes 003](industrial-revolutions/003-game-industry-technology-regimes.md) 对齐，本节点只提出当前可检验假说：

### H-AI-01 — Complementary Skill Constraint falls
AI / agents 可能降低一个作者把判断转成可验证 artifact 时，对完整互补团队的最低需求。

关键不是“单项任务快多少”，而是：

> **judgment → playable / inspectable reality 的转换成本是否显著下降。**

### H-AI-02 — Recognition can move after Creation
非标准履历创作者过去可能需要“先被组织认可 → 得到资源 → 才能证明判断”。

若 prototype 成本下降，路径可能部分变为：

> **先制造小型证据 → 再获得社会 /资本认可。**

这将提高 artifact-first credential 的价值。

### H-AI-03 — Bottleneck migration
当 Variation / execution 更便宜时，相对稀缺变量可能移动到：
- problem formation；
- selection / taste；
- integration；
- falsification；
- discovery；
- trusted curation。

因此不能从“更多人能做出作品”直接推出“优秀作品同比增加”。

### H-AI-04 — Full-stack Judgment
未来“全栈”可能部分从亲自掌握所有 craft，迁移为：
- 知道该研究什么；
- 知道任务如何拆；
- 知道该调用什么能力；
- 知道输出哪里错；
- 知道什么时候杀掉；
- 知道哪些判断不能外包。

这不是“prompt engineering”同义词，而是 capability orchestration + selection + responsibility。

### H-AI-05 — AI-mediated conformity
模型擅长产生统计上合理、语言上完整的候选答案。

因此 AI 既可能扩大 search，也可能让大量创作者更高效地进入相似解空间。若用户只要求模型完善自己的既有假设，还可能出现：

> **Acceleration of Wrongness — 错误方向被高效率工业化。**

检验必须依赖外部 reality loop，而不能用“多个 agent 都同意”当作独立证据。

### H-AI-06 — Discovery becomes relatively scarcer
若生产供给增长快于玩家注意力，市场瓶颈会进一步转向：
- platform discovery；
- trusted publisher / curator；
- streamer / creator network；
- community reputation；
- author brand。

这是经济方向假说，需要未来平台供给、销量分布、曝光与中介价值数据验证。

## 11. 当前公开证据锚点

### Christensen / incumbent resource allocation
Bower & Christensen, “Disruptive Technologies: Catching the Wave”, Harvard Business Review, 1995.
https://hbr.org/1995/01/disruptive-technologies-catching-the-wave

当前只把它作为 incumbent incentives / resource allocation 的理论工具，不把 disruption 当创新万能解释。

### Grove / strategic inflection point / Cassandra
Andrew S. Grove, Academy of Management Annual Meeting speech, Intel, 1998-08-09.
https://www.intel.com/pressroom/archive/speeches/ag080998.htm

Grove 明确强调战略转折早期很小、不能简单从历史数据中找到，以及低层“Cassandras”向高层传递坏消息的重要性。

### Nintendo / Splatoon prototype selection
Iwata Asks: Splatoon.
https://iwataasks.nintendo.com/interviews/wiiu/splatoon/0/0/
https://iwataasks.nintendo.com/interviews/wiiu/splatoon/0/1/
https://iwataasks.nintendo.com/interviews/wiiu/splatoon/0/3/

直接材料支持：
- 半年产生至少约 70 个 idea；
- 最终候选具有可玩的 4v4 prototype；
- 团队强调从 function / game structure 出发；
- 成员经历过自己提出方案、现场被拒绝的过程。

### Catmull / Braintrust authority separation
Ed Catmull, “Inside the Braintrust”, Stanford eCorner transcript, 2014-04-30.
https://stvp.stanford.edu/wp-content/uploads/sites/3/2024/09/inside-the-braintrust-transcript.pdf

Catmull 明确说明 Braintrust 的一个关键条件是：
- 它不是“聪明人坐在一起”就自动成立；
- Braintrust 没有命令导演的 authority。

### AI adoption / prototyping
GDC, “2026 State of the Game Industry”.
https://gdconf.com/article/gdc-2026-state-of-the-game-industry-reveals-impact-of-layoffs-generative-ai-and-more/

当前公开摘要显示：
- 36% 的受访游戏行业人士在工作中使用生成式 AI；
- 常见用途包括 research / brainstorming、daily tasks、code assistance；
- 35% 报告用于 prototyping。

这只能证明采用与用途，不证明 productivity、quality、employment 或 innovation outcome 因果。

## 13. Falsification agenda

以下结果会削弱本节点的若干核心假说：

1. 大样本显示 prototype cost 显著下降，却没有增加非标准履历创作者进入或首次公开 artifact 数；
2. AI-heavy小团队并未降低最低有效团队规模，反而因 integration / QA / legal / discovery 成本抵消；
3. selection / taste 在控制专业能力、runway、市场接入后，与项目方向质量没有稳定关系；
4. 组织拥有 prototype / kill / persistence rights 并不提高异质项目的存活或纠错速度；
5. 创作者失败后的 re-entry 率与所在产业的 exit infrastructure 无显著关系；
6. Nintendo / Pixar 等案例表明所谓制度化机制其实高度依赖少数人物，无法跨代保持；
7. “真实异议”与形式化 devil’s advocate 在创新结果上没有可重复差异；
8. 供给爆炸没有增加 discovery concentration，反而平台匹配效率同步提高。

## 15. 暂定总命题

本节点目前只允许写到这一强度：

> **创新不是 Idea Generation 单点问题，而是一条由 variation、selection、现实验证、权利配置、资源升级、失败可逆性和知识遗传共同构成的供应链。**

以及：

> **当执行能力变便宜时，瓶颈可能向 problem selection、taste、integration、reality arbitration 与 discovery 迁移；这是生成式 AI 时代值得优先检验的结构性假说，而不是已经证明的历史定律。**
