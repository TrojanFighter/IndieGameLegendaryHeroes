# CASE-037 — Darkwood / Acid Wizard Studio：众筹“成功”以后，钱为什么不到一年就没了

- Case ID: CASE-037
- Subject: Acid Wizard Studio / Darkwood
- Period covered: 2012–2019
- Research status: RESEARCHING
- Corpus role: **CROWDFUNDING-RUNWAY STRESS TEST / CONTRACT-WORK BRIDGE / EARLY-ACCESS EXTENSION / POLISH INDIE**
- Evidence Ledger: [`../evidence/CASE-037-darkwood-source-ledger.md`](../evidence/CASE-037-darkwood-source-ledger.md)

## Why this case

Darkwood 很适合用来拆一个长期存在的独立游戏误区：

> **“众筹达成 143% / 募到一大笔钱”不等于“开发资金充足”。**

Acid Wizard 是三个没有职业游戏开发前史的朋友。早期他们需要靠接商业委托吃饭；Indiegogo 成功后，团队原本按大约一年开发期估算资金，但后来自己承认没有把税、VAT、许可证、工作室、设备、实体回报制作与邮寄、推广等成本充分算清，而且严重低估了完成时间。众筹资金不到十二个月就耗尽，而项目总开发超过四年、Early Access 约三年。

因此 Darkwood 是 FTL/Hollow Knight 等“众筹如何买 runway”正向案例的必要压力样本：同一种工具，在错误工期与成本模型下也会迅速失效。

## Myth

### Myth A — Darkwood 众筹 143%，所以开发期资金无忧

错误。2017 年团队直接回顾：约 20 万 PLN 看起来很多，但扣除所得税、VAT、许可证、工作室、硬件、backer 实体奖励生产和邮寄等成本后远非“坐在金袋上”。更关键的是，他们按约一年完成项目估算，而实际根本不可能一年做完；Indiegogo 钱不到 12 个月就耗尽。

### Myth B — 三个人没有专业经验，说明经验不重要

错误方向。2013 年采访确认三人此前主要是 hobbyist，并参加 Global Game Jam；这解释了他们为什么能做出初始可玩物，但也与后来的 scope / runway 误判同时存在。

本案更像：

> **原型能力足以让你进入市场，不等于已经具备估算四年商业项目的制作能力。**

### Myth C — Early Access 只是“没做完先卖”

对 Darkwood 来说，EA 还是 runway extension、真实用户反馈和风险暴露机制。团队最终在 EA 约三年后完成正式版；不能只把 EA 当营销标签。

## Origin / Capability

2013 年同期采访明确说，三人此前没有职业游戏开发经验，主要以 hobby 制作与 Global Game Jam 练习为主。Darkwood 从约 2012 年 11 月开始开发，中间需要停下来做付费委托以维持生活。

这条前史同时支持两个相反但兼容的判断：

- game jam / hobby work 已经形成足够的快速制作与作品展示能力；
- 缺乏长期商业项目经验，使工期、成本和 scope 估算更脆弱。

因此“能力资本”不能只按有没有 AAA 履历二分。

## Runway

本案至少存在三层 runway：

1. **paid contract work**：众筹前维持基本生活；
2. **Indiegogo**：把团队推向更连续的全职开发，但只撑不到一年；
3. **Steam Early Access**：项目继续存活和迭代的重要商业阶段。

众筹金额必须扣掉大量非工资成本；开发者回顾还特别指出，自己当时把三个人的最低生存工资、税费和实体 reward fulfillment 等成本估算得不成熟。

这正面支持 C002：

> **runway 是“资金 ÷ 全部真实 burn + 时间误差”的动态变量，不是 campaign 页面的 gross amount。**

## Production / Scope

Darkwood 的三人核心并不意味着传统职能全部外包。官方 FAQ 说音频由团队自己完成，Artur 负责音频及整体美术相关工作。这是一种高 labor compression。

与此同时，团队也做了明确删除：不做 multiplayer，理由是专注 single-player。这是小团队最重要的生产动作之一——不是把每种行业标准功能都做差一点，而是删除会引入长期网络、同步、匹配与支持成本的产品面。

## Failure / Estimation Error

Darkwood 的“失败”不是项目最终失败，而是**生产模型失败**：

- 以为一年能做完；
- 没有充分预算税/平台外成本/reward fulfillment；
- crowdfund gross 被高估为可用开发资源；
- 真实项目最终持续四年以上。

这个案例特别适合与 FTL / Hollow Knight / Project Wingman 对照，因为它证明：

> **众筹的意义取决于团队是否已经会估算完成路径。筹得更多，并不会自动修复错误工期模型。**

## Market Access

Darkwood 的市场接入并非等正式版才开始：

- Indiegogo trailer / campaign；
- backer alpha；
- Steam Early Access；
- 社区反馈与口碑；
- 后续主机发行与平台传播。

2017 团队还说，正式发布后几天的销量接近此前三年 EA 销量的一半，说明 EA 并没有“吃掉所有 launch demand”；但该数字来自开发者访谈，不能写成审计收入。

## Environment / Cultural Specificity

Darkwood 的东欧/波兰文化表达不是“地方题材卖不出去”的简单反例。官方 FAQ 列出 Strugatsky brothers、Stanisław Lem、Slavic folklore 等灵感；团队采访也讨论过将陌生的波兰/东欧气质带给更广受众。

可迁移的不是“做民族题材”，而是：**低预算项目可以把作者熟悉的文化语汇变成差异化表现，同时不承担写实大规模内容成本。** 这部分仍需更多同期设计资料验证。

## Preliminary Verdict

### STRONGLY SUPPORTED

- Acid Wizard 是三人核心，之前主要是 hobby/game-jam 经验而非职业游戏开发；
- Darkwood 早期靠 paid contract work 维持；
- Indiegogo 获得近 3,000 backers、达到 143% goal；
- 团队后来明确承认众筹预算没有充分覆盖税、VAT、许可证、工作室、设备和 rewards 等真实成本；
- 团队按约一年工期估算，而资金不到十二个月耗尽；
- 项目总开发超过四年，并在 Early Access 约三年；
- multiplayer 被明确删除以专注 single-player。

### ANALYTICALLY STRONG, STILL TESTING

- 缺少长项目经验与 runway 误判之间存在合理关联，但不能仅凭相关性写成唯一原因；
- Early Access 是项目从一次性 crowdfunding 向持续玩家融资/反馈系统过渡的一部分；
- 强烈的东欧文化/作者性同时构成表现差异化和市场识别面。

### NOT YET SUPPORTED

- Darkwood 的精确总成本与净利润；
- crowdfund 钱耗尽后每阶段具体现金来源占比；
- 所有设计删减都由现金压力导致；
- 波兰生活成本/政策是成功的决定性因素；
- piracy/torrent stunt 对销量的精确因果贡献。

## Transfer

- 众筹预算必须从 gross pledge 转为**净可用 runway**，逐项扣税、平台费、reward、设备、许可证、工作空间与宣传；
- 新团队的 schedule uncertainty 本身应进入预算，不能只给“理想工期”；
- paid contract work 可以作为原创项目前期桥梁，但会切碎开发时间；
- Early Access 可以接替一次性融资，前提是已有值得付费的 playable core；
- 对三人团队，删除 multiplayer 这类高长期成本表面，往往比“少做点内容”更有效。

## Non-transfer

- Darkwood 独特的美术/氛围与文化语汇；
- 2013–2017 survival-horror / Steam EA 市场窗口；
- 三位创始人长期承受低工资与四年开发压力的意愿；
- crowdfund backer 社区；
- 后续口碑与 right-tail attention。

## Next verification

1. 重建 Indiegogo gross → fees/taxes/rewards → actual runway 的更精确口径；
2. 核 2014–2017 EA 销量/价格变化与现金流；
3. credits audit：移植、发行、QA、翻译、外部服务；
4. 查三名创始人在 Darkwood 前的专业职业，以区分“没做过职业游戏”与“没有其他可迁移技能”；
5. 对照同期香港/波兰/东欧众筹失败项目，避免把最终成功反推为同一方法普遍可行。
