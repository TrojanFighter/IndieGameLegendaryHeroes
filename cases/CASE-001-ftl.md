# CASE-001 — FTL / Subset Games

- Status: ACTIVE — FIRST EVIDENCE PASS

- Related Claims: C001, C002, C003, C004, C006, C008, C010, C011

## Why this case

FTL 是一个极适合检验“独立开发者如何制造自己的生产条件”的案例，因为它同时拥有：

- 两位核心开发者的职业游戏开发前史；
- 离职后的个人储蓄 runway；
- 上海这一特殊开发地点；
- 小规模原型 → 竞赛验证 → 商业化 → Kickstarter 的阶段转换；
- 两人核心团队，但并非所有工作都由两人包办；
- 对表现形式和技术复杂度的主动约束；
- Kickstarter 后来极容易覆盖掉前史，形成“众筹神话”。

本案的关键不是证明“上海便宜所以 FTL 成功”，而是把每一个生产变量拆开。

## Provisional Timeline

### Before 2009 / education and hobby work

- Matthew Davis：Computer Science 教育背景，之后进入专业游戏开发。
- Justin Ma：艺术/设计倾向；其 2013 年采访回忆称，大学期间已经花大量空闲时间构思游戏并制作小型 prototype。

证据状态：SUPPORTED（P1 near-contemporary interview）。

### 2009 — 2K Shanghai

- Justin Ma 2009 年进入 2K Shanghai，职位方向为 game design。
- Matthew Davis 同样在 2K Shanghai 从事 programmer 工作。
- 两人在上海的大型传统工作室环境中相识。

证据状态：SUPPORTED。

### 2011 — prototype / transition out of studio work

- 多个来源一致表明 FTL 最初不是一个“我们辞职创业、目标成为下一家成功独游公司”的明确商业计划。
- 同期/回顾采访把它描述为 small project、hobby project、prototype，甚至是两份工作之间用来保持创作与扩充 résumé 的项目。
- 2012 同期采访明确说，两人此前在传统游戏工作室工作，并**攒够了一笔钱，足以给自己几个月时间一起做一个小项目**。

精确的离职/brainstorming/prototype 时间点在不同回顾材料里有压缩差异；暂不写成单一日期。

### 2011 — China Independent Games Festival

- FTL 成为 China Independent Games Festival 2011 finalist。
- 这一步发生在 Kickstarter 之前。
- 创作者后来的回忆强调，在 China IGF 接触到其他开发者、获得认真反馈，是“别人真的对这个 prototype 感兴趣”的重要信号之一。

证据状态：SUPPORTED。

### Early 2012 — wider validation before crowdfunding

- FTL 获得 IGF 2012 Excellence in Design 等 honorable mention。
- 开发者后来还提到早期媒体关注（如 PC Gamer）对他们“这东西可能真的有人要”的判断有重要作用。

因此不能把 Kickstarter 写成 FTL 的**第一次**市场验证。

### 2012-02-27 — 2012-04-01 — Kickstarter

Kickstarter 原始页面：

- location: Shanghai, China
- goal: **USD 10,000**
- pledged: **USD 200,542**
- backers: **9,818**
- duration: 33 days

这是一个约 **20 倍目标**的超额众筹。

重要边界：

> USD 200,542 是 pledged，不等于完整开发预算，也不等于净到账，更不等于 FTL 从第一天起只靠这笔钱生产。

### 2012 — release

- FTL 于 2012 年完成商业发行。
- 2013 年 GDC postmortem 已经能够完整回顾 concept → crowdfunding → release 的设计路径。

## Myth Audit

### Myth A — “两个人做了个游戏，上 Kickstarter，一夜成功”

**PARTIALLY REFUTED / compressed narrative.**

目前证据呈现的是至少五层前史：

1. 个人教育与 hobby prototype；
2. 2K Shanghai 职业开发经验；
3. 个人储蓄提供几个月初始 runway；
4. 小项目 / prototype；
5. China IGF、IGF、媒体和同行反馈；
6. 之后才是 Kickstarter 大幅超额。

Kickstarter 很重要，但它不是故事的起点。

### Myth B — “FTL 是纯粹的 two-man game”

**需要口径化。**

Justin Ma + Matthew Davis 是明确的 core team，但至少音乐应单独计入 Ben Prunty 等外部贡献。

所以正确表述应优先写：

> **two-person core development team**

而不是暗示所有创意/音频/QA/发行工作都由两个人完成。

### Myth C — “他们是一开始就决定赌上职业生涯创业”

**目前不支持。**

Davis 后来明确把原始目标描述成 hobby/prototype / résumé project，预期之一是之后寻找更有兴趣的 studio 工作。

这意味着：

> FTL 的早期 downside 不是“成功或破产”二选一；再就业本身就是一种隐形安全网。

这对 C001/C002/C006 很重要。

## Origin / Capability Stock

### Matthew Davis

当前可确认：

- Computer Science 教育；
- 2K Shanghai programmer；
- FTL 核心编程能力。

仍需核：

- 具体学校/毕业年份；
- 2K 参与项目；
- 在 FTL 前的个人 prototype / engine / networking / tooling 积累。

### Justin Ma

当前可确认：

- art/design 侧背景；
- 大学期间有 game idea / small prototype 前史；
- 2009 起 2K Shanghai game designer；
- FTL 中承担 art、大量 scripting，并与 Davis 共同设计。

### Complementarity

FTL 不是“两个全能独立开发者”的简单复制。

目前更合理的结构是：

> **programming-heavy founder + art/design/scripting-heavy founder + shared design + external specialist contributions**

这种互补组合可能比“人数=2”本身更值得研究。

## Runway

### VERIFIED / supported

- 初始阶段存在个人 savings-funded runway。
- 2012 同期采访表述为足以支持“a few months”做 small project。
- Kickstarter 后获得远高于目标的资金，使项目从已经获得外部验证的小项目进入更稳固的商业完成阶段。

### UNKNOWN

- 两人的具体储蓄额；
- 离职后每月 burn；
- 上海房租/生活成本；
- 是否有伴侣/家庭/其他收入支持；
- Kickstarter 扣费、税务和项目支出后的净可用资金；
- opportunity cost。

因此：

> “FTL 因上海生活成本低而成为可能”目前只能是 H，不是 Case fact。

## Production / Scope

2013 Game Developer 采访给出了非常具体的生产分工和工具线索：

- Ma：art + significant scripting；
- Davis：programming-heavy；
- design shared；
- Photoshop；
- Game Maker 被用于 animation / small feature test；
- Notepad++ scripting；
- SVN version control。

这说明 FTL 并没有追求“看起来像同年代大型太空游戏”的成本结构。

后来的制作史材料还指出，团队没有资源也没有意图去承担复杂 3D 表现，像素/2D 表现与 Ma 当时能覆盖的 art skill 更匹配。

### Provisional production interpretation — H

FTL 的关键创新可能不是“用两个人硬做出大团队太空游戏”，而是：

> **把“当星舰舰长”的幻想从 3D 驾驶/电影化表现，重新 representation 成房间、系统、船员、事件和资源决策。**

也就是把昂贵的“太空模拟器”问题，改成两人能力组合可以承受的“信息与系统模拟”问题。

这一解释需要继续由 GDC talk 和 prototype evolution 验证。

## Failure / Risk

目前最重要的风险事实不是某次具体濒死 crisis，而是：

- 原计划规模很小；
- 创作者对市场吸引力预期很低；
- 商业和公司运营经验不足；
- 只有在竞赛/媒体/玩家正反馈不断出现后才持续加码。

这与典型创业神话相反：

> 他们不是先建立一个巨大愿景再募集资源，而是让外部证据逐步提高承诺等级。

## Market Path

FTL 明显不是 `zero marketing / pure organic` 的简单案例。

目前已知路径至少包括：

1. competition submission；
2. China IGF 2011 finalist；
3. IGF recognition；
4. early enthusiast / media attention；
5. Kickstarter page + campaign传播；
6. release platforms / storefront exposure。

关键研究问题因此应从“有没有营销”改成：

> **在没有传统大预算广告的情况下，他们是如何一层一层取得可信度和市场接入的？**

## Environment / Luck

### Environment — supported

- 两人在上海的大型游戏 studio 相识并获得职业经验；
- Kickstarter campaign 公开 location 为 Shanghai, China；
- China IGF 为早期外部验证节点。

### Environment — still UNKNOWN

- 上海的实际成本优势；
- 中国居住/签证/税务等条件；
- 这些条件相对美国同类开发者能把 runway 延长多少。

### Luck / right-tail events

- Kickstarter 远超预期本身属于强烈 right-tail market response；
- 竞赛与媒体关注形成连续正反馈。

但“有运气”不能抹掉此前已经可玩的 prototype 和主动提交竞赛的行动。

## Provisional Verdict

FTL 第一轮证据目前最有价值的不是“贫穷独立开发者逆袭”，而是一个**分阶段承诺模型**：

> 职业能力资本 → 储蓄换取几个月自由时间 → 做小 prototype → 主动送入竞赛/同行环境 → 根据外部反馈增加承诺 → 众筹放大 runway 与需求验证 → 完成商业产品。

这对“制造生产条件”命题是有力案例，但还不能证明：

- 所有人都应该辞职；
- 大厂经验是必要条件；
- 上海低成本是核心因果；
- 众筹是主要成功原因；
- 小团队天然更创新。

## Transferable

第一轮可迁移候选：

- 在全面创业前先设计**有限 runway 的小实验**；
- 保留再就业/职业回撤路径，降低一次失败的永久成本；
- 核心团队按互补能力组合，而不是只追求少人数；
- 用 representation / scope 重切昂贵幻想；
- 在正式融资前主动把 prototype 送进高质量外部评审环境；
- 把每轮真实反馈作为是否继续加码的依据。

这些仍需跨 Case 验证，不能因 FTL 一例就变成普遍处方。

## Non-transfer / Context-specific

- 2011–2012 Kickstarter / indie boom 时机；
- 当时 roguelike-like / PC indie 市场竞争密度；
- China IGF / IGF 路径；
- 两人此前已经拥有的专业开发技能；
- Kickstarter 的异常超额反应。
