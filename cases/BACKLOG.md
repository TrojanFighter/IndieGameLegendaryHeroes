# Case Backlog — 历史语料与深度研究案例池

- Status: ACTIVE
- Last updated: 2026-10-03

本表用于回答一个治理问题：**我们过去已经用过哪些案例，它们当时被用来证明什么，现在有没有资格升级为正式 Case？**

它不是“想研究的名作列表”。来源分为：

- `PUBLIC-AUTHOR`：洪荒行者 / 游戏炼乳 / 公开长文中明确使用过；
- `CHAT-RESEARCH`：历史 ChatGPT 深研或跨案例推演中明确使用过；
- `EXTERNAL-VERIFIED`：已找到外部来源，可作为后续正式建档起点；
- `COMPARATOR`：主要用于反例、失败或结构对照；
- `CROSSOVER`：同时服务《独立游戏英雄传说》与《斯拉夫游戏英雄传说》等姊妹研究。

## 下一批优先正式化

### Minecraft / Markus Persson → Mojang
- Provenance: CHAT-RESEARCH
- Tests: C003 / C004 / C008 / C010 / C011
- Why: 2009 周末原型、TIGSource 社区、付费 Alpha、频繁更新与口碑扩散，适合研究“边做边卖”的市场—生产耦合。
- Next evidence: Notch contemporaneous blog/TIGSource archive、早期销量/Alpha 定价、Mojang 组建时间。

### Hollow Knight / Team Cherry
- Provenance: CHAT-RESEARCH
- Tests: C003 / C004 / C007 / C010 / C011
- Why: game jam → 三人核心 → Kickstarter → 超范围扩张；可与“严格 scope control 才能成功”的强命题形成反例。
- Next evidence: Team Cherry Kickstarter、Nintendo/开发者访谈、jam 原型资料。

### Early id Software / Commander Keen–Doom 前史
- Provenance: CHAT-RESEARCH
- Type: proto-indie / historical comparator
- Tests: C003 / C004 / C006 / C007 / C009 / C011
- Why: 小型高能力团队、shareware、工具与技术优势如何改变成本结构；需要避免用 1990s 分发条件直接类比现代 Steam。

### Among Us / Innersloth
- Provenance: CHAT-RESEARCH
- Tests: C002 / C003 / C010 / C011
- Why: 长期低可见度存活后因 streamer / social context 再爆发，适合研究“市场时点 ≠ 开发起点”。

### Roblox creator cluster
- Subjects: Cindering / Brian Wilson；alexnewtron / Alex Binello；Alex Balfanz 等
- Provenance: CHAT-RESEARCH
- Type: cluster case
- Tests: C003 / C006 / C008 / C011
- Why: 青少年 UGC 平台可能把教育、作品集、第一次就业、产品所有权与创业压缩在同一生产环境中。
- Boundary: 不能把平台头部幸存者反推为普通 Roblox 创作者的典型路径。

## Crossover / comparator

### Escape from Tarkov / Contract Wars / Hired Ops / Battlestate
- Provenance: PUBLIC-AUTHOR + CHAT-RESEARCH
- Type: CROSSOVER with 《斯拉夫游戏英雄传说》
- Current author-source hypothesis: 更低成本 F2P 项目先训练团队并形成资金/技术/题材积累，再进入更激进的 Tarkov。
- Required verification: AbsoluteSoft → Contract Wars/Hired Ops → Battlestate 的人员、资金、IP、代码/技术连续性；主播传播与发行选择。
- Do not promote author-source causal narrative to fact before primary verification.

### ZERO Sievert / Hell is Others / Arena Breakout
- Provenance: PUBLIC-AUTHOR
- Type: COMPARATOR / adaptation study
- Why: 用于研究 Tarkov 机制被 2D、PVE、F2P/mobile 等不同成本结构重新翻译时，哪些东西能迁、哪些会失真。
- Not automatically a “hero” Case.

### Into the Breach
- Provenance: PUBLIC-AUTHOR
- Current handling: 先作为 CASE-001 Subset Games 的第二阶段能力验证，不急于拆成独立 Case。
- Why: 用户公开知乎回答直接引用 Noclip《The Design of FTL & Into The Breach》，适合比较同一微型团队在成功后如何继续压缩问题空间。

## 纳入规则

新候选只有满足至少一项才正式编号：

1. 能直接检验一个核心 Claim；
2. 是已有 Claim 的强反例；
3. 能暴露“solo / 零营销 / 小预算 / 突然成功”等神话中的隐藏生产条件；
4. 作者历史公开观点曾把它当关键论据，需要重新核验；
5. 能解释一种不同于现有案例的生产结构。

单纯“好玩 / 有名”不足以进入本项目。
