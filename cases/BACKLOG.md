## 回收审计原则

“尽量推进所有旧案例”不等于把所有名字升级成正式英雄 Case。回收顺序固定为：
1. 先登记 provenance，防止旧论据继续散落；
2. 区分人物生产史、组织/失败 comparator、市场案例、玩法比较；
3. 有一手/高质量证据后再升级正式编号；
4. 作者过去公开使用过的关键论据优先做事实复核，即使最终结论会推翻旧说法。

## 纳入规则

新候选只有满足至少一项才正式编号：
1. 能直接检验一个核心 Claim；
2. 是已有 Claim 的强反例；
3. 能暴露“solo / 零营销 / 小预算 / 突然成功”等神话中的隐藏生产条件；
4. 作者历史公开观点曾把它当关键论据，需要重新核验；
5. 能解释一种不同于现有案例的生产结构。

单纯“好玩 / 有名 / 与 KWP 是竞品”不足以进入本项目。
