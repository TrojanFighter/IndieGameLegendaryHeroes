# CASE-050 — Nomada Studio / GRIS → Neva：不是让画家变程序员，而是让团队围绕作品重新组成

- Case ID: CASE-050
- Subject: Nomada Studio / Conrad Roset + Adrián Cuevas + Roger Mendoza / GRIS → Neva
- Period covered: pre-2017 professional prehistory → GRIS formation and production → 2018 release → Neva 2024
- Research status: RESEARCHING
- Corpus role: `CAPABILITY-COMPOSED / VISUAL-FIRST / AAA→AUTHORIAL / LONGITUDINAL`
- Related Claims: C003, C004, C006, C007, C010, C011, C013, C015
- Evidence Ledger: [来源账本](../evidence/CASE-050-nomada-gris-neva-source-ledger.md)

## 1. Why this case

GRIS 对“能力反向立项”提供了一种此前没有正式编码的结构。

不是：
> 一个 solo 作者先看自己的能力，再给自己定制项目。

也不是：
> 有钱以后雇人，把 capability set 扩大。

而是：

> **先出现一个强但不完整的 project thesis，再由互补能力的创始人围绕它组成团队。**

Conrad Roset 是职业插画/艺术家，没有游戏工业 network，也不会自己完成技术生产；
Adrián Cuevas 与 Roger Mendoza 则是多年 AAA programmer / technical developers，反过来缺少 Conrad 那种作者型视觉语言。

他们自己在 2019 访谈里把这个关系说得非常直接：
- Conrad 有 idea / concepts，但缺 programmatic capability；
- Roger / Adrián 有程序与 AAA production capability，也早就想做更小、更个人的东西，但缺艺术这块；
- GRIS 先出现，Nomada Studio 后成立。

因此本案暂定义第三种 formation mode：

> `CAPABILITY-COMPOSED`

即：
> project thesis 已有雏形 → 找到互补 cofounder capability → 共同组成 founding capability vector → 再围绕这个 vector 设计 production architecture。

## 2. Context–Situation–Action Snapshot

### Era / Production Regime

GRIS 形成于 2010s 中后期：

- Unity / commercial engine 已能承载小型 2D/2.5D 高艺术密度项目；
- digital distribution 与 boutique publisher 为欧洲小团队提供全球发行接口；
- 2010s indie audience 已能接受 Journey / Ori / Inside 等“视觉、情绪、低对白”的产品语言；
- 但高质量手绘 animation / art 依然是昂贵劳动，无法仅靠“有风格”自动完成。

### Actor Situation

**Conrad Roset**
- 多年 illustration / advertising / editorial / fashion / gallery art；
- 游戏是长期爱好；
- 最初有的是一个非常压缩的视觉 thesis：世界从黑白开始，玩家逐步把颜色带回来；
- 没有现成 game-development team。

**Adrián Cuevas + Roger Mendoza**
- 多年 AAA programming / technical-production experience；
- 公开履历涉及 Ubisoft / Square Enix 体系及 Assassin's Creed、Hitman、Far Cry 等；
- 有技术实现和大型生产经验；
- 自己也想做更小、更不同的作品。

### Action / Maneuver

不是“Conrad 学会做完整游戏”，而是：

`visual-author capability + technical/AAA capability → founding-team composition`

2019 三位创始人的直接访谈明确说：
> GRIS came first; the studio was formed around the project.

这是本案最重要的因果方向。

### Anachronism Check

- 2016–2018 的 boutique-publisher / Gamescom demo 路径不能直接当作 2026 固定打法；
- 当时高质量 2D hand-drawn presentation、digital-store attention 与 labor/tool cost 都处于特定历史窗口；
- 可迁移的是 `project thesis → complementary founder composition → demo → selective capability expansion`，不是具体发行渠道；
- 不能从 GRIS 成功推出“visual artist + AAA programmer”通常会成功，也不能把 cofounder composition 当作无成本招聘。
## 3. Why 2D / Side-Scroller Was Not Neutral

2024 Nomada 直接访谈进一步把 capability → product form 说得更清楚：

> 他们从 2D 开始，是因为那正是 Conrad 的背景。

同时 side-scroller 提供：
- 更强 pacing control；
- 更容易控制玩家视线和情绪节奏；
- 更适合让 hand-crafted visual composition 成为主体验。

因此：
> 2D 不是“独立游戏预算不够所以降级”。

它同时是：
- artist capability fit；
- narrative control；
- production cost structure；
- player-facing identity。

这非常接近 C015 的 Strength Loading。

## 4. Production Architecture

公开材料显示 GRIS 不是“三个人做完”。

已知：
- 三位创始人承担 authorial/technical core；
- 团队随后扩张；
- 2019 Roset 一处访谈称 studio/team 在不同阶段可到约 17；
- 另一处 2018 访谈称一个美国 partnership 让他们能融资并雇到接近 26 人；
- 采访还称约 80% studio labor 与 art / animation 有关。

这些数字口径显然不是同一统计边界。

因此当前只能写：

> **GRIS 的 core founding team 很小，但 production perimeter 明显更大，而且高度偏向 art / animation。**

禁止写：
> “三个人做出了 GRIS。”

## 5. Capital Expansion After Capability Composition

Roset 在 2018 采访中明确说：
- 最初需要找团队和融资；
- 外部 partnership 让他们能扩大 production capacity。

另外 2018 自述：
- 三位创始人先离开工作；
- 做 demo；
- 再去 Gamescom 向 publishers 展示。

因此顺序接近：

`idea → complementary founders → demo → publisher/financing interface → team expansion`

这与 Outer Wilds 不同：
- Outer Wilds 是 student project → institutional validation → multi-layer external capital；
- GRIS 是 authorial visual thesis → complementary founders → publisher-facing demo → production expansion。

## 6. C013 — AAA Capability Transfer Without AAA Objective Function

Adrián / Roger 的 AAA 前史并没有把 GRIS 变成“小型 Assassin's Creed”。

真正迁移的是：
- engineering；
- production literacy；
- shipped-game reliability；
- technical translation；
- platform/optimization competence。

被主动重写的是：
- combat dependence；
- difficulty assumptions；
- content-density logic；
- visual hierarchy；
- narrative delivery。

这使 GRIS 成为 C013 很好的正例：

> **商业/AAA capability 可以迁移，objective function 不必一起迁移。**

## 7. Visual Author Capability Becomes Product Architecture

从一开始：
- colour progression 既是 visual system，也是 mechanic / chapter language；
- storyboard / frame-by-frame art 进入 level/narrative construction；
- 大量 labor 被集中到 art/animation；
- dialogue 被弱化；
- player failure pressure 被压低；
- visual coherence 本身承担 market legibility。

这不是“请一个概念美术给普通 platformer 画皮”。

而是：

> **visual author capability 被放到 product architecture 的最上游。**

## 8. Longitudinal Check — Neva

Neva 的价值在于它不是简单重复 GRIS。

公开 2024 访谈显示：
- studio 延续无对白 / 强视觉叙事；
- 仍然由 Roset visual authorship + technical team 协作；
- 但加入 combat；
- team 讨论过 3D，仍明确知道自己为什么长期使用 2D；
- 对 combat 的解释之一，是让从 GRIS 入门的玩家接触更经典的游戏 paradigms。

这意味着 Nomada 并非只是“画风工作室”。

更像：
> **先固定 authorial capability core，再逐步扩大 mechanics vocabulary。**

## 9. C015 Extension — CAPABILITY-COMPOSED

目前 C015 至少有三种不同移动方式：

1. `CAPABILITY-SHAPED`
   - 改项目，让它适合已有的人。
2. `CAPABILITY-COMPOSED`
   - 项目 thesis 先出现，再由互补 cofounders 组成 founding capability set。
3. `CAPABILITY-EXPANDED`
   - 用资本 / hiring / specialist periphery 扩 capability supply。

GRIS 最接近第 2 种。

它的治理成本也不同：
- hiring 用 cash；
- publisher capital 可能带 contract / recoup；
- cofounder composition 通常用 equity / control / authorship sharing。

因此“补能力”不能只问多少钱。

还要问：

> **你是雇这个人，还是让这个人成为共同作者？**

## 10. Market / Publisher Boundary

Devolver Digital 是已知 publisher。

但当前公开来源还不足以写清：
- advance amount；
- recoup；
- IP ownership；
- milestone approval；
- marketing spend；
- exact hiring financed by publisher vs other capital。

所以不能把“partnership financed team expansion”直接等同于某一具体合同条款。

## 11. Temporal Validity

### Durable
- complementarity can be designed into founding team；
- visual author capability can become mechanics/representation, not decoration；
- AAA capability transfer can be separated from AAA objective function；
- project-first studio formation is possible。

### Historical / Conditional
- 2016–2018 boutique-publisher market；
- Gamescom demo→publisher pipeline；
- exact art-heavy cost structure before current AI/tooling；
- 2018 digital-store discoverability.

## 12. Verdict

GRIS 的真正“能力模型”不是：

> 伟大画家学会了做游戏。

而是：

> **一个画家知道自己要表达什么；两个程序员知道如何把它变成可运行的工业对象；他们没有要求其中任何一方先变成六边形战士，而是围绕互补能力共同发明了公司。**

这使 Nomada 成为“能力—项目适配”里非常重要的一类：

> **有时不是给现有团队找项目，而是给一个值得存在的项目找共同作者。**
