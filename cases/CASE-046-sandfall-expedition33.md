# CASE-046 — Sandfall Interactive / Clair Obscur: Expedition 33

- Case ID: CASE-046
- Subject: Sandfall Interactive / Clair Obscur: Expedition 33
- Period covered: Ubisoft prehistory → studio founded 2020 → release 2025 → post-release 2026
- Research status: RESEARCHING
- Corpus role: AAA→AUTHORIAL STUDIO / SMALL-CORE + INDUSTRIAL-PERIPHERY COMPARATOR
- Related Claims: C003, C004, C006, C007, C011, C013
- Evidence Ledger: [来源账本](../evidence/CASE-046-sandfall-expedition33-source-ledger.md)

## Why this case

Expedition 33 很容易被压成一句：
> “不到 30 人做出 AAA 级 RPG。”

这个叙事对研究几乎有害。

更精确的问题是：

> **一个小 core 如何把 AAA 工作经验、现成引擎、commercial tools、publisher、外部 production partners 与强 authorial thesis 组合成远大于 core headcount 的 production perimeter？**

## 2. Context–Situation–Action Snapshot

### Era / Production Regime

核心生产发生在 2020–2025：

- Unreal Engine 4→5、Blueprint、MetaHuman、Nanite、Lumen、World Partition 等成熟工具显著降低部分高规格 3D production obligation；
- 专业 performance capture、voice、localization、QA、external production 可以通过全球供应链外围化；
- publisher / platform / contemporary premium-console-PC market 仍承担高昂的 distribution、certification 与 market-access 工作；
- “core team <30”因此不能和 1990s/2010s 的 30 人团队做裸 headcount 比较。

### Actor Situation

Sandfall 的 founders 并不是从零进入高规格 RPG：

- Guillaume Broche 有 4+ 年 Ubisoft 经历；
- cofounding team 中存在其他 Ubisoft 开发者；
- 2021 项目早期已有约 8 人 core；
- 但离开 AAA 后，原组织里“每个专业问题都有专门专家”的结构消失；
- 小团队必须重新学习跨职能工作，并决定哪些问题由工具或外部伙伴承担。

### Action / Maneuver

| 生产问题 | Sandfall 的动作 | 被压缩/转移的成本 | Evidence |
|---|---|---|---|
| realistic character / animation | Character Creator / ActorCore / Rokoko 等现成工具 | 部分角色/动画 pipeline | E001 |
| gameplay logic | UE Blueprint | 降低纯 programmer bottleneck，扩大跨 discipline ownership | E002/E003 |
| cinematic collaboration | Sequencer | 减少跨工具/跨部门同步摩擦 | E003 |
| environment scale | Nanite / World Partition | 手工 LOD 与 scene contention | E002/E003 |
| high-end production completion | publisher + voice/performance/QA/external partners | 大量非 core labor | E004–E007 |
| product thesis | early combat prototype | 在团队继续扩大前验证 turn-based + real-time defense 核心 | E002 |

### Anachronism Check

Expedition 33 是 **2020s tool regime** 的案例。

它不能证明：
- 30 人今天等于过去 100–300 人；
- UE5 自动让任何小团队做 AAA；
- contractor / publisher / platform labor 可以忽略。

可迁移机制是：
> **small core 通过成熟工具与 industrial periphery 保留更高 authorial decision density；完整成本必须按 production perimeter 而不是公司 payroll 统计。**

## Founder / Team Prehistory

2021 年开发早期直接采访已经记录：

- Guillaume Broche 在 Ubisoft 工作超过 4 年；
- 与另一位 Ubisoft developer 一起创办 Sandfall；
- 当时团队约 8 人，计划扩到 15；
- 明确知道从 AAA 到 indie 后失去“每个领域都有超专业人员”的舒适；
- Broche 自己一度承担 character creation 等非原 specialty；
- 团队利用 Character Creator / ActorCore / Rokoko 等现成工具压缩 realistic-character / animation cost。

这不是成功后的神话，而是项目仍叫 Project W 时的同期证据。

## Core Team Growth

2025 Unreal 官方采访给出：

- core team <30；
- Montpellier 约 25，Paris 约 5；
- 项目历时约 5 年；
- UE5 的 Blueprint、MetaHuman、Nanite、Lumen、World Partition 等被明确视为小团队 production leverage；
- early combat prototype 已经测试 real-time offense/defense + turn-based structure。

2025 后续访谈进一步说明：
- Blueprint 让不同 discipline 更直接参与逻辑；
- Sequencer 让 design/VFX/sound 同步；
- environment team 只有约 3–5 人时，World Partition 降低协作 contention；
- Nanite 删除手工 LOD obligation。

这正是 C004/C007 的现代高端版本：
> 不只是砍内容，而是用 toolchain 删除一批传统 AAA production obligations。

## The “30-person game” Myth

MobyGames 当前 credits 记录约：

- 438 people；
- 429 professional roles；
- 530 credits。

其中包含：
- Sandfall internal team；
- voice production；
- performance capture；
- production partners；
- playtesting/mock reviews；
- localization / other specialist labor。

因此严禁写：
> “30 个人完成了 Expedition 33。”

更准确：
> **<30 core team + substantial industrial periphery。**

这和 Manor Lords / RCT / The First Tree 的研究结构相同，只是 scale 大得多。

## Publisher Boundary

Sandfall 官方页明确：
- Expedition 33 由 Kepler Interactive 发行。

但当前仍需核：
- funding amount；
- recoup；
- IP / control；
- Kepler co-ownership relationship；
- marketing / platform deals / Game Pass economics。

在这些未核前，不能把“independent studio”自动等同完全自筹 / 完全独立资本结构。

## AAA Capability Transfer

本案对 C013 很重要，因为它同时显示两面：

### 正迁移
- production vocabulary；
- pipeline thinking；
- quality bar；
- Unreal / AAA tooling fluency；
- cross-discipline collaboration；
- prototype discipline。

### 必须重新学习
2021 Broche 明确说小团队失去超细 specialization，成员必须学习大量非原岗位工作。

因此：
> **AAA experience transfers capability, not the old organization itself.**

## Current Verdict

### 强支持
- founders 有 Ubisoft AAA 前史；
- studio 2020 成立；
- early 8-person state 有同期证据；
- core team later <30；
- UE5/tooling 被直接用于删除/压缩传统 production work；
- complete product perimeter 远大于 core team；
- Kepler 是 publisher。

### 仍 UNKNOWN
- total budget；
- founder personal prototype chronology；
- publisher financing terms；
- external partner cost；
- internal vs external person-month share；
- exact “after-work prototype before studio” timeline。

## Transfer

- small core + industrial periphery = DURABLE organizational pattern；
- modern engine/tool leverage = CURRENT but tool-specific；
- AAA training → indie capability transfer = CONDITIONAL, mediated by decision rights and willingness to de-specialize；
- “30-person AAA” = misleading shorthand。
