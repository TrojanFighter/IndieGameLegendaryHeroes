# CASE-023 — despelote / Julián Cordero + Sebastián Valbuena

- Case ID: CASE-023
- Subject: despelote / Julián Cordero + Sebastián Valbuena
- Period covered: 2018–2025
- Research status: RESEARCHING
- Last verified: 2026-10-04
- Related Claims: C002, C004, C010, C011

## Why this case

`despelote` 的价值不在于证明“grant 能做出好游戏”，而在于它提供了一条少见、可逐段核验的**资金阶梯**：

> 学生 thesis / 小规模原型 → NYU Incubator 的时间、行业接触与 advisor network → 资金耗尽 / freelance 生存 → Microsoft DAP grant 恢复全职 → vertical slice → publisher pitch → Panic 融资与发行外围 → 完成七年项目。

开发者本人明确说，DAP grant 来在开发资金耗尽、团队已经需要接 freelance 付账单的节点；grant 让他们重新全职，并完成最终成功的 publisher-pitch vertical slice。因此本案允许把“non-dilutive funding 的价值”从抽象补助金额，推进到**它购买了哪一段生产状态、制造了什么下一阶段资产**。

## 1. Myth

最容易出现的简化叙事有两种：

1. **“两个厄瓜多尔年轻人做了七年个人作品，然后被 Panic 看中。”**
2. **“拿到政府 / Microsoft grant，所以把游戏做完。”**

两者都把真实资金链压扁了。

实际过程更接近多次 runway bridge：早期教育/孵化环境帮助原型获得行业接触；项目数次获得外部小额或阶段性支持；钱仍然会用完；团队需要 freelance；随后新的 grant 购买一段全职时间，这段时间不是直接“完成游戏”，而是生产一个可融资的 vertical slice；Panic 才成为把项目真正推进到长期全职制作与多平台发行的关键下一层。

## 2. Origin

### Julián Cordero

- 出生、成长于 Quito，18 岁后前往纽约学习 game design；
- NYU Game Center BFA ’19；
- `despelote` 起源于其大学 thesis / capstone 时期；
- 在此之前，他已有学生作品 `levedad`，并获得 2019 IGF Best Student Game finalist / Nuovo honorable mention，说明正式做 `despelote` 时并非第一次完成和公开展示交互作品。

### Sebastián Valbuena

- Cordero 在 Quito 成长时期就熟悉 Valbuena 的视觉与音乐创作；
- Valbuena 加入 `despelote` 时没有 videogame production 经验，但已有动画、插画和音乐能力；
- 因此这不是“两名相同技能的游戏开发者”，而是**已有游戏设计/编程训练 + 已有独立视觉/音乐作者能力**的互补组合。

## 3. Capability

本案的 capability formation 有三层：

1. **学校与旧作**：Cordero 在 NYU 的游戏设计教育、prototype / thesis 训练与 `levedad` 前作；
2. **互补作者能力**：Valbuena 的 2D animation / illustration / music 并非游戏行业履历，却成为项目最难替代的视觉与声音 identity；
3. **外围专业能力逐步加入**：Ian Berman（sound design）、Gabe Cuzzillo（production / level design）、Niall Tessier-Lavigne（additional design/programming）等把“两人核心”包围在更宽的专业 contributor network 中。

Unity 对开发过程的回顾还显示：团队没有简单追求传统 3D realism，而是把 Quito 实地照片/扫描、Valbuena 的 2D 画风和 shader 结合，形成与小团队能力结构匹配的表现方案。

## 4. Runway

| 阶段 | Runway / support | 已知口径 | 证据 | 当前判断 |
|---|---|---|---|---|
| 学生 / thesis 阶段 | NYU 教育环境 | tuition / personal living support 未核 | E002, E005 | 能力与初始制作环境，不视为“免费开发” |
| 2019 | NYU Game Center Incubator | program 明确提供 support / industry advisors；当届具体现金口径待核 | E002 | 时间、行业接触、pitch/商业能力入口 |
| 2021 | Ecuador IFCI “Producción de Videojuegos” | 官方：每个获奖项目 USD 10,000；决议列 Julián Cordero Dávalos / Despelote 为受益项目 | E003 | 小额 non-dilutive runway |
| DAP 阶段 | ID@Xbox Developer Acceleration Program | 金额未公开 | E001 | 资金耗尽后的关键 bridge；恢复 full-time，并制作 publisher-pitch vertical slice |
| Panic 阶段 | publisher financing + publishing perimeter | 合同金额/recoup/分成未公开 | E004, E006 | 使团队进入稳定 full-time，并承担 marketing / ports / distribution 外围 |

Sebastián Valbuena 2026 年回顾说，厄瓜多尔公共资金约 USD 10,000，甚至不到总投入的 10%；这与官方 IFCI 每项目 10,000 美元额度吻合。但**不能据此精确反推总预算**，因为“不到 10%”只是范围性自述，且总投入可能包含 publisher spend、labor valuation、ports 等不同口径。

## 5. Production

“Julián + Sebastián 两个人做了游戏”只能描述作者核心，不能描述完整 production boundary。

官方 presskit / credits 至少明确：

- Julián Cordero — design / programming；
- Sebastián Valbuena — art / music；
- Gabe Cuzzillo — production / therapy / level design；
- Ian Berman — sound design；
- Niall Tessier-Lavigne — additional design / programming；
- 还有 additional programming、casting、Quito production、recording、3D cleanup、localization / QA / ports / publisher staff 等更外围角色。

因此本案应描述为：**双作者核心 + 数个关键专业协作者 + publisher / porting / marketing perimeter**。

## 6. Scope

### 原本预计约一年，最终约七年

Cordero 回顾说项目 2018 年开始，早期预期不会超过一年；最终开发约七年，其中大约后面三年更接近 full-time。

这里不是简单的“scope creep = 多做内容”。团队很早就找到：

- 球的 physical interaction；
- Quito 的视觉语言；
- 人物与空间 atmosphere。

真正长期未解决的是**“这到底如何成为一个完整游戏”**：叙事弧、世界如何推进、玩家自由游荡和结构如何共存。Cordero 说理解 narrative / arc / mechanics-world integration 花了大约五年。

Unity 的 postmortem 给出一个具体结构突破：传统 objective / task list 破坏他们想要的童年自由感，后来用手表 / 时间推进规则让世界无论玩家在哪里都会继续，这才让 playtest 出现明显“before / after”。

所以七年不是七年线性 content production，而是大量时间花在**找到正确的产品问题定义**。

## 7. Failure / Near-death points

### 资金耗尽

最明确的 near-death point 来自 Cordero 自述：开发资金用完后，他们必须接 freelance 来支付账单，意味着项目事实上从 full-time 状态退回到碎片化制作。

Microsoft DAP grant 的作用因此非常具体：

> 不是“让他们富起来”，而是把项目从 freelance-survival 状态重新切回 full-time search / production 状态。

### 早期正反馈反而诱发过度野心

Cordero 也指出，早期 prototype 很快得到积极反馈，使团队在并不知道完整制作代价时变得非常 ambitious。换言之，早期 validation 既是资产，也可能让团队错误估计 scope。

### 设计反复

- 一度设想几乎没有 dialogue；
- 尝试过 documentary interviews；
- 后来才找到环境式、重叠式生活对话；
- narrative structure 长期不稳定。

这使本案成为一个反例：**prototype hook 很强，并不代表“剩下只是 execution”。**

## 8. Market

市场接入从很早就嵌进制作过程：

- NYU student showcases / IGF / Game Devs of Color 等提供早期公开展示；
- 2019 NYU Incubator 提供 industry advisor network；
- Cordero 明确说，正是在 Incubator 认识当时 ID@Xbox 的 Sarah Conde，后者告知团队 DAP；
- DAP grant 被用于制作 publisher pitch vertical slice；
- Panic 表示从第一次 pitch 就被项目吸引，之后成为正式 publisher；
- Panic 后续承担/协助宣传、marketing、platform ports 与多平台发行；
- 2023 Tribeca、Day of the Devs 等进一步形成 release 前市场接入；
- 2025 正式多平台发行。

因此“Panic 偶然发现了一个成品”是不准确的。更像是：**学校/孵化器网络 → grant relationship → pitch asset → publisher → festival / platform release** 的连续 market-production pipeline。

## 9. Environment

本案同时跨两个环境：Quito 的文化/生产来源与 New York 的教育/产业接入。

### 有利条件

- NYU Game Center 提供训练、同行、展示、Incubator 与 industry advisors；
- Microsoft DAP 为 underrepresented / emerging-market creators 提供 non-dilutive support；
- Ecuador IFCI 提供本国公共文化资金；
- Panic 提供成熟国际发行外围；
- Unity / photogrammetry / shader workflow 让小团队把高度具体的 Quito 记忆转换成可承担的 production style。

### 约束

- Valbuena 认为 Ecuador 本土 game industry 几乎不存在，难以依赖成熟本地产业链；
- 跨国协作与实地采集增加协调成本；
- 小额 grant 可以桥接阶段，却不能替代长期完整预算；
- 项目对具体文化的坚持反而同时构成融资风险与 differentiation asset。

## 10. Luck

幸运因素包括：

- prototype 很早得到强反馈；
- 在 Incubator 恰好遇到能把项目导向 DAP 的行业 advisor；
- grant 在资金耗尽节点出现；
- publisher 对高度地方性的作品有兴趣；
- 2020s publisher / platform 生态对 underrepresented / culturally specific work 存在明确支持窗口。

但这些并非纯随机“中奖”：团队已经有可玩的 prototype、公开展示历史和足以让 funding / publisher 判断的具体作品资产。

## 11. Verdict

### STRONGLY SUPPORTED

- `despelote` 不是“一次融资完成开发”，而是多阶段 runway bridge；
- DAP grant 的直接作用是把开发者从 freelance survival 拉回 full-time，并购买制作 publisher-pitch vertical slice 的时间；
- 这个 vertical slice 后续 publisher pitch 成功，因此 grant → publisher 之间存在可观察的中间生产机制；
- Panic 是完成长期 production 与国际发行的重要条件，而非仅在成品完成后负责宣传；
- “七年开发”里包含长期 design search，不是七年稳定执行既定 specification。

### SUPPORTED WITH BOUNDARY

- NYU Incubator 的 advisor network 对后续 DAP access 有直接连接；
- Ecuador IFCI USD 10,000 是真实 non-dilutive support，但只是整个资金结构的一小部分；
- highly specific cultural identity 似乎帮助 pitch / funding differentiation，但无法从单案证明“越地方越容易融资”。

### UNKNOWN

- Microsoft DAP grant 精确金额与支付时间；
- Panic 签约日期、advance、milestone、recoup、revenue share；
- NYU Incubator 2019 对本队的精确现金 stipend；
- 七年期间个人储蓄、家庭支持与 freelance 收入；
- 总 budget 的统一会计口径。

## 12. Transfer

本案可迁移的不是“去申请某个 grant”，而是一条融资资产链：

1. **让每一笔小钱生产下一阶段可融资资产**：DAP grant 最重要的产物不是最终游戏，而是能通过 publisher due diligence 的 vertical slice；
2. **把 incubator 当 network infrastructure，不只当现金来源**：advisor introduction 可能比 stipend 本身更具长期价值；
3. **资金耗尽时降低 burn，而不是把项目死亡和兼职混为一谈**：freelance 是 bridge，但会降低项目 search bandwidth；
4. **pitch 前先把作品的不可替代性做成可体验证据**：Panic 的公开说法强调第一次 pitch 就能感受到项目的具体时间、地点与 universal resonance；
5. **publisher 的价值应按外围职能计价**：finance、marketing、ports、platform relations、distribution 都是 production capacity，不只是 logo 和曝光；
6. **强 prototype ≠ execution solved**：最难的问题可能是结构、叙事、scope convergence，而不是核心 interaction。

## 13. Non-transfer

- NYU 教育/Incubator 网络是具体制度资产，不是任何团队自动拥有；
- DAP 有 eligibility / cohort / platform policy，不是无限可复制资金；
- Panic 的审美、portfolio strategy 与当期资金能力无法复制；
- `despelote` 的文化差异化与作者生活史是高度特异资产；
- 七年开发本身不是成功策略，长期未收敛同样可以导致项目死亡；
- grant→publisher 的这条成功链存在幸存者偏差，需要补“拿 grant 但没签 publisher / 没完成”的失败对照。
