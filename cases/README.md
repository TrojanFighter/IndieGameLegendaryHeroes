## 规则

- 每个案例先建立事实时间线，再写判断。
- 所有“研究目的”都是待检验问题，不是当前结论。
- 案例文件必须回链 Claim 与 Evidence；不得成为孤立传记。
- 状态、关系、证据成熟度、解释重要性与叙事价值的机器索引见 [`../metadata/cases.json`](../metadata/cases.json)。
- 本表是人读索引；CI 会检查它与 metadata 状态一致。
