# CASE-036 — Manor Lords / Slavic Magic：“单人开发”是真的，但不是“一个人完成整条生产链”

- Case ID: CASE-036
- Subject: Greg Styczeń / Slavic Magic / Manor Lords
- Period covered: c. 2017–2026
- Research status: RESEARCHING
- Corpus role: **SOLO-CORE BOUNDARY / GRANT-TO-OUTSOURCING / PUBLISHER MARKET-ACCESS / POLISH INDIE**
- Evidence Ledger: [`../evidence/CASE-036-manor-lords-source-ledger.md`](../evidence/CASE-036-manor-lords-source-ledger.md)

## Why this case

Manor Lords 是研究 `solo dev` 最好的当代压力样本之一，因为两个看似冲突的事实同时成立：

1. Greg Styczeń 长期确实是 Slavic Magic 唯一的 permanent studio member，并承担核心产品作者角色；
2. 游戏并不是由一个人独立完成美术、动捕整理、QA、资产、发行、市场、分发和所有专业劳动。

更准确的生产结构是：

```text
长期 solo core / authorial control
+ video freelance day job
→ Patreon + Epic MegaGrant
→ full-time runway + specialist outsourcing
→ Hooded Horse marketing/distribution/advice
→ QLOC QA + purchased assets + freelancers
→ Early Access success
→ post-launch team expansion
```

这不是“拆穿 solo 神话”后否定 Greg 的作者性，而是把**核心作者规模**与**完整 production perimeter**分开。

## Myth

### Myth A — Manor Lords 是 Greg 一个人七年包办出来的

不准确。Greg 本人在 Unreal Engine 访谈中说，早期确实是业余/兼职个人项目，因为白天靠视频自由职业接活，没有条件雇人；但 Patreon 和 Epic MegaGrant 之后开始把工作外包给专业人士。官方 FAQ 进一步写明：他是唯一 permanent studio member，但越来越多与 freelancers 合作，也购买资产、使用 QLOC 专业 QA，并由 Hooded Horse 负责 marketing/distribution。

### Myth B — 既然有外包和发行商，就不能算 solo dev

同样错误。现有证据支持 Greg 长期拥有异常集中的产品定义、工程与设计责任。`solo core` 是有意义的组织事实，只是不能扩写成 `total production = one person`。

### Myth C — Publisher 是成功后才来“收割”的外围

现有材料不支持。Greg 说最初对 publisher 没兴趣，但 Hooded Horse 的 Tim Bender 持续帮助解决问题、提供建议，后来他认为合作确实增加了 wishlists。发行商的价值包括媒体触达、商店标签、合作方沟通、distribution 等大量机会成本很高的工作。

## Origin / Capability

Greg 公开说自己从小学时期用 RPG Maker 2000 开始做游戏，后来经历 Flash、Dark Basic，再进入 UE4。Manor Lords 是第一款他称得上“serious project”的作品，但不是第一次碰游戏制作。

这对 C003/C011 很关键：

> **第一款正式商业大作，不等于能力资本从项目立项那天才开始。**

此外，他没有选择自研引擎。Greg 明确把 Unreal 的现成工具、profiling、LOD、Material Editor、CSV Data Tables、SDK/兼容性处理视为单人能承担项目的重要条件，并提醒不要为了技术完美不断自建组件。

## Runway

可见 runway 阶段至少包括：

- 视频自由职业收入 → 允许 hobby/part-time 长期开发；
- Patreon → 社区型持续支持；
- Epic MegaGrant → 允许停止接日常委托、转全职并购买更多专业外围；
- Early Access 销售 → 后续扩团队与持续开发。

MegaGrant 的关键不应写成“给钱做完游戏”，而应写成：

> **购买开发者自己的 full-time 时间，同时购买原本无法承担的专业外围。**

## Production / Contributor Boundary

官方 FAQ 的表述非常适合作为本项目的 solo 定义样板：

- only permanent studio member：Greg；
- increasing cooperation with freelancers；
- purchased assets / Megascans；
- QLOC professional QA；
- Hooded Horse marketing and distribution。

因此本案建议统一使用：`solo core / single permanent studio member`，避免写“one-man production”。

2025 年一周年更新又明确说明项目已扩张到地图设计、程序、AI、2D、3D、game design 等多名人员，证明 `solo` 不是永恒身份，而是某一生产阶段。

## Scope / Problem Redefinition

Manor Lords 不是典型“砍成极简游戏”的 C007 样本，因此本案不把低 scope 当主要解释。更重要的是**复杂度所有权重写**：

- 核心设计/代码与长期一致性留给作者；
- 通用引擎承担底层技术栈；
- assets / scans 避免全部从零生产；
- specialist art / mocap cleanup 等外包；
- QA 外移；
- marketing/distribution 外移。

这是 `organizational compression`，不是简单 `content compression`。

## Market Access

Manor Lords 说明“大量 wishlists”也有生产史。

Game Developer 引述 Hooded Horse 数据：Steam wishlist 超过 3.2m；Next Fest demo 在活动期增加约 500k；EA 前两周 press/influencer coverage 又带来约 800k。两百万销量发生在 EA 后不到三周，但发行方 CEO 也明确表示这种规模远超他们敢预期的程度。

因此：

- publisher/creator/press/demo 是可观察的 market-access machinery；
- 但最终 right-tail 爆发仍不能被写成可预测公式。

## Preliminary Verdict

### STRONGLY SUPPORTED

- Greg 长期是唯一 permanent Slavic Magic studio member；
- Manor Lords 早期是 hobby/part-time project，Greg 靠视频自由职业维持；
- Patreon + Epic MegaGrant 后开始全职并扩大 outsourcing；
- freelancers、purchased assets、QLOC QA、Hooded Horse marketing/distribution 都属于真实 production perimeter；
- Hooded Horse 介入并非只有发售渠道，Greg 明确认为其帮助增加 wishlists；
- 项目成功后 permanent production structure 已进一步扩张。

### ANALYTICALLY STRONG, STILL TESTING

- Manor Lords 的“solo”优势来自**高作者一致性 + 对外围劳动的选择性外部化**；
- non-dilutive grant 在此的高杠杆用途是把兼职作者转成全职作者，并购买专业外围；
- publisher 最大价值之一是保护核心开发者免受高机会成本的 market-access labor 吞噬。

### NOT YET SUPPORTED

- 精确总预算与 Greg 的累计个人投入；
- Patreon / MegaGrant / publisher 各自净资金规模；
- publisher 对销量的精确 causal share；
- “solo core”天然比普通小团队更有效；
- 3.2m wishlists 的增长完全可复制。

## Transfer

- 使用 `core team` 与 `production perimeter` 两层人数口径；
- grant 优先购买最稀缺的 full-time focus 与专业短板，而不是立刻膨胀 permanent payroll；
- 对核心作者项目，外包不必意味着失去产品控制；
- 发行商价值应拆成具体劳动：媒体 outreach、store optimization、partner calls、distribution、QA/porting coordination 等；
- 成功后扩团队也应围绕已出现的 throughput bottleneck，而不是提前工业化。

## Non-transfer

- Greg 多年单人积累的 Unreal 熟练度；
- Manor Lords 题材/视觉本身的巨大市场吸引力；
- Epic MegaGrant 与 Patreon 的具体获得条件；
- Hooded Horse 的策略游戏 audience / creator / press network；
- 大规模 wishlist right-tail；
- 七年量级长期坚持的个人机会成本。
