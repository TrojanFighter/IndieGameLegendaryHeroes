## 一句话定义

这不是“俄罗斯独立游戏史”，也不是泛泛的“东欧游戏史”。

它研究的是：

> **为什么以俄罗斯、乌克兰、白俄罗斯为核心的斯拉夫游戏生产传统中，反复出现商业级、工程规模并不小，却在玩法、系统、题材、审美或生产方式上激进得不亚于独立游戏的作品？这些作品背后的开发者、工作室与生产条件是怎样形成的？**

因此研究对象不以“是否独立”筛选，而以：

- 是否重新定义了品类问题；
- 是否建立了异常的技术 / 组织 / 商业解法；
- 是否形成了可追踪的生产谱系；
- 是否实质改变了后来者的市场想象。

## 为什么从“俄罗斯”改成“斯拉夫”

俄罗斯仍将占据全书样本的绝对主导地位，但只用“俄罗斯”会系统性遮蔽乌克兰与白俄罗斯两条不可替代的产业谱系：

- **乌克兰：GSC Game World / S.T.A.L.K.E.R. → 4A Games / Metro → Vostok 等人才与技术裂变**；
- **白俄罗斯：Wargaming / World of Tanks → World of 系列与大规模战争网游商业化**。

同时，书名使用“斯拉夫”不意味着自动把整个斯拉夫世界全部纳入同等权重。

### 当前核心范围

- **核心主轴：俄罗斯、乌克兰、白俄罗斯**；
- 波兰、捷克、斯洛伐克、巴尔干等其他斯拉夫国家原则上作为比较组进入；
- 只有在某条产品 / 人才 / 技术 / 资本谱系与主轴直接相连时，才提升为正式主案例。

这是一个生产网络定义，不是民族性解释。

## 与《独立游戏英雄传说》的差异

《独立游戏英雄传说》主要研究：

- 小团队 / 个人如何制造 runway；
- 如何重切 scope；
- 如何积累 capability stock；
- 如何以极低组织成本完成作者性产品；
- 如何接入全球市场。

《斯拉夫游戏英雄传说》则允许：

- 中型乃至 AAA 级团队；
- 传统发行商融资；
- 大型工程项目；
- 免费网游与长期运营；
- 非独立公司；
- 强烈商业野心。

只要它们仍然提出了足够激进的产品问题，并形成值得研究的生产解法。

## 美国 PC 纵向对照组：early id / DOOM → Quake → Ion Storm

《独立篇》的 [《DOOM启世录》纵向母案例](../../book/research-notes/masters-of-doom-longitudinal-master-study-001.md) 作为**跨书对照**引用，而非在本篇重建一份美国案例。它帮助把 GSC→4A 的组织裂变、PC 工程传统、俄罗斯/乌克兰游戏的全球发行结构等问题转为可比较变量：

- 技术机会是被动继承、重新组合，还是由本团队主动推进 frontier？
- 谁把技术突破转译为实际玩家体验、内容生产工艺与商业发行接口？
- 早期高度互补的成员为什么会产生 authorship、product thesis、governance 与 decision-rights 的分歧？
- 相同公司/融资/品牌下的不同开发团队，为什么可能拥有不同的 production closure？

DOOM 仍归根目录 CASE-016 / Ledger；斯拉夫篇只交叉引用，不复制证据。不同历史时期的 PC 硬件、分发、劳资、政治与市场条件必须分开核算；美国对照组不构成民族创造力高低排序。

## 共同母题

两书共享同一个方法论问题：

> **创作者面对一个按主流行业答案很难做成的问题时，究竟改变了哪些变量？**

斯拉夫线尤其关注：

- 国际市场导向如何形成；
- 本土购买力、盗版、融资环境与产品路线之间是什么关系；
- 工程传统、数学 / 系统思维、mod / PC 文化是否构成真实能力资本；
- 资金匮乏到底是约束、筛选器还是被浪漫化的神话；
- 发行商与海外资本在“激进作品”中实际承担了多少风险；
- 大规模战争题材网游为何在这里获得产业化；
- 工作室裂变、核心人才出走、劳资关系如何生产出新公司；
- 苏联制度遗产、1990s 市场化、2000s PC 全球化、2010s F2P / Steam、2020s 战争与迁移分别改变了什么。

# 三条必须进入主干的产业谱系

## A. 乌克兰：S.T.A.L.K.E.R. → 4A Games / Metro 的组织裂变

这条线不能只作为“两个著名 FPS”的作品比较，而要研究：

> **一套技术与创作能力如何在公司内部形成，又如何因为工资、分成、管理与裁员冲突发生人才外流，并在新组织里重新组合。**

目前可核实的事实包括：

- 4A Games 由 GSC Game World 的前核心开发者在基辅创立；
- 多个来源将离开 GSC 的直接背景指向工资 / royalties / 管理冲突；
- 后续还有相当数量原 GSC 美术与技术人员进入 4A；
- 4A 的公开自我叙述强调其创始成员拥有长期 PC / 游戏开发经验，并以制作 AAA 级 PC / console 产品为目标。

### 对“labor union 造反”的边界

作者过去会把这件事概括成类似“labor union 造反”的成功范例，这个比喻保留为研究入口，但**当前证据不支持把 4A 的成立写成字面意义上的工会组织、集体谈判或正式 labor union 行动**。

更准确的研究表述应是：

> **由薪酬 / royalties / 管理冲突触发的核心创作与技术骨干出走式组织反叛 / studio schism。**

后续必须继续寻找：

- 创始人当事访谈；
- GSC 方面的反方版本；
- S.T.A.L.K.E.R. 制作期工资、分成、裁员与团队结构资料；
- 4A 创立后是否真的改变了员工待遇与组织制度。

参考入口：

- 4A 十周年采访：https://www.videogameschronicle.com/features/interviews/metro-10-years/

## B. 白俄罗斯：World of Tanks 作为战争网游产业化转折点

《坦克世界》不能再作为候选池里的普通一个案例，而应成为本书的**产业级转折章节候选**。

Wargaming 官方自己明确把 World of Tanks 称为公司历史的“ultimate turning point”。其公开时间线为：

- 1998：Wargaming 在 Minsk 成立；
- 2000s：长期制作多人策略与战争题材产品；
- 2010：World of Tanks 在 CIS 上线；
- 2011：进入北美 / 欧洲；
- 2013：World of Warplanes；
- 2015：World of Warships。

这条线需要研究的不是“坦克题材为什么火”这么简单，而是：

- 为什么一支长期做策略 / 战争游戏但商业规模有限的团队，突然找到可全球扩张的 F2P 产品结构；
- 15v15 短局、单载具操控、科技树、收集与长期运营如何重构传统军武模拟的门槛；
- 这套产品如何把“军事载具爱好者”从小众市场扩张成大众在线市场；
- 它如何建立服务器、运营、内容生产、历史考据、社区与全球发行能力；
- 成功后如何反向塑造 Wargaming 的公司组织与“World of”品牌。

参考入口：

- Wargaming 20 周年官方历史：https://worldoftanks.eu/en/news/general-news/wargaming-20th-anniversary/
- Wargaming 15 周年官方纪录片：https://worldoftanks.com/en/news/general-news/wargaming-15-years-video/
- 2010/2011 前后早期采访：https://www.gamereactor.eu/interview-world-of-tanks/

## C. World of Warships 与 War Thunder：同一市场转折中的两种继承关系

### World of Warships：直接的公司 / 品牌继承

World of Warships 可以比较有把握地写成 World of Tanks 成功之后 Wargaming 战争网游体系扩张的一部分。

Lesta / Wargaming 开发者明确把它称为：

- World of Tanks、World of Warplanes 之后的“next logical step”；
- World of 系列陆 / 空 / 海三部曲的一部分；
- 同时又强调不能简单做成“水上的坦克”。

这里应重点研究 **成功模板如何被迁移，同时又必须重新发明玩法**。

参考入口：

- Making Games 2015《The Development of World of Warships》
- Wargaming 官方设计回顾：https://wargaming.com/en/news/wows_getting_it_right/
- Lesta 开发者访谈：https://www.gamer.ru/ru/p/v-gostyah-u-lesta-studio-intervyu-s-razrabotchikami-world-of-warships-C8EXCHn2tzqzS

### War Thunder：不能写成 World of Tanks 的简单后果

作者提出过一个强命题：

> “没有 World of Tanks，就没有 War Thunder。”

**当前证据足以否定这个命题的字面版本。**

Gaijin 创始人 Anton Yudintsev 明确表示，War Thunder 的开发在 World of Tanks 上线之前就开始；团队的能力前史来自 IL-2: Sturmovik — Birds of Prey、Apache: Air Assault、Birds of Steel 等飞行 / 军事载具游戏。

但 World of Tanks 仍可能有另一层重要作用：

> **它在 War Thunder 开发过程中证明了“非 fantasy、军武题材、大规模 F2P 在线游戏”可以形成巨大市场，从而改变投资者、媒体、玩家与竞争者的品类预期。**

因此当前状态应记录为：

- “WoT 导致 War Thunder 出现” → **REFUTED（字面因果）**；
- “WoT 显著改变 War Thunder 所处市场窗口与品类合法性” → **SUPPORTED / 待继续量化**。

参考入口：

- Anton Yudintsev 访谈：https://dtf.ru/gamedev/470-gaijin-interview
- War Thunder 早期官方材料：https://gaijinent.com/en/news/86
- 2012 Igromir 同期采访：https://warthunder.com/ru/news/100-igromir-2012-intervu-s-kommuniti-menedzerom-andreem-sumakovym-ru

# 首批正式候选案例池

以下只是研究池，不代表已经接受任何成功原因解释。

## 苏联 / 转型起点

- **Tetris / Alexey Pajitnov** — 作者性、国家机构、知识产权与全球商业化。

## 俄罗斯：系统型与作者型商业作品

- **Vangers / K-D Lab** — 类型混合、世界系统与极端审美。
- **Perimeter / K-D Lab** — RTS 结构与地形系统实验。
- **Space Rangers / Elemental Games / Katauri** — 多系统混合与动态世界。
- **Pathologic / Ice-Pick Lodge** — 商业失败风险、作者性与长期生存。
- **IL-2 Sturmovik / 1C:Maddox** — 飞行模拟 / 军事载具技术谱系，对 Gaijin 等后来团队的重要前史。
- **Hammerfight / Konstantin Koshutin** — 个体能力资本与异常交互设计。
- **HighFleet / Konstantin Koshutin** — 个人 / 小团队前史累积到商业级复杂系统作品。
- **Escape from Tarkov / Battlestate Games** — extraction shooter 的资源、风险、市场结构。
- **Loop Hero / Four Quarters** — 极小团队、旧式表现、系统创新与全球发行。
- **Black Book / Morteshka** — 地方文化研究与商业产品化。
- **INDIKA / Odd Meter** — 强作者性、商业规格、战争后迁移与发行关系。
- **War Thunder / Gaijin Entertainment** — 飞行模拟能力资本如何转化为大众军武 F2P。

## 乌克兰：工作室裂变与技术 / 人才谱系

- **S.T.A.L.K.E.R. / GSC Game World** — 长开发周期、开放世界 / A-Life / PC 技术野心与东欧全球市场。
- **4A Games / Metro 2033** — GSC 核心人才出走后如何重新组织 AAA 能力。
- **Vostok Games** — GSC 解体后的另一支人才与系统设计延续。

## 白俄罗斯：战争网游商业化

- **World of Tanks / Wargaming** — 产业转折主案例。
- **World of Warships / Wargaming + Lesta** — 成功模板迁移与玩法再发明。
- **World of Warplanes** — 必须作为对照：同一公司、同一品牌逻辑为什么效果明显不同。

# 禁止的浪漫化叙事

本项目不得预设：

- “俄罗斯 / 斯拉夫穷，所以更有创造力”；
- “融资困难天然促进创新”；
- “斯拉夫民族性更适合系统游戏”；
- “盗版迫使出海，所以盗版是好事”；
- “没有资本干预，所以作者绝对自由”；
- “激进作品多，所以整个产业都激进”；
- “所有乌克兰 / 白俄罗斯工作室都只是俄罗斯游戏工业的分支”；
- “World of Tanks 之后出现的所有战争网游都由它直接催生”。

这些只能作为待检验命题。

# 关键对照

斯拉夫线必须有失败者和普通项目作为对照。

至少需要建立：

- 同期成功但保守的商业游戏；
- 激进但失败 / 消失的项目；
- 获得稳定资本仍保持激进的团队；
- 极端缺钱但没有产生创新结果的团队；
- 同一公司内部成功 / 失败产品对照，例如 World of Tanks vs World of Warplanes；
- 与中国、波兰、捷克、芬兰、德国等 PC 开发传统的对照。

# 与作者旧文的关系

本项目的重要思想前史是作者 2023 年长文《正在到来的中度数值通胀率游戏设计革命》，其中已经汇编了“游戏炼乳”大多数早期文章，并包含《中俄游戏产业特征对比，兼论执行主策是怎么来的》等内容。

这些旧文提出过：

- 中国 / 俄罗斯产业结构对照；
- 外向型市场；
- 资方干预与执行主策；
- 匮乏、筛选压力与产品激进性；
- 赛博地主 / 渠道权力；
- 认知一致与内卷。

全部只作为 **A0 — Author-Origin**，必须用公司史、开发者史、融资 / 发行 / 招聘 / 产品 / 失败史重新验证。

2025 年之后的《DeepSeek——第四次工业革命的瓦特蒸汽机》等后期文章属于**后续思想增量**，不能反向伪装成 2023 长文已经包含的观点。

# 预期章节形式

每个主要案例仍采用与主项目相容的生产史结构：

**传说 → 出身 → 粮道 → 兵器 → 战役 → 天时 → 判词**

其中“判词”必须回答：

1. 真正异常的能力是什么？
2. 有哪些被传奇叙事抹掉的外部帮助？
3. 项目最接近死亡的地方在哪里？
4. 环境究竟帮助还是阻碍了它？
5. 哪些能力是多年积累，哪些是项目中现学？
6. 哪些东西可迁移，哪些只属于特定时代和地区？

# Repo strategy

当前只在本仓库保存方法论接口、跨书命题和首批产业谱系。斯拉夫篇形成大量独立 Case 后，再决定是否拆成独立仓库。

在此之前，不复制一套平行 schema，避免两套研究规则漂移。
