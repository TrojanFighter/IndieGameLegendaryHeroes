## 一、时代切片，不得把1998年的制度当2026年的制度

| 阶段 | 有证据的机制 | 缺口 |
|---|---|---|
| 苏联末期—1990年代初 | 科研/高校/爱好者计算文化进入商业游戏；软件开发、零售与知识产权结构剧变 | 主创阶层/城市/家庭资源的代表性分布 |
| 1998—2004 | 经济危机、盗版与低价正版共存；1C/Buka/Akella 的开发、代理、本地化和出口；部分项目依赖国外回本 | 发行合同、净回款、项目退出率 |
| 2005—2009 | 盒装PC与国际发行并行；各公司开始尝试在线、社交和数字分发 | Steam 前后销量、国家别净收入 |
| 2010—2021 | WoT/WT 等服务化与成熟出口型 PC 作品并存；不能再以2003年代表这十余年 | 逐公司收入地区矩阵和创作者迁移 |
| 2022—2026 | 战争、支付/制裁、业务外迁等可能改变组织生存制度 | 逐法人、逐团队、逐职业证据；避免把外迁率当总体统计 |

## 二、2003年的同期硬证据

**S01** Alexander Malakhov, “Березовый софт”, *Коммерсантъ-Деньги*, 2003-06-09，P0（同期行业采访）+ S1（记者综合）。
https://www.kommersant.ru/doc/387894 （核读 2026-10-07）

- 1C 负责人 Yuri Miroshnikov **估计** 2002 年俄罗斯合法游戏市场 8000万—9000万美元；Akella 的 Dmitry Arkhipov 估计约 1 亿美元。**这不是审计后统一统计**。
- Arkhipov **估计**盗版销售份额已降至约 60%；同一报道引述的 BSA 是 87%，但 BSA 统计对象/方式与游戏光盘销售不必一致。禁止将数值拼成同口径时间序列。
- 同期采访明确说，行业人士无从精确估算海外收入，但估计 **俄罗斯开发游戏的海外收益总量小于国内合法游戏市场**。二者范围不同（出口的是本土开发游戏；国内包括进口代理），只能驳斥“整个游戏业只靠出口”，不能得出“原创项目以国内收入为主”的结论。
- Akella 称 1998 危机后关闭本土发行/分销，改做西方发行商委托开发，2000 年重新恢复本土发行。**出海是可选择的应急现金流，不等于产业恒定唯一生存模式**。
- 1C 称《Дальнобойщики / Hard Truck》俄罗斯正版销售超过 60 万套、批发价约 1.5 美元，国内销售约 90 万美元量级，而项目成本近 100 万美元，若缺海外收入回本困难。这是 **单个项目对国际市场的依赖**，不等于总产业口径。
- 1C 称非爆款但质量合格的国内游戏销售可能贡献 20万—30 万美元，其他独联体市场也可重要；这些是经营者口头估算，不是行业均值。
- 同期采访说明典型商业团队 15—20 名核心专业人员、游戏预算平均约 50 万美元、程序员月薪约 500—1000 美元（均为当事人口径）。人才从大学直接获得的游戏生产管理知识不足；发行商扮演早期能力审查者。
- Orlovskiy 说 Nival 在 1999 年尝试在线项目，但俄罗斯当时支付、线路和用户规模难支撑持续经营；不能把俄罗斯网吧文化与早期成熟网游盈利市场画等号。
- 同期还记录 Buka 曾以约 25 万美元支持 Nival 早期《Аллоды / Allods》，项目超预算且未赚到钱。这是 **国内发行商为第一代团队承担资金风险** 的直接个案。

**S02** *Game Developer*, “Interview: The State Of Russian Gaming, According To 1C”, 2008，P0/P1（当时的发行商经营者观点）。
https://www.gamedeveloper.com/game-platforms/interview-the-state-of-russian-gaming-according-to-1c （2026-10-07）

## 三、保留四项不可合并的变量

1. **Domestic-market survival**：本土消费者、低价正版、独联体渠道和进口代理如何支撑发行商。
2. **International recoupment**：欧美/国际合同与销量如何补足个别高成本项目的回本。
3. **Developer–publisher contract**：谁拥有 IP、谁垫资、验收里程碑、回收顺位与版税如何分配。
4. **Capability continuity**：资金断裂或商业模式变化后，人、引擎、设计语法、发行关系实际留下什么。

初步判断（H）：1990s—2000s **国内渠道提供许多早期团队第一次付费验证，国际市场提升部分项目利润上限，发行商在两者之间转译风险**。不可自动推成“这种组合提高原创率”。

## 四、针对流行叙事的判定

| 命题 | 状态与边界 |
|---|---|
| “俄罗斯游戏业自始至终靠海外养活” | REFUTED AS BLANKET CLAIM（2003同期内销规模/阿凯拉恢复本土发行）；具体高预算项目另算 |
| “高盗版必然杀死本土商业发行” | REFUTED AS NECESSARY RESULT；真实损害程度仍待财务审计 |
| “俄罗斯没有网吧，因此无网游” | UNVERIFIED/OVERGENERALIZED：有计算机俱乐部文化；缺同口径全国覆盖率、营收与支付研究 |
| “国内市场较小，使所有团队更原创” | H — 没有因果识别；应取失败与保守样本 |
| “国外市场更重要，因为全靠美国” | UNVERIFIED：需要早期德国/中东欧/CIS/美国项目级分区域合同 |
| “苏联/后苏联/俄罗斯/俄语工作室是一回事” | REFUTED AS ANALYTICAL CATEGORY；国别、注册地、控制权和人才实际地点必须拆开 |

## 五、下一轮证据缺口（优先）

1. 1995—2010 **至少12个项目的预算→俄/CIS→德国/欧洲→北美净收入**；预算需分工作室收款与发行商总流水。
2. 2000—2010 俄罗斯与中国 **网吧/家庭PC/网络支付/网游消费** 同口径数据；访问地点不等于游戏时长/付费。
3. Buka / 1C / Akella / Snowball 的合同、资金结构及失败项目退出率，避免以名作抽样。
4. 2010—2021 WoT/WT、MY.GAMES、单机出口与 Steam-era 小团队分制度比较。
5. 2022—2026 外迁：个体迁移、法人迁移、知识产权迁移、跨国远程开发与俄罗斯本土人员损失分别建表。
6. 同期中国匹配研究：不仅比原创与运营，还比 **游戏开发者能否获得中间商融资及决策权成本**。

**时效门槛**：2003 年 1C 的渠道打法、工资和盗版比例为 HISTORICAL；2026 的平台/支付/工资不可沿用。
