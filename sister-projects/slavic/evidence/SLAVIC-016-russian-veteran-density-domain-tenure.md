# SLAVIC-016 — 俄罗斯游戏从业者“老兵密度”：行业平均资历、核心决策位与问题域复利

- Type: Workforce / career-cohort evidence ledger
- Status: ACTIVE — MIXED EVIDENCE
- Date: 2026-10-07
- Core question: 俄罗斯/后苏联硬核游戏为何常给人“主创都是超级老兵”的印象？这是全行业人口结构，还是核心决策位与长期问题域的选择效应？

## 一、先否掉过强命题：全行业并非“都是老兵”

2019年Values Value对俄罗斯游戏行业的调查中，接近一半受访者游戏行业经验不足3年。该调查还提醒，所谓新人中包含从其他行业切入的switchers。
https://dtf.ru/gameindustry/52977-issledovanie-mediannaya-zarplata-v-rossiiskom-geimdeve-sostavlyaet-tysyachu-dollarov-v-mesyac

因此：
> “俄罗斯游戏从业者大多数都有十几年经验” = NOT SUPPORTED。

但2008年1C高管已把俄罗斯开发生态描述为“正在变老、更加专业化”，并强调越来越多团队直接与西方发行商合作，带回国际生产经验。
https://www.gamedeveloper.com/game-platforms/interview-the-state-of-russian-gaming-according-to-1c

全球基准也说明十年以上资历本来就是少数：2010年Game Developer Research调查称71%从业者行业经验不超过6年，仅13%超过10年、4%超过15年。
https://www.gamedeveloper.com/game-platforms/study-game-developers-increasingly-newcomers-to-business

所以更值得测的不是全行业平均，而是：
**Lead / founder / creative-director / technical-director 等决策位的 veteran density。**

## 三、核心发现：真正异常的可能不是Age，而是“Hands-on Domain Tenure”

只统计“在游戏业工作多少年”会把不同能力混在一起。建议拆三项：

1. **GIE — Game Industry Experience**  
   从第一次商业/准商业游戏工作到目标项目的年数。

2. **HCT — Hands-on Creative Tenure**  
   主创在这段时间里有多少年仍直接做设计、程序、美术、关卡或系统，而不是完全转成纯管理/资本角色。

3. **PDT — Problem-Domain Tenure**  
   同一个人/核心团队持续研究相近问题域多少年，例如：
   - Maddox：飞行/航空模拟；
   - Gaijin：载具、飞行、物理、跨平台；
   - Gusarov：系统型策略/RPG；
   - Koshutin：惯性、机械系统、战争指挥；
   - Dybowski：高摩擦作者型叙事/生存；
   - Owlcat核心：CRPG / party RPG设计语法。

**HYPOTHESIS**：俄／后苏联真正值得比较的优势可能是 HCT + PDT 较高，而非单纯平均年龄较高。

## 四、为什么玩家会产生“全是超级老兵”的印象

存在至少四种选择效应：

### 1. Survivor visibility
长期留下的人更容易被英语媒体、Steam和大型项目看见；大量新人、小团队和退出者不可见。

### 2. Premium项目的seniority filter
复杂Premium/模拟/CRPG项目需要较长技术与制作周期，核心决策位天然更偏向资深者；这不是俄罗斯独有。

### 3. 组织裂变保留资深核心
Nival→Owlcat、K-D LAB→KranX/KD Vision、GSC→4A等路径，使老员工不是随着公司变化而退出行业，而是携带经验进入新组织。

### 4. 同一问题域允许资历真正复利
“十年游戏经验”只有在下一作仍能使用时才有价值。俄方部分谱系的特殊点在于：
> old skill → next related project → deeper skill
而不是：
> old skill → completely different monetization/operations role

## 五、与中国比较时不能只比“老员工比例”

中国也有大量10—20年老兵。2019腾讯750名受访者平均游戏行业经验5.8年，0—3年占34.7%；平均年龄29.66岁。
https://games.sina.cn/cyfw/cyxw/2019-07-03/detail-ihytcerm1042679.d.html

2014中国软件开发者调查还显示，工作年限越长者进入游戏开发的比例反而更高，并不存在“老程序员全部退出游戏”的简单规律。
https://img-bss.csdnimg.cn/201910110328382214.pdf

所以中俄真正应比较：

- 同样10年以上GIE的人，有多少仍在直接设计/程序/技术决策位；
- 其过去10年是否持续研究同一problem domain；
- 是否从Premium转Online后又能把能力带回Premium；
- 创业/工作室裂变后老兵经验能否传给新cohort；
- 老兵是否掌握最终项目否决权，而不仅是高级执行岗位。

### 特别值得检验的中国反事实
中国早期目标、像素、祖龙、上海软星、新瑞狮等也产生了大量老兵，但这些人的资历后来分别复利在：
- MMO / live ops；
- 引擎与大型内容生产；
- 管理/制作；
- 新Premium工作室；
- 或离开行业。

因此“俄罗斯老兵多、中国老兵少”很可能是错误问题。
更好的问题是：
> **两国的老兵分别老在什么能力上？他们到40岁以后是否仍然掌握作者性/技术性决策？**

## 六、下一轮测量协议

对2005俄方1C cohort、2003中国13款cohort，各取每个组织2—4名可核核心人员，记录：

person / role / first_game_year / target_project_year / GIE / hands_on_role / problem_domain / next_5y_projects / management_shift / spin_off / final_decision_right

计算：
- **Veteran Decision-Role Density (VDRD)**：核心决策角色中GIE≥10年的比例；
- **Hands-on Retention Rate (HRR)**：十年以上从业者仍直接承担设计/技术/美术核心工作的比例；
- **Problem-Domain Continuity (PDC)**：五年后仍在相近问题域工作的比例。

这些指标比“平均年龄/平均工龄”更能解释为什么某些生态不断产生老兵主导的复杂作品。

## Verdict

**REFUTED AS BLANKET CLAIM**：俄罗斯全行业大多数从业者都是十年以上老兵。

**SUPPORTED BY SELECTED FLAGSHIP COHORTS**：俄罗斯/后苏联多条旗舰Premium、模拟、策略、CRPG谱系的核心决策者在关键作品时已有约8—17年以上行业经验，而且经常保持hands-on或相近问题域连续性。

**HYPOTHESIS**：真正的跨国差异不是 veteran headcount，而是 **Veteran Decision-Role Density + Hands-on Creative Tenure + Problem-Domain Tenure**。
