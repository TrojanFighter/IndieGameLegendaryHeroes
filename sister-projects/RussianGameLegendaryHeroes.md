# 《俄罗斯游戏英雄传说》— Sister Project Brief

**Russian Game Legendary Heroes**

- Author / 主创：洪荒行者
- Relationship: 《独立游戏英雄传说》的姊妹篇
- Status: RESEARCH PROGRAM — NOT YET A BOOK OUTLINE

## 一句话定义

这不是“俄罗斯独立游戏史”。

它研究的是：

> **为什么俄罗斯及其相关后苏联开发传统中，反复出现商业级、工程规模并不小，却在玩法、系统、题材、审美或生产方式上激进得不亚于独立游戏的作品？这些作品背后的开发者、工作室与生产条件是怎样形成的？**

因此研究对象不以“是否独立”筛选，而以**是否改变了问题、是否推进了设计边界、是否形成了异常生产结构**筛选。

## 与《独立游戏英雄传说》的差异

《独立游戏英雄传说》主要研究：

- 小团队/个人如何制造 runway；
- 如何重切 scope；
- 如何积累 capability stock；
- 如何以极低组织成本完成作者性产品；
- 如何接入全球市场。

《俄罗斯游戏英雄传说》则允许：

- 中型乃至商业级团队；
- 传统发行商融资；
- 大型工程项目；
- 非独立公司；
- 强烈商业野心。

只要它们仍然提出了足够激进的产品问题，并形成值得研究的生产解法。

## 共同母题

两书共享同一个方法论问题：

> **创作者面对一个按主流行业答案很难做成的问题时，究竟改变了哪些变量？**

俄罗斯线尤其关注：

- 国际市场导向如何形成；
- 本土购买力、盗版、融资环境与产品路线之间是什么关系；
- 工程传统、数学/系统思维、mod/PC 文化是否构成真实能力资本；
- 资金匮乏到底是约束、筛选器还是被浪漫化的神话；
- 发行商与海外资本在“激进作品”中实际承担了多少风险；
- 作品激进性是少数幸存者造成的选择偏差，还是存在可识别的产业结构原因；
- 苏联制度遗产、1990s 市场化、2000s PC 全球化、2010s Steam、2020s 战争/迁移分别改变了什么。

## 地理边界

书名使用“俄罗斯”，但研究时不能把所有后苏联作品都自动归为俄罗斯。

默认：

- **核心样本：俄罗斯 / 俄罗斯开发传统直接相关团队。**
- 乌克兰、白俄罗斯、波罗的海、中亚等后苏联团队若进入，只能作为明确标注国别的比较样本，不能被叙述成“俄罗斯作品”。
- 跨国迁移团队按实际成立地、成员来源、生产地点、资本来源分别记录。

这条边界尤其重要，因为战争与迁移之后，许多团队的法律主体、人员所在地与文化来源已经分离。

## 首批候选案例池

以下只是研究候选，不代表已经接受任何成功原因解释：

### 苏联 / 转型起点

- **Tetris / Alexey Pajitnov** — 作者性、国家机构、知识产权与全球商业化之间的极端案例。

### 1990s–2000s：系统型商业作品

- **Vangers / K-D Lab** — 类型混合、世界系统与极端审美。
- **Perimeter / K-D Lab** — RTS 结构与地形系统的激进实验。
- **Space Rangers** — 多系统混合、动态世界与商业可读性的结合。
- 其他同时代 PC 系统游戏：待建立比较组。

### 2000s–2010s：作者型工作室与全球 PC 市场

- **Pathologic / Ice-Pick Lodge** — 商业失败风险、作者性、叙事系统和长期生存。
- **Hammerfight / Konstantin Koshutin** — 个体能力资本与异常交互设计。
- **HighFleet / Konstantin Koshutin** — 小团队/个人前史如何累积到商业级复杂系统作品。
- **Escape from Tarkov / Battlestate Games** — 商业级团队如何定义并放大 extraction shooter 的资源、风险和市场结构。

### 2010s–2020s：小团队与新全球发行条件

- **Loop Hero / Four Quarters** — 极小团队、旧式表现、系统创新与全球发行。
- **Black Book / Morteshka** — 地方文化题材、研究型内容与商业产品化。
- **INDIKA / Odd Meter** — 强作者性、商业制作规格、战争后迁移与发行关系。

## 禁止的浪漫化叙事

本项目不得预设：

- “俄罗斯穷，所以更有创造力”；
- “融资困难天然促进创新”；
- “俄罗斯民族性更适合系统游戏”；
- “盗版迫使出海，所以盗版是好事”；
- “没有资本干预，所以作者绝对自由”；
- “激进作品多，所以整个产业都激进”。

这些只能作为待检验命题。

## 关键对照

俄罗斯线必须有失败者和普通项目作为对照。

否则我们只能得到：

> 我们挑出了一批最奇怪、最成功、最容易被记住的作品，因此俄罗斯看起来特别奇怪。

至少需要建立：

- 同期成功但保守的俄罗斯商业游戏；
- 激进但失败/消失的项目；
- 获得稳定资本仍保持激进的团队；
- 极端缺钱但没有产生创新结果的团队；
- 与中国、波兰、捷克、乌克兰、芬兰等 PC 开发传统的对照。

## 与作者旧文的关系

本项目的重要思想前史是 2023 年“游戏炼乳”文章：

《中俄游戏产业特征对比，兼论执行主策是怎么来的》

https://mp.weixin.qq.com/s/id2D7gXl7Q1PxAefD5Kopw

旧文提出过“俄罗斯游戏产业是中国镜像对照”“外向型市场”“资方干预较少”“匮乏形成筛选压力”等解释。

这些观点只作为 **A0 — Author-Origin**：

> 姊妹篇的任务不是证明作者 2023 年说对了，而是用具体公司、开发者、融资、发行、销量、招聘、产品与失败史把这些解释逐条拆开。

## 预期章节形式

每个主要案例仍采用与主项目相容的生产史结构：

**传说 → 出身 → 粮道 → 兵器 → 战役 → 天时 → 判词**

其中“判词”必须回答：

1. 真正异常的能力是什么？
2. 有哪些被传奇叙事抹掉的外部帮助？
3. 项目最接近死亡的地方在哪里？
4. 环境究竟帮助还是阻碍了它？
5. 哪些能力是多年积累，哪些是项目中现学？
6. 哪些东西可迁移，哪些只属于特定时代和地区？

## Repo strategy

当前只在本仓库保存方法论接口和跨书命题。俄罗斯篇形成大量独立 Case 后，再决定是否拆成独立仓库。

在此之前，不复制一套平行 schema，避免两套研究规则漂移。
