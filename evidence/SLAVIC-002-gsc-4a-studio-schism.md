# SLAVIC-002 — GSC Game World → 4A Games：组织裂变、人才迁移与能力资本重组

- Project: 《斯拉夫游戏英雄传说》
- Type: Evidence Ledger
- Status: ACTIVE — FIRST EVIDENCE PASS
- Last updated: 2026-10-03

## 研究问题

> **4A Games 的成立究竟是一次普通创业、一次劳资冲突后的集体出走，还是一批已经在 GSC 内部形成的创作 / 技术能力资本脱离旧组织并重组为新生产单位？**

作者过去用“labor union 造反”概括这一事件。这个比喻可以保留为研究入口，但不能直接当事实描述。

## C1 — 4A Games 确由 GSC / S.T.A.L.K.E.R. 核心成员裂变而来

**Status: VERIFIED**

4A Games 2020 年官方十周年回顾写明：

- 工作室在乌克兰创立；
- 创始核心来自 GSC Game World；
- 发生在 S.T.A.L.K.E.R. 开发末期；
- 官方点名“四个 A”：Andriy/Andrew Prokhorov、Oles Shyshkovtsov、Aleksandr Maksymchuk、Andriy Tkachenko；
- 新工作室希望建立一种更 close / supportive family 的组织哲学。

Source:
- 4A Games, `Metro 10th Anniversary Studio Update`, 2020-11-17
  - https://www.4a-games.com.mt/4a-dna/2020/11/17/metro-10th-anniversary-studio-update
  - Evidence class: P1/OFFICIAL-RETROSPECTIVE

Supporting contemporary trace:
- 2004 年 ModDB 对 Oles Shyshkovtsov 的采访中，他仍以 S.T.A.L.K.E.R. Lead Programmer 身份出现，可确认其在 GSC 的关键技术位置。
  - https://www.moddb.com/games/stalker/features/stalker-interview
  - Evidence class: P0/CONTEMPORARY-INTERVIEW

## C2 — “2006 因一次工资冲突突然出走”过于简化

**Status: REFUTED AS SIMPLE ONE-CAUSE STORY**

2026 年 Andriy Prokhorov 回顾称：

- 他与几位志同道合者早在 2004 年就决定未来离开 GSC 创建自己的工作室；
- 他们提前告知 Sergiy Grygorovych，并承诺先把 S.T.A.L.K.E.R. 做完，因为这对未来团队履历很重要；
- 2006 年 1 月，GSC 为削减成本计划裁掉大量美术和动画人员；
- Prokhorov 等人判断这些人才一旦被解散会迅速流失，于是提前启动 4A Games、开办公室并吸纳人才。

Source:
- Andriy Prokhorov long interview, Mezha, 2026
  - https://mezha.ua/en/articles/andriy-prohorov-pro-s-t-a-l-k-e-r-metro-ta-kosmos-314120/
  - Evidence class: P1/FOUNDER-RETROSPECTIVE

Interpretation:

> **4A 的成立更像“长期独立意图 + 对旧组织资源分配 / 管理方式不满 + 对关键人才流失的应急反应”叠加，而不是单次欠薪事件。**

## C3 — “薪酬 / royalties / 管理冲突”存在，但证据强度不均

**Status: PARTIALLY_SUPPORTED / CONTESTED DETAILS**

多份二手与后来的历史整理把 Prokhorov 与 GSC 创始人之间的矛盾描述为：

- 工资；
- royalties / 分成；
- 对员工待遇的看法；
- 管理风格；
- 资源集中于老板而非团队。

但第一轮高质量一手证据目前最清楚支持的是：

- 有长期独立意图；
- 有成本削减与裁员背景；
- 有对组织文化 / 人才待遇的明确反感。

对“具体拖欠了多少钱”“是否正式承诺 royalties 后拒付”“哪一次工资争议直接触发离职”等说法，当前仍缺同期合同、工资单、内部邮件或双方同时期证词。

因此：

- `管理 / 资源分配冲突` → SUPPORTED；
- `工资 / royalties 是核心矛盾之一` → PLAUSIBLE / NEEDS PRIMARY CORROBORATION；
- `欠薪直接导致集体出走` → UNVERIFIED。

## C4 — GSC 自己也把这次事件称为“revolution”

**Status: VERIFIED AS RETROSPECTIVE LANGUAGE**

GSC 创始人 Sergiy Grygorovych 在后来的采访中回顾 S.T.A.L.K.E.R. 长期开发时，把 4A 成员离开称为团队中的一次“revolution”，并说他们想走自己的道路、想独立开发，也已经被漫长的 S.T.A.L.K.E.R. 开发消耗。

Source:
- DOU / GameDev Ukraine 对 Sergiy Grygorovych 的采访
  - https://gamedev.dou.ua/forums/topic/49007/
  - Evidence class: P1/COUNTERPART-RETROSPECTIVE

Value:
- 这提供了 GSC 一侧的反方叙述：不是单纯“老板压榨 → 员工逃亡”，而包含项目疲劳、独立野心和路线分化。

## C5 — 4A 不是从零开始，而是带着能力资本迁移

**Status: VERIFIED / STRONGLY SUPPORTED**

4A 的第一部作品 Metro 2033 不是一个新手团队的学习项目。

可确认：

- 核心成员在 S.T.A.L.K.E.R. 已承担 lead programmer / design 等关键职位；
- 4A 2005/2006 创立后很快进入自研 4A Engine 与 Metro 开发；
- 2009 年 THQ 宣布发行 Metro 2033 时，官方材料称项目已开发超过两年；
- 2010 年 Metro 2033 已支持 DX11 / PhysX / 3D Vision 等当时较高端 PC 技术；
- 4A 后来明确说自 2005 年工作室创立起一直持续迭代自家引擎。

Sources:
- THQ / Game Developer, 2009-10-22
  - https://www.gamedeveloper.com/game-platforms/thq-to-publish-new-post-apocalyptic-fps-i-metro-2033-i-
  - Evidence class: P0/CONTEMPORARY-ANNOUNCEMENT
- Game Developer, 2010-02-17
  - https://www.gamedeveloper.com/game-platforms/thq-i-metro-2033-i-to-support-3d-vision-physx-dx11
  - Evidence class: P0/CONTEMPORARY
- 4A Games / Game Developer on Exodus SDK and engine history
  - https://www.gamedeveloper.com/business/4a-games-is-handing-the-metro-exodus-sdk-over-to-players
  - Evidence class: P1/OFFICIAL-RETROSPECTIVE

Interpretation:

> **真正被迁移的生产资料不是办公室或 IP，而是人脑里的技术、设计判断、协作关系和工具经验。**

这是《独立游戏英雄传说》“能力资本”命题在中型商业团队上的重要平行案例。

## C6 — “labor union 造反”可以作为解释框架，但不能当字面事实

**Status: H / METAPHORICAL FRAME ONLY**

目前没有证据显示：

- 4A 创始人在 GSC 内成立过正式工会；
- 发生过法定集体谈判；
- 以 union 名义提出工资 / 工时诉求；
- 4A 是工会组织直接转化成的公司。

但更广义的劳动史视角仍然有价值：

> **一批关键劳动者因为对旧组织的资源分配、管理和未来方向不满，选择 collective exit，并把自己的能力资本重新组合成新公司。**

这是一种“生产单位重组”，不是正式 unionization。

## 需要继续验证的“传奇细节”

以下流行叙事目前都不能直接写进正文：

- “老板开 Ferrari，员工只有一辆二手车”作为精确事实；
- “所有 140 人里只有老板有豪车”之类戏剧化数字；
- “老板拒绝分 royalties，4A 因此成立”作为单一因果；
- “4A 成立后所有人待遇马上显著改善”；
- “整个 S.T.A.L.K.E.R. 核心团队都去了 4A”。

这些需要找到原始采访、同期报道或工资 / 人员名单再判断。

## 当前 Verdict

第一轮证据支持的较强叙述是：

> **4A Games 是一次典型的能力资本迁移。核心成员并非在 2006 年突然受刺激创业，而是至少从 2004 年起已有独立意图；当旧组织开始削减成本、准备解散部分关键人才时，他们提前启动新工作室，把已经在 S.T.A.L.K.E.R. 开发中形成的技术、设计和协作能力重新组织起来。**

这比“工会造反”更准确，也更有分析价值。
