## Research question / 不要先写答案

俄罗斯创作者到底在追求什么？他们何时形成“原创作品 / 创业收入 / 全球市场 / 控制权 / 安全 / 移居”的不同目标？商业成功、海外主体和实际迁居先后发生的顺序是什么？“为了润才做国际市场”和“全球成功之后有条件迁居”应分别检验，不得倒置时序。

可拆的决策单元：形成创作偏好 → 第一次商业尝试 → 首次外部支付/资金 → 立项与产品选择 → 发行/众筹/市场 → 境外法人/人员迁移 → 迁后新作/融资/培养下一代。**境外登记、开发所在地、IP持有人、创始人居留不同字段。**

### RCM-01 — K-D LAB：国际市场意图早于1998年危机

- Source class: P1（公司史回顾，利益相关方自述）；P0补强：1998 Game.EXE 同期Kuzmin访谈，目前公开转录可读，归档/页码待核。
- Source: K-D LAB, About K-D LAB Company, 公司官方历史，发布时间 UNKNOWN；https://kdlab.com/about/en
- Source: Game.EXE issue 02/1998, Kuzmin同期访谈；https://djvu.online/file/9oFrzp4JfZ1Sg
- Event time: K-D LAB创业阶段1995/1996；1996获ENIX 10,000美元；1998获ENIX 200,000美元大奖；Vangers 1998世界发行。
- Exact wording (official English retrospective): "intending to conquer the whole world with them"
- Source fact: 公司称早期已希望将自有技术商业化并面向世界；ENIX奖金帮助维持公司生存；Buka与Interactive Magic分别承担国内/部分国际发行。
- Boundary: 公司史有自我叙事倾向；比赛获奖并非公司总预算；无法仅由这一案推断俄罗斯创始人普遍抱有世界市场野心；不能从这条来源断言创业动机是移民。
- Interpretation [H]: 国际化可先于国内市场生存危机成为正向事业抱负，后被危机加强。

### RCM-02 — Buka：本国发行能力与海外出口同时发展

- Source class: P0/P1：Buka官网公司历程/2004具名公司访谈及公司回顾；商业数据口径待独立审计。
- Source: Buka official company history, https://buka.ru/about/
- Source: GameDev.ru, 「Интервью с Букой」, 2004-08-07, https://gamedev.ru/industry/articles/?id=4310
- Source: Kommersant 「Ас «Бука»」, 2004-06-07, https://www.kommersant.ru/doc/859735
- Source: Igromania Alexandr Mikhailov interview (retrospective), https://www.igromania.ru/article/24575/Buka_ot_nachala_i_do_nashih_dney.html
- Exact wording (2004, company's stated mission): "издавать качественные компьютерные игры для российских потребителей."
- Source fact: Buka同时建立国内低成本正版渠道（jewel case等策略）与国际授权；公司官网将1997年《Аллоды》《Vangers》的国际授权列入年表。不能把俄国市场描述成只有“海外出口”才能运作。
- Boundary: 低价发行的增益为Buka个案，不是所有俄国发行商的默认做法；与中国同期渠道比较需要采用统一平台、年份、抽成及IP条款。

### RCM-03 — Morteshka：原创作者的职业自主，而非有据可查的移民意图

- Source class: P1（2024/2025创始人回忆）
- Source: VGTimes, Vladimir Beletsky interview, 2024-11-11（英文译页2025-01-28更新）, https://vgtimes.com/vgtimes-interviews/115289-vgtimes-interview-with-the-author-of-black-book.html
- Source: GTOGG, developer interview, 2025-07-31, https://gtogg.com/News/en/Inside_the_Minds_of_Indie_Devs_Interviewing_Morteshka_the_team_behind_Slavic_folklore_games_Black_Book_and_One_Eyed_Likho/
- Event time: 2013 Perm local studio employment; 2015 side project / jam-like start; 2017 The Mooseman; 2020 Black Book Kickstarter; 2021 release.
- Exact wording (VGTimes English page): "At first, I just wanted to make a game."
- Source fact: 先在Alternative工作室任程序及产品管理，之后业余制作The Mooseman，部分外围花费自有资金；在盈利后辞职专职开发；Black Book以之前收入 + HypeTrain发行投资 + 约16万美元Kickstarter扩大范围。创始人不想仅为销量采用更热门的北欧题材；不想立即转为AAA管理型工作室。创始人明确不支持“其游戏90%销量都来自境外”的未经实测断言。
- Boundary: 初期Flash小作是否由国际发行商付费及金额需要追查具体作品与合同；现有来源**没有直接证明创始人2026居留地点**，不能把“原在彼尔姆”自动写成“至今从未迁移”。
- Interpretation [H]: 对某类作者而言，全球市场是保有题材决定权、改变劳动身份与控制团队规模的工具。

### RCM-07 — WN / App2Top：2022—23迁移比例（抽样，而非普查）

- Source class: S1（行业媒体自发问卷原始统计，非随机抽样）
- Source: WN 2022-04-08, https://wnhub.io/news/analytics/item-20032 ; WN 2024-08-20公布2023春问卷, https://wnhub.io/news/wn-researches/item-45092
- Exact wording (2023 sample methodology): "1004 completed questionnaires"
- Source fact: 2022第一轮426答卷（其中85.6%来自俄罗斯），俄受访者17.8%已离境、24.5%正准备离境、57.7%留俄且近期不打算离开；2023春非随机问卷参与者中按留俄者+自述离俄者计算，46%海外居住。2023样本商务拓展90%、社区支持72%、中层管理及分析岗位>60%境外，职业结构有偏。
- Boundary: 两轮不是可链接的同一人纵向队列；46%**不是俄罗斯全体开发者的迁移普查比例**；岗位交叠、样本代表性、跨年人员去向不可得；数据不支持“大部分人从创业时就为移民”。

### RCM-08 — Wachs：独立IT开发者样本支持“网络中心人才偏高迁移”

- Source class: S1（研究论文，计算机开发者而非游戏开发者）
- Source: Johannes Wachs, Digital Traces of Brain Drain, version 2, 2023-01-26, https://arxiv.org/abs/2209.01041
- Exact wording: "Developers leaving Russia were significantly more active and central"
- Source fact: 基于事前高度活跃软件开发者位置公开资料，2022年11月俄样本11.1%显示改为其他国家，邻近比较组为2.8%；另有13.2%俄样本隐藏地点，作者发现外流者网络活跃与中心性偏高。
- Boundary: GitHub位置变更 ≠ 实际人口迁移，未公开居留/隐藏信息带来偏差；计算机开发者不等于游戏行业；无法给俄游戏制作人“高端流失”套用这组百分比，也无法仅靠网络中心性证明因果。

## Context–Situation–Action：三个暂可成立的决策链

**A｜K-D LAB 早期国际抱负**：已经具备自制技术及原创类型构思 → 寻找发行/赛事/国际可见性 → Buka国内合作 + Interactive Magic海外发行 + ENIX奖金提供再投资。没有证据证明创业时为了出境。

**B｜Morteshka 业余作者转型**：先有地方游戏业职业经验，想做不常见本土文化作品 → 小型业余开发、低burn和少量专业外围 → 前作收益买下辞职与下一作时间 → Kickstarter + 发行投资扩展。没有数据证明90%来自海外，更没有创业为移民的证据。

**C｜Odd Meter 先有作者项目、后有迁移**：建筑可视化与VR公司 → 2019作者立项、2020已有出版计划 → 2022迁移法人及人员、承认成本 → 2024项目国际发行与坦承有条件回国意愿 → 2026境外投资。不可把后期移民决定投射回2019年初衷。

## Author-Origin 假说及证伪计划

- H1 「国际市场是一种**购买独立决策权与退出选择权**的生产工具」，研究目标不是先声称每个人都想移民；支持证据需前后本人访谈 + 收入/股权/迁移节点。
- H2 「俄罗斯起源的全球化企业可能逐步把IP持有、管理、募资与再生产网络移往境外」，需公司法人与版权归属、雇员人数、真实投资去向；不可把塞浦路斯注册公司比例当成所有俄开发者移民比例。
- H3 「部分俄罗斯创作者更珍视个人题材表达及控制权而非只求安全/盈利」，只能在受访者本人自述与行为一致范围内成立；不能推出民族性格、全行业胜率。
- H4 「索伦兵再生产危机」只是**能力生产地与最终价值捕获地分离**的历史比较提示。索伦营军役调遣和现代自由流动机制不等同；目前未证实俄本土高端原创能力长期趋势与移民强因果。
- Competing explanations：低成本/语言/Steam与全球PC惯例；早期风险资本和发行商业制度；自选择（本就具有国际资源者更易成功也更易迁出）；2022外生冲击；同样全球化却留在本土的俄罗斯/波兰团队；俄国内仍有原创新作。

## 本轮结论的证明边界（供接手者）

已直接支持：1990年代就存在全球市场事业抱负；国内低价正版与外销并行；Morteshka创业前在游戏业有工作经历、低成本试验买到职业自由；Odd Meter2019创作目标先于2022迁移；2022—23样本有显著外迁。

仍是H：俄罗斯人大多为了移民而做国际市场；俄罗斯高端原创能力已经因人才外流结构性衰竭；全球化本身提升原创成功率；俄罗斯比人口更大的国家拥有更高的创业者比例。
