# Signals / 弱信号入口

这里保存**公开安全、但尚不足以进入正式 Evidence Ledger** 的研究线索。

适用对象：

- 口述、转述、圈内传闻；
- 作者记忆但当前无法恢复原始出处的材料；
- 已删除 / 未索引来源的可追踪残影；
- 多个弱来源重复出现、值得提高核验优先级的说法；
- 高时效行业变化的早期信号。

不适用：

- 已有可归属、可追溯来源的正式证据——应进入 `evidence/`；
- 纯粹的作者理论——应进入 Author-Origin / Hypothesis；
- 能识别未授权私人信源的信息——不得进入公开仓库；
- 私人项目材料、私聊原文、合同、截图或保密商业资料。

## Owner 规则

每个 Signal 只在本目录维护一个 `SIG-XXX` 主档。Case / Claim / research note 只能链接，不复制完整 Signal。

模板：[`../../../schemas/signal-template.md`](../../../schemas/signal-template.md)

协议：[`../../../schemas/signal-decision-protocol.md`](../../../schemas/signal-decision-protocol.md)

## 关键边界

> Signal 可以改变“先查什么、是否做低成本试探、是否保留选择权”，但不能改变“什么已经被证明”。

因此 Signal 不直接提高 Case evidence strength，也不单独升级 Claim。
