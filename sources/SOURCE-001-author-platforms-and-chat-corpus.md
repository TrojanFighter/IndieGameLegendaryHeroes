## 5. 游戏史知识的纪录片来源

作者确认：过去形成大量游戏史知识时，**纪录片是主要来源之一**。

这类记忆与材料不得丢弃，但不能简单写成“纪录片说过，所以为事实”。

默认处理：

- 能确认纪录片片名、片段、说话人的，按 `SOURCE-002-documentary-talk-media-protocol.md` 拆分评级；
- 暂时只记得“来自某纪录片”的，先记为 **A0-SOURCE-MEMORY**；
- 优先寻找纪录片中出现的开发者本人、原始采访、GDC / Gamescom 演讲、postmortem、同期媒体报道；
- 纪录片中的当事人直接证词与导演旁白必须分开；
- 对产业转折、工作室冲突、销量 / 预算 / 人数等硬事实，尽量找到同时代的 P0 / P1 / S1 交叉核验。

详见：[`SOURCE-002-documentary-talk-media-protocol.md`](SOURCE-002-documentary-talk-media-protocol.md)。

## 6. ChatGPT 历史对话

作者授权：仅讨论公开行业资料的历史对话可提供行业研究线索；私人项目对话、文件及其摘要不得导入。

证据等级：**A0-CHAT**。

允许进入：

- 独立游戏生产条件、runway、scope、能力资本、OPC / solo；
- 中国游戏行业组织结构与“老中”分析；
- 平台、资本、发行、市场接入与生产认知；
- 俄罗斯 / 乌克兰 / 白俄罗斯 / 斯拉夫游戏产业与作品讨论；
- 公开或通用的方法论、游戏设计、工程和行业判断。

明确排除：

- 私人项目的名称、玩法、叙事、世界观与专有生产资料；
- 未公开发行谈判、合同条件、融资细节、预算与商业策略；
- 非公开团队成员、合作伙伴或个人敏感信息；
- 与本研究无关的私人生活信息。

历史 ChatGPT 中的模型回答只能用于找回问题、假说和线索，**不能作为事实证据**。其中出现的外部事实必须重新找到 P0/P1/S1 来源。

## 7. Provenance rule

任何从作者历史语料恢复出的命题，落库时都应尽量标注：

- 原始平台；
- 原始日期；
- 原始标题 / 对话主题；
- 当时表述；
- 属于 2023 汇编母本还是后续增量；
- 当时主要知识来源（如已知为某纪录片 / 演讲，应记录）；
- 2026 年是否修正；
- 外部证据状态。

目标不是制造一个永远正确的作者，而是留下**观点如何形成、从哪里获得材料、又如何被事实纠正**的生产史。
