# David Wehle：留着全职工作，完成《The First Tree》

© 2026 洪荒行者。All Rights Reserved.

2016 年，David Wehle 在美国犹他州的 The VOID 担任技术美术，已经成为父亲，还在制作个人游戏《The First Tree》。全职工作与育儿之外，留给游戏的时间有限。

他在当年7月的开发笔记里把取舍说得很清楚：作品要短、简单，利用现成工具、授权素材和脚本，把精力放在自己更擅长的环境设计、故事与玩家体验上。他承认自己的编程能力有限，也没有打算先补齐大型游戏所需的全部技术与美术能力。

后来完成的作品让玩家操纵一只狐狸，在场景之间旅行，逐渐听到关于家庭、失去与记忆的故事。理解这款游戏为什么长成这样，需要往前看：在这只狐狸出现以前，Wehle 已经做过视觉与互动工作，也完整做过另一款游戏。

## 在这只狐狸出现以前，他已经做过一款游戏

Wehle 接受过 Media Arts 教育，做过视频、剪辑、调色、交互与视觉设计工作。转向 Unity 和技术美术时，他已经熟悉怎样通过画面、运动和交互组织体验；但把这些经验变成一款能发售的游戏，仍需要实际练习。

《Home is Where One Starts…》承担了这段练习。按他的个人项目记录，这款短篇第一人称探索游戏起初有学习 Unity 与 Maya 的目的，耗费约两年，最终进入 Steam。该项目页面可能经过后续编辑，不能把页面日期当作全部回忆的写作时点。

到了2015年，他已经在公开文章里复盘 Greenlight，并讨论 Steam 准入和发现作品的条件如何变化。第一款游戏带来的经验因此包括两部分：完成作品，以及面对作品完成后仍然难以被看见的市场。2017年的发售复盘还记录，前作收入参与了《The First Tree》的制作，具体金额尚未核清。

这段前史改变了第二款作品的起点。工具学习、正式出货和市场接入都已有一次经验，Wehle 可以在下一作中更明确地决定哪些工作要自己承担，哪些交给已有工具和素材。

## 把环境与叙事留在作品中心

《The First Tree》的探索把环境构图、色彩、声音与故事放在前面。Wehle 的视觉与互动经验能够直接作用于这些部分，2016年的笔记也明确把环境设计、叙事与用户体验列为自己愿意发挥的强项。

他用购买或授权的素材、脚本减少需要从头制作的内容，让短而简单的作品范围配合这种能力分布。这里的作者性仍然存在：选择哪些材料，怎样组织空间与流程，何时让玩家看见或听见什么，都是作品的创作决定。承认外部材料的贡献，才能准确看清他自己完成了哪些工作。

这种取舍也有代价。作品必须让有限的探索、环境和叙事承担体验，不能指望不断增加系统来解决所有问题。让已有强项成为核心，是这款游戏的组织方式，并不保证同样的范围选择会让另一款游戏成立。

## 低成本没有消除生活约束

2019年在 GDC 回顾这段开发时，Wehle 提到在 The VOID 每周工作四十多个小时，同时抚养两个孩子。这是发售后的回顾；2016年的同期笔记只确认他已成为父亲，不能把两个孩子的情况直接倒写到整个开发期。

全职工作保留了工资与职业关系，也占用了制作游戏的时间。购买素材、减少需要自己生产的内容，因而同时涉及现金和时间：省下的制作劳动，可以让他把有限注意力留给作品中更依赖本人判断的部分。

工资使游戏销量不必成为当时唯一的生活来源，却不能据此算出这个家庭能承受多大风险。伴侣收入、照料分工、住房、医疗与家庭支出仍然未知；育儿责任也不能写成由他独力承担。能够确认的是，他保留了全职职业，又压低作品的制作负担，两项选择共同构成了这次个人项目的边界。

## 一张漂亮的 GIF 不是商业计划

狐狸、森林与鲜明色彩，让《The First Tree》在发售以前就能以短画面向外展示。Wehle持续分享视觉素材，在Reddit、Imgur、Tumblr和Twitter积累受众。他2017年的发售复盘还谈到预告片、PAX、媒体接触、商店呈现、本地化、定价与发售时机；一张广泛传播的GIF只是这份市场工作中的一部分。

作品与展示在这里共用了一套视觉能力。环境、色彩和构图既进入玩家体验，也让未玩过的人较快看懂作品，Wehle可以用游戏本身的画面接触潜在玩家。作者看重这种连接：让有辨识度的生产强项，也成为外界理解产品的入口；其他品类未必能以同样成本做到。

传播仍有他无法掌握的部分。一次帖子被大量分享，不保证下一次同样有效，也不能单独说明后来有多少销售来自它。2016–2017年的社媒信息流与Steam Direct初期，是这次尝试的具体条件；到2026年，渠道、排名和发现机制都须重新核验，不能把“每天发几张GIF”作为从这段历史拿走的配方。

## 发售不是制作工作的尽头

2017年9月，作品在PC发售。后来的主机版本涉及另一组平台与性能工作。DO Games的项目记录列出2018年11月的主机发行，明确记载自己承担Xbox One、Switch和PS4的移植与性能优化；具体合同、人数与每项任务分工仍未公开到足以核算的程度。

Wehle早期用授权素材和脚本降低个人制作负担，扩展平台时又有专业合作方参与。**作者核心很小，交付边界却大于作者本人。** 这些劳动应当进入贡献记录，也应当进入对成本的理解：完成个人PC项目，与独自承担所有资产和后续平台交付，是不同的工作量。用“一人开发”遮住它们，会让读者低估这款游戏实际调用的专业能力。

## 他到底赚了多少，值不值？

Wehle保留了全职工作，完成个人作品，并通过合作把游戏交付到更多平台。这些经历说明尝试怎样被组织起来，却还不能告诉我们，投入的业余时间换回多少净收入，与其他职业选择相比是否值得。

真实工时、税后收入、授权与合同成本、家庭支出、长期销售、平台分成和后续职业发展，仍缺完整记录。若要引用2019年GDC回顾里的成本、工时或收入数字，也须取得原始讲述或幻灯片逐项核口径，不能当作已经审计的财务报表。**完整出货与财务回报是两个问题。** 工资、短范围和外部协作让我们看见生产安排，不能替缺失的生活账本作答。

## 作品完成了，生活账本仍未齐全

Wehle 把视觉与互动经历用于个人作品，通过前作练习出货，再以较短的范围、授权素材和后来的专业移植合作完成《The First Tree》的不同阶段。他保留的全职工作既支持这次尝试，也持续限制他能投入的时间。

这段经历留下的判断，比模仿狐狸与彩色森林更有用：作品怎样安排，才能让作者已有的能力进入玩家体验，同时把需要亲自承担的劳动压到生活容得下的范围？这是作者对其路径的归纳，不是 Wehle 已为所有后来者算好的答案，更不能用来承诺收入或无损回撤。

家庭支持和财务账本的空缺仍需留下。**生命时间从来不属于游戏项目一个人**，作品完成也不能替我们回答，围绕它的每一个人付出了多少。

## 人生岔路、不可复制条件与研究回链

**可核时间线：** BYU Media Arts 与视频/交互职业前史 → 约两年制作并发售《Home is Where One Starts…》 → 在 The VOID 做 Unity technical artist，同时为父亲 → 2016 年以短流程、环境叙事和外部资产组织《The First Tree》 → 2017 PC 发行与持续视觉市场接入 → 2018 年由专业合作方参与主机移植 → 2019 GDC 回顾。

**2016–2018 条件：** Unity Asset Store 和授权素材市场、Steam Direct 初期、Reddit/Imgur/Tumblr/Twitter 的视觉传播机会。能迁移到 2026 的是能力—项目匹配、用外部化弱项降低时间成本、让产品天然形成可传播的外部展示素材；历史传播渠道和销售窗口不可照抄。

**UNKNOWN：** 准确净收入、家庭收入与伴侣分工、抚养责任的日常安排、房屋和医疗支出、完整授权素材采购额、全部贡献者工时、平台和发行分成、console 合作合同条款。任何“用一年业余时间必赚多少钱”的说法都缺乏证据。
