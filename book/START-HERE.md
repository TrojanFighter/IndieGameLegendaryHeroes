## 我喜欢游戏、技术、写作或别的东西，但不知道这算不算“正事”

先读：

- [early id / DOOM](profiles/early-id-doom.md)
- [Gunpoint / Tom Francis](profiles/gunpoint.md)

**兴趣怎样转成能被检验的作品？** 下面是一条可能的路径：

```text
喜欢
→ 比较
→ 拆解
→ 修改
→ 做出东西
→ 给陌生人看
→ 被现实反馈
→ 再修改
```

爱好可以只是娱乐。若开始比较、拆解和制作，再拿作品接受外部反馈，它就可能逐渐带来能力、作品集、判断力、合作者或职业入口；这条转换并不保证成功。

## 我喜欢游戏，但家里不让我玩，也不相信做游戏是正经工作

可以从这几段经历读起：

- [early id / DOOM：Romero 的家庭冲突、继父买电脑与职业形成](profiles/early-id-doom.md)；
- [第一章：目标不是先想清楚的](chapters/01-goals-are-made-not-found.md)。
- [梁其伟与《雨血》](research-notes/family-gate-china-near-miss-liang-qiwei-030.md) — 母亲保存了留存的童年画稿；2007年挂科、失去保研资格后，家庭压力又使制作暂停一年，2008年重新开工。研究也保留部分早年画作被毁的经历。

有些家庭反对的是**玩游戏占用学习时间**，却欢迎学习编程、画画和写作；有些家庭允许游戏和作品，但不愿让你承担无保障的职业风险；也有家庭不理解，却尊重成年人的选择。它们对应完全不同的问题，不能只归结为“家长不支持”。

能否接触作品、亲自动手、公开获得反馈，以及成年后能否选择职业，需要分别看。和家人发生冲突，不能证明作品会成功；准备转行时，工资、存款、住所、照护和再就业退路仍要算清楚。成年人仍有权决定自己的生活，即使作品没有成功、家人也未认可。

想进一步研究家庭控制如何让一部分潜在创作者**还没入行便从样本里消失**，进入 [中美代际与家庭门控研究](research-notes/family-gates-game-creator-us-china-029.md)。那里也保留支持/失败的反例和历史时效限制。

## 家人后来终于认可了我的选择，过去的冲突就算结束了吗？

[early id人物传记](profiles/early-id-doom.md) 保留了一条家庭变化线。按Kushner多年后写成的《DOOM启世录》，Romero的继父曾因他玩街机施暴；到1993年前后，在游戏事业已有成绩时，继父承认早年的职业判断错了，1999年又在外界争论中维护他的作品。Carmack母亲后来也会玩《Commander Keen》。这些是书中记述，不能当作同期录音。

**职业判断的道歉，不等于过去的伤害已经获得完整道歉。** Romero在2025年采访中说，自己会和孩子一起玩游戏、采用不同的养育方式；这是他的自述，也不能代替孩子对关系的评价。想沿这条线继续读，可看[家庭代际和解研究032](research-notes/doom-intergenerational-reconciliation-032.md)，其中梁其伟的对照只记录已知态度变化，没有补写最终和解。

另外两条路径没有这样的结尾：2011年Croshaw已有游戏评论声望，却说父母仍不认可他的工作；Keith Judge得到配偶工资与储蓄支持，独立项目仍未完成，后来回到专业就业。两例见[研究035](research-notes/family-acceptance-non-success-countercases-035.md)。认可、实际出资和作品完成，会各自发生变化。

李远扬2017年说，家人从管束他玩游戏，转而支持他制作游戏。到2019年，《纽扣兄弟》经历数次发行仍未回本，他说家里没有施加太大压力。这里的家庭态度由他转述，不能写成家属共同受访的结论，也没有证据说明他们承诺无限填补亏损。详见[《项目没有回本，家人也没有收回尊重》036](research-notes/family-support-after-commercial-failure-li-yuanyang-berardi-036.md)。

美国开发者Gianfranco Berardi则在2010年辞职，约2012年恢复受雇工作。2013年写反思时，他转述妻子对那两年尝试的肯定。到首次全职独立十五年后的2025年，他仍未能第二次全职独立，却继续兼职开发、发售小作品，每年为自己的游戏留出一天“Indie Day”。重返工作以后，创作并没有从生活里消失；2013年的配偶支持也不能自动延伸为2025年同意再次辞职。

新加坡Joysteak的认可变化发生得更早。制作人2019年6月说，父母看见他与伙伴长期在家工作，逐渐支持制作；当时已有专业奖项和发行合作，游戏尚未正式发售。发售后工资仍不足的说法，目前仅见2019年9月采访的搜索索引摘录，正文尚未完整读取，不能据此判断后来的总收入。Joysteak与Berardi的后续详见[研究037](research-notes/family-legitimacy-visible-labor-and-fifteen-year-exit-037.md)。这些公开经历让人看见获准创作、承担账单和继续谋生的不同安排，不能回答多少家庭会如此选择。

先读跨人物章节：

## 我没有很多钱，甚至必须一边活着一边做

先读跨人物章节：

- [先买几个月试错](chapters/02-buy-time-before-betting-your-life.md)

再读人物全文：

- [Kenshi](profiles/kenshi.md)
- [Rocket League](profiles/rocket-league.md)
- [FTL](profiles/ftl.md)

三条路线完全不同：

- Chris Hunt 用夜班工资购买个人开发时间；
- Psyonix 为其他工作室承接合同，支付公司账单并保留一部分原创制作；
- FTL 两位创作者先用储蓄购买一个有限实验窗口。

工资、客户合同和储蓄，给三者提供了不同的生存安排。比较这些故事时，要问清楚：**谁在支付继续试错的时间，能付多久？** 玩家收入也可能在后续改变这个安排，只问有没有一次融资，无法说明项目怎样持续。

## 我已经失败很多次了，是不是说明我不适合做这件事

先读跨人物章节：

- [失败不是资产：只有留下下一次还能使用的东西，失败才开始值钱](chapters/03-failure-only-matters-if-something-survives.md)

再读人物全文：

- [Bills Must Be Paid](profiles/bills-must-be-paid.md)
- [Rocket League](profiles/rocket-league.md)
- [Josh Parnell / Limit Theory](profiles/josh-parnell-limit-theory.md) — 项目取消不等于能力消失，也不能将技术残值当作交付。
- [Question / The Magic Circle → The Blackout Club](profiles/question-magic-circle-blackout-club.md) — 首作销售不够，工作室却没有消失；下一作为什么改变市场入口。

**失败以后留下了什么，下一次还能不能使用？** 可以检查：

- 更快的制作能力；
- 一个工具；
- 一段代码；
- 对某个平台的知识；
- 对某种用户反应的判断；
- 一个以后还能重新做的问题；
- 也可能什么都没留下。

据Rike团队复盘，《Bills Must Be Paid》本作制作约七个月；两人从2019年开始的约七年共同实践，还包括原型、未成功的作品、发行商合同与平台学习。把这些经历放回去，才能区分本作制作时间和能力积累时间。《Rocket League》的团队则早在2008年就发售过“汽车踢球”的前作；第一次没有得到后来的商业结果，玩法与团队学习仍进入了后续迭代。这些前史有可使用的部分，不等于每次失败都会留下资产，更不能保证下一作成功。

这些毕竟都是后来被媒体看见的人物。想看没有成名、只做过小作品的公开经验，还可以阅读 [Week Sauce 2022.04 的18个普通参赛项目](research-notes/public-unfeatured-week-sauce-apr-2022-cohort-031.md)，以及 [2026年18个投稿账号的公开后续回访](research-notes/week-sauce-2022-public-creator-followup-033.md)：有人仅做了两天，有人因生活事务来不及改 Bug，有人明确不知道会不会继续，有人后来真的做出了更完整版本。**这18个项目不是独立游戏行业成功率的统计分母。**

## 我总觉得别人有了新技术就无所不能，而自己是不是已经晚了

先读跨人物章节：

- [技术时代不会替你做选择：有人用现成工具，有人重组平台，有人自己造出窗口](chapters/04-technology-will-not-choose-for-you.md)

再深入：

- [early id / DOOM](profiles/early-id-doom.md)
- [Gunpoint / Tom Francis](profiles/gunpoint.md)
- [PLAYERUNKNOWN / Brendan Greene 研究档案](../cases/CASE-032-pubg-brendan-greene.md)
- [工业革命比较实验室](../cross-industry/industrial-revolutions/README.md)

回顾early id时，Carmack谈到团队一边推进渲染与引擎技术，一边围绕实际做到的能力重新设计游戏；想要的体验也会反过来推动技术。DOOM的技术窗口有他们主动创造的部分。读到这里，可以区分三种技术位置：

- 有人继承已经扩散的工具；
- 有人把已有技术重新组合成新用途；
- 有人自己把技术边界向前推，给团队创造新窗口。

判断自己是否错过机会时，可以问：**它具体把什么变便宜了？谁真正能用？谁看见了新的可能？谁甚至亲手创造了那个可能？**

先读：[第一次成功以后：钱可以买时间，也会把新的工作交给你](chapters/07-success-buys-the-next-question.md)。

- [thatgamecompany](../cases/CASE-057-thatgamecompany-vc-equity-expansion.md) — 股权融资支持扩充开发与自发行能力；投资者加入董事会，后续筹资也占用创始人的制作时间，具体条款仍需另核；
- [Zachtronics](../cases/CASE-051-zachtronics.md) + [Spiderweb Software](../cases/CASE-058-spiderweb-fit-lock-in.md) — 工具、品牌与受众长期积累以后，改做不同游戏的成本会怎样变化。


先读：

- [early id / DOOM](profiles/early-id-doom.md)
- [Rocket League](profiles/rocket-league.md)

成功后的钱与选择权可以用来维持小规模、扩大组织，也可以为不同作品留出探索时间；扩张还可能提高固定成本和协调要求。early id从DOOM走到Quake，技术与商业成绩没有替团队解决下一阶段的协调问题。读这些后续人生，仍要问：**我们以后究竟要成为什么，要为此承担哪些新的成本？**

# 读过这些经历，可以留下的八个判断

1. **目标常常是做出来的，不是先想出来的。**
2. **兴趣只有发生转换，才会变成能力资本。**
3. **活下来本身是一项生产策略。**
4. **失败值不值钱，要看它有没有留下下一次还能使用的东西。**
5. **技术既可以被继承，也可以被重组，甚至可以被创作者自己向前推进。**
6. **市场不是最后一步；它可能很早就开始提供钱、反馈、误导和约束。**
7. **任何成功经验都有年份；机制可能耐久，具体平台打法会过期。**
8. **成功不是证明你找到了终极答案，而是给你换了一套更难的问题。**

## 关于“能不能照着做”

读到一种做法时，还要分清：哪些机制可能在别处成立，哪些条件只属于当事人，哪里有运气，哪些事实仍不知道。这些经历不能保证回报；比较的用处，是让人在承担几年真实人生之前，多看见一些代价和选择：

> **别人当年到底付了什么、拥有什么、错了什么，又在哪一步获得了继续下注的资格。**
