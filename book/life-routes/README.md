# Life Risk Routes

这里不是“成功方法”。

如果尚不确定自己的真实处境和首要瓶颈，请先使用 [作者型项目决策总分诊](../DECISION-ROUTER.md)；本目录只承接已经明确的人生路径问题。

每条 Route 面向一种现实处境，把 Case / Evidence / Creator Life Audit 压成一个可执行的决策界面：

```text
我的处境
→ 最大错配风险
→ 最小现实实验
→ 什么时候值得加承诺
→ 什么时候必须停
→ 哪些英雄案例与我相似
→ 哪些失败案例专门反驳我
```

## 使用规则

- Route 只迁移机制，不复制年代打法。
- 不给固定成功率。
- 不把单一成功案例写成普遍建议。
- household / runway / exit option 必须单独核算。
- 每条 Route 至少绑定一个成功案例和一个失败/混合压力。
- 有新 Case 推翻 Route 时，优先修改 Route，而不是替旧结论找借口。
