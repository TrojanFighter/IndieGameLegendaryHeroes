# 《植物大战僵尸杂交版》：UGC 如何从长期玩家创作变成公共作品、传播网络与职业入口

- Status: RESEARCH INTAKE / HIGH PRIORITY CHINA UGC CASE
- Subject: 潜艇伟伟迷 / 《植物大战僵尸杂交版》
- Period: 早期 PVZ 改版实践 → 2024 爆发 → 官方创意模式吸收 → 2025–2026 重制/原创转型
- Current case status: **尚未编号**。先补协作者、技术实现、IP/授权和版本时间线，再决定是否升正式 Case。
- Related themes: `player → producer`, UGC/mod ecosystems, goal formation, capability-project fit, community co-production, market access, China good-student syndrome（仅作为待检验对照，禁止因果化）

## 为什么值得研究

《植物大战僵尸杂交版》不是一个“国产独立买断游戏爆款”。

它更适合被研究为：

> **一个长期围绕同一商业游戏做视频、改版和规则想象的玩家作者，怎样把多年非正式能力积累压进一个可玩 fan game；作品又怎样通过 Bilibili/抖音/贴吧/粉丝群的内容循环爆发，继而被原 IP 的本土官方运营吸收到创意模式，并进一步催生团队化重制和原创项目。**

它和 CASE-021 Roblox creator cluster、CASE-032 PUBG lineage、CASE-016 DOOM mod ecology 一起，可以帮助本书回答：

> 游戏生态是否能形成一套“先做作品，再获得资格”的替代学习/职业系统？

但这里必须保留一个更强边界：

> **《杂交版》的巨大认知基础来自《Plants vs. Zombies》现成 IP、资产语言与玩家共同记忆；它不能直接被当作“原创 IP 的低成本市场成功”迁移。**

---

## 1. 创作者前史：不是 2024 年突然出现

2024 年游研社对“潜艇伟伟迷”的采访提供了一条目前最有价值的 creator-side 生产史。

作者自己把《杂交版》描述成“以前所有作品的一个大集成”：多年围绕 PVZ 做设计、改动与视频后，过去积累的植物点子终于可以装进一个完整改版。

这意味着正式可玩版本的开发期不能等同于能力形成期。

需要继续重建：

- 最早开始玩 PVZ 的时间；
- 最早公开视频 / 自制植物设计；
- 各阶段 Bilibili 账号和粉丝增长；
- 哪些玩法先以视频概念存在，哪些先进入可玩改版；
- 何时开始和程序协作者合作；
- 2024-03 左右“完整杂交版”首发的准确 P0 时间线。

### 教育 / 人生路径

2024 年公开报道转述创作者本人经历：来自湖北咸宁，00 后，约 15 岁后因身体与心理健康原因离开标准学校路径，长期在家创作。

这个信息对本书的“目标形成”主题很重要，但**必须禁止浪漫化**：

- 辍学不是成功原因；
- 健康困境不是创作优势；
- 不能写成“学校无用”；
- 不能把一个幸存者案例当成教育建议。

真正值得问的是：

> **当标准教育/职业路径中断以后，他通过什么活动重新形成了学习 agenda、作品反馈、身份和未来预期？**

公开回答是：围绕自己真正长期感兴趣的 PVZ，持续设计、改版、视频化、测试和吸收玩家反馈。

这可以作为 `AC-008 中国好学生综合征` 的反压力/对照对象，但不是其因果证明。

## 2. 立项不是“从零想一个塔防游戏”，而是重组共享语法

《杂交版》最强的机制发明非常容易解释：

> **把两个或更多玩家已经熟悉的植物能力组合在一个新单位里。**

例如：

- 豌豆 + 向日葵；
- 阳光 + 土豆雷；
- 经典单位的视觉、名字、能力互相组合；
- 熟悉僵尸被重新命名、强化或混搭。

官方站点 2026 仍然把产品定义为：在经典 PVZ 核心体验上，通过“杂交”机制重新组合植物能力，让熟悉阵容产生新战术。

这里出现了至少四层生产杠杆。

### A. Representation Borrowing / 表现借力

玩家已经知道：

- 豌豆射手是什么；
- 向日葵是什么；
- 土豆雷是什么；
- 铁桶、撑杆、冰车等视觉语法是什么。

所以一个新单位不需要从零教育。

### B. Combinatorial Design / 组合式设计

作者不需要为每个新植物创造全新的系统范式，只需要问：

> **两个熟悉能力放在一起，会产生什么新的资源/空间/节奏问题？**

这让有限设计与程序能力获得很高内容增殖率。

### C. Meme Legibility / 梗式可读性

“豌豆向日葵”“冰车二爷”这类东西在一张图、一句标题或几秒视频中就能被老玩家理解。

这是典型的：

> **production shortcut + marketing hook = double dividend**

### D. Fan-IP Leverage / 粉丝 IP 杠杆

这也是最不可迁移的部分。

它节省的不是普通资产成本，而是借用了十五年玩家共同记忆、角色认知和原作传播资本。

所以它必须和原创独立游戏分开归类。

## 3. 协作者边界：不能再写成“一个 UP 主独立开发全部”

游研社 2024 采访明确指出：

- 早期朋友“小小咩MS”承担杂交版代码工作，让潜艇伟伟迷可以集中于植物设计与数值；
- 关卡平衡和视频录制由伟伟迷大量亲自完成，他回忆一个视频常需录几十遍，有时超过 200 遍；
- 爆火后团队又增加至少两个人：一人承担画图/素材，一人承担测试以及玩家反馈接收/管理。

因此，早期 production model 更接近：

```text
潜艇伟伟迷：创意 / 植物设计 / 数值 / 关卡 / 视频 / community-facing
        +
小小咩MS：早期程序实现
        +
后续美术 / 测试 / feedback management
```

而不是单纯 solo dev。

到 2026 年，全新引擎重制版官方站点已直接列出三名主要角色：

- 潜艇伟伟迷 — 总策划；
- 虚无今天摸鱼 — 开发者；
- 一只吴铭仕哒 — 美术。

这说明项目后来进一步从“作者 + 朋友”演化成小型明确分工团队。

仍需补：

- 小小咩MS 参与的准确版本区间；
- 原始版本使用何种技术/框架/改版工具；
- 新引擎重制何时开始、具体引擎与代码重写范围；
- QA、网站、服务器、移动端、社区系统的完整 contributor perimeter。

## 4. 视频不是“开发完成后的营销”，而是生产系统的一部分

这是本案最值得和普通游戏营销区分的地方。

潜艇伟伟迷长期把：

> **设计一个新植物 / 新机制 → 录成视频 → 玩家评论 → 再修改 / 再选择新点子**

本身当作日常创作循环。

游研社采访明确写到：制作改版的过程本身就是其视频素材。

这意味着：

- prototype 是内容；
- devlog 是娱乐视频；
- 娱乐视频又是用户测试入口；
- 用户评论再成为设计资料。

形成：

```text
idea
↓
playable implementation
↓
video demonstration
↓
Bilibili audience
↓
comments / fan groups / memes
↓
selection + balancing + new ideas
↓
next playable artifact
```

这是一种很强的 **Distribution-through-Demonstration / 演示即分发**。

传统营销常要求玩家先理解：“这个游戏是什么？”

而杂交植物只要出现在缩略图或几秒 GIF/视频里，已有 PVZ 玩家就能立即完成理解。

## 5. Community Co-production / 玩家并不只是流量

游研社采访还记录：

- 玩家长期呼吁某些早已设计的植物进入正式杂交版；
- 图鉴里的搞怪描述会从评论区、粉丝群收集和筛选；
- 爆火后团队专门增加成员管理测试与玩家反馈。

因此社区至少承担四种生产功能：

1. idea pool；
2. demand signal；
3. QA / balance feedback；
4. meme / copy / cultural elaboration。

这不是“完全由玩家设计游戏”。

更准确是：

> **作者保持 selection authority，但把社区转成一个高频、低成本的外围研发网络。**

这一点可以和 DOOM WAD、Roblox、Landfall community interaction、Jonas public prototyping 等案例比较。

## 6. 传播链：不是一个视频凭空爆

截至目前，可重建的 2024 爆发链大致是：

### Phase A — 长期同好积累

- PVZ 老游戏拥有巨大中文玩家记忆；
- 贴吧/民间改版长期存在；
- 创作者自己多年做植物点子、视频和改版；
- 粉丝逐渐要求把零散点子整合成完整改版。

### Phase B — 完整可玩版本 + 高频可视化内容

杂交机制极适合：

- Bilibili thumbnail；
- 短视频；
- “这个离谱组合会发生什么”的 click curiosity；
- 主播挑战；
- 玩家二次传播。

### Phase C — 2024 春夏右尾爆发

游研社 2024-06 报道给出的时点数据：

- Bilibili 粉丝约 373 万，其中 300 多万约在此前三个月新增；
- 2024-06-01《感谢大家对植物大战僵尸杂交版的支持》当时约 1,625 万播放；
- 抖音 `#植物大战僵尸杂交版#` 相关视频播放量当时超过 44 亿。

到 2026 年，Bilibili 页面上该 6 月 1 日视频已经超过 2,290 万播放，作者账号约 500 万级关注。

这里必须记录**时间口径**，不能把后来的累计量倒写成 2024 爆发当天已有。

### Phase D — 平台/媒体再放大

- 大量主播和二创作者继续做挑战、攻略和恶搞内容；
- 微博、小红书、虎扑、贴吧等扩散；
- 大量媒体/纪录片式采访把“作者人生故事”也变成内容；
- 传播从“游戏机制很离谱”扩展到“一个非标准年轻创作者突然找到人生路径”的人物叙事。

### Phase E — Official Absorption / 官方吸纳

2024-06，《植物大战僵尸》官方 Bilibili 账号宣布第三方《杂交版》内容进入小程序版本创意模式，并表示后续会继续收集玩家意见，与杂交版团队更新更多玩法。

这不是“EA 把整个同人项目收购”或“杂交版变成官方正统续作”。

必须精确写成：

> **原 IP 的本土官方运营把部分第三方杂交玩法吸收到官方创意模式，并与作者团队发生合作。**

2026 年杂交版自己的网站仍明确声明：本站与 Electronic Arts 无隶属关系。

### Phase F — Team / Infrastructure / Original-IP Transition

2025–2026，项目出现：

- 新引擎重制；
- 自有官网；
- 玩家关卡社区；
- 更明确团队分工；
- 作者进一步尝试原创游戏。

这最后一段尤其值得持续跟踪：

> **一个依附商业 IP 的超级同人作者，能否把 fan-IP audience、制作能力和社区资本迁移到自己拥有权利的原创作品？**

这是整个案例未来最有价值的“第二幕”。

## 7. 和“中国好学生综合征”的关系：只能作为对照，不得写成功因果

潜艇伟伟迷的人生经历很容易被写成反教育传奇：

> “没继续读书 → 在家打游戏 → 爆火 → 所以学校没用。”

本项目必须拒绝这种写法。

真正值得研究的是另一条链：

```text
标准教育路径中断
↓
长期稳定兴趣对象
↓
反复做具体东西
↓
学习被具体问题牵引
↓
公开发布
↓
真实玩家反馈
↓
能力与声誉积累
↓
作品 / 团队 / 职业机会
```

它与 AC-008 的关系是：

> **这里出现了一种没有考试大纲的学习制度。**

作者必须自己决定：

- 今天设计什么；
- 哪个点子值得做；
- 怎样平衡；
- 视频怎样展示；
- 玩家到底喜欢什么；
- 什么时候需要找程序、美术、测试协作者。

但这只证明“非正式作品反馈可以形成能力”，不证明“退出学校更优”。

## 8. 与独立游戏运动的关系

《杂交版》不适合被简单收编成“国产 indie hero”。

原因：

- 使用商业 IP；
- 大量依赖原作视觉/规则/认知资本；
- 免费同人作品的经济结构与原创 premium game 不同；
- 官方授权/容忍/合作边界需要持续核实。

但它非常适合进入本书更宽的：

> **independent-production / player-to-producer lineage**

因为它展示：

- 一个玩家如何通过 fan work 获得生产能力；
- 如何在正式公司职位之外获得巨大真实用户；
- creator platforms 如何让游戏制作、视频传播、用户反馈和职业声誉合并；
- 商业 IP 公司如何反向吸收民间创新。

所以未来若升正式 Case，应显式标记为：

`UGC / FAN-PRODUCTION LINEAGE CASE`

而不是 core independent original-IP case。

## 9. 当前可提炼的概念

### Remix Leverage / 重组杠杆

用已知对象的组合制造新体验，而不是从零生产全部语法。

### Representation Borrowing / 表现借力

借用原 IP 已完成的角色认知、视觉词汇和玩家教育。

### Distribution-through-Demonstration / 演示即分发

游戏机制天然适合被短视频展示，开发演示本身就是传播产品。

### Audience Co-production / 受众共同生产

社区承担 idea/demand/QA/copy/meme 等外围功能，但 selection authority 仍在核心作者。

### Official Absorption / 官方吸纳

商业 IP 持有/运营体系看到社区创新后，把部分玩法或作者吸进官方生态。

### Fan-capital → Original-IP test / 粉丝资本向原创 IP 的迁移测试

作者能否把“喜欢 PVZ 的 500 万人”中的一部分，转化为“愿意跟随这个作者做原创作品的人”？

这将决定杂交版是一次巨大 fan-work right-tail，还是长期作者/工作室形成的前身。

## 11. Open Questions before formal Case promotion

1. 2024 完整版首发的 P0 日期与版本归档；
2. 更早期公开视频、概念植物和改版时间线；
3. 小小咩MS 的准确 contributor role、代码范围和参与时间；
4. 原版本实际技术栈、工具与对原作代码/资产的依赖方式；
5. 新引擎重制的工程重写范围、团队规模和时间；
6. 下载量、活跃用户和地域分布有无可信平台数据；
7. Bilibili 推荐、UP 主互推、抖音搬运/二创、媒体采访各自在传播中的先后与作用；
8. 与 PVZ 官方/PopCap/EA 的授权、许可、合作主体和边界；
9. 免费同人项目的收入来源：商单、平台激励、直播、赞助、团队成本如何运作；
10. 2026 原创项目是否能迁移 fan-IP audience；
11. 玩家创作社区是否形成“作者→玩家作者”的二级生产链；
12. 爆火后团队扩张是否改变了最初高频视频—反馈 loop。

## Preliminary Verdict

> 《植物大战僵尸杂交版》最值得研究的，不是“一个辍学少年靠魔改爆火”，而是**长期玩家知识、已有 IP 语法、低门槛改版、视频内容生产、社区共同创作和 creator-platform 分发怎样形成一个完整的非正式研发系统；当它取得巨大 public proof 后，官方组织与更正式的小团队结构才开始跟上。**

这使它成为中国语境下极强的 `player → producer → public creator → team / official ecosystem` 候选案例，同时也迫使本书保留一个边界：**独立生产能力可以在商业 IP 内生长，但 IP ownership 与原创商业可迁移性必须另外审计。**
