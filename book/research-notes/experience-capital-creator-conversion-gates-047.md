## 0. 这篇新增什么，不新增什么

[中国 019](../../country-studies/china/019-taste-institutions-player-literacy-creator-selection.md)已经把社会鉴赏基础设施拆为 ACCESS / INTERPRETATION / LEGITIMATION / PRACTICE / TRANSACTION / MEMORY，也已提出 `TASTE-TO-CREATION CONVERSION`。

本篇不再重建那六层**社会基础设施**。本篇只回答一个更贴近传记的问题：

> **同样具备游戏阅历的人，究竟如何跨过一连串“玩家 → 能完成并持续生产作品的人”的个人关口？为什么有些人在某一关永久停下？**

不能把“玩得多”“批评得对”“知道一个好点子”“做出原型”“卖出产品”“能做第二作”压成单一的“会做游戏”。

## 1. 七道 Gate：每道都需要不同的能力或资源

| Gate | 可观察的转换 | 最小证据 | 常见失败/盲点 |
|---|---|---|---|
| G0 `ACCESS` | 接触足够多类型与不同版本作品 | 可核游戏阅历、资料来源、语言/设备入口 | 只看到高度筛选的局部市场；但广泛玩游戏并非成功充分条件 |
| G1 `DISCRIMINATION` | 从“喜欢”变成对机制与体验差异的判断 | 同期评论、具体设计批评、和原型母本的比较 | 仅有偏好强烈程度，缺少解释力 |
| G2 `THESIS / ABSTRACTION` | 抽出一个值得制作且可测试的体验假说 | 清晰规则提案、mod 方案、可执行 design sketch | 只会写行业规格书或复制表面形式 |
| G3 `FIRST ARTIFACT` | 原型、mod、jam、可玩作品 | 仓库/上传/演示、原型时间线 | 技术、时间、家长/职业许可、协作与工具不匹配 |
| G4 `FEEDBACK & REVISION` | 用真实测试反驳或修订假说 | 版本迭代、测试者反馈与变更记录 | 原型被关在私人文档/朋友赞美里；或误把非目标用户反馈当真相 |
| G5 `PAID CREATOR RETURN` | 首次让作品获取维持创作的可用资源 | 收款、合同、销量口径、捐赠、资助与净收入 | 有名气无收入；有销量无利润；有收入但丧失作者权 |
| G6 `REPEAT & AUTONOMY` | 保留可用于下一次尝试的资本与判断权 | 第二作、再就业/融资、IP、技术、作者受众 | 首作成功是一次性右尾事件；第二作选择权仍不足 |

这不是人生必经的线性流程。有人从技术岗位直接进入 G3；有人获得薪资支持或共同创始人互补，跳过某些显性的步骤；也有人反复回到 G1/G2。关键是**记录发生了什么，而不是要求每个人按表格成长**。

## 2. 原创发生在哪一关？

经验积累最容易被误当成 G2 的充分条件。

同一个熟悉 FPS 的人，可能：
- 有能力精准指出某一代射击游戏的设计缺陷（G1）；
- 能提出可被两周原型验证的规则替代方案（G2）；
- 能真正把代码、美术、音效和反馈集合为可玩的演示（G3–G4）；
- 能找到肯买单的玩家并保持现金流（G5）；
- 能把获得的资源转成下一项目的选择权（G6）。

这些技能有交集，不能自动相互替代。**设计判断与生产判断之间还有一个“可玩证据”关口。**

DOOM 则提醒我们：G2 并不总是先于技术突破。在 [CASE-016](../../cases/CASE-016-early-id-software.md) 和 [DOOM 纵向母研究](masters-of-doom-longitudinal-master-study-001.md) 中，技术前沿本身改变哪些体验能够被想象和生产；`TECH ENABLES DESIGN SPACE` 与 `TASTE SELECTS WITHIN IT` 应双向观察，不能预先宣布哪一侧始终主导。

## 3. 人物与非明星对照怎样安排

### 已有生产史锚点
- [CASE-007 Gunpoint](../../cases/CASE-007-gunpoint.md)：评论/玩家前史如何通向低成本原型、删除 scope、测试与售卖。须保留工资 runway 与既有媒体身份的影响。
- [CASE-008 Dream Quest](../../cases/CASE-008-dream-quest.md)：玩家/卡牌规则经验与简陋表现成本的项目匹配；成功后职业变化不等于普通玩家转换率。
- [CASE-021 Roblox Creator Cluster](../../cases/CASE-021-roblox-creator-cluster.md)：平台同时提供工具、练习和分发，但平台选中的前排创作者不能代表全部参与者。
- [CASE-032 PUBG](../../cases/CASE-032-pubg-brendan-greene.md)、[CASE-040 Tripwire](../../cases/CASE-040-tripwire-lineage.md)：mod/规则生产如何连接商业化组织；商业成功后实际控制权须另行审计。
- [CASE-042 The First Tree](../../cases/CASE-042-the-first-tree.md)：项目设计顺着已有能力和个人时间约束走，并非人人必须先学齐 AAA production 诸职能。
- [CASE-026 Brigador](../../cases/CASE-026-brigador.md) 与 [CASE-048 The Magic Circle](../../cases/CASE-048-the-magic-circle.md)：能力与作品匹配很好，也仍可遭遇市场解释或规模经济失配。

### 纠正媒体可见性
- [Week Sauce 2022 固定入口](public-unfeatured-week-sauce-apr-2022-cohort-031.md)及其[四年回访](week-sauce-2022-public-creator-followup-033.md)；
- [Beginner Friendly Game Jam 2020 完整18账号公开作者性观察](beginner-jam-public-authorial-persistence-cohort-045.md)。

这些只能观察**公开账号/作品的有限持续性**，无法直接观察职业、收入、家庭支持、没有提交的人或真正退出。它们的价值，是使 G3 到 G6 的分母开始可操作化，而不是宣称找到了各国创作者成活率。

## 4. 三个容易混淆的比例，必须分开

- `EXPERIENCED_PLAYER_RATE`：在给定地区、年代、平台，达到指定参考广度的玩家比例（当前多为 UNKNOWN）。
- `ARTIFACT_CONVERSION_RATE`：给定起点群体中，至少公开/交付一个 mod、jam 或原型的比例。
- `SUSTAINED_AUTHOR_RATE`：相同预先定义队列中，达到第二次公开作品、重复付费回报或可持续职业创作的比例。

三者**不是一个分母**，更不能用热门独立游戏数量除以国家人口，来估算“民族创新力”。

需要同时记录：
- 时间窗口和首次可观察时点（late entry / left-censoring）；
- 失联并不等于职业退出（right-censoring）；
- 作品入口、平台、语言、支付方式与审核机制；
- 用户量与付费 / 可用净收入；
- 未进入者、未上传者和不愿公开的创作者几乎不可见。

跨国比较最有价值的是**同一 Gate 上的机会差异**：有多少人能尝试、尝试以后谁继续、谁获得支持，哪一关的差距最大，而不是孤立列举异类天才。

## 5. 原文“审美割裂”应怎样用在传记里

作者旧稿有一个值得保留的张力：从业者可能以海外成熟精品作为个人体验基准，但雇主的收入模型要求其服务不同用户和付费结构。如今应拆成三个互不等价的量：

1. `PERSONAL REFERENCE SET`：作者本人接触过什么、怎样判断；
2. `TARGET DEMAND`：项目实际想服务谁，哪些需求被发现；
3. `REVENUE / DISCOVERY INTERFACE`：谁付钱、谁控制流量、谁拥有决定权。

三者不一致时，结果可能是原创冲突，也可能是一种成功的商业发现。CASE-033《征途》更适合作为“需求和收益体系创新”的对照，而不是被包装成 G2 玩法原创能力的范例。参见[中国 018 富豪阶级游戏性](../../country-studies/china/018-wealth-class-gameplay-player-socialization-design-attractor.md)。

旧稿关于西方玩家与开发者“自然互洽”、俄罗斯资源匮乏“逼出创新”的强解释也需要延后检验。玩家与作者并不共享单一效用函数；资源限制可能促进问题重定义，也可能使大量人连 G3 都无法到达。需同时记录成功率与**从未开工的数量**。

## 6. 未来 Profile 的证据摄取字段

- `PLAYER_REFERENCE_PREHISTORY`：可核的早期重要作品/社区/媒介；
- `TASTE_TO_THESIS`：哪些具体体验判断成为一个独特规则提案；
- `FIRST_PLAYABLE`：第一次可玩 artifact 的年份、成本、工具、协作者；
- `FEEDBACK_CORRECTION`：一次可证的外部反馈 → 改动或取消；
- `MARKET_TRUTH`：谁真正验证了体验/愿付钱，是否把渠道信号误当需求；
- `SECOND_ATTEMPT_CAPITAL`：失败或成功后能带走的钱、作品、技术、玩家、署名和关系；
- `UNOBSERVED_GATE`：作者没提到、媒体无法证明的步骤，明确 UNKNOWN。

每个字段都要有 Observation / Source / Counterexample / Temporal Regime。未写入不代表从未发生。

## 7. 下一轮取证设计

1. 使用相同时期的 game jam / mod uploader / 社团公开队列，至少在两地区分别追 G3→G4→G6；不把公开上传样本当全部意愿人口；
2. 找长期资深玩家/评论员但没有完成商业项目者，区分 G1→G2 与 G2→G3 的失败；
3. 对 CASE-007/008 补“早期失败点子数量、真正删除的规则与测试时间”，避免只从最终售卖作品倒推 taste；
4. 对跨国样本记录信息信源直达性、课程/工具、原型社区、可承受失败的生活时间；与 [OQ-013](../../OPEN-QUESTIONS.md#oq-013外部资讯摩擦是否改变创新速度)对应；
5. 使用[样本偏差审计 028](media-selection-survivorship-and-denominator-protocol-028.md)进行固定队列设计。

**Current verdict:** 体验资本可能提高问题发现能力，原型/反馈接口可能提高其向作品转化的概率，但 `reference breadth → original design → commercial success` 并非已经证明的因果链。现阶段应把它作为人物选择节点和跨国失败关口研究框架。
