# 049 — 创新不是一根尺：《征途》与 DOOM / Gunpoint 在创造什么？

- Status: **RESEARCH NOTE / AUTHOR-ORIGIN × CASE COMPARISON / PRE-CLAIM**
- Date: 2026-10-08
- Program: 《独立游戏英雄传说》 × 产业制度比较 × 创作者人生抉择
- Author origin: 洪荒行者《正在到来的中度数值通胀率游戏设计革命》（2023）的“中产阶级游戏性 / 富豪阶级游戏性”“渠道为王”“审美割裂”“游戏需求发现”。历史用语是**作者需求模型**，不是人口学分类。
- Primary case & evidence: [CASE-033 史玉柱／《征途》](../../cases/CASE-033-zhengtu-shi-yuzhu.md)及[其 Evidence Ledger](../../evidence/CASE-033-zhengtu-shi-yuzhu-source-ledger.md)；[CASE-016 early id](../../cases/CASE-016-early-id-software.md)及[纵向母研究](masters-of-doom-longitudinal-master-study-001.md)；[CASE-007 Gunpoint](../../cases/CASE-007-gunpoint.md)
- Related: [中国018](../../country-studies/china/018-wealth-class-gameplay-player-socialization-design-attractor.md)、[048 人才选拔](revenue-to-career-selector-audit-048.md)

## 0. 反对两种同样粗糙的写法

A. “史玉柱只懂割韭菜，因此《征途》没有任何创新。”

B. “《征途》赚到了大量钱，因此他在创造新玩法方面和 DOOM、Gunpoint 一样有原创能力。”

两句话都跨越了问题维度。

《征途》值得进入本书，不是“主角是否配称独立游戏英雄”，而是它迫使我们区分：**发现尚未充分交易的需求、构造商业制度、创造新交互、掌握分发和组织生产，是几种性质不同却可能同时重要的创新。**

## 1. 六个维度，四种强度（暂行评估模型）

维度（非互斥，可相互放大）：

1. `EXPERIENCE / RULE GRAMMAR`：玩家实际进行的新决策、动作、策略空间、情感体验结构；
2. `TECHNICAL AFFORDANCE`：使旧时代不能廉价实现的体验成为可行的引擎、工具、接口和技术；
3. `DEMAND DISCOVERY`：找到此前没有被既有产品/受众充分承认、购买或参与的用户需求；
4. `MONETIZATION / INSTITUTION`：改变进入门槛、谁为体验支付、谁以什么方式得到游戏内价值；
5. `DISTRIBUTION / AUDIENCE BRIDGE`：新获客、传播、社群、用户验证路径；
6. `PRODUCTION / GOVERNANCE`：新的组织配置、协作与原型迭代生产方法。

每个维度独立标：
- `INHERITED`：继承既有方法；
- `RECOMBINED`：将已知要素重组以解决新约束；
- `FRONTIER-CREATING`：有证据展示此前少见/不存在的有影响力方法或体验；
- `UNKNOWN`：证据不足。

**这不是一根0–100分的总分轴。** 同一项目可在一个维度开创，在另一个维度落后；市场份额和收入影响需要另开 `IMPACT` 栏，不得倒推出创新发明权。

另需给出一个方向标：`ORIGINATOR / SYSTEM INTEGRATOR / FAST FOLLOWER / DIFFUSER`，并逐维度判断，而不能把“第一个”误当“影响最大”。

## 2. 《征途》：不是首个F2P，但整合了另一个更有回报的系统

已核实：

- 巨人2007年F-1明确记载中国free-to-play MMO在**2003年已出现**，到2006年已成为中国网游收入的重要模型。因此《征途》并非免费网游的唯一发明者。[F-1](https://www.sec.gov/Archives/edgar/data/1415016/000119312507217827/df1.htm) / [CASE-033](../../cases/CASE-033-zhengtu-shi-yuzhu.md)
- 史玉柱2006年的直接访谈把免费/低支付人口理解为高支付者社会体验的重要部分。他不是单纯把买断门槛改成0，而是将免费人口、玩家地位竞争、虚拟商品、持续更新与下沉市场推广整合成产品—商业系统。[2006采访](https://tech.sina.com.cn/i/2006-04-13/0913901818.shtml)
- 公司配备>140位产品开发相关人员、>250个联络办公室、>2000名线下联络人员，并形成高频运营和全国渠道。[F-1](https://www.sec.gov/Archives/edgar/data/1415016/000119312507217827/df1.htm)
- 2006年网游净收入约4.085亿元、2007年全公司网游净收入约15.214亿元；后者不能全按单款《征途》口径归因。[2007业绩6-K](https://www.sec.gov/Archives/edgar/data/1415016/000119312508034863/d6k.htm)
- 2007年财报也记录了研发架构人员新增期权激励，不能把这套工业化产品的技术与团队劳动抹成“营销一个人的作品”。[2007业绩6-K](https://www.sec.gov/Archives/edgar/data/1415016/000119312508034863/d6k.htm)

### 暂定分类

| 维度 | 对《征途》可说什么 | 不可说什么 |
|---|---|---|
| 体验/规则 | MMO、升级、虚拟商品等继承并重组；高强度财富→游戏地位转换形成特定体验 | 因收入高就宣布发明了新交互范式 |
| 技术 | 具有支持大规模多人和高频运营的实际工程能力 | 史玉柱本人发明这些技术 |
| 需求发现 | 直接访谈与社会人口分层构成较强的需求发现证据 | 500–600谈话等于有代表性的调查 |
| 商业制度 | 将已出现的F2P、虚拟商品、阶层化付费重组并规模验证 | 他发明F2P和全部P2W |
| 分发 | 把消费品地推经验移植到县乡网吧和线上支付/营销 | 中国过去没有线下网游推广 |
| 生产组织 | 大规模研发+运营+分发能力紧密耦合 | 由此推导具体哪个策划提出了哪个系统 |

更准确的历史角色是：**具有强商业系统整合与市场需求发现能力的规模化创新者；玩法原创能力仍需按具体规则提出者与原型另行审计。**

## 3. DOOM：技术突破与新的体验语法相互创造

[early id CASE-016](../../cases/CASE-016-early-id-software.md)及[纵向母研究](masters-of-doom-longitudinal-master-study-001.md)告诉我们：Carmack的实时三维渲染/引擎能力并非游戏玩法之外的独立技术装饰；它直接扩张了可做的空间、移动和战斗体验。Romero、Hall和其他团队成员围绕技术能力、编辑工具、节奏与关卡推进进行了有实际分歧和改动的设计。

因此 DOOM 的关键不是“第一个射击游戏”或“凭空发明FPS”，而是**技术 frontier 与互动设计、工具、shareware 接口形成了相互强化的组合**。从 Wolfenstein 3D 到 DOOM 再到 Quake 仍需要拆出各自已有的设计母本、技术跃迁和作者信用，不可把整个品类历史简单归于一个人。

与《征途》相比，它的突出维度位于新的实时空间体验、工具/技术可供性和玩家制作生态，而不是高付费深度的重新设计。

## 4. Gunpoint：在既有工具里创造小规模规则突破

[CASE-007](../../cases/CASE-007-gunpoint.md)证据支持：Tom Francis长期评论积累机制比较能力；借GameMaker低成本原型将《Deus Ex》喜欢的潜入体验改写成Crosslink电路重连和可组合规则；2010年主动砍掉昂贵脚本内容。没有资料支持他发明GameMaker或某种崭新收费商业制度。

所以它是另一个不同组合：

`inherited accessible technology + high rule recombination + scope deletion + publicly testable market interface`

这不比《征途》“整体上更创新”或“绝对更伟大”；它是在本书更关心的**个人作者型体验设计**维度有清晰强证据。

## 5. 对照矩阵：不是分数表

| 案例 | 可观察的主突破 | 主要继承/受限项 | 结果代表什么 |
|---|---|---|---|
| 《征途》 | 需求人口、F2P变现、社会地位激励、地推和组织的**制度重组** | 非首创F2P；继承MMO语法；大量专业研发劳动 | 强规模化商业系统创新，不证明原发玩法 |
| DOOM | 实时渲染/技术可供性与FPS空间玩法语法的**耦合推进** | 继承早期射击与id已有的前作/工具/渠道积累 | 技术—玩法共创范式的重大历史样本 |
| Gunpoint | 以低成本重组潜入与环境操控规则、压缩scope | GameMaker与premium模式是既有工具/市场 | 个人作者如何将品味转为可交付的规则组合 |

必须另开 `IMPACT / REVENUE / DIFFUSION / TIME` 面板，分别计量全球传播、销量/利润、追随作品、后来设计惯例；**绝不把营销营收的数量级当作原创玩法能力的数量级，反过来亦然。**

## 6. 史玉柱的“异类”身份，恰好应该成为传记冲突

史玉柱是经过IT创业失败、保健品营销重新积累资本的人。他不是从零开始的独立游戏开发者，更不是完全不懂软件的纯外行；此前消费品行业训练的市场感知与渠道组织方法，恰好成为自己进入网游行业的差异化能力。

但是他在2005–2007年能够整合产品系统，是因为已经有资本采购工程与创作能力的优势地位。其“像玩家一样理解游戏”的能力和普通评论者、资深独游玩家的品味资本不能直接当作同一类型。

本书的人生问题因而更深了一步：

> 你的既有经历能否让你看到现有从业者看不到的需求？如果看到的是一个**更能赚钱的游戏制度**，而不是一个新玩法，你是否仍愿意承认这是创新？反过来，你会不会把这个商业成功误认成你已经拥有设计下一种全新体验的能力？

它既是中国商业产业的形成史，也是“创新神学”需要的反压力测试——新颖不应成为唯一正当目标；判断价值，应先说明对哪一类问题、哪一群用户、在哪个时代进行创新。

## 7. 需要正反验证的下一步

- 作品→产品：研究《征途》团队的关卡、数值、核心系统具体作者，保留史的决策与团队的创作劳动边界；
- pioneer→followers：找同时期盛大/韩国F2P先例，比较巨人的增量贡献，而非事后全归单个英雄；
- reward→selection：将收入激励是否真的重塑岗位编制、晋升与下一代立项能力交给[048](revenue-to-career-selector-audit-048.md)，不混在创新能力评级中；
- 对照“很会发现付费需求但未完成可玩创新”“做出新玩法却没有商业市场”“二者兼备”“商业领先但后来固化”的正反样本，形成至少两期时间窗；
- 需要一组*商业/营销创新成功但产品玩法无显著新语法*的非中国控制样本，以及*中国玩法原创但商业失败*的反向样本，避免文化/国别本质化。

**Current verdict:** 《征途》的商业制度创新可有强证据地讨论；DOOM和Gunpoint的体验/技术创新另有自身证据。三者不应排单轴“创新英雄榜”；要说明创新方向、作者、当时资源、外部效果和后来被模仿的是什么。
