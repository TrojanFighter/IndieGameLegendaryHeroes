# 创作者队列证据底座 001：不能再用明星案例估计游戏发明者的生产率

- **Date:** 2026-10-09
- **Status:** SOURCE REGISTER / OBSERVABLE POPULATIONS / COHORT DESIGN, **not a completed five-year longitudinal cohort**
- **Program:** Game inventors / prototype ecology / China comparison / earned scale / orthodoxy inversion
- **Parent:** [Creator-to-Studio × Decision Rights](creator-to-studio-conversion-decision-rights-audit-20261009.md), [029 中国正统倒置](../../country-studies/china/029-orthodoxy-inversion-chundeng-farmer-inventor.md)
- **Research question:** 固定2018—2021年原型作者的入门队列，五年后有多少仍在独立创作、商业化、取得项目发起与设计决策权？各国家/时期/类型/职业背景有何差异？
- **Non-claim:** 目前**无法**从已找到的聚合数据直接算中国、美国、欧洲原创人才率。建立数据入口不等于完成追踪。

## 1. 五类不同分母，不能相互替代

1. **HOBBYIST ENTRANTS:** 曾经参与原型/Mod/Jam/学生作品的人；不是所有报名注册者都亲自完成游戏。
2. **PLAYABLE AUTHORS:** 实际交付可玩作品，并拥有清楚可辨的作者贡献者；一款作品可以有多人，不可把游戏数量当人次。
3. **PERSISTENT CREATORS:** 3/5年后仍有自主发布或持续制作记录的人，可以是业余、自雇、在公司任职或兼任。
4. **COMMERCIAL SHIPPERS:** 已参与正式商业上市、具有已实现消费/市场反馈的人；就业岗位并不能自动替代此证据。
5. **ORIGINAL DECISION-HOLDERS:** 对某个独特游戏设计问题及产品方向拥有提案、关键机制更改、kill/pivot、设计与测试组织实权的人；游戏主策/制作人头衔仅是 proxy，必须另证。

两条最容易被忽略的路径：
- **INVISIBLE AMATEUR CONTINUITY:** 没进入职业游戏公司，仍持续发明新作品的人；
- **VISIBLE EMPLOYMENT BUT LOST AUTHORSHIP:** 已入职大公司，参与过知名项目，却失去 end-to-end 创作者循环的人。
二者应分别检验，不先贴任何国别标签。

## 2. 新发现：可以利用的真实聚合与档案源

### A. 瑞典 Uppsala University / GAME 校友数据库（2026-08-28）

一手页面：https://game.speldesign.uu.se/alumni-statistics/

- 2001/02—2023/24 各入学队列记录 836 人；
- 已知最新工作/学习类别708（84.7%），未知128（15.3%）；
- 在可对应国家的648条记录中瑞典546，其他国家共102，覆盖另31国；
- 项目类别中 Game Design & Graphics 324（已知282），Game Design & Programming 248（已知219）；
- 校方**明确警告**：living register，不是 longitudinal employment survey；未知不等于失业；旧队列信息更新程度不同。
- 学校网站还保留 student games、开发日志、年度 Gotland Game Conference，以及2007—2025多届奖项/学生项目，可追溯个别作品—作者—学校活动路径，但普通个人资料不能在无同意情况下进行侵入式身份拼接。

**价值**：一个覆盖二十余年、具有人数和缺失量的职业成长框架；**不足**：非统一的固定年龄或出校年份跟踪、未记实际项目发起权、未给公开可下载的脱敏逐人纵向表。严禁写为“瑞典毕业生84.7%就业”。

### B. HEVGA 2019 Survey of Program Graduates（2018年实地问卷）

官方报告：https://hevga.org/wp-content/uploads/2020/02/HEVGA_2019_Survey_of_Program_Graduates.pdf
可检索文本转写：https://www.readkong.com/page/program-graduates-2019-survey-of-2113860

- 387份完整问卷，89%受访者调查时住在美国，其余国别数量小，样本是成员院校转发的**自愿回应**，非总体概率抽样。
- 找工作来源：专业人际关系26%，在线职位搜索24%；这反映网络资本可能是一条重要门槛，不应把所有成果只归于单人原型技术。
- 已有部分人离开游戏业；职业满意度、职业选择后悔以及自雇者遭遇等都被具体问及，研究不能假设“独立=满意度更高”。
- 受访者在不同岗位出现“自我感觉自主”并不等同真正能提出并推行原创项目（`creative decision right`不同于 general job autonomy）。
- 报告观察独立自雇者工作满意度相对较低，是评估反融资、无生产经理的小团队模式的**重要逆风证据**；不要以成功率替代创业风险与职业福利。

**价值**：已有的职业/收入/满意度分母；**不足**：没有初始Jam作者被动退出队列，也没有完整原创决策权。

### C. Ludum Dare Database（非官方长期作品档案）

页面：https://ldj.am/ ，2026-10-09 检索页面显示 `152 Jams / 99K Games / 159K Authors`。
- 此为爱好者运营的**非 Ludum Dare 官方站点**；网站自己的标签“Authors”不能未经字段核验等同去重后的159,000名实际自然人。
- 它与官方 https://ldjam.com/ 和 https://ludumdare.com/resources/questions/who-hosted-ludum-dare/ 一起，为2018/2019/2020固定届次追踪提供作品入口。
- **最大价值**：先按某一届全部已投稿的作品取样，而不是只从日后成功的Steam游戏倒查作者（anti-survivorship）。
- **仍未验证**：是否有许可的完整机器可读导出、哪些昵称可合法/可靠对应Steam创作者以及作者对长期追踪的同意；无核验不能承诺自动化抓取。

### D. 2026 Game Jam 长期职业作用的访谈研究

Ali Arya & Omar Bani-Taha (2026), *Insights on game jams as bridging educational activities*, Discover Education：https://doi.org/10.1007/s44217-026-01810-5
- 2023秋—2024冬采集15名访谈对象：14人曾参加本校 Global Game Jam，一人是外站组织者；经历1至12次Jam，中位数约4。
- 发现教育→职业、在职→实验创作的双向桥接；部分受访人不从事游戏行业，反映“跨行业继续实践”不能认定失败。
- 研究者自己强调真正纵向的职业效果评价非常缺乏；研究样本按grounded theory目的抽样，不可计算“Jam毕业成为游戏人的概率”。

### E. Brendan Keogh 2023《The Videogame Industry Does Not Exist》

MIT Press 出版社页：https://mitpress.mit.edu/9780262545402/the-videogame-industry-does-not-exist/
2019/2021 学术文章：https://journals.sagepub.com/doi/10.1177/1555412019873746
- 书汇集 >400 人、跨澳大利亚/北美/欧洲/东南亚的不同生产角色（业余者、兼职、学生、公司人员、艺术家、合同商），重点反对只用“游戏公司雇员”定义谁在制作游戏。
- 先前澳大利亚研究公开方法：2018全年150次半结构化访谈 + 288份开放自愿问卷。许多现有资本/就业叙事是**样本框架对业余作者的遮蔽**，不一定是他们真正不存在。
- 但跨国400+不是四国的可比随机队列，不能用来给中国与欧美排数量级。

### F. 2018年《The Missing Producer》：真实小团队为何不想一代就变大

Jennifer R. Whitson, Bart Simon, Felan Parker, *The Missing Producer*（2018网上发表；2021刊期）：
https://pmc.ncbi.nlm.nih.gov/articles/PMC8022774/

- 作者通过2015—2017 Indie MEGABOOTH 场景开展62次半结构化访谈、120余份问卷；展会与参展者招募意味着样本具有“仍活跃、能够展出”的幸存者偏差。
- 研究发现相当一些独立游戏作者把“成功”定义为**能够继续和同一批人再做下一款游戏**，不是扩大到百人、股权融资或IPO。
- 游戏作者回避正式 Producer 并不代表财务、制作计划、商务与社区劳动消失；任务只是被无形转给创作者，可能导致耗竭与脆弱性。
- 这是 Earned Scale 必须处理的关键张力：**保有创作主权 ≠ 取消生产管理知识**；small team 不代表 free labor；资本投入和规模可以被选择而非固定追求。

## 3. 真正的设计：两个不同队列，避免犯分母错误

### Cohort P：原型作者固定入门队列（推荐2019与2020作一轮pilot）

建议原始取样端：
- 中国：CiGA GGJ参赛 / 66RPG晚期与Project1迁移后的作者公共档案 / BOOOMJam早期；
- 国际：Ludum Dare 2019/2020、GGJ对应城市活动；
- 专门学校对照：Uppsala 2018/2019学年参与学生作品者；
- 所有平台按当地报名—实际完成—可玩作品—作者去重进行明确口径拆分。不能从学校比赛获奖者开始抽样，也不能用全球GGJ当欧美样本。

**最小前瞻/回溯字段**：
`first_public_submission_year, selected_cohort, verified_author_role, work_finished, prior_games_at_entry, initial_game_intent, follow_up_year, follow_up_observed, repeat_public_creations, commercial_game_involvement, currently_paid_game_work, independent_personal_authorship, product_decision_right_level, retained_IP_or_revenue_rights, stopped_making_games, stopping_reason_self_reported, response/source_tier, missingness_type`

**隐私**：仅在用户公开选择身份关联或提供明确同意的范围作高置信映射；缺失不得推断失业/游戏停止，更不得把社交平台信息拼接成公开个人档案。发布统计优先去识别化。

### Cohort S：首代已上市工作室的次代生存队列

- 2015—2022间首次完成买断制/EA商业游戏的一般团队，国别×类型×年份×初代销量档×初代规模分层；
- 截至2026-10追踪五年内是否有新商业游戏、二代是否扩大、资本来源、原主创是否保留及作者权益变动；2022加入者观察窗短，标 `RIGHT CENSORED`，不可简单算作“未完成续作”；
- 失败作品与永久停工者必须保留为分母，不许只算《Risk of Rain》《Helldivers》《失落城堡》《Larian》这类明星。

需要的指标：
- PCT_COMPLETE: 起始人群有独立可玩作品比例
- PCT_REPEAT_5Y: 起始可玩原型作者5年后继续制作比例
- PCT_COMMERCIALLY_SHIPPED_5Y: 首个完成原型后5年内有参与商业发布比例
- PCT_ORIGINATOR_AUTHORITY_5Y: 实际独立拥有新设计方向或项目发起权比例（需问卷/采访，不能从岗位名称推断）
- PCT_RETAIN_ORIGINAL_CONTROL: 原始作者在第二个商业作品中保留创作/IP决策权比例
- MEDIAN_SCOPE_AT_ENTRY & AT_SEQUEL: team FTE/year、feature burden、production throughput；不提供可审成本的团队不得进行ROI比较

## 4. 数据可信度红线与伪统计隔离

2026-10-09搜索结果出现一篇SEO汇编“Game Jam Participation and Prototype Statistics (2026)”宣称 GGJ2026 `118,400`参与者、`24,680`原型、`4.2%`的商业化转换率。GGJ **官方网站** 同届为 `39,197`参与者和 `9,874`完成上传作品，与前两数直接冲突：
官方 https://globalgamejam.org/news/global-game-jam-2026-jammer-survey-data 。
该汇编网址 https://voxbooster.com/blog/game-jam-statistics-2026/ ，不可采用其中任何无法追溯的转化率或ROI数据，更不能把看起来精确的百分数当成可信科研结果。

这也是项目研究方法重要防线：**宁可留下 UNKNOWN，不伪造一个“世界独游4% Jam商业转化率”并在下游传播。**

## 5. 回到中国理论：检验“发明者被商业行业吸收”需要一个新的对照

在可比的职业入门队列里应分至少四类：
- 从不进入大厂、一直独立创作；
- 进入大厂后保持独立Jam/业余作品创作；
- 进入大厂后停止自主制作、主要负责成熟系统；
- 先入大厂后离职创作并形成第二代工作室。

对照一定要控制刚入门时的制作习惯（selection into firms），才能区分 **NEGATIVE TRANSFER（职业训练改变）** 与 **PRE-EXISTING DIFFERENCE（本来选不同路线的人）**。

换言之：
> 优秀原创作者在进入主流组织后被改造成什么，不能只从一份大厂岗位表推断；需要他进入前后两个时间点的作品记录与他自述的决策权变化。

另一个新结论是，业内“融不到钱独游困难”的讨论可能系统性忽略了不以主业收入定义创作身份的人。但业余路径同时面临不稳定、家庭劳动、雇佣协议与持续生产管理缺口，不能浪漫化。
