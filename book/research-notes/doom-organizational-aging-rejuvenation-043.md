# 043 — 从答案追赶到问题主权：DOOM 长周期中的组织老化、后发化与再年轻

- **Status:** RESEARCH NOTE / ORGANIZATION × INNOVATION × PRODUCT EPISTEMOLOGY / PRE-CLAIM / 2026-10-08
- **Primary longitudinal anchor:** DOOM (1993) → Quake → post-Romero id / Rage → cancelled Doom 4 → DOOM (2016).
- **Core question:** 一个曾经创造范式的组织，为什么会逐渐开始学习别人已经证明的答案；又怎样重新获得“没有标准答案时自己定义问题并让现实裁决”的能力？
- **Related:** [040 — strategic disloyalty](early-id-strategic-disloyalty-american-individualism-040.md) · [041 — truth shield / Ion Storm](truth-shield-to-narcissism-shield-ion-storm-governance-041.md) · [042 — Carmack × Romero error-correction network](carmack-romero-complementary-error-correction-network-042.md) · [DOOM longitudinal master](masters-of-doom-longitudinal-master-study-001.md).
- **Scope rule:** 不把“春登”“农民发明家”当人格或国民性标签；这里把它们只作为作者研究术语，分别描述**被上一轮成功经验俘获的认知状态**与**在未知问题上通过低成本现实试验搜索解法的工作方式**。任何人物/国家归类都必须由具体机制和数量级证据支持。

## 0. 核心命题

early id 最初最稀缺的并不是“知道正确答案”，而是：

> **当正确答案不存在时，仍然能够把技术假说、设计假说和市场假说做成可运行 artifact，并快速接受现实裁决。**

这套能力在 1990–1993 的小团队里高度依赖创始人互补和低协调成本；Quake 以后，技术复杂度、团队规模和生产周期上升，原先由几个人直接承担的隐性协调逐渐失效。到了 2000 年代末的 Doom 4，id 甚至出现一个反转：

> **曾经定义 FPS 答案的公司，开始以当代成功 FPS 的既有答案来定义自己。**

DOOM (2016) 的价值因此不只是“成功重启老 IP”，而是一个成熟组织重新获得 **PROBLEM SOVEREIGNTY / 问题主权** 的案例：不再首先问“现代 AAA FPS 应该怎么做”，而重新问“什么玩家行为才使 Doom 成为 Doom”，随后让 prototype、playtest 和系统反馈去裁决具体机制。

## 1. 后发优势、后发劣势，与“后发者模式切换”

杨小凯、Jeffrey Sachs、胡永泰关于“后发劣势”的原始论证主要位于政治经济制度层，不应直接搬来解释游戏公司。相关论文：

- Jeffrey D. Sachs, Wing Thye Woo, Xiaokai Yang, **Economic Reforms and Constitutional Transition** (2000): https://www.jeffsachs.org/bookchapters/7wmkf77rkk2msea84jaet97ehelm8n
- Lin Yifu, **后发优势与后发劣势——与杨小凯教授商榷**，2003，《经济学（季刊）》: https://ccj.pku.edu.cn/Article/info?aid=301469700
- 北京大学国家发展研究院存档版：https://nsd.pku.edu.cn/xzyj/cbw/tlg1/19962015a/250612.htm

可安全抽象出的机制不是“某种制度结论”，而是：

1. 后发者可以低成本取得先行者已经验证的技术/管理答案；
2. 这在距离前沿很远时是巨大优势；
3. 但越接近前沿，现成答案越少；
4. 如果组织仍把“寻找成熟 benchmark”当成主要认知算法，就会发生 **MODE-SWITCH FAILURE / 模式切换失败**。

这里提出一个仅用于创新研究的 H 级框架：

### LATECOMER MODE-SWITCH PROBLEM / 后发者模式切换难题

| 距离前沿 | 高收益行为 | 主要风险 |
|---|---|---|
| 远离前沿 | 模仿、吸收、工程化、规模化 | 重复探索浪费 |
| 接近前沿 | 学习 + 改良 + 局部探索 | benchmark 依赖 |
| 抵达前沿 | problem framing、实验、失败筛选 | 仍按追赶逻辑找标准答案 |
| 范式转换 | 主动否定旧答案、创建新评估标准 | 成功经验反成锁定 |

这并非杨小凯原理论的直接延伸结论；这里只借其“容易取得已有成果可能改变更深层能力建设激励”的一般结构，形成产品创新层假说。

## 2. “春登”不是国籍，而是 incumbent epistemology

本项目内部研究术语：

### 春登 / INCUMBENT EPISTEMOLOGY

不是“老”“保守”或“资历高”，而是：

> **上一范式中的成功经验获得了过高的先验权重，以至于新的问题首先被迫证明自己符合旧答案。**

因此：
- 美国 AAA 老兵可以春登化；
- 日本大企业管理者可以春登化；
- 中国大厂制作人可以春登化；
- 原本极具革命性的创业者本人也可能春登化。

其危险不在于“经验是错的”，而在于：

> **把过去系统中的必要条件误认成跨时代充分条件。**

与之相对：

### 农民发明家 / REALITY-FIRST SEARCHER

不是学历、职业或阶级身份，而是一种搜索方式：

> **当没有可靠标准答案时，先建立可验证 artifact，让现实而非权威决定下一步。**

高知识密度的 Carmack 完全可以在此意义上是“农民发明家”；术语强调的是搜索顺序，不是反专业主义。

## 3. Quake：Founder Stack 开始失效

[042](carmack-romero-complementary-error-correction-network-042.md) 已经将 early id 从“Carmack 技术 + Romero 设计”改写为 **互补纠错网络**。Quake 的关键变化不是“二人突然性格不合”，而是：

- 引擎前沿移动得更快、更久；
- design/content 面对不断变化的 affordance；
- 技术结果与可玩内容之间的反馈延迟从小时/天拉长到周/月；
- 大量隐性协调开始超过创始人直接沟通所能承载的范围。

这里新增 H 级概念：

### FOUNDER-STACK FAILURE / 创始人栈失效

早期组织实际上把：
- 产品定义；
- 引擎接口；
- scope；
- 反馈；
- 冲突裁决；
- 商业判断

封装在少数创始人之间的高带宽关系中。

这在小规模时极其高效，但不是可无限扩展的 architecture。复杂度跨过阈值后，**“人本身就是 API”** 会出现：
- 决策接口不清；
- 纠错延迟增长；
- 局部事实被不同角色解释成对方“不工作/不理解”；
- 关系冲突替代结构化裁决。

这不是“正式管理一定优于创始团队”，而是说明隐性治理有规模边界。

## 4. Romero 离开以后：专业化解决了一类问题，也可能固化能力非对称

不能把 Quake 后 id 写成“失去 Romero 后停止创新”。Quake II、Quake III、Doom 3 以及后续 id Tech 仍然证明 id 保有极强技术与产品能力。

更准确的研究问题是：

> early id 的异常结果来自多种能力相乘；冲突后，组织是否把其中最稳定、最可制度化的一支能力误认成整个创新函数？

这里提出：

### CAPABILITY ASYMMETRY LOCK-IN / 能力非对称固化

一种组织曾靠 A × B × C 取得异常结果；

随后因为治理冲突，优先制度化 A；

A 的成功继续强化 A 的资源与权威；

最后组织逐渐把 A 认作自己的“真正核心竞争力”，而忽视原始乘法结构。

对 id 的具体强弱尚需更多 Rage、Doom 3、内部组织来源验证，因此这里保持 H，不写成“Carmack 技术主义导致 id 产品创新下降”的确定因果。

## 5. Rage：技术上的前沿搜索仍然存在，产品问题主权却未必同步

Rage 不是“吃老本”的证据，反而说明 Carmack/id 仍愿意承担新技术风险：id Tech 5、MegaTexture、跨平台目标、新 IP、车辆和更开放环境都不是保守选择。

因此 Rage 对本研究的价值是区分：

> **技术原创 ≠ 产品范式原创。**

一个团队可以持续解决世界级工程问题，却仍需要单独回答：
- 玩家为什么持续做这些动作？
- 这些系统之间有没有形成高强度行为闭环？
- 技术优势有没有被转译成清晰、独特、不可替代的 player grammar？

现阶段本节仍为方向性解释；在升级为正式 Claim 前，应补：
1. Carmack / Tim Willits / design leads 对 Rage 目标与 production constraints 的直接访谈；
2. MegaTexture 对内容生产方式的真实收益与成本；
3. Rage 设计变更、延期和团队结构的同期记录；
4. 将“技术前沿仍强”与“产品独特性争议”分开测量，避免用评论分数替代机制。

## 6. Doom 4：“Call of Doom”是 Benchmark Capture 的高价值案例

DOOM (2016) 负责人 Marty Stratton / Hugo Martin 后来回顾，早期 Doom 4 并非“完全做不出来”；核心问题是它越来越不像他们最终认为的 Doom。2017 Game Developer 对二人的访谈直接把被取消版本与更剧情化、受当时主流 shooter 影响的方向联系起来，并记载团队重启后如何以 playtest 和 design filters 收敛。

来源：
- Kris Graft, **'Make me think, make me move': New Doom's deceptively simple design**, Game Developer, 2017-04-06:
  https://www.gamedeveloper.com/design/-make-me-think-make-me-move-new-i-doom-i-s-deceptively-simple-design

这里新增：

### BENCHMARK CAPTURE / 标杆俘获

定义：

> **当组织失去问题主权时，最容易采用的“专业”行为是以当前市场赢家的解法来证明自身方案合理。**

其危险在于它通常：
- 有市场数据；
- 有成功案例；
- 有成熟 pipeline；
- 有可解释 feature checklist；
- 容易获得预算与组织共识。

所以 benchmark capture 往往不是低水平抄袭，而可能是：

> **高水平、专业化、昂贵地回答了错误的问题。**

Doom 4 的研究价值正在这里：FPS 范式的早期创造者，在新的 AAA 时代内部“后发化”，开始向已经凝固的主流 FPS solution 学习。

## 7. DOOM (2016)：重新取得 Problem Sovereignty

2017 Game Developer 访谈给出的直接材料非常强：

Marty Stratton 说团队是 **“fun first”**，持续玩游戏，让“the game tell us what it wanted”，然后 **“steered into the fun”**。他们把核心过滤器压缩为：
- 个性鲜明的 demons；
- 强烈区分的 guns；
- fast movement；
- push-forward combat；
- combat chess；
- “make me think, make me move”。

同一访谈还给出非常重要的反例式迭代：
- 早期 AI 若同时积极扑向玩家，玩家会自然退到墙边/choke point；
- 这在别的游戏中完全可以成立；
- 但它破坏了 Doom 希望玩家主动挑选目标、穿过竞技场的行为；
- 因此团队让大量非近战敌人更愿意保持位置，把主动穿越战场的责任交回玩家。

来源同上：
https://www.gamedeveloper.com/design/-make-me-think-make-me-move-new-i-doom-i-s-deceptively-simple-design

这使 2016 的创新方法可以定义为：

### PROBLEM SOVEREIGNTY / 问题主权

> **组织有权先定义自己真正需要解决的玩家问题，而不是先接受行业 benchmark 已定义的问题。**

### REALITY ARBITRATION / 现实仲裁

> **争论不由资历、历史声望或“行业通常这样做”最终裁决，而尽快转成 playable artifact，由实际行为反馈筛选。**

二者必须同时存在：
- 只有问题主权，没有现实仲裁 → 可能变成自恋式异端；
- 只有现实测试，没有问题主权 → 只能在别人定义的目标函数上优化。

## 8. 2016 没有“复刻 1993”，而是提取行为不变量

DOOM 2016 若只是复古，可以复制：
- 迷宫形式；
- 1993 UI；
- 原样资源分布；
- 老式关卡节奏。

它实际做的更接近：

### INVARIANT RECOMPOSITION / 不变量重组

> **保留决定玩家行为与体验身份的深层关系，但允许表层机制彻底改变。**

示例：
- 现代 shooter 常见受伤逻辑：受伤 → 退后 → 躲避/恢复；
- DOOM 2016 用 Glory Kill 将生命恢复绑定到向敌人靠近；
- 因而“低血量”没有把玩家推出核心行为，而是把玩家重新推回核心行为。

所以 1993 与 2016 的创新类型不同：

### DOOM 1993：ORIGIN INNOVATION / 原发性范式创新
技术突破、空间表现、战斗、多人和分发共同扩大可行域。

### DOOM 2016：INVARIANT RECOMPOSITION / 不变量重组创新
在成熟类型内重新识别产品 identity 的因果结构，用全新机制实现同一或更强行为关系。

这正适合与本项目“同构异性创新”研究联动：商业组织并不需要每次发明新类型，能稳定识别真正的结构不变量并以异质机制重组，本身就是高阶创新能力。

## 9. 大组织真正困难的不是“想不到”，而是能不能处决沉没成本

Doom 4 → DOOM 2016 的转向意味着已经存在的：
- 资产；
- 工程；
- narrative work；
- 管理承诺；
- 组织声誉；
- 时间投入

不能自动获得未来继续投入权。

这里提出：

### SUNK-COST KILL CAPACITY / 沉没成本处决能力

> **组织在方向证据恶化时，能否撤销过去的高成本承诺，而不要求那些承诺先在政治上“证明自己没有错”。**

这是 mature organization 与 tiny team 的关键差异：
- 小团队 pivot 的账面损失可能很小；
- AAA reboot 会触碰预算、职位、里程碑、既有资产和责任归属；
- 所以“知道方向不对”与“能真正停掉”是两种不同能力。

现有 2017 访谈足以证明 DOOM 2016 前发生过完整方向取消/重启，但关于 ZeniMax/Bethesda、id 管理层具体谁拥有 kill right、预算如何重置、人员如何迁移，仍需独立来源补证。

## 10. Protected Heresy：成熟组织中的“内部退出权”

early id 的创新自由很大程度来自真正的 **EXIT**：
- 离开 Softdisk；
- 通过 shareware 绕过传统发行；
- 用收入购买独立。

大型组织中的开发者通常不能靠“全员辞职”维持每次产品异议。

因此成熟组织需要另一种等价物：

### PROTECTED HERESY / 受保护异端权

> **团队能够在不先离开组织的情况下，推翻一个已获批准、已有沉没成本的旧方向，并获得重新验证新方向的有限资源。**

这可以视作 **internal exit / 内部退出**：
- 退出旧方案；
- 不退出组织能力；
- 保留工具、人才、资金与历史资产；
- 重开 problem definition。

它与 1990 年 early id 的 permissionless production 不是同一种机制，但功能相似：都降低“少数判断活到验证日”的成本。

## 11. Selective Institutional Amnesia：忘掉答案，不忘掉能力

组织“返老还童”不能靠真的清空历史。

更有效的是：

### SELECTIVE INSTITUTIONAL AMNESIA / 选择性组织失忆

应该保留：
- engine capability；
- production craft；
- art/AI/tools expertise；
- shipping experience；
- IP memory；
- market access。

应该允许失效：
- “我们一直这样做”；
- 旧 feature checklist；
- 旧 benchmark；
- 创始人个人答案的永久权威；
- 已经无法解释新玩家行为的 production dogma。

原则：

> **保留 capability，降权 solution。**

这比“年轻人打倒老登”或“全部推倒重来”更可迁移。

## 12. Mature team 如何重新成为“农民发明家”

这里给出一个 H 级组织模型，不把 DOOM 2016 神化为充分证明：

1. **Reopen problem definition**  
   允许“不够像 Doom”上升到方向问题，而不是只做 polish。

2. **Compress to behavioral invariants**  
   用少数强原则过滤 feature：movement、guns、demons、push-forward、combat chess。

3. **Shorten artifact-feedback loops**  
   持续玩、持续删，而不是到 production 末期才做市场验证。

4. **Bind authority to kill/rescope rights**  
   设计负责人必须能删除已投入系统，而不是只有建议权。

5. **Separate valid mechanics from valid-for-this-game mechanics**  
   “其他游戏这么做也没错”不等于“这个游戏也该这么做”。

6. **Introduce new interpreters without deleting institutional memory**  
   传统可以被新一代重新解释，而不是只有创始人有资格定义正统。

这里可称：

### INDUSTRIALIZED REALITY-FIRST SEARCH / 工业化现实优先搜索

大型专业团队也可以执行“农民发明家”式搜索；关键不是团队小或反专业，而是**把现实反馈置于权威答案之前，同时保留足够强的生产能力把假说快速做出来。**

## 13. Quake 与 DOOM 2016：从“拥有创新者”到“拥有创新机制”

| Quake 时代风险 | DOOM 2016 重建方向 |
|---|---|
| 技术前沿长期移动 | 先锁定行为目标，再让技术服务目标 |
| 创始人承担大量隐性接口 | 明确的 design filters |
| 返工来自不稳定 frontier 与目标分歧 | 主动 playtest / edit / cut |
| 高质量冲突依赖少数强人格 | 把部分判断外置为可共同测试的 artifact |
| 关系破裂后能力组合不可完整复制 | 用组织流程承载一部分原本的人际纠错功能 |

因此一个暂定主命题：

> **1993 的 id 更接近“拥有创新者”；2016 的 id 更接近“尝试拥有创新机制”。**

这不是说 2016 不依赖关键人物，也不是说制度可以制造 Carmack；而是说成熟组织若只等待“再来一个天选之子”，无法解决规模化创新问题。必须把部分创新行为转译成：
- 可重复的问题定义；
- 快速 artifact；
- 明确删改权；
- playtest 反馈；
- 沉没成本停止规则。

## 13.5 Hall → Petersen → McGee：能力存在不等于能力拥有出题权

前面的 **CAPABILITY ASYMMETRY LOCK-IN** 仍需进一步修正。Tom Hall 离开后，id 并没有简单失去“世界、气氛、叙事、作者性”人才；Sandy Petersen 与 American McGee 都说明相关能力仍然存在。真正需要审计的是：**这些能力在组织内是否仍拥有定义产品问题的合法性与决策权。**

### A. Tom Hall：项目不适配不等于能力低级

Hall 在 early id 里承担的不只是“写剧情”：
- Carmack 后来回忆 Commander Keen “very much Tom Hall's baby”，Hall 对角色、世界和创意方向有实质贡献；
- Wolf3D 的 secret/push-wall 争论中，Hall 与 Romero 一起持续推动探索奖励；
- Doom Bible 则代表更强的角色、连续世界、功能空间与叙事取向。

这些方向与 1993 年最终形成的高速、抽象、以战斗为核心的 DOOM 发生真实冲突。就 **当前项目收敛** 而言，拒绝其中很多答案完全可能是正确的。

因此必须区分：

### CAPABILITY MISFIT ≠ CAPABILITY INFERIORITY

> **一种能力不适配当前项目，不等于这种能力本身低级，也不等于组织未来不再需要它。**

错误的长期外推不是“DOOM 不需要这些 feature”，而是“这类提问不再值得参与产品定义”。

### B. Sandy Petersen：id 补回了设计产能与局部异质性，但未必补回 Hall 的 problem-definition function

Petersen 进入 id 前已经设计《Call of Cthulhu》等桌面 RPG，显然不缺世界、规则与氛围构造经验；加入 DOOM 后，他又高速修改/制作关卡，并在 DOOM II、Quake 延续强烈而异质的空间设计。

值得注意的不是“Petersen 有没有世界观能力”，而是 id 主要如何调用这些能力：

> **environment → encounter → pacing → atmosphere**

而 Hall 更接近：

> **character → place → continuity → interaction → world system**

因此职位补位不等于认知功能一对一补位。更准确的说法是：

> **id 很快补回了 level-design throughput 和局部 solution diversity；但“整个产品应该解决什么问题”这一层的 decision rights 未必同步恢复。**

Sources / leads:
- Sandy Petersen interview, 1 More Castle (2013): https://www.1morecastle.com/2013/01/sandy-petersen-an-interview-about-doom-quake-and-aoe/
- Shacknews, Rocket Jump / Petersen on Doom & Quake level design: https://www.shacknews.com/article/101156/rocket-jump-quake-and-the-golden-age-of-first-person-shooters?page=9
- Shacknews, Quake degrees of freedom: https://www.shacknews.com/article/124733/the-making-of-quake-part-2-degrees-of-freedom

### C. American McGee：latent capability 可以在组织里存在，却不被激活为新的产品定义

McGee 在 id 内从测试/支持等工作逐步进入关卡设计，参与 DOOM、Quake、Quake II；这本身说明 early/mid id 仍具有较强的 **capability discovery**：人可以先进入生产，再由真实表现重定角色。

但 McGee 后来回忆，看到 Valve 基于 Quake 技术做更叙事化、角色化的演示后，他意识到同一技术还可以服务另一种产品表达；而当时 id 的兴趣中心并没有因此重新开放成“id 可以做什么”。这类回忆属于多年后的个人叙述，当前只作为 H 级组织线索，不升级为“id 明确压制叙事创新”的强因果。

Source / lead:
- PC Gamer, McGee on Valve demo and narrative possibility: https://www.pcgamer.com/games/alice-creator-american-mcgee-says-he-was-inspired-by-a-valve-demo-he-saw-while-working-on-quake-2/

这要求新增一个核心区分：

### CAPABILITY PRESENCE ≠ CAPABILITY AGENCY

组织的真实能力不是员工技能简单求和。一个工作模型是：

```text
EFFECTIVE CAPABILITY
≈ SKILL
× DECISION RIGHTS
× RESOURCE ACCESS
× PROBLEM LEGITIMACY
```

其中任何一项接近零，组织都可能“拥有这种人才”，却无法让这种人才真正影响产品定义。

### D. PERSONNEL AMPUTATION 与 DECISION-RIGHT AMPUTATION 必须拆开

#### PERSONNEL AMPUTATION / 人员截肢
人离开，能力随人离开。

#### DECISION-RIGHT AMPUTATION / 决策权截肢
人仍在、能力仍在，但只能回答已经被别的认知范式定义好的问题，无法再参与“我们究竟应该做什么”的出题。

后者更隐蔽，也更适合解释成熟组织的认知收窄：
- 组织可以同时拥有叙事设计、系统设计、美术、用户研究、技术专家；
- 但如果 greenlight / product definition 只有一种 worldview 拥有合法性；
- 那么名义上的能力多样性并不等于真实的认知多样性。

### E. SOLUTION DIVERSITY 与 PROBLEM DIVERSITY

Hall → Petersen → McGee 线索迫使本研究再拆两层：

#### SOLUTION DIVERSITY / 解法多样性
> 在同一个已定义问题里，组织允许多少种不同解法竞争？

id 在 DOOM / Quake 关卡、空间、战斗和美术层面长期保持很强的 solution diversity。

#### PROBLEM DIVERSITY / 问题多样性
> 组织是否仍允许成员质疑“我们为什么必须继续回答这道题”？

长期风险不一定是“设计师都变得一样”，而可能是：

> **大家仍能用很多方式设计 FPS，但“id 是否应该重新定义 FPS / 做另一种体验”越来越少进入合法问题空间。**

因此“内部异质性下降”不能写得过粗。更安全的假说是：**局部设计异质性可以很高，同时 problem-definition layer 仍逐渐收窄。**

### F. ORGANIZATIONAL COGNITIVE PRUNING / 组织认知修枝

“组织性截肢”过于二元，更合适的上层概念是：

> **组织在连续项目中不断强化曾经产生胜利的思考方式，并逐步降低其他思考方式的资源、地位与问题定义权。**

其短期收益是真实的：
- identity 更清楚；
- production 更稳定；
- 新人更容易理解好方案；
- 当前项目更容易 scope down。

其长期风险同样真实：
- PROBLEM DIVERSITY ↓
- latent capability 无法 activation
- ORTHODOXY HALF-LIFE ↑
- 组织越来越擅长回答自己已经知道怎样提出的问题。

这不是“所有修枝都错”。真正需要审计的是：

> **项目层的 Not Now，是否被错误升级成能力层的 Never Again。**

### G. 对小团队 / playable stone 的迁移边界

这一条可以迁移到任何高强度 scale-down 阶段，但不能借此反对 MVP：

> **CURRENT PRODUCTION PRIORITY ≠ PERMANENT EPISTEMIC HIERARCHY**

当前 playable stone 可以正确地砍掉大量叙事、世界模拟、战略层或未来系统；真正危险的是把“当前不生产”误写成“完整产品不需要这类问题/能力”。

因此成熟的 scope discipline 应同时保存：
1. **production cut**：现在不做；
2. **capability memory**：知道未来仍需要谁/哪类认知；
3. **future-option pool**：区分“垃圾”“当前不适配”“技术/时机尚未成熟”；
4. **re-entry trigger**：什么证据出现时，允许该问题重新进入 product definition。

本节目前保持 **H / longitudinal interpretation**。Petersen / McGee 的具体 decision rights、Quake/Quake II 时期正式组织权力结构和 id 对 Valve 式叙事方向的内部反应，仍需更多同期材料，不将后见叙述直接升级为强因果。

## 14.5 跨行业升级：从 DOOM 专用假说到 Second-Answer Test

本节点后续关于 **DOOM Eternal → The Dark Ages** 的压力测试，已上提到跨行业研究：

- [Self-Obsolescence / Second-Answer Test](../../cross-industry/self-obsolescence-second-answer-test-001.md)

新增的 H 级桥梁变量包括：
- DOCTRINE HARDENING / 理论硬化；
- MANDATORY ACTION TAX / 必修动作税；
- INTERACTION-SURFACE COMPRESSION / 交互表面积压缩；
- SUCCESS-FORMULA KILL CAPACITY / 成功公式处决能力；
- ORTHODOXY HALF-LIFE / 正统半衰期；
- SECOND-ANSWER TEST / 第二答案测试；
- LAGGED-EVIDENCE TRAP / 滞后证据陷阱。

跨行业节点用 Intel/Grove、Christensen、Apple、Nintendo 和 Pocketpair 边界样本压力测试这些概念，并明确：**一个项目的创新性不能直接推出公司拥有长期 self-obsolescence；找到个例也不能替代分母和失败对照。**

## 15. 对后发国家与游戏产业比较的研究启示

不能从 DOOM 个案直接推出国家层因果，但它帮助把问题改写得更可研究。

不再只问：
> “某国有没有天才/原创游戏？”

而应问数量级与机制：

1. 一个年轻创作者面对未知问题时，接受的是“找 benchmark”还是“自己先做 artifact”的训练？
2. 没有 benchmark 时，组织还能否批准 prototype？
3. prototype 做错一次的成本多高？
4. 有多少条直接 market interface 可以绕过同质化专家门控？
5. 组织里谁拥有 kill / rescope 权？
6. 上一代成功者的判断是 evidence 还是 oracle？
7. 一个异端需要连续通过多少同质化 gate 才能获得现实验证？
8. 同等人口中，允许多少个失败搜索者长期存在？

因此“能举出一个异类案例”不能证明数量级相同。国家/地区比较必须继续坚持：

> **案例证明可能性；分母、频率、分布和路径容量决定结构性。**

### A. DOOM Eternal：革命理论会不会立刻变成新教条？

2016 找到 push-forward combat / combat chess 后，Eternal 将其强化为更明确的资源循环、弱点、武器用途和移动要求。

若 The Dark Ages 真正用 grounded movement、projectile weaving、shield/parry 和更开放空间重构 Doom 的行为不变量，那么它将成为 INVARIANT RECOMPOSITION 的第二次纵向验证，而不是“2016/Eternal 再做一遍”。

## 17. 当前证据等级与禁写项

### 较强
- 2016 团队明确以 push-forward / combat chess / make me think, make me move 为 design filters；
- playtest 中 AI 过度逼近会诱发退守，因此团队主动改行为以维持玩家主动推进；
- Doom 4 方向被完整取消，2016 不是简单 continuation；
- Eternal 明确把资源循环和敌人用途进一步系统化；
- Dark Ages 官方明确宣称从 fighter jet 改为 iron tank、从 jump and shoot 改为 stand and fight。

### H / 需要继续验证
- “Quake 后 id 能力非对称固化”的强因果；
- Rage 是“技术原创强、产品问题主权弱”的程度；
- ZeniMax/Bethesda 对 Doom reboot 的具体决策权、预算承担和内部政治过程；
- DOOM 2016 是否已经把 innovation institutionalized 到不依赖关键人物；
- Eternal 的争议是否代表“新教条化”，需要玩家行为数据、设计方复盘与后续 Dark Ages 决策三角验证。

### 禁写
- “Carmack 技术主义毁掉 id”；
- “Romero 离开后 id 不会设计游戏”；
- “Doom 4 是纯 COD 抄袭，因此必然失败”；
- “Bethesda 收购拯救/毁掉 id”而无决策链证据；
- “2016 证明大公司比独立团队更能创新”；
- “杨小凯理论已经证明游戏公司的 benchmark trap”。
