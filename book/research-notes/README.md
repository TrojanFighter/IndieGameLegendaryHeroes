## 使用边界

- A0-CHAT 只用于记录“作者曾提出什么问题”，不能承担外部事实。
- 私人经历、私人项目材料、聊天黑话和未经核验的人物归因不得进入公开研究结论。
- 一条研究笔记只有在形成明确可证伪命题并经过 Case / Evidence 检验后，才可升级到 `claims/` 或 `THESIS-CANDIDATES.md` 的更高状态。
