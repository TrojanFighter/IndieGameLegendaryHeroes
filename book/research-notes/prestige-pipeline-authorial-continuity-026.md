# 声望管道与作者连续性 026：为什么同样进大公司，有人带走能力，有人带走评分器

- Status: RESEARCH NOTE / CROSS-LAYER SYNTHESIS / PRE-CLAIM
- Last verified: 2026-10-07
- Related: `AC-010`, `CASE-059`, `china-creator-constraints-three-layer-map-018.md`, `china-creator-three-layer-pressure-tests-019.md`, `china-creator-three-layer-failure-pressure-tests-020.md`
- Boundary: 比较“职业身份与作者身份如何耦合”，不把个案升级成中国/西方人格结论。

## 0. 研究问题

用户提出一个重要修正：

> 中国创作者的风险可能不只是“进大厂以后被旧 production regime 训练”。

更严重的可能是：

> **从名校绩优主义一路无缝进入名企绩效主义，导致外部评分器从学校延续到职业，直到想做独立游戏时才第一次真正失去标准答案。**

这个命题比“应试教育害创新”更可检验。

它预测的是：

```text
考试评分器
→ elite-school prestige
→ campus hiring
→ elite-employer prestige
→ performance/promotion
→ high salary/status
→ social legitimacy
→ independent transition requires multi-layer exit
```

如果耦合很强，独立项目就可能为了保全身份而操作变形。

# 一、Slay the Spire：Amazon 不是反例的全部，真正反例是“作者线程没有断”

CASE-059 已确认：

### Casey Yano
- 大学和 Anthony 一起做 Flash/mobile hobby games；
- CS 毕业后进入 QA/software 职业路线；
- Amazon QA 约四年；
- 自己说总体喜欢那里，但后来觉得无聊、想再做游戏；
- 先离开 Amazon。

### Anthony Giovannetti
- 同样有 college hobby-game prehistory；
- 长期 card-game / board-game taste；
- 管理过 board/card store；
- 做过 QA/software；
- 在工作期间继续写 Slay the Spire design document。

后来：

```text
old collaborator reconnects
→ design doc
→ Casey creates time
→ prototype
→ external playtests
→ Anthony quits
→ full build
→ metrics / Early Access / weekly patches
```

这里最重要的不是：

> “Amazon 没把 Casey 训练坏”。

而是：

> **Amazon 从来没有成为 Casey 唯一的身份来源。**

作者身份、朋友关系、失败小作品、游戏 taste 在公司之外有独立历史。

这叫：

> **Parallel Authorial Thread｜平行作者线程**

# 二、王妙一是中国的重要反例：问题不是“中国人必然被捕获”

王妙一 / WILL 已经证明：

- 清华高标准教育；
- 网易核心技术岗位；
- 大组织技术/流程训练；
- 仍然可以保留高度 Problem Ownership；
- 离职时主动重写 objective function；
- 并把“没钱、不会画，但会编程和写作”转化成 capability-shaped product。

所以不能写：

```text
中国名校
→ 中国大厂
→ 作者性消失
```

更准确是：

> **中国 prestige pipeline 可能提高 identity-capture 风险，但并不决定个体结果。**

王妙一和 Casey Yano 的共同点反而很接近：

- 大公司能力可迁移；
- 作者性有公司外来源；
- 离职不是否定职业训练；
- 新项目没有被旧公司规模/流程定义；
- 个人 taste 能直接定义产品。

# 三、月下是另一端：人离开公司，评分器还在

月下 / 《铸仙之境》提供了最强负压力之一。

已有公开复盘：

- 腾讯制作经验；
- 很快拿到大额融资；
- 团队一度 31 人；
- 多轮大改；
- 核心玩家流失；
- 后来自己总结最大的收获是“不要有乙方心态”；
- 早期感觉只是“换个地方上班”。

这个案例可以重新解释成：

> **Career Identity / Evaluation Function 没有随 Employment Exit 一起退出。**

即：

```text
company gone
但
external evaluator remains

老板
→ 投资人/发行
KPI
→ milestone / data demand
执行者身份
→ founder title without founder problem ownership
```

这就是：

> **Exit from Organization ≠ Exit from Evaluation Function**

AC-010 加的是：

> **有时这套评价函数甚至早于公司，在教育/名校/就业 prestige pipeline 里已经连续存在多年。**

# 四、Sea 是“主动卸载”的中间态

Sea /《安尼姆》不是完全负例。

更接近：

```text
big-company veteran
→ first independent attempt still carries old habits
→ expensive mismatch
→ explicit reflection
→ next project uses 1–2 person core demo before adding people
```

所以 deliberate unlearning 往往不是：

> “辞职当天完成”。

而是：

> **一次或多次项目失败后才真正发生。**

这对 reader layer 非常重要。

“大厂老兵转独立”应该问：

> 你有没有给自己设计一个**便宜到足以允许去大厂化失败**的过渡项目？

而不是第一作就承担：
- 大团队；
- VC；
- publisher milestones；
- 多年 burn；
- 家庭全部现金风险。

---

# 五、The Magic Circle：西方老兵也会遇到另一类失败

The Magic Circle 证明：

- BioShock / Thief / Dishonored 老兵；
- 真的拒绝 AAA process-heavy 文化；
- 三人核心；
- 强作者性；
- creator-project fit 很高；
- 最终商业仍不可持续。

因此：

> **成功卸载 prestige / process 也不是商业成功充分条件。**

它阻止我们把 Casey / 王妙一写成：

> “只要不被身份捕获，就会成功。”

真正模型必须保持：

```text
Authorial Continuity
+
Objective-function Reset
+
Cheap Validation
+
Market Sufficiency
+
Runway
```

# 六、真正值得跨国比较的不是“有没有绩优主义”

美国并不缺 pedigree hierarchy。

Rivera 的 elite-firm 研究显示：
- elite university prestige 是真实招聘过滤器；
- elite professional firms 集中在顶尖学校校招；
- prestige 与 cultural matching 都会进入录用；
- 这些工作拥有巨大收入与 status 回报。

中国研究同样显示：
- elite university 在 job entry 有显著 premium；
- institutional reputation 参与 graduate ranking；
- 高学历毕业生会形成 high-status occupational expectation。

所以两边都有 prestige。

真正要比较：

| 变量 | 需要问什么 |
|---|---|
| **Pipeline Coupling** | 学校 prestige 与公司 prestige 是否形成连续人生合法性？ |
| **Parallel Authorial Thread** | 雇佣之外是否持续有作品/社群/共同作者？ |
| **Side-project Legitimacy** | side project 是被视为正常技能/兴趣，还是“不务正业”？ |
| **Exit Optionality** | 离开后能否回来？resume gap 成本多大？ |
| **Household Expectation** | 家庭是否把 elite employer 当终局证明？ |
| **Employment Identity** | 公司是“我工作的地方”还是“我是谁”？ |
| **Prototype Status Cost** | 做一个丑小实验会不会被理解为职业降级？ |
| **Failure Legitimacy** | 一次不成功能否继续被视为高能力者？ |

这些才值得未来做中美/中欧比较。

# 七、Prestige-Preserving Project Distortion：独立游戏里的操作变形

如果 AC-010 成立，最危险的不是创作者不敢离职。

而是：

> **已经离职，但仍按 prestige preservation 设计项目。**

典型表现：

## 1. 先做 vertical slice，而不是 cheap truth

不是因为市场需要，而是：

> “必须让别人看出我们是专业团队。”

## 2. 先招完整岗位

因为：

> “正规游戏公司就应该有这些职位。”

## 3. 先复制成熟大作 representation

因为：

> “我以前做的就是这个规格。”

## 4. 不愿公开 ugly prototype

因为早期粗糙会伤害：
- 个人职业身份；
- 同行评价；
- 投资人印象；
- 家庭对创业的信心。

## 5. 项目必须解释得像一个“赛道”

如果不能说：
> “这是 X + Y，市场多大，竞品是谁”

就觉得它不够合法。

这些行为单看都可能合理。

只有当它们发生在：
> core product thesis 还没得到现实验证

才构成 Prestige-Preserving Distortion。

# 八、Slay the Spire 为什么没有这样变形

它恰好反着走：

- 两个 founder；
- 2D；
- 原始 prototype；
- 大量外部测试；
- metrics server；
- Early Access；
- 初期市场并不强；
- weekly update；
- category 在作品后逐渐变得可读。

最重要的是：

> **他们不需要让第一版产品证明“我们是 Amazon/CS 出来的专业人士”。**

第一版只需要证明：

> card + roguelike 到底好不好玩。

这就是 status cost 与 prototype cost 分离。

# 九、给“大厂老兵转独立”的新增审计

Creator Life / Decision Audit 增加三项：

### Identity Coupling
- 我的职业 title 是能力，还是自我价值证明？
- 如果下一作很小，我会觉得自己降级吗？

### Parallel Authorial Thread
- 过去三年有没有不受公司 KPI 支配的 artifact？
- 有没有非同事 collaborator / audience？
- 有没有自己长期积累的 taste / domain？

### Prestige-Preserving Distortion
- 项目哪些成本是真正产品需要？
- 哪些只是“看起来像专业项目”需要？
- 如果 nobody knew my résumé，我还会这样做吗？

这个最后的问题非常重要：

> **If nobody knew your résumé, would you still build the project this way?**

如果答案明显变化，prestige distortion 风险就高。

# 十、当前结论等级

### STRONG

- Casey Yano 的 Amazon 经历没有抹去大学时期作者线程；
- Slay the Spire 核心 thesis 来自长期 taste 与公司外 collaborator history；
- 公司能力可以选择性迁移而不复制公司 objective function；
- 王妙一提供中国同类反例；
- 月下提供“离职但评价函数没退出”的负压力；
- 美国 elite labor market 同样存在 pedigree prestige。

### HYPOTHESIS

- 中国名校→名企路径的 **pipeline coupling intensity** 是否高于美国科技/创意职业；
- 中国大厂老兵是否更常出现 Prestige-Preserving Project Distortion；
- side-project legitimacy、家庭 expectation、resume-gap penalty 是否是中美差异的重要中介；
- “好学生→大厂高绩效”是否让首次真正自主问题定义发生得更晚。

### REJECT

当前不允许：

- “西方人进大厂不会丢作者性”；
- “中国人一进腾讯网易就不会原创”；
- “Amazon 比腾讯/网易更自由”；
- “名校生不适合独立游戏”；
- “离开大厂就是找回作者性”。
