## 一、研究对象必须从“一个人/一个爆款”转向纵向生产关系

David Kushner 的 *Masters of Doom*（标准中文书名《DOOM启世录》，常被误写成《启示录》）价值不是“卡马克与罗梅洛的传奇”，而是少数能连续写出 **能力前史 → 付薪职业生产 → 技术/产品/市场互补 → 商业独立 → 工具和社区杠杆 → 产品成功 → 组织裂变 → 再创业与反事实** 的产业史。

但它是 2003 年采访式非虚构（S1）；人物对话、私人动机、股份、融资、销量数字不能据此直接裁决。用户上传中文 EPUB 供研究及章节定位，**不向公共仓库上传 EPUB 或长篇摘录**。与 1994 年 Game Developer、2000 年 Spector 同期复盘、Carmack/Romero 直接访谈交叉核验。

分析基本单位：**Person × Team Capability × Project Definition × Technical Opportunity × Market Interface × Governance / Decision Rights × Historical Regime**，不允许把某人的成功或失败还原成恒定人格属性。

## 二、十阶段实验链

| 阶段 | 能力、生产约束或接口 | 研究结论及反面 |
|---|---|---|
| Romero / Carmack 青少年—职业前史 | 玩 → 拆解/修改 → 写/投稿/发表；不同的游戏品味与工程兴趣 | 玩得多≠有生产能力；转化动作才算 |
| Softdisk / Gamer's Edge | 工资、机器、连续高频交付、旧作/工具复用、共同工作 | **micro-project compounding** 先买到“反复做完”的能力；极端工时不可复制 |
| PC scrolling proof → Commander Keen | Carmack 打开新图形可行域，Romero/Hall/Adrian 等转译成游戏 | **endogenous window**，不是单纯被动赶上技术时代 |
| Apogee + shareware | 免费入口、后续付费、市场与真实现金验证 | 市场接口购买全职自主性；同时有 Softdisk 履约成本 |
| Wolfenstein 3D | 新实时渲染能力、游戏速度与商业回报 | 现金增量首先买选择权，而不必然是扩大团队 |
| DOOM | 空间/光影、编辑器、关卡/战斗节奏、网络、WAD | 技术 → 玩家体验 grammar → 可完成工具链；不等于“发明所有 FPS” |
| DOOM 传播 | 免费试玩、直接销售、多人、mod/UGC | 发行/社区是产品系统组成部分；社区存在≠销量因果已证 |
| Quake | 全 3D、渲染/网络/内容转化难度同步提升 | 技术越来越成功，内容返工与目标/治理负担也可恶化；**Quake 产品仍是成功的** |
| id split → Ion Storm | 创始人带走不同能力，旧互补关系不再完整 | 能力不变而团队/项目/决策权改变，是强纵向比较 |
| Daikatana vs Ion Storm Austin / Deus Ex | 同一公司资本/声誉之下，不同经验资产与局部管理 | 不能用 Daikatana 把 Ion Storm 全体写成失败 |

## 三、DOOM 是“能力创造机会窗口”而非“时代给天才机会”

机制应写为：

**想做的玩家体验 ↔ 技术限制迫使自主发明 → 新可行域 → 设计/关卡/工具把能力转换成玩家行为 → 发布/付费/社群验证 → 后续扩散**。

Carmack 2013 年 WIRED 直接回顾早期 id 反复在“勉强可行的技术边缘”推进工具，再寻找游戏形式（CASE-016:E015）。Romero 2020 年 PC Gamer 访谈又谈到 DOOM 关卡效果需要亲自改工具和代码：技术创造者与“设计者”不是毫无重叠的两个箱子。

**CAPABILITY-CREATED-WINDOW / ENDOGENOUS WINDOW** 应当是 **technical-opportunity 来源维度**，不是与 CAPABILITY-COMPOSED / CAPABILITY-SHAPED 互斥的新立项标签；相同 id 团队可以同时符合三者。

最小证据链要回答：旧瓶颈具体是什么、谁在何时实现了什么、新体验如何可玩、什么编辑器与 scope 控制使它可交付、市场如何回报、还有哪些硬件/先行者/传播共同解释成功。

禁止单因论：DOOM 不是首次第一人称视角、不是发明 BSP 数学，也不是所有 FPS 设计要素的唯一来源。

## 四、成功时的互补，怎样在 Quake 变成成本

早期团队不是只有两位 John：Tom Hall、Adrian Carmack、Sandy Petersen、Kevin Cloud、Jay Wilbur、Scott Miller 等人参与定义内容、视觉、组织与商业。Kushner 的“双主角”有文学解释力，但不能充当完整 credits 和权力结构。

必须拆开：**能力互补**（能否完成工作）、**目标兼容**（想做同一类产品吗）、**治理兼容**（谁对 scope/技术/发布有最终裁决权）。DOOM 开发期 Tom Hall 的方向冲突已显出差异，不能将冲突简化为单个人的好坏。

Romero 2023 长访谈回顾 Quake 的巨大 R&D 成本：引擎性能随研发推进变化，先做出的关卡/内容无法代表新的能力边界，技术、内容与团队疲惫相互强化；Carmack/Romero 后来讨论过拆分技术和产品周期的反事实。**这不代表 Quake 是一款失败游戏。** 产品历史成功和创始人关系/生产制度失败可以同时成立。

此处把 Quake 与 Limit Theory/Factorio 共同用于问：**技术强了，剩余的 player/product obligations 是减少还是反增？研发何时应该停？** 但不能把 Quake 简写成 Limit Theory 式 project non-completion。

## 五、Ion Storm 的关键对照：Dallas 不等于 Austin

Romero 2023 GamesBeat 直接谈到 Daikatana 中途由 Quake 向 Quake II 改引擎导致未预料的转换成本。这是可追踪的生产机制，不是“设计师自负”的道德寓言。原书关于 Ion Storm 的股权、Eidos 资金、创始人争端等仅能标 S1 / 待合同与同期报道复核。

**2000-12-06 Warren Spector 亲写的 Deus Ex 同期 [postmortem](https://www.gamedeveloper.com/design/postmortem-ion-storm-s-i-deus-ex-i-) 是关键对照**：Deus Ex 的 vision 来自 Origin / Looking Glass 时期持续积累；Austin 本身也发生两个设计领导人互不相让的内耗，后来合并重组；Dallas 的异地矩阵管理让 Austin 艺术团队的人事/汇报权混乱；Dallas 的负面新闻又妨碍 Austin 的招聘与士气。但 Deus Ex 仍在 2000 年完成并得到正面专业反馈。

由此可研究 **同一公司 / 外部资本 / 品牌下不同团队的 capability-project fit 与 local decision rights**，而不是把 Ion Storm 简写成“罗梅洛又把一家公司毁了”。Austin 成功也不等于毫无组织错误。现阶段仍只将此作为 CASE-016 的纵向延伸，不凭空新增已完成的 Ion Storm Case。

## 六、给整个系列的比较入口

- **Gunpoint / The First Tree**：能力认知引导立项；early id 再添“能力主动创造新机会”。
- **Nomada / Playdead**：互补创始人可能在 authorship、产品目标、control 上失配；Quake / Ion Storm 加入纵向验证。
- **Limit Theory / Factorio**：工程成熟是否真的推动产品完成，以及技术足够好的 stop condition。
- **Zachtronics / Spiderweb**：长期成功后 product grammar 形成路径依赖；与 Quake“前沿升级超过内容/组织转化速度”是不同机制。
- **GSC→4A、俄罗斯/乌克兰/白俄罗斯 PC 游戏**：作为美国纵向技术—产品—组织基准跨书引用，比较人才出走、技术与发行制度；**不以民族性排名**。
- **教育/行业版本/社会版本三层**：Softdisk 的训练、shareware 的市场验证、Quake 的组织裁决权都比“某国人天生怎样”更可证伪。

对于读者：程序员从 Carmack/Limit Theory 看 frontier 与停手；关卡策划从 Romero 看设计与工具往返；互补创业者看 founding complementarity 与 governance compatibility；第一次成功的人看如何把新现金变成选择权，而不是更大固定承诺。对应全书 Part IV 与 Part VI。

## 六点五、从Softdisk到Sierra：early id的连续优势也可解释为“保护下一阶段选择权”

[040](early-id-strategic-disloyalty-american-individualism-040.md)把此前零散决策连成一条更精确的纵向变量：`OPTIONALITY PROTECTION × AUTHORITY DISCOUNTING × REVERSIBLE LOYALTY`。

1990–1993，团队先后不把Softdisk稳定身份、Keen成功系列、传统publisher地位和Sierra收购报价视为不可撤销的历史权利。最强解释不是“他们天生反叛”，而是**每次都有越来越强的外部验证和outside option**：Keen/shareware现金、3D原型、直接用户市场，让切割旧安排不再只是性格姿态。Sierra案例尤其证明id并非原则上拒售，而是在对未来价值和decision rights定价。

但这条能力在Quake以后可能出现反噬：**如果高切割能力不再伴随同等强的产品判断/反馈，组织关系资本会被过快耗散**。Ion Storm可作为“相信自己+放大自由”并非自动正确的后段压力样本。这个倒U关系目前是H级框架，不升级为Claim。

## 六点七、“真理之盾”并非人格常数：Ion Storm是对early id方法的规模反例

新增 [041](truth-shield-to-narcissism-shield-ion-storm-governance-041.md)。Romero 2023本人明确承认：Ion Storm的整体formula已经改变，而自己没有相应改变方法；过去在id获得成功所依赖的团队、技术、决策方式与环境不能直接搬过去。

Deus Ex是最重要的内部控制：同样的Ion Storm资本与“design autonomy”理念，在Austin由Warren Spector形成更清晰的项目责任链并最终收敛；所以不能把Dallas问题归结为“创作自由太多”。新的纵向变量是`FEEDBACK_INTEGRITY / COMPLEMENT_DEPENDENCE / SCALE_DISCONTINUITY / DECISION_RIGHT_ACCOUNTABILITY`。

## 六点九、互补不是岗位拼图：early id 的高价值可能在“对方真的能让你改答案”

[042](carmack-romero-complementary-error-correction-network-042.md)把二人关系从“Carmack技术 + Romero设计”升级为事件级纠错网络：Dangerous Dave显示技术突破需要战略解释；Wolf3D push walls显示设计端可迫使工程洁癖让步；Doom时期Romero本人称自己是design与Carmack之间的glue；Quake时期则出现共同artifact与反馈延迟拉长，互补逐渐转为互相归因。

同时必须保留Tom Hall等第三顶点与Playdead CASE-056反例。当前更强模型是：CAPABILITY COMPOSITION → EPISTEMIC CORRECTION → GOVERNANCE DURABILITY 三层分别审计，不能用产品成功替代后两层。
## 六点十、组织也会“后发化”：Doom 4 → DOOM 2016 的问题主权重建

新增 [043 — 从答案追赶到问题主权](doom-organizational-aging-rejuvenation-043.md)。它把本纵向案例继续推进到 mature id：曾经创造 FPS 语法的组织，在 Doom 4 阶段也可能被当代成功 shooter 的既有答案俘获；2016 的关键不是简单“复古”，而是重新以 push-forward combat / combat chess / make me think, make me move 定义问题，再用持续 playtest 和删改让现实裁决具体机制。

043 暂定的组织变量包括：PROBLEM SOVEREIGNTY、REALITY ARBITRATION、BENCHMARK CAPTURE、SUNK-COST KILL CAPACITY、PROTECTED HERESY、SELECTIVE INSTITUTIONAL AMNESIA 与 INVARIANT RECOMPOSITION。杨小凯/林毅夫“后发优势—后发劣势”争论只作为模式切换的类比背景，不直接升级成游戏产业因果。

Hall → Petersen → American McGee 的后续压力测试进一步修正“组织失去某类人才=失去某类能力”的过粗叙事：需要区分 **CAPABILITY PRESENCE vs CAPABILITY AGENCY**、**PERSONNEL AMPUTATION vs DECISION-RIGHT AMPUTATION**，以及 **SOLUTION DIVERSITY vs PROBLEM DIVERSITY**。当前更安全的 H 级解释是 **ORGANIZATIONAL COGNITIVE PRUNING**：连续成功会强化曾经有效的出题方式，而不必真的把异质人才全部清除。详见 043 §13.5。

这个延长段把 id 从“创新英雄”改造成完整生命周期样本：**产生答案 → 成功与制度化 → 创始人栈失效/能力偏科 → 学习外部标准答案 → 重新夺回问题定义权**。下一步用 Eternal 与 The Dark Ages 检验：2016 的新理论是否会再次教条化，以及组织是否仍能推翻自己刚建立的成功公式。

## 六点十一、第二答案测试：革命理论也必须重新接受现实审判

043 的下一轮 Eternal → The Dark Ages 已进入跨行业节点 [Self-Obsolescence / Second-Answer Test](../../cross-industry/self-obsolescence-second-answer-test-001.md)。DOOM 2016 找到 push-forward / combat-chess 后，Eternal 将其进一步系统化；Dark Ages 则公开改变 movement / control grammar，并把多个 shield 行为压到 contextual input。研究问题因此从“id 能否重启失败项目”升级为：

> **一个组织能否在上一套公式仍然成功时，主动撤销它的下一作默认权？**

当前新增 H 级变量：DOCTRINE HARDENING、MANDATORY ACTION TAX、INTERACTION-SURFACE COMPRESSION、SUCCESS-FORMULA KILL CAPACITY、ORTHODOXY HALF-LIFE 与 SECOND-ANSWER TEST。跨行业对照只用来检验机制，不把 Grove / Apple / Nintendo 直接混入本书游戏 Case 统计。

## 七、待核证据优先级

1. Quake 原型转向、引擎/关卡返工、谁有最终裁决权及 Romero 退出的多方直接版本。
2. Ion Storm/Eidos equity、board、milestone、approval、资金及 Dallas/Austin 人事审批；不要用原书数字直接当财务史实。
3. Tom Hall、Adrian Carmack、Sandy Petersen、Kevin Cloud、Spector、Harvey Smith 的一手叙述修正双人视角。
4. Daikatana 改引擎的时间/工时成本与 Deus Ex 生产数据，形成可比较样本。
5. DOOM 具体技术—game grammar—玩家反馈链，以及当年的真实销量与 mod 职业通道的偏差。
6. 另外找“有先进技术但没有产品闭环”以及“产品创新不依靠新技术”的同时代对照。
7. Rage 的技术目标、产品目标和组织结构一手材料，避免把评论口碑误写成“技术强/产品弱”的因果。
8. Doom 4 reboot 的 kill-right / decision chain：id、ZeniMax、Bethesda 各自的实际权限、预算与人员迁移。
9. DOOM Eternal → The Dark Ages：资源循环、玩家 agency、Eternal 反馈与 Dark Ages 方向变化的直接开发者证据。
