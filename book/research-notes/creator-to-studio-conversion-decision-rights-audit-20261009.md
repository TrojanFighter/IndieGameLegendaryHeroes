# 从原型作者到产业决策者：创作者吸纳、能力转化与产业筛选机制（2026-10-09）

- **Program:** 中国 029 正统倒置 × 028 Hacker/Scale Down × Earned Scale × Creator Selection
- **Status:** EVIDENCE-GROUNDED WORKING PAPER / SELECTION-MECHANISM HYPOTHESIS, not a representative cross-country result
- **Date:** 2026-10-09
- **Author-origin premise:** 中国较强的成熟品类商业生产能力，未必能把原型作者按同等数量级转化为原创项目的创作决策者；甚至有可能将其吸收到只奖励成熟产品优化的岗位。这是必须量化检验的结构性假设，而不是已被证明的全国现象。

## 1. 为什么不能以“公司招到了优秀原型作者”作为原创生态成功

要分别追踪四个 transition：`hobbyist → completed playable prototype → shipped commercial game → possesses actual product direction rights`。每一步并不自动发生。

一个原创作者进入商业公司，可能：
- **AUTHOR-ENABLEMENT：** 带着原型/设计哲学成为小团队负责人，保有核心设计决定权、玩家测试权和项目终止或转向建议权，获得真实资源和回报；
- **AUTHOR-INTEGRATION：** 进入项目设计部门，与生产工业互补，但只能影响局部，仍能成长为主创；
- **AUTHOR-ABSORPTION WITHOUT AUTHORITY：** 原创能力被招聘宣传承认，却长期从事竞品拆解、运营调整或大项目模块生产，缺乏完整产品发起权；
- **INDEPENDENT / EXIT：** 保持独立、兼职制作、转其他创作或完全离开开发。

**重要边界**：受雇不必然抹杀原创能力，独立身份也不必然保有作者性。判断的是完整创作经验、实际项目决策权、对成果的经济权利，而非公司国籍/规模。

## 2. 同一时期中国存在极不相同的生产结构：2026《触乐》投资现场

2026-04-29，《触乐》实地采访成都2026年4月20多支团队的独游路演，记录了：

- 一名手游老兵拟融资**1800万元**作为项目启动款；另有三人类银河恶魔城团队认为AI可把原本7000万元规模的设想变为需要500万元融资。两者是**受访者预估**，非核算成本。
- 两人项目《仙骰诡道》自费全职约8个月（以工资机会成本计20多万元），希望20万元预付款，但受访时明确无融资也将继续开发。
- 某发行部门从80款候选签了两款，**两款均未收回预付款**；一个初步项目直接对标《空洞骑士》推算10–20万销量并要求300万元 MG，发行人认为推算无依据。这是**选择偏差 + benchmark analogical forecasting failure** 的具体材料，并不能由此推断所有美术类银河恶魔城项目失败。
- 业内孵化从业者表示：对于3–4人的限定产品，200万元可在其所见上海样本中支持开发至上线，2–4人项目未必要股权融资；此为个人经验判断而非全国预算标准。
- 同文采访的鹰角**开拓芯**代表对学生项目的判断强调核心设计力、学习能力与作品 proof，不只靠大厂履历。

**重要案例：** 2024中国传媒大学六名学生完成《鼠鼠来了》毕业作品，用于比赛/公开展示；两位核心作者毕业后约两周完成《浣熊推币机》初始原型；开拓芯在看到两个作品后约一个月内形成投资意向；2026-04首发24h官方通报卖10万份。这是 **SCHOOL PROJECT → AUTHOR PROOF → 2-WEEK PROTOTYPE → INVESTOR DISCOVERY → COMMERCIAL LAUNCH**，不应写成“独立游戏必须靠融资才可存在”，亦不应凭这一成功就判定该工作室长期续作能力已被验证。

## 3. 大公司如何处理原创者：Supercell 2026 对其过去失败的实质反思

Supercell CEO Ilkka Paananen **2026-02-10** 年报型文章描述重大组织修正，具有极高比较价值：

- 回顾《Squad Busters》2023年的两轮封闭测试：第一轮5000人、D7=29%，第二轮超14万人、D7=38%，但大规模上线后留存无法复现；团队认为**只验证D7、约一个月的soft launch、在产品愿景未确证前进行大规模marketing**是重大失误；最后7500万次下载、总收入超1亿美元仍决定停止运营。注意为当事方的统计/回顾，不是独立审计，也不是“高收入必为成功”。
- 2025年新游戏/创新投资**较2024年翻番**，2026年计划再翻番，企业另设 New Games 专门组织，与现有 Live Games 经营团队分开。它的判断是**两种工作的节奏、评价标准、文化根本不同**。
- 为创作者提供**真实预算约束**、团队而不是预先筛中的游戏点子作为greenlight对象、成功上市可分享游戏利润；Spark 以 Game Jam 与快速原型来测试潜在联合创始人与小团队匹配，接纳公司内外成员。
- CEO 特别承认之前所谓startup-like small cells只做了一半：没有真的提供能够与自己独立创业竞争的资源、激励与自主权结构。
- **负面边界：** 公司宣传与制度设计不等于真实转化率成果；目前未公开全体 Spark 参与者最终项目发售/所有权数据。Supercell 的产品也是商业 F2P/live-ops，说明成熟商业体系与原型驱动不按“买断制vs手游”分界。

## 4. 社区与跨国数量级：目前只能建立数量观察，不能算“原创者转化率”

- GGJ官方 2025：35,427 参与者、12,100作品、805站点/98国；2026：39,197 参与者、9,874作品、824站点/94国。全世界参加，不能写成欧美国别样本。
- GGJ2026 对3535名志愿回答者的调查，61%曾参加其他jam，28%此前不认识自己的队友；37%学生、28%爱好者。9%左右回应率、志愿样本，不能直接用于总体推断，更不能代表多年后职业轨迹。
- GGJ中国区 CiGA 2026官方活动方披露：约3500人、45线下站、650余作品，600多件提交GmHub；不能不经去重与活动口径核对，就算其占全球GGJ作品的比例。这里是国内较真实的现代原型活动规模，不是“没有Game Jam”。
- CiGA Game Jam 2025另一场活动有2000余人、450余件作品；与 GGJ x CiGA 2026不同活动，不得误认同一年度连增长率。
- 2026同行评审学术论文通过66RPG档案与前成员访谈证明2005—2017中国有活跃的业余创作体系、教程/作品/脚本分享网络，2013起衰落。作者调查25份有效问卷，**其中5名受访核心成员目前全职游戏业**：这不是 66RPG 成员职业转化率（样本选择严重不代表总体）。
- 论文重要细节：66RPG创始人亲手搭建社区；早期rpgchina与66RPG的比较中，后者更重普及动手工具和免费教学；社区中资源被盗用出售、创作者加密工程与监管/商业化变化共同冲击公共知识积累。其经验恰好否定“中国从未有Hacker创作文化”的绝对化叙事。
- 全球/中国差距尚缺同一口径的**实际开发者分母、被动退出队列与职业创作者决策权数据**。

## 5. 新研究概念：不仅是“Creator-to-Studio Conversion”，还是 “Creator-to-Decision-Right Conversion”

两类量必须分开：
1. **CREATOR-TO-STUDIO CONVERSION RATE**：一个固定入门原型作者队列，5年后有多少仍然完成、销售或参与完整产品，以及能否建立可持续团队。
2. **CREATOR-TO-DECISION-RIGHT CONVERSION RATE**：其中有多少拥有独立发起、调整、终止项目、控制关键机制与玩家测试的实际权力；可以发生在独立工作室内，也可以发生在大公司内部。

建议另计：
- **ORIGINATOR AUTONOMY RETENTION**：原型作者入职后的3/5年，仍具有独立定向创作空间者占比；
- **PROTOTYPE PORTFOLIO RECOGNITION**：原型业余经历是否可换取面试、薪资、创始/主策机会；
- **CREATIVE ATTRITION RATE**：最初完成可玩原型的人，几年后不再继续制作游戏的比例，区分经济压力、自愿退出、角色转型、合同限制等原因；
- **IP / PROFIT / REVERSION RIGHTS**：是否持有IP、项目利润分成、失败项目代码/经验重新利用的自由；不同国家劳工/IP法律比较前必须以UNKNOWN标记。
- **DESIGN THESIS DISCOVERY RATE**：每个开发者每年的不同玩法假设原型、首轮可用玩家测试、项目被及时取消的比例。

## 6. 最小可执行实证研究：两层队列，避免“举例=数量级”

**A. 人员成长队列**：从2018、2020、2022年各地的CiGA/GGJ/GMTK/LD/BOOOM投稿者抽样，去重并核实作者身份；与 2026-10 的现状关联：职业职位、仍制作小作品与否、过去3年发起产品数、实际主导权。最好经同意访谈，切勿凭社交账号名字强行匹配私人身份。

**B. 商业首作工作室队列**：对应上一阶段 Earned Scale 表格，用 2015—2023 发布首作的公司作为分母，逐步统计 2026 年是否形成第二代或新的商业游戏，项目期限未到的标为 **RIGHT-CENSORED** 而非失败。

**建议初次采集字段**：entry_year, platform, country, prior_industry_years, prototypes_shipped_pre_job, hours spent, first_paid_game, year, employee/employer role, actual project decision-right category, retained_ip, founder/employee, game_sales_public_or_estimated, invested/publisher/retained-profit source, continued_authorship_since, industry_exit_cause, evidence_tier, right_censored.

**反对过度政治化国别归因**：
- 即使欧美整体水平更高，也需控制地区、年代、类型、教育、工资、经济安全网、语言和市场可及性；
- 就业进入大厂对某些人可能正是获得创作资源的路径；不能预设其必然“被同化”；
- 无论中国/芬兰/美国，成熟Live游戏与从零孵化的组织制度不同；重要的是公司是否**有意识分开两者并保护发明者**；
- 公开资料只能显示声称的组织原则，不能不经访谈就断言员工具有真实自主权。

## 7. 一句可用于章节但需标示为研究判断的收束

> 真正的问题不是一家公司能招到多少聪明的开发者，而是这些开发者入职十年后，还剩多少人在亲自发明游戏，又有多少能决定它们是否被制作出来。

它回应春登/农民发明家及正道/邪道武功的作者比喻，但该比喻属于社会制度研究的分析工具，而非对国别从业者人格的道德判断。
