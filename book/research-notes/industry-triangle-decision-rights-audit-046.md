## 0. 与现有研究的分工

旧文提出「创作者品味—消费者偏好/市场表现—资方预期与操控」三角关系。中国 017–021 已深入研究玩家如何选择、付费如何给不同需求加权、作者信用如何转换为议价权。因此本篇**不再重复**“渠道为王”、富豪阶级游戏性或品味基础设施。

本篇的新增问题限定为：**在某个具体项目的关键节点，究竟是谁能提出方向、决定花钱、驳回、修改、停产、保有 IP，以及携带作品声誉离开？这些权利又怎样随产品验证而转移？**

一个人在片尾列为 director、producer 或 founder，不足以回答这些问题。“有创作自由”也不是一个一维量。

## 1. 三角关系应按时期、交易与组织拆开

静态三角遗漏了两类中介：

1. **分发与注意力中介**：商店、发行商、平台、媒体、创作者社群。它们不一定拥有正式 veto，却能通过可见度和准入改变项目可行性。
2. **组织与合同治理**：共同创始人、董事会、IP 权利人、关键专业人才、债权与资金来源。资方、发行商、IP 所有者未必是同一方；创始人也未必控制全部决定。

因此使用三角作为问题入口，正式审计采用五类主体：

`CREATOR / TEAM — AUDIENCE — CAPITAL — DISTRIBUTION — GOVERNANCE`

任何项目应先辨明**谁在何时拥有哪项权利**，再研究它们是否与个人品味、真实用户需求相符。不得把所有外部制约统称“资本打压”，也不得把一个人的主创署名等同于排他性控制。

## 2. Decision-Rights Ledger：七项可以落到证据的权利

| 权利 | 应寻找的可见证据 | 常见误判 |
|---|---|---|
| `THESIS / ORIGINATION` 提出产品方向 | 同期 prototype、pitch、开发日志、明确设计发起人 | “职称最高者就是作者” |
| `GREENLIGHT / KILL` 立项及终止 | 批准、取消、项目冻结与复工记录 | “能提点子就是有立项权” |
| `SCOPE / ROADMAP` 机制和范围取舍 | 版本史、公开转向、设计裁决、工作室内部证词 | “主策执行了就一定由他决定” |
| `BUDGET / HIRING` 预算和能力采购 | 融资用途、人员/合同安排、资金来源与提款限制 | “拿到投资等于预算可任意用” |
| `MARKET INTERFACE` 测试与销售路径 | demo、Steam/平台账号权属、发行协议、地区/档期与定价权限 | “市场决定产品”即“玩家真实决定产品” |
| `IP / CREDIT / DATA` 归属及署名 | 商标/IP、credit、用户关系、后台数据和公开作者认知 | “创造者自然拥有作品及用户” |
| `EXIT / NEXT TITLE` 离职、另起炉灶、下一作 | 竞业、资产迁移、保留收益、后续项目筹资和作者品牌可迁移性 | “首作成功自动买来下一次自主权” |

每项至少按项目**成立—第一个可玩原型—融资/签约—上市—成功或失败后**分时记录。UNKNOWN 不能猜。

## 3. 两个不同层次的机制假说

### H1｜市场给作者判断定价，可能增加其议价权

`明确的作者性 → 可识别玩家需求 → 可重复的销售/资助 → 更好的 outside option → 下一次更有利的谈判位置`

这和[020 作者品牌资本](../../country-studies/china/020-author-brand-capital-portable-demand-bargaining-power.md)相连，但后者侧重声誉可迁移性；本篇侧重**具体哪一项权利真的发生了转移**。

若无法观察到合同、融资条件或对项目关键决策的实际控制，最多写“可能提高议价能力”，不得直接写“获得完整创作自由”。

### H2｜收入接口可能经职业晋升筛选下一代决策者

`收入目标 → 企业内最受奖赏的能力 → 晋升/招聘 → 有权筛选项目的人 → 下一轮项目方向`

这比“资本影响创作”更有解释力，也更容易被证伪。对中国历史商业游戏行业，观察 monetization、发行/流量、成熟赛道运营岗位和原创设计/玩法原型岗位在人数、预算权限、晋升、决策权上的**相对量级**；对美/日/斯拉夫同时取相同口径。高 F2P 能力是真实能力，不等于“没有创新”；判断必须按创新维度和历史时期分类。

## 4. 人物对照：用不同机制，而不是堆成功者

- [CASE-007 Gunpoint / Tom Francis](../../cases/CASE-007-gunpoint.md)：从工资与低成本原型取得一段可自行决定的试错窗口。研究其最终能控制的 scope、销售和后续作者身份，不把媒体履历与品味全部归入个人天赋。
- [CASE-016 early id Software](../../cases/CASE-016-early-id-software.md) 与 [040 Strategic Disloyalty](early-id-strategic-disloyalty-american-individualism-040.md)：Softdisk 工资/生产资源、shareware outside option、拒绝收购与后续权利变化。早期能做出新产品，不代表成熟后的组织治理会继续正确。
- [CASE-047 The Witness / Jonathan Blow](../../cases/CASE-047-the-witness.md)：前作保留收益购买下一作的能力和较长时间的自主决策，但不表示这种高成本下注可普遍复制。
- [CASE-049 Outer Wilds](../../cases/CASE-049-outer-wilds.md) 与 [CASE-057 thatgamecompany](../../cases/CASE-057-thatgamecompany-vc-equity-expansion.md)：外部资本可扩大能力，亦可能带来治理约束；没有合同证据时，不虚构发行商或 VC 的某项 veto。
- [CASE-056 Playdead](../../cases/CASE-056-playdead-founder-governance.md)：艺术成果与互补创始人能力并不保证长期 authorship / governance 一致。
- [CASE-033 征途](../../cases/CASE-033-zhengtu-shi-yuzhu.md)：作为收入模型与资源转换制度比较对象，**不是**玩法范式创新和独立作者生产的同一分母。

这些案例说明机制的可能形态，**不能**以六个明星对象推出哪国更常见。需要加入没有获得自主权、取得自主权但项目失败，以及主动选择组织内职业路线的长期非明星对照。

## 5. 失败与异议也必须出现在理论里

- 权利集中于作者，可能加速有效判断，也可能让错误更久得不到纠正；见 [041 Ion Storm](truth-shield-to-narcissism-shield-ion-storm-governance-041.md) 与 [042 互补纠错](carmack-romero-complementary-error-correction-network-042.md)。
- 玩家反馈不等于有效发现：测试对象可能不是目标受众，单点指标可能只是渠道偏好，热度未必转成付费。
- 外部投资不必然侵蚀作者性：资本可以购买专业能力、可持续运营和风险缓冲，并通过治理提升纠错能力。
- 获得作者权不是每个人的最优人生选择。必须比较收入、家庭 burn、失败后就业、人格与职业目标，参见 [OQ-005](../../OPEN-QUESTIONS.md#oq-005作者权-vs-工资回报为什么有人永远不离职)。

## 6. 未来传记的强制核对清单

在任何 Profile 的至少一个真正决策节点回答：

1. 他当时面对的真实替代路线是什么？离开原组织会损失哪类资源？
2. 想法、否决、预算、IP 和市场账号各由谁决定？有明确材料还是 UNKNOWN？
3. 哪一轮玩家/市场信号被谁读取、怎样解释、据此改了什么？
4. 作品失败以后，此人保有的是钱、技术、作品署名、玩家、雇主关系，还是只剩经验？
5. 如果另一个人采用类似路径而未成功，我们能观察到什么？分母如何定义？

## 7. 下一步需要取证什么

- 同期合同、联合创始协议、采访中具体 greenlight / kill / IP / veto 描述；
- 创作者在融资前后同一项目实际决策改变，而非募资宣传措辞；
- 每国相同岗位类别的职业梯队、组织配置与可见决策权限；不能以单个公司的强例代表总体；
- 失败或未签约项目在不同 market interface 下的负反馈与退出结果；
- 2026 的平台、合同、成本和市场数据不得用 2010s 的条款替代。

**Current verdict:** 可建立“谁控制发现、生产和退出”的比较账本；国家规模、普遍性及强因果仍属于 OPEN。此前三角关系提供了很好的问题模型，但未完成的权利—数量级审计不能靠修辞补齐。
