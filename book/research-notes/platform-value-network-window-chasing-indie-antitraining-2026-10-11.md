## 0. 本轮真正新增了什么

既有研究已经证明“商业岗位与独游目标函数不匹配”“旧渠道模型可能遮蔽国际直销”以及“Scale Down是保留体验核心、改写资源约束的能力”。本轮新增的不是再说一遍“商业训练不好”，而是把 **价值网络的收益分配 → 立项时间点 → 人力扩张节奏 → 市场学习路径 → 作者能力再生产** 接成一条可检验的生产机制。

> **H / 核心机制**：一种既掌握用户入口又参与游戏商业化的价值网络，可以先以流量、广告、推荐、结算和议价权筛选产品的收益模型，再使资本、组织、招聘和职业声望偏向“成功品类出现后快速复制并放大”的能力；这种能力对追赶型项目可能高效，但若未经重训进入原发创新型极小团队，可能产生系统性的负迁移。

这里的“价值网络”借鉴Christensen，但不局限于硬盘行业或低端颠覆：它还涵盖 **玩家可见集合、平台收入函数、开发者用户关系产权、融资与职业筛选、文化评判及未来创作供给**。本轮为跨制度的理论扩展，尚不是已证明的中国独有因果规律。

### 模型的五个相互独立关口

1. **Access**：谁决定游戏能否接触玩家（社交API、联运商店、应用商店、Steam发现、creator网络）？
2. **Rent / bargaining**：谁从销售、支付、广告、服务器及流量中收费，开发者拥有什么outside option？
3. **Selection**：什么类型的项目容易在该网络中融资、获曝光、回本？商业需求发现、付费需求发现和玩法体验发现分别受到何种奖励？
4. **Production rhythm**：未知需求下先采购产能，还是先用低承诺原型购入信息、在证据充分后扩编？
5. **Reproduction**：什么样的人获得职位、预算、作者权、晋升与下一次立项机会？成功者会不会把局部制度的成功答案误认成通用规则？

不要把以上五环由“逻辑上可能”偷换为“数量级已证实”。

## 1. QQ空间案例：平台创造市场，也可能重新分配创新租金

**S1 / 同期专业报道**：[《腾讯开放前传》，第一财经周刊，2011-06-13](https://www.yicai.com/news/856328.html)记录：五分钟《开心农场》在接入QQ空间前已通过其他社交平台达到约100万DAU、至少300万元月收入；2009年接入后服务器承压，腾讯对农场游戏实施买断与重写运营。报道称买断费用500多万元、2009年第三季度产品DAU超过1500万、月收入超过5000万元；**金额为媒体报道及当时采访，并非本库复核后的审计流水**。马化腾同期回应买断系双方谈判，并否认胁迫；不得将“存在悬殊议价能力”直接写成违法行为。

该例必须双面读取：

- **平台正向价值**：社交关系、流量、基础设施和运营能力能够把第三方玩法放大到远超其原有规模；中小开发者可由此获得此前无法触达的市场。
- **平台权力问题**：原创玩法的发现者、承担扩张运营风险者、拥有用户关系者与最终取得收益者可能不是同一个主体。作品被规模化，不意味着原创开发者持续占有等比例价值。
- **不能推出**：所有腾讯合作均采用买断、所有开发者被迫签约、开发者完全得不到收益，或中国互联网独有此问题。

**P0/P1 / 公开分成政策对照**：[2012年Q+报道](https://news.cntv.cn/20120111/116056.shtml)披露月收入10万元以下开发者获得100%；10万至100万开发者70%；100万至1000万各50%；[2013年财新采访腾讯侯晓楠](https://other.caixin.com/2013-08-26/100573808.html)确认2012年有相关调整。**平台、合同类型、分段区间与时间不可混同**。

**Weak Signal / 2025-08-12 B站评论截图（用户提供，未找到精确视频及可复查评论URL）**：留言者自称长期从业，叙述2016年QQ空间游戏导流、服务器租用、竞价广告、机器用户等经历，并提出一组流水对应分成比例，与上述公开政策不一致。处理为 **不可归属到已核实企业条款的口述信号**：仅保留机制线索与待查范围，不能认定该评论者的身份、机器人比例、广告单价和所有CP利润情况。此前聊天曾指向一篇2021年知乎相似叙述；现未核正文与作者关系，故不把它当作来源闭环。

## 2. “逆推荐规训”要操作化为平台目标函数，而不是道德标签

将作者雄文里的“渠道为王”“逆推荐规训系统”“赛博地主”分解：

- **发掘需求型发现机制（理想型）**：平台受激励把产品与用户匹配，从成交、留存和长期满意度受益。
- **售卖曝光型机制（理想型）**：平台出售可竞价注意力，拥有高预期用户价值（LTV）与高贡献利润率的产品能支付更高的可承受获客成本；广告成本可能随同类竞争上升。
- **混合现实**：两种机制可以并存；推荐也会追逐交易，广告系统也关心体验/转化。不能直接把“中国平台”与“美国平台”归为两种纯型。

研究须分辨：**Paid impression vs organic discovery；渠道毛流水分成 vs 广告费；发行商可选服务 vs 平台必需费用；营收 vs 开发者净利润；商业化成功 vs 玩家体验质量**。

**P0 / 平台制度边界**：[Steamworks Visibility](https://partner.steamgames.com/doc/marketing/visibility)载明不能付费购买Steam算法曝光；愿望单、页面流量、转换率和评论的实际算法地位应按文档核对，不得把“好评率高”当算法保证。[Steam Direct](https://partner.steamgames.com/steamdirect/)公开允许权利人自行开户，完成税务/银行/身份及每款100美元应用费即可走直销流程，不要求另签第三方发行商。Steam有可见度稀缺、算法偏差和外部营销门槛；**它不是自然公平或零营销市场**。中国本地合规、境外税务与各市场实际发行运营成本另行审计。

截图中“所有中国小团队必须有海外发行商才能卖”的断言因将 **商店费用、可选发行代理、税收、退款、推广投入** 强行叠加而无法成立；但“平台存在获客与可见度问题”并非因此被否定。

另一项逻辑检验：销量证明用户在 **实际接触到的选项** 中购买了什么，不能证明用户在未出现的新玩法面前仍有相同偏好。需求发现型平台是否更易给原发玩法机会，还需控制制作预算、语言、发行时点、类型、用户规模与Steam头部集中度。

### 反垄断命题的正确边界

“社交+广告+游戏业务纵向整合”可能带来利益冲突；拆分、平等接入、算法透明、用户数据/账号关系可迁移分别改变不同市场权力。**结构性激励不自动等于已经实施差别待遇、违法垄断或拆分必然改善创新**。比较腾讯与Facebook/Zynga、Steam、Roblox、移动商店时，须同口径审计自身游戏竞争、佣金、转移成本和市场进入机会。

## 3. 两种相反的生产时间函数：风口赶工与探索验证

**A0 作者原命题（2026-10-11）**：中国若干大型商业研发组织常以PUBG、Lethal Company、《幻兽帕鲁》等已走红产品作为市场信号，快速集结人力、压缩开发周期、以高强度加班与大量营销费用抢上市窗口。相反，原发创新型indie应通过长期积累游戏阅历、反复低成本原型、细分用户识别、保核Scale Down与便宜的社区传播，控制burn rate及人效，**等证据出现再双向选择发行商、团队扩张和资本**。“砸钱招聘高质量做题家／人月工程／996甚至007”是作者批判性概括；项目普遍加班程度、盈利窗口长度与人员结构待证，不能写成全行业统计事实。

| 观察维度 | 已知赛道的风口追赶（exploit） | 需求未知的独立探索（explore） |
| --- | --- | --- |
| 市场信号 | 外部爆款先证明某种需求 | 自己提出未经证实的玩家体验假设 |
| 核心不确定性 | 能否抢占时间窗口、商业化和渠道 | 核心玩法可行、目标用户是谁、为什么愿付费 |
| 早期团队 | 可能快速扩人以平行制作内容和系统 | 通常保持小队与可删除scope |
| 投入对象 | 买产能、缩交付期、扩大投放 | 买信息、增加可逆试验次数、延长runway |
| 人才考核 | 已知答案下协调与高速度交付 | 问题定义、实现原型、设计删改与用户判断 |
| 营销 | 常采用付费流量、渠道联运 | demo/creator/community/愿望单/口碑，必要时也可买量 |
| 放大时点 | 可能以“竞品已爆”作为自家项目前置验证 | 自身demo或市场信号增厚后，按条件扩编 |
| 主要错误 | 对外部爆款过拟合，自身产品未验即扩张 | 过久探索、低保真误杀、传播失败、永不交付 |

**最重要的不是小规模永远优于大规模，而是承诺规模与已得到的证据匹配。** 追赶型项目有市场窗口、内容吞吐和并行任务，扩编可合理；原型阶段多雇10倍人，不会自动把对未知玩家需求的学习速度提高10倍。生产效率（有效交付/人月）与探索效率（有效可证伪信息/试错成本）必须分开记录。

**理论锚点**：James G. March (1991), [Exploration and Exploitation in Organizational Learning](https://doi.org/10.1287/orsc.2.1.71)：组织对已知知识的利用会获得更快收益反馈，可能压缩长期探索。本文件将其用于游戏生产节奏属于机制移植，**不能靠理论引用证明中国特有的频率或因果强度**。

### 应拿来对照而非直接宣判的案例

- **PUBG / Brendan Greene**：mod → H1Z1等实践 → standalone 的玩法谱系，对比 **2017《荒野行动》快速mobile化**。这不等于追赶项目只割国内市场：2018《荒野行动》在日本表现强；要分别测量原创机制、商业化改造和国际竞争力。既有主案[CASE-032](../../cases/CASE-032-pubg-brendan-greene.md)。
- **Lethal Company / Zeekerss**：独立开发与多人可传播互动循环作为探索样本；并非“没有先前多年实践、没有市场传播成本”的奇迹。见[CASE-011](../../cases/CASE-011-lethal-company.md)。
- **Palworld / Pocketpair**：从小队、宣传测试到更大团队，适合研究 **扩编的证据顺序**，但其实际预算与研发管理不一定精益；项目最终很大，不能称全程超低成本典范。所有团队人数、预算与时间线需回到一手采访立证。
- **Vampire Survivors**：早期便宜素材和小型原型，后续巨大成功；素材采购价不等于全项目开发成本；不能单靠右尾案例推总体成功率。
- **Hades / Supergiant**：成熟小团队用抢先体验向玩家持续学习，反证“独游一定是一人／廉价美术／不用完整团队”。
- **Helldivers 1→2**：第一代验证核心合作哲学，再用更大规模跨视角改造与市场再验证；作为 **explore → exploit → re-explore** 而非永久反增长样本，待生产史逐阶段核证。
- **中国反压力**：腾讯NExT、网易Mini已有原型与提案机制；《枪火重生》及其他中国独游、国内外大厂转型团队并不能自动排除。见[050制度比较](creator-selection-institution-comparison-050.md)和[岗位来源审计005](china-commercial-game-training-role-origin-audit-005.md)。

## 4. 商业游戏“反训练” = 岗位经验的制度特定负迁移，不是价值贬损

对接[中国028既有7项negative transfer](../../country-studies/china/028-hacker-spirit-scale-down-commercial-antitraining.md)；本轮新增 **时间与资金时点**：

1. **WINDOW-CHASE REFLEX / 追窗口反射**：先问“还能不能赶上热门赛道”，而不是“核心体验有什么尚未满足？”
2. **UPFRONT-COMMITMENT REFLEX / 前置承诺反射**：在自己产品玩家证据稀薄时，将“加人、加规格、加班”误认为降低不确定性。
3. **HEADCOUNT-AS-LEARNING FALLACY / 把人月当认知购买力**：并行工程产能 ≠ 开放题求解速度；尤其在做错题时会扩大损失。
4. **OUTSIDE-OPTION BLINDNESS / 退出选项盲区**：把本地渠道/发行代理/买量视作不可拆分的世界规则，看不到Steam直发、mod、试玩节庆、社区和海外creator路径。
5. **SUCCESS-RECIPE INHERITANCE / 成功经验制度化**：经过渠道利润、招聘、晋升选择留下的“好员工”，后来成为下一代立项评委；即使市场入口改变，旧评价标准仍被复制。
6. **SCALE-DOWN MISREAD / 错把收缩当弱小**：只学会保住spec并请求新增资源，不练习删除scope、替代资源、限制承诺以及让小原型直面玩家。

**保留正迁移**：大型商业团队的程序、性能、网络、数值经济、在线运维、美术管线、质量管理、国际本地化、组织协调可能极有价值；原型期与产能期的最优组织不同。最危险的是把“在一个业务中成功做对题”扩展成“任何问题我都能出题”，并用资金替代创造性判断。

### 与应试教育过拟合的接合点（H）

学校可能奖励标准题熟练度；高收入商业组织可能优选已知目标下的交付者；他们获得升迁与决策权后可能延续标准答案的立项规则。**教育 → 职业 → 资本 → 作品 的因果强度未测**。优绩教育也可训练工程扎实、耐心和高质量证据处理；组织训练可能比教育背景有更大解释力。不要写成中国国民性或所有名校生都无法创新。

## 5. “价值网络自我再生产”与开放市场的边界

候选反馈环：

```text
渠道/广告/支付价值捕获
  → 开发商选择可负担买量与回本的产品
  → 投资、招聘、晋升奖励已验证赛道快交付
  → 更多同类型作品和同类岗位经验
  → 玩家可见集合与行业成功样本被重复筛选
  → 立项者以这些历史数据论证下个相似项目
```

每一个箭头单独审计。市场扩大既能让平台与作者共同获益，也能制造高集中度和佣金依赖；平台高度不平等不等于没有创业机会。Steam并无店内竞价购买推荐位，但仍存在算法、外部营销与市场集中；不能将其神圣化。Roblox、MOD、UEFN、Steam都应作为 **不同测试和商业放大的制度** 比较，不是任一模式的道德替身。

作者的餐饮比喻可归纳为“**observed demand is conditioned on available choice set**”：在有限商品和算法供给里卖得好，不等于未被展示的新体验无人需要；同时廉价便利与高付费数值游戏可满足真实需求，不能以阶级或国籍取消用户偏好。独游全球直销创造另一种接入可能，而不保证任何作品成功。

## 6. 下一轮必须完成的数量级研究，而非继续堆爆款故事

| 分析单位 | 必需分母与字段 | 竞争解释 / 反证 |
| --- | --- | --- |
| **平台年度队列** | 新进入开发者数、实际发布数、各收入分位数、关闭/退出、全球分区、自然/付费获客占比 | 平台规模、品类结构、定价与留存差异 |
| **风口项目队列** | PUBG/Lethal/Palworld首发后12—24个月的中国/国际跟进项目**全集**：立项→原型→上线/流产→收入/利润；招人速度、投放 | 模仿也可能有真正玩法重组，先发未必有商业优势 |
| **自主作者队列** | mod/jam/UGC/Steam Demo起始，含失败与沉默样本；原型次数、花费、删scope次数、进正式产品概率、二作留存 | 游戏阅历、家庭runway、技能、运气与社群网络 |
| **职业迁移队列** | 进入独游前岗位、原型权/删减权/ownership跨度、独立后人月花费、玩家验证时点与产品结果 | 先天作者倾向、职种、自选创业、团队资源 |
| **平台契约** | 同年代佣金计算基数、支付/广告/发行/服务器的独立费用、IP/账号与数据归属、退出条件 | 服务能力实际增值、合约差异、开发者outside option |
| **需求/创新产出** | 玩法机制原创、同构异性创新、题材创新、付费创新、区域化和国际成绩**分轴计量** | 把“商业成功”或“先出现”误认成“原创性” |

特别重要：**不能用2017全年被监测的买量游戏数除以2025 Steam收入门槛游戏数**，也不能用Steam某年高收入游戏数除以当年新发布数算同一队列成功率；时间、产品人群、平台收入口径和币种不同。

三个可证伪预测：
- **H-VN1 / 价值网络筛选**：在相近规模/品类和年份下，高度依赖付费曝光的市场中，研发团队是否更常在外部爆款之后扩编而非在自身原型验证之后扩编？
- **H-VN2 / 反训练**：控制开发者前史、预算、所在公司和最初能力后，经历追风口工作流的人是否更少使用低成本试玩、更晚砍规格、首作成本更高？
- **H-VN3 / 反路径**：同一作者或公司一旦转为 demo/社区驱动的分阶段投入，是否出现可观察的决策顺序变化？如果没有，所谓旧商业训练“负迁移”解释力就下降。

## 7. 研究裁决／给写作车道的边界

- **已可确证的机制事实**：2011同期腾讯农场交易报道、2012腾讯开放平台分成政策、Steam自行上架制度与不可购买站内推荐、March的探索/利用组织学习冲突。
- **作者主张，可保留为研究问题**：赛博地主、逆推荐规训、商业游戏风口赶工、教育过拟合与商业筛选共振、作者主权、平台创新选择性。
- **待证的因果与数量级**：腾讯具体产品的差别推荐、哪类平台净产出更多创新者、国内追风口的项目总量/成本、996/007频率、国别原创玩法密度、商业培训相对于教育的解释权重。
- **明确不采纳**：中国游戏人全体缺创新、中国玩家只有“韭菜”、国际市场天然公平、全部发行商是纯地租、做买量都无法出精品、游戏低成本本身就证明优越、单个爆款可代表全国水平、截图匿名评论等于经审计合同。

**Lane C拟写入口（非正文）**：可以用“某位中国商业游戏老兵反问独游工作室没有发行商如何登陆Steam”作观点冲突切面，但原评论尚无可定位URL，**不得伪装可署名可核的真人言论**。更稳妥的成文路径是以2011《开心农场》交易和2012分成政策开篇，再对照Steam直营的制度边界，最后转入2017 PUBG→国内跟进与2023 Lethal→2024 Palworld追风口生产组织，配完整失败者队列，落在“谁有权自己定义题目和决定何时加人”。无足够人物档案之前不得生成有内心描写的小说化叙事。
