## 1. 为什么要做 portfolio 而不是只盯《重生边缘》

单独看《重生边缘》很容易得到两个相反但都过强的结论：

- “NExT 圈养创新完全失败”；
- “《重生边缘》失败只是一次正常探索，不能代表 NExT”。

更合理的方法是把 NExT 的公开 portfolio 分层：

1. 早期 small-scope / experimental；
2. 中等规模 premium；
3. mobile / service experiments；
4. scaled 2A / live-service；
5. tech demos / shared technology。

然后看资源扩大后，产品结果是否同步扩大。

## 3. Early portfolio：低/中 scope、单一 hook、相对清晰产品边界

### Death Coming

Steam:
- $6.99；
- single-player puzzle；
- 2017 release；
- current English reviews 470, 83% positive.

Source:
https://store.steampowered.com/app/705120/Death_Coming/

研究意义：
- scope 很容易解释；
- 玩法 hook 可一句话表达；
- 内容规模有限；
- 不承担服务器人口、赛季和长期 economy。

### Iris.Fall

Steam:
- 2018；
- single-player puzzle/adventure；
- current English reviews ~345, 85% positive.

Source:
https://store.steampowered.com/app/907470/IrisFall/

研究意义：
- 强视觉长板；
- 游戏机制直接围绕光影主题；
- 产品义务有限。

### Bladed Fury

## 4. Early portfolio 的共同 production grammar

这些项目高度异质，但反复出现：

- 单一明确 hook；
- 低到中等内容义务；
- premium / finite product；
- 小团队可直接理解的 scope；
- 不依赖 massive concurrency；
- 失败时损失相对可控；
- 即使销量普通，项目仍可以 ship、形成 credits 和团队经验。

这与 NExT 早期公开制度相吻合：

> self-proposal → small resource incubation → playable/vertical slice → review → expand if justified.

因此“早期 NExT 只是技术演示，没有产品能力”不成立。

## 5. Online/service escalation：风险结构发生变化

Metal Revolution、Spiral Storm、SYNCED 等服务型/在线项目引入了完全不同的 obligation：

- server / matchmaking；
- content cadence；
- progression/economy；
- live balancing；
- acquisition；
- retention；
- concurrency；
- monetization；
- long-term operations。

其中 SYNCED 是最清楚的 scale-up case。

## 6. SYNCED：portfolio 中最大的 regime jump

公开资料：

- 2018 开始筹备；
- 2019 团队从 13 人扩大到 48；
- 后续百人规模；
- 总开发约五年；
- 2019 即以 2A、AAA pipeline / technology accumulation 为目标公开；
- 项目目标长期发生变化；
- 2023-09 launch；
- 2024-03 后基本停止大更新；
- 2024-09 service ended.

Sources:
- https://www.youxituoluo.com/522992.html
- https://youxichaguan.com/archives/128234
- https://www.gameres.com/903715.html
- https://steamcommunity.com/app/1008080/allnews/
- https://36kr.com/p/2855126478555781

这使 SYNCED 与早期产品的差别不只是“质量好坏”，而是 production regime 彻底变化：

| Early NExT | SYNCED |
|---|---|
| finite premium | F2P/live-service |
| 单一 hook | PVE/PVP/build/characters/live ops |
| 小/中团队 | 百人级 |
| 小项目失败可接受 | 五年组织能力建设载体 |
| ship 即完成主要价值 | 上线只是长期义务开始 |
| acquisition 不要求大 DAU | concurrency / retention 是生存条件 |

## 7. 效费比目前能说什么

### 可以说

1. 早期小/中 premium portfolio 产生了多个已 ship、口碑稳定、部分具有明显长尾的产品；
2. Unheard / Biped 的 current review scale 明显高于 Iris.Fall / Crown Trick 等，说明早期 portfolio 自身也有较大结果分布；
3. SYNCED 的开发周期、组织规模和 asset production obligation 显著高于早期项目；
4. SYNCED 上线不足一年停服，因此其直接产品市场结果与投入规模明显不匹配；
5. 但 SYNCED 可能产生工具、技术、人才训练和 pipeline 残值，不能把全部投入视为“归零”。

### 不能说

- 不知道所有项目预算，因此不能给真实 ROI 排名；
- Steam review 不是销量；
- NExT 内部 shared staff / tech lab 成本无法按项目准确分摊；
- early small games 也可能得到腾讯共享资源；
- SYNCED 不能代表 NExT 所有“大项目”。

## 8. 当前最强 portfolio-level hypothesis

> **NExT 的制度在 small-scope 0→1 上有可观察成功；真正值得解释的是，当组织把“创新”与 2A/AAA 能力建设、F2P/GaaS、全球主流市场和大团队扩张绑定后，验证成本与错误持续成本是否非线性上升。**

Status:
PROMISING / one major scaled failure is not enough to prove a universal curve.

## 9. 对“圈养创新失败论”的修正

Reject:
> “NExT 所有项目都失败，所以腾讯内部创新无效。”

Supportable:
> “NExT 早期 portfolio 证明大公司内部可以制度化产生有差异化的 0→1；SYNCED 则显示，当同一组织转向规模化、服务化和 AAA 能力建设后，原本低成本 portfolio search 的优势可能被高 obligation、目标漂移和资源升级抵消。”

这比单纯成功/失败叙事更接近效费比问题。
