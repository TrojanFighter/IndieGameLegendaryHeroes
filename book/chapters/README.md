## 正在建设的章节

### Part II｜先买时间，再谈梦想
候选主章：
- 谁在替你支付试错时间？
- 辞职不是勇气测试。
- 一笔融资和一个可持续生活结构有什么区别？

人物：Kenshi、FTL、Rocket League、Stardew Valley、Hollow Knight。

### Part III｜失败不是资产，留下来的东西才是
候选主章：
- 为什么有些失败让下一次更便宜，有些只是把钱烧掉？
- 七个月爆款为什么可能站在七年失败史上？
- 前作不成功，为什么仍然值得再做一次？

人物：Bills Must Be Paid、Rocket League、R.E.P.O.、Landfall、Tarkov lineage。

### Part IV｜技术时代给你什么牌，你又能不能自己造牌
候选主章：
- 技术窗口不是只有“赶上时代”一种。
- Carmack：当技术突破者本人就在产品团队里。
- 工具越强，为什么不代表所有人都会变强？

人物：early id、Gunpoint、PLAYERUNKNOWN、Project Wingman。

### Part V｜市场不是最后一步
候选主章：
- 玩家什么时候开始给生产系统供血？
- Demo、paid alpha、EA 到底改变了什么？
- 好游戏为什么仍然会因为没人看见而失败？

人物：Minecraft、Factorio、Kenshi、Bills Must Be Paid、Brigador。

### Part VI｜第一次成功以后
候选主章：
- 成功买来的不是答案，是下一轮选择权。
- 为什么小团队成功以后反而更容易出现治理问题？

人物：early id → Quake、Subset、Minecraft、Among Us。
