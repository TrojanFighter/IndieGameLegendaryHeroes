# 003 — 台湾创作者 Intake：原始鸟熊 × Team9（能力重组、范围变形与市场接口）

- Status: EVIDENCE INTAKE / PRE-CASE / NO POPULATION INFERENCE
- Program: A-case candidate linkage + C Taiwan comparator
- As of: 2026-10-07
- Subjects: 原始鸟熊 / 《活侠传》；Team9 / 《文字游戏》
- Method: Creator Life / Decision Audit；Capability–Project Fit
- Selection warning: 两案都是媒体可见成功者，属于机制样本，不是台湾普通开发者的代表比例。

## 0. 为什么把两案放在同一轮

两案都经常被叙述成「非科班／小团队做出惊人作品」。现有一手/准一手材料却显示，更准确的问题不是“他们怎么从零学会游戏开发”，而是：

> 不同职业与兴趣中已经形成的异质能力，如何被重新组合成项目；项目又如何主动适配或反过来压垮这些能力？

两案都不能拿来证明台湾社会更支持独立开发；家庭、住房、生活 burn、储蓄、伴侣收入、完整失败分母均未解决。

# A. 原始鸟熊 / 《活侠传》

## A1. 当前可确认的前史与创始关系

**OBB-E01｜2024-07-16，游戏角落专访（发售后一个月左右，开发者回顾性访谈；P1）**  
URL: https://game.udn.com/game/story/122090/8098442

- 两位主创自高中相识，毕业后进入社会仍保持联系。
- 两人曾长期讨论共同创业，甚至谈过牛肉面店；后因“鸟擅长写程序、熊有写作与绘图兴趣”，决定做游戏并创造自己的IP。
- 报道写工作室于2020年成立。

- 《活侠传》最初是以闪避弹幕为核心的趣味手机游戏；约经历近一年改版后，团队放弃手机方向，转向PC，增加大量系统和剧情。
- 边界：报道未提供鸟的完整职业前史、家庭资金、工资/储蓄、生活成本或公司资本来源。

**OBB-E02｜2025 TGDF讲者页（主办方机构资料 + 开发者公开简介；P1/机构资料）**  
URL: https://2025.tgdf.tw/en/speakers/8

- TGDF写“原始鸟熊成立于2021年”，与E01的2020冲突。
- TGDF写《活侠传》由两人历时约三年打造。
- 状态：FORMATION YEAR CONFLICT / UNRESOLVED。暂不得自行选择2020或2021为公司法人成立年；可能分别对应开始合作、工作室品牌/公司登记等不同口径，需要公司登记或同期主页确认。

## A2. “完全外行”叙事需要修正

**OBB-E03｜2024-07-25，游戏角落专访（二）（P1）**  
URL: https://game.udn.com/game/story/122090/8114531

- 熊明确表示自己曾在在线游戏产业担任美术相关职位。
- 因此，“两位完全没有游戏行业经验的外行直接做出《活侠传》”至少对熊不成立。
- 鸟的职业履历仍UNKNOWN；目前只能确认“擅长程序”及项目内负责编程/项目管理。
- 该文也记录项目的作者输入并非单纯“传统武侠素养”：两人都很喜欢安科作品，并把“骰子分歧—多路径叙事”转化为核心结构。这是 Experience Capital / Demand Discovery 的可检验入口。

## A3. 项目形态是能力适配，同时发生明显 scope explosion

同一来源（OBB-E03）支持：

- 早期“只能逃不能打”的手机弹幕机制被重写为PC武侠RPG。
- 决斗系统亦从团队称为“超低级格斗”的简单版本继续演化。
- 多分支随机叙事造成每个选项都要写后续，形成极高文本复杂度；团队自称埋文本耗时三年以上。
- 背景建筑因开发时间不足主动简化。
- 原本2D手绘战斗角色因动作量提升后成本过高，最后将3D赵活外包。
- 22首配乐由外部“幽火的音乐工作室 / TPOP Studio”制作。

因此“两人开发”必须解释为 two-person authorial/core team，不是“两人完成所有资产与音乐/外包”。

### 暂定 Capability–Project Fit 读法（H）

- 熊的文本、美术、在线游戏美术经验 → 大量角色、分支与视觉资产；
- 鸟的程序/项目管理 → 复杂事件与系统整合、发售后高频修补；
- 两人共同的安科/武侠兴趣 → 内容结构；
- 外包3D和音乐 → 将核心团队不适合或边际成本过高的工作外部化。

但项目也显示明显 FIT-CAPTURE / scope capture risk：文本分支、系统与未完成内容不断扩大。成功不能反向证明scope是健康的。

## A4. 发售危机提供了“现实裁决”证据，但不能被英雄化

# B. Team9 / 《文字游戏》

## B1. “没做过游戏”并不等于“没有生产能力”

**TEAM9-E01｜2021-01-20，映CG团队专访（正式版发售前；P0/P1边界：当事人同期自述）**  
URL: https://www.incgmedia.com/all-articles/word-game-interview

采访列出的五人及当时能力前史：
- 张文韦：总制作人；接案设计师，平面/展览设计；
- 黄威恺：营销与游戏企划；贝壳放大共同创办人；
- 陈育律 Hank：编剧；文字工作者，做过文学翻译与创作；
- 张文瀚：程序；前端工程师，研究所从事科技艺术、做过新媒体作品；
- 邱梁钧：动画美术；工业设计背景并从事动态设计/接案。

2019年后美术梁钧与程序文瀚加入。团队自称此前没有游戏制作经验，但这些不是“零经验劳动力”，而是跨行业成熟能力组合。

**TEAM9-E02｜2022 TGDF讲者页（机构+开发者讲者简介；P1）**  
URL: https://2022.tgdf.tw/en/speakers/wenhan_chang_team9

- Team9被写为成立于2018年。
- 张文瀚明确被描述为此前“完全没做过游戏的网站前端工程师”。
- 团队使用Godot；讲者回顾约两年实际开发流程。
- 边界：“成立2018”“两年开发”需要与2019成员加入、早期概念阶段区分，不能机械相减为完整生产周期。

## B2. 项目从一开始就是 Problem Redefinition

E01显示团队没有把《文字游戏》做成普通“文字谜题关卡集”，而是从一开始决定做成类似JRPG的长篇体验，并把：

- 文字 = 场景图像；
- 文字 = 可移动物件；
- 文字 = 谜题规则；
- 文字 = 叙事内容；

压到同一表现媒介。

这形成极强的 Capability Leverage：平面/展览、文学、前端、新媒体、工业设计都能直接进入核心玩法，而无需先复制传统3D RPG完整资产管线。

但这并非纯粹“降成本”。采访也明确记录：
- 企划不断提出超出现有系统架构的谜题，导致程序特例增加；
- 文字动画最初近似逐格，后来由美术开发AE文字遮罩流程，并用3D软件先制作动画后再转成文字画面；
- 配乐仍请外部专业音乐人黄镇洋制作。

因此更准确的机制是：

> Problem Redefinition把某些传统资产成本删除，但把复杂度转移到文字系统、特例程序和自定义动画工具链。

## B3. 市场接口不是“游戏做好以后才营销”

E01还记录：
- 团队在独立开发者聚会“增肥聚”和线上社团展示Demo；
- Demo吸引到贝壳放大共同创办人/执行长林大涵，促成集资合作；
- 团队把众筹视为较早接触玩家和改进体验的工具；
- 黄威恺本身横跨Team9和专业集资团队，意味着market capability从早期就是团队能力的一部分，而不是发售末期临时外包。

这与本仓库“Market Interface Is Production”命题高度相关。

## B4. 众筹数字必须拆开，不得把“324倍达标”写成神话

**TEAM9-E03｜嘖嘖项目页（P0）**  
URL: https://www.zeczec.com/projects/wordgame

- 募资期：2020-11-18—2021-02-09；
- 名义目标：NT$9,999；
- 最终累计：NT$3,240,193；
- 3578次赞助、3263名不重复赞助者；
- 2022-01-21正式Steam发售（项目更新可核）。

由于名义目标只有9,999元，3,240,193 / 9,999 约为324倍，不能解释为获得了“预算需求的324倍”。目标额明显不是开发总预算估计。正式Case必须区分：
- 宣传性/象征性目标额；
- 实际众筹毛额；
- 平台/履约/周边成本；
- 开发者可用净额；
- 项目在众筹前已投入的时间和接案收入；
- 众筹是否让成员转为全职、持续多久。

2021映CG采访的“超过目标20倍”只是采访当时的阶段性进度或不同时间截面，不能与最终约324倍混作冲突结论。

## B5. 当前人生审计最关键的UNKNOWN

采访说“大家原先都是接案工作者”，但不能自动推导：
- 五人都以接案作为唯一收入；
- 众筹前后所有人全职；
- 没有家庭支持；
- NT$3.24m足以覆盖全部开发成本。

正式Case前至少要补：
1. 2018起点究竟是概念、团队还是公司；
2. 五人在2018—2022各阶段的full-time/part-time状态；
3. 接案与开发的时间/现金关系；
4. 黄威恺/贝壳放大的商业合作条款、是否收服务费或其他权益；
5. 团队所有权、IP和发行权；
6. 外部配乐、QA、移植、本地化等完整perimeter；
7. 商业发售结果及下一作/团队存续；
8. 同期其他“跨行业非科班”台湾团队失败对照。

当前资格判断：HIGH-VALUE CASE CANDIDATE / NOT READY。

# C. 两案对照后新增的研究判断（H）

| 机制 | 原始鸟熊 | Team9 |
|---|---|---|
| 核心组合 | 程序/项目管理 + 文本/美术 | 设计+营销+文学+前端+动态视觉 |
| 游戏行业前史 | 熊有网游美术经历；鸟未知 | 自称此前没做过游戏 |
| 项目塑形 | 手机弹幕 → PC武侠RPG | 文字媒介 → JRPG结构 |
| 复杂度代价 | 分支文本/系统规模膨胀 | 谜题特例/文字动画工具复杂度 |
| 外围能力 | 3D外包、音乐工作室、发行商 | 专业配乐、众筹专业网络 |
| 市场接口 | 试玩/Steam/发行商，完整时间线待核 | Demo聚会+社群→众筹→Steam |
| 人生runway | 大量UNKNOWN | 接案存在，但现金结构UNKNOWN |

### 暂定命题：TW-CN-H04A

> “非科班”最值得研究的不是学历标签，而是传统游戏工业以外的能力是否能够被一个足够特殊的项目重新定价。

反证要求：
- 同类跨行业背景但做普通游戏/失败的台湾团队；
- 传统游戏从业者同样能有效进行Problem Redefinition的案例；
- 跨行业能力实际没有进入核心产品、只是履历装饰的案例。

只有完成这些反证后，才有资格把两案提升为更广泛判断。
