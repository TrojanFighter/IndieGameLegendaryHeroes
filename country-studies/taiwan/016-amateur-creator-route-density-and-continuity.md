- Restriction:
  - 路线存在 != 普通人实际可达；
  - 活动持续多年 != 同一批作者持续多年；
  - 社群人数、投稿数、参观人次、Steam发行数属于不同单位，禁止拼成“转化率”；
  - 台湾路网也存在中断、台北集中、资金桥较新和活动成本；
  - 不因为中国也有大量路线就取消台湾机制研究；比较应放在路线寿命、重叠和切换成本，而不是活动总数。

## 0. 第一轮结论：台湾优势候选不是 ROUTE_COUNT，而是 ROUTE_REDUNDANCY

截至2026，台湾创作者可以观察到的公开路线至少包括：

- 业余开发社群；
- 找队友 / 技术交流；
- Game Jam；
- 学校课程与毕业展；
- 巴哈 ACG 创作大赛；
- 放视大赏；
- G-EIGHT 玩家展；
- Taipei Game Show Indie Game Award；
- TGDF 开发者论坛；
- 国际讲者 / 国际开发者 peer review；
- publisher / platform / investor；
- 近年的 GameWorks 资源整合。

单独看任何一条，都不能证明台湾普通人更容易成为独立开发者。

真正有解释力的是：

> **这些入口覆盖不同成熟度，而且长期并存。一个人不必从“学生比赛→创业成功”走一条单线；他可以在社群、Jam、展会、开发者大会、全球奖项和发行接口之间多次切换。**

新增核心变量：

ROUTE_DENSITY  
ROUTE_REDUNDANCY  
ROUTE_CONTINUITY  
ROUTE_SWITCHABILITY  
BRIDGE_OVERLAP  
GLOBAL_REFERENCE_INJECTION  
PUBLIC_AUTHORSHIP_NORMALIZATION  
PLAYER_FEEDBACK_ACCESS  
COMMUNITY_TO_MARKET_BRIDGE  
ROUTE_HALF_LIFE

当前最强工作假说：

> 台湾indie生态的作用，不只是制造成功者，而是反复提醒潜在创作者：“这条职业/作者路线一直存在，而且周围有人正在走。”

这可能解释013中的 AUTHOR_ROUTE_SALIENCE。

# 1. 2001—2012：最早的开发者社群并非连续无断裂，但会被新的组织补位

## TW-ROUTE-E01｜IGDA Taiwan：2001成立，2008停摆，2012年底恢复

TGDF 2026合作伙伴官方介绍：
- IGDA Taiwan最早成立于2001；
- 2008一度关闭；
- 2012年底重新开始活动；
- 主要对象是“开发者个人”；
- 活动包含资讯分享、建立开发者社群、主办Global Game Jam；
- 目标之一是加强“业界、社群、学校”互动。

Source:
https://2026.tgdf.tw/sponsors

这是一条重要反例：

> 台湾创作者生态不是一条从2001无缝增长至今的直线。

早期组织会关闭。

但它也提供一个 ROUTE_REDUNDANCY 问题：
2008—2012 IGDA Taiwan停摆期间，是否有其他社群承担交流、组队和创作活动？

后续证据显示至少2010、2011又出现两个独立组织。

# 3. DIY Game Jam：重点不是比赛，而是训练“做完”

## TW-ROUTE-E03｜公开开发心得说明jam被用来补“从没做完过”的经验

2022第四届DIY Game Jam公开心得：
- 有第一次参加者因为不敢组队而solo；
- 有人明确说这是“第一个独立制作的游戏”；
- 有团队称自己过去没有真正完整开发过游戏，为了获得开发实感和动力，主动选择参加Game Jam。

Source:
https://itch.io/jam/diygj20220214

2023第六届继续出现：
- 重复参加者；
- 和学校社团同学组队；
- 第一次真正感觉自己参与完整开发；
- 开发者互相写作品体验心得。

Source:
https://itch.io/jam/20230305

因此这条路线的主要功能不是挑赢家，而是：

> **把“想做游戏”转换成一次可结束、可展示、可被别人试玩的完整生产循环。**

这和013里的 PUBLIC_PROTOTYPE_HABIT直接相连。

# 12.5. 最强的“路网”证据：同一批人真的把社群、国际知识与资本桥接起来

## TW-ROUTE-E12｜林容生：IGDShare → IGDA Taiwan → TGDF → Manapool

TGDF 2017讲者页提供一条罕见的个人—机构连续记录：
- 林容生自2011年初投入独立游戏相关活动推广；
- 长期参与IGDShare；
- 同时担任IGDA Taiwan联系人；
- 是TGDF共同发起人之一。

Source:
https://2017.tgdf.tw/speakers/%E6%9E%97%E5%AE%B9%E7%94%9F/

同一页面还记录了更关键的资本桥：
- 2013 TGDF邀请美国Indie Fund发起人之一来台介绍独立游戏融资模式；
- 当时台湾团队实际上很难直接成为Indie Fund资助对象；
- 2015年底Muse Games创办人曹之昊提出在台湾寻找类似投资标的；
- 数月接洽后形成“Manapool 法力池”；
- 该模式随后与赤烛《返校》发生实际合作。

这构成一条罕见的可验证路径：

foreign indie-finance idea
→ TGDF local knowledge import
→ community connector
→ local investor relationship
→ Taiwan-specific funding vehicle
→ local indie production.

它直接支持：
**BRIDGE_OVERLAP并非只是活动同时存在，而可能由同一批中介者把不同资源层连起来。**

这也是台湾小型生态的潜在优势之一：
一个活跃社群组织者可能同时知道开发者、海外经验、会议、publisher/investor，从而降低“我知道有这条路，但不知道找谁”的中介成本。

边界：
- Manapool/《返校》是成功且媒体可见案例，不能据此推断多数台湾indie能获得投资；
- 这里证明的是“桥可以被走通”和机构之间真实连接，不是资本可得率。

# 13. 台湾路网不是“一个漏斗”，而是多个可进入、可回退的层

当前可观察结构：

PLAYER / STUDENT / ARTIST / PROGRAMMER
↓
巴哈社区 / 自制游戏公会 / IGDShare
↓
DIY Game Jam / KUSO Game Jam / GGJ
↓
课程作品 / 毕业专题 / 巴哈ACG / 放视大赏
↓
G-EIGHT / TGS / Indie Game Award
↓
TGDF / international talks / peer-review network
↓
publisher / platform / grant / investor / GameWorks
↓
Steam / console / global market

但真实人生不一定顺序向下。

可能：
- 先上班，再回Game Jam；
- 商业作品之后仍参加jam；
- 毕业作不继续，几年后重做；
- 一作失败后换publisher；
- 成人独游作者从美术/写手旁路进入；
- 社群成员直接组队而跳过学生赛事。

因此更准确的是：

**CREATOR ROUTE NETWORK**
而不是
**CREATOR PIPELINE**。

# 14. 为什么“多条重复的路”本身可能改变意识

假设一个台湾学生：
- 今年没进放视；
- 仍可参加巴哈ACG；
- 作品不够成熟，可以参加Game Jam；
- 想找队友，可以进社群；
- 想听专业知识，可以去TGDF；
- 想测试玩家，可以报名G-EIGHT；
- 成熟后可以报IGA；
- 想找资金，可以接publisher/grant/GameWorks。

那么一次失败更难被解释成：

> “这条人生路不存在。”

而更容易解释成：

> “这次入口没过，换一个入口继续。”

这就是：

**ROUTE_REDUNDANCY → AUTHORSHIP LEGITIMACY**

的工作假说。

它可能通过心理/社会许可起作用，而不仅是资源数量。

# 15. 这也会制造“作者身份的社会证据”

一个潜在创作者长期看到：

- 巴哈每年有人交作品；
- Game Jam不断有人做完；
- TGDF有开发者谈失败/生产；
- G-EIGHT现场有小团队摆摊；
- TGS有国际indie；
- 本地成功团队又回来当讲者/协办者。

那么“独立开发者”不再只是国外YouTube里的异常职业。

它成为一个：

**LOCAL, REPEATED, LEGIBLE SOCIAL ROLE**

新增变量：

**PUBLIC_AUTHORSHIP_NORMALIZATION**

它不是社会整体尊重游戏开发的证据；
而是一个年轻人在本地可以反复看到“普通人以作者身份公开存在”。

# 16. 路网也有明显断点和成本，不能浪漫化

## A. 组织会关闭

IGDA Taiwan 2008停摆、2012才恢复。

所以台湾也经历route failure。

## B. 很多关键桥其实很新

- G-EIGHT：2022才开始；
- GameWorks：2024；
- 资本/发行桥的成熟远晚于社群/比赛。

不能用2026生态解释2010创业条件。

## C. Taipei concentration

TGDF、TGS、G-EIGHT、许多社群都高度集中台北/北部。

台湾地理小降低移动成本，但：
- 南部学生；
- 低收入创作者；
- 有全职工作/家庭的人

仍面临时间、交通、票价、摊位费。

## D. 活动多不等于稳定收入

Jam / meetup / award / exhibition
可以提高：
- network；
- knowledge；
- feedback；
- visibility。

却不能自动解决：
- 24个月开发现金流；
- publisher terms；
- rent；
- failed-title runway。

这也是005、010、011存在的原因。

# 17. 和大陆比较时，不能再说“台湾有路、中国没有路”

中国016已经明确废弃这个粗命题。

大陆截至2026同样有：
- 66RPG历史hobbyist commons；
- GGJ；
- CUSGA；
- CiGA / indiePlay / WePlay；
- GWB /腾讯创作赛事；
- TapTap Spotlight；
- China Hero；
- Steam / publishers。

因此真正值得比较：

| Variable | Taiwan question | Mainland question |
|---|---|---|
| ROUTE_COUNT | many | many |
| ROUTE_AGE | many indie-specific routes since 2010–15 | some early, many modern bridges after 2015 |
| ROUTE_CONTINUITY | several 10–15y institutions, but breaks exist | several historical discontinuities / platform transitions |
| ROUTE_REDUNDANCY | high candidate | increasing rapidly |
| GLOBAL_REFERENCE_INJECTION | structurally low friction | requires more active bridging |
| PLAYER FEEDBACK ACCESS | many public exhibitions | also rapidly increasing |
| MARKET/CAPITAL BRIDGE | exists but newer / opaque | broader commercial capital but high proof threshold |
| EMPLOYMENT PULL | weaker large-studio pull | very strong major-company pull |
| SECOND ATTEMPT | still insufficiently measured | still insufficiently measured |

这不是国别排名表，只是下一阶段比较变量。

# 19. 下一步：不要再数活动，要追“跨路线的人”
普通作者重复使用低门槛路线的第一轮实证见：[017 — DIY Game Jam重复参与](017-repeat-amateur-attempts-diy-game-jam.md)。017不以商业成功筛选，记录多个公开账号跨第4–7届连续完成作品，作为ROUTE_REDUNDANCY可能支持Second Attempt的微观存在性证据。


当前最值钱的实证不再是证明台湾还有第17个活动。

应从已有固定队列中追：

### A. 同一作者跨几个节点？
例如：
school project
→ ACG / Vision
→ jam
→ G-EIGHT
→ Steam
→ TGDF speaker / publisher.

### B. 第一次失败后是否换路？
未入围
→ jam
→ second project
→ exhibition
→ publisher.

### C. 老作者是否反过来成为基础设施？
former indie
→ organizer / mentor / publisher / investor.

### D. ROUTE SWITCH COST
每次切换要不要：
- 重新组队；
- 重新注册公司；
- 重新做vertical slice；
- 交摊位费；
- 换平台；
- 放弃IP。

只有追到这些，才能把“路网存在”升级成“路网真的提高作者存活率”。

# 20. Verdict

台湾独立创作者生态目前最值得保留的结构性解释是：

> **它不一定拥有比大陆更多的创作冲动，也没有证据证明顶尖学生明显更强；但十多年间形成了多个互相重叠的低门槛与中门槛入口，把“找人—做完—公开—被试玩—学行业—看全球—见发行/投资”分散到不同机构。因为路线不是单线，一次比赛失败或一次项目终止不必等于作者身份终止。**

这为013的“作者路线显著度”和015的“GLOBAL AUTHORSHIP BY DEFAULT”提供了一个更具体的制度解释：

> **作者意识可能不是课堂教出来的，而是被一个长期可见、可反复进入的本地路网社会化出来的。**

Status: ROUTE EXISTENCE / CONTINUITY STRONGLY SUPPORTED; EFFECT ON CREATOR SURVIVAL STILL OPEN.
