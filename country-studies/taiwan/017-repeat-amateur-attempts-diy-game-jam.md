# 017 — 台湾“普通作者第二次尝试”：DIY Game Jam重复参与与低风险作者身份存活

- Status: REPEAT-ATTEMPT PILOT / PUBLIC-ACCOUNT COHORT / NO CAREER-RATE CLAIM
- Program: C Taiwan comparator
- As of: 2026-10-08
- Parents:
  - [013 — 学生/业余独游默认生产意识](013-student-amateur-indie-default-production-awareness.md)
  - [016 — 独立创作者路网密度与连续性](016-amateur-creator-route-density-and-continuity.md)
- Core question: 台湾创作者路网是否只会把少数优秀项目送上媒体，还是也能让没有爆款、没有融资、没有Steam商业成功的普通作者重复做第二次、第三次、第四次？
- Observation frame: 自制游戏公会 DIY Game Jam 第4—7届公开 itch.io entries / developer logs，2022—2023。
- Unit: public creator/account participation trace；不是自然人身份证明，也不是收入/就业状态。
- Restrictions:
  - itch/Gamer账号不强行实名化；
  - 重复账号 != 全职开发者；
  - 继续参加jam != 商业成功；
  - 没继续出现 != 退出游戏行业；
  - 当前只研究4届连续活动，不估台湾全国 second-attempt rate；
  - 团队submission与个人账号混合，不能简单把submission数除成人数。

## 0. 为什么这比明星独游更重要

此前台湾研究已经能看到：
- Red Candle；
- 《活侠传》；
- 《文字游戏》；
- 成人indie的头部作者；
- 学生赛事进入Steam。

这些都存在明显selection。

真正检验“作者路线是否能活下来”的问题是：

> 一个做出来的游戏几乎没人报道、没拿大奖、没融资，他还会不会再做一次？

DIY Game Jam公开档案提供一个很少见的窗口：

- 免费；
- 同好性质；
- 一个月左右；
- 不以商业成功为入场条件；
- 每届约9—10个公开作品；
- itch.io长期保留作品；
- 参与者可公开写开发心得、试玩别人的作品；
- 多个账号跨届反复出现。

第一轮最重要结果：

> **重复参与不是少数明星成功者的特征。多个低知名度公开账号在连续数届中反复完成作品，即使没有可见Steam商业成功。**

这支持新增机制：

LOW_STAKES_REPEATABILITY  
SECOND_ATTEMPT_ACCESS  
AUTHOR_IDENTITY_PERSISTENCE  
REUSABLE_CREATOR_ROUTINE  
PEER_FEEDBACK_LOOP

# 8. 为什么这套活动特别适合“第二次尝试”

第6/7届公开规则暴露几个关键设计：

### 低经济门槛
- 免费。

### 低失败声誉成本
- 同好交流；
- 第7届甚至明确“不是比赛”。

### bounded scope
- 一个月；
- 固定主题。

### support
- Discord；
- 可向干部请求帮助。

### ownership
- 作品版权归团队。

### public artifact
- itch上传；
- playable/downloadable。

### peer feedback
- 组织鼓励/奖励写开发心得和多作品试玩心得。

因此它同时降低：

MONEY COST  
REPUTATION COST  
SCOPE COST  
TEAM-FORMATION COST  
FEEDBACK COST.

这可能是“普通作者能再试一次”的制度条件。

# 9. 一个重要反差：Second Attempt不一定需要capital

独立游戏研究很容易把Second Attempt写成：

首作失败
→ 发行商再投一笔钱
→ 第二作。

DIY Game Jam显示更低一层：

first tiny attempt
→ almost no revenue required
→ reusable skills/account/community
→ next tiny attempt.

所以 Second Attempt 至少应拆：

### MICRO SECOND ATTEMPT
下一次jam/prototype。

### PROJECT SECOND ATTEMPT
第二个数月项目。

### COMMERCIAL SECOND ATTEMPT
第二款正式商业产品。

### COMPANY SECOND ATTEMPT
一次公司/商业失败后重新组建团队。

台湾路网可能首先在前两层有优势。

不能因此直接推出商业公司生存率高。

# 10. 重复尝试产生的可能资产

即使一个jam game卖不出钱，作者可能积累：

- Unity / Godot / engine familiarity；
- scope estimation；
- bug fixing；
- build/upload；
- itch creator page；
- bilingual product copy；
- teammates；
- public devlog；
- feedback habit；
- assets/code/templates；
- self-identity as “someone who makes games”。

建议新增：

**ATTEMPT-CARRIED CAPITAL**

它不是金融资本，而是一次尝试可以带进下一次尝试的：
- capability；
- identity；
- network；
- public proof；
- reusable production routine。

这可能解释为什么失败成本并不等于归零。

# 11. 这才是“路网社会化作者身份”的微观证据

016提出：
ROUTE_REDUNDANCY
→ PUBLIC_AUTHORSHIP_NORMALIZATION.

017补出一个可观察微观链：

community tells me there is another jam
→ I finish one tiny game
→ account/artifact remains public
→ I see/play peers' games
→ next jam has another bounded theme
→ I submit again
→ I now have a small personal catalog.

作者身份不是一句价值观教育。

它可以由：
**重复做完小东西**
社会化出来。

# 12. 不能得出的结论

本文件不证明：

- 台湾普通学生大多会反复做游戏；
- DIY Game Jam提高商业成功率；
- 参加四次的人比参加一次的人更有创造力；
- 这些账号都靠游戏工作；
- 没重复出现的人都退出；
- 台湾second-attempt rate高于大陆。

尤其存在强烈self-selection：
愿意连续参加的人本来就可能更有兴趣、更有时间。

当前能证明的是：

> **台湾存在一个低成本、长期重复的公共机制，而且公开档案确实能观察到一批非明星作者利用它进行第二次、第三次甚至第四次制作。**

# 14. Verdict

台湾creator ecology目前最重要的新证据不是又一个爆款，而是：

> **普通、低可见度、没有明确商业成功的创作者，也可以在同一社群里连续数次完成小作品。**

它提示台湾作者生态的一项潜在核心能力：

> **不是让第一次尝试更容易成功，而是让第一次尝试不需要决定一生。**

这可能是 PUBLIC_AUTHORSHIP_NORMALIZATION 和 SECOND_ATTEMPT_CAPACITY 最基础的一层。
