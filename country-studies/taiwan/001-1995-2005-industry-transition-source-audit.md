# 001 — 台湾游戏产业1995—2005转轨：研发、发行、代理与两岸市场（同期来源审计）

- Status: SOURCE-AUDIT / PRE-CLAIM / FIRST PASS
- Program: C (Taiwan comparator to mainland industry-history)
- As of: 2026-10-07
- Source window covered: 1999-06 to 2004-09, **不是**1995—2005完整时序
- Research question: 游戏生产的利润和决策权怎样在研发、发行、海外代理及跨地区经营之间重新分配？
- Unit warning: 一家工作室／一款发售作品／市场整体营收／网游产品数属于不同单位；不能静默合并。

## 0. 初步发现（不得升级为因果定论）

1. **原创供给衰退早于韩国网游热潮的全面扩张。** 1999同期报道已称1998约300款上市游戏中台湾本土制作不足60款，且约1995的40—50家制作公司/工作室高峰后出现团队消失。报道指向 Windows 95技术平台转移、融资、盗版、发行与规模经济等多项解释；目前不能据此识别单一主因。见 E01。
2. **单机到网游并非「台湾厂商停止开发」的同义词。** 2002/03报道说明部分传统厂商裁并单机部门、转投网游与韩国产品代理；同时雷爵《万王之王》、中华网龙、昱泉等亦存在本土研发。不同公司出现代理、自研、合作研发和代工几种生产模式。见 E03—E08。
3. **发行/代理优势可以先改善现金流，却不一定制造原创产品能力。** 2003年MIC经新闻报道给出网游代理产品高达约80%的说法；但是**80%究竟是上线产品、销售额、玩家份额或其他口径仍未核原始MIC表**，绝不能写成已审计营收占比。见 E05。
4. **台湾与大陆当时是耦合市场，不是两个独立实验组。** 2002年资料列举台湾厂商在大陆投资研发、代理、合资；2003报道又呈现大陆业者逐渐直接获得韩国代理权并扩张本土研发。必须研究台湾生产能力向大陆转移/混合、监管差异和市场规模共同作用。见 E04、E09。
5. **融资和创作主导权冲突具有早期同期证据。** 1999年的融资采访涉及宇峻成立初期难获银行抵押贷款、VC偏好上市路径、开发周期空窗与发行投资对控制权的影响；不是2020年代独立开发才出现的问题。见 E02。
6. **观察到逆向选择与组织分叉。** 昱泉2003年自报单机代理退货与营业损失，同期探索由外部承担100%研发费用、公司保留产品权利的合作开发方案；其他代理商则尝试建立内部研发组。不能把「代理→研发」与「研发→代理」二者抹平成一个单线衰退故事。见 E07、E10。

## 1. 同期证据登记（报道本身为S1；具名当事人的同期引述可作P0 testimony，但并非独立核算）

**E01｜1999-06-29，王佳琪，《製作公司急速萎縮，產業分工不清》，iThome。**  
URL: https://www.ithome.com.tw/news/3856  
文中转述 MIC：1998年台湾游戏最终消费额新台币28亿元；转述《电脑玩家》统计：市场约300款游戏、本土制作少于60款；称1995年左右约40—50家制作公司及工作室。提及 Windows 95转移、盗版、资金和发行；举第三波研发团队独立后与原公司项目投资合作、智冠内部利润中心和版税制度之例。**边界：**28亿是1998总体终端消费；300/60是**款数**，不是销售额或发行商数量；40—50为媒体保守估计而非工商登记全数。原始MIC/《电脑玩家》表格尚未回收。

## 2. 预备性因果图（HYPOTHESIS，不是结论）

```text
本地付费市场/盗版/支付习惯 ─┬─> 单机回收机会 ─┬─> 开发者存续/资金压力
技术平台迁移(Windows/3D) ───┘               │
渠道/代理/授权收益结构 ────────────────> 研发 vs 代理 vs 自研网游 vs 合作开发
韩国产品与网吧网络 ─────────────────────> 竞争基准与技能需求
大陆市场开放/扩大 + 两岸资金与人员流动 ──> 市场份额/海外设点/技术与团队配置
治理、融资与主创控制权 ────────────────> 可立项项目种类与个人退出路径
```

### 四种竞争解释，未来逐个压力测试

- H-TW01 **渠道/代理回报优势**：能够更快变现的进口代理挤压高风险原创。反例：E06/E10存在从代理转自研；E08认为某些单机反而比在线代理更便宜。
- H-TW02 **技术/资本门槛上升**：Windows/3D/联网维护带来成本提升，弱小工作室退出。反例：需要寻找低成本仍稳定原创的台湾厂商。
- H-TW03 **两岸市场网络转换**：台湾企业早期跨海峡扩张，后来大陆市场扩大重塑代理与研发谈判权。反例：没有进入大陆也长期存活的台湾研发团队。
- H-TW04 **发行合作与作者性张力**：融资和发行控制权改变可做的产品。反例：智冠利润中心版税制、昱泉出资/版权合作组合可能提供不一样的组织实践；都要核最终执行而非只读公告。

## 3. 重点未核与下一步取证
两条跨期修正已移交专档：
- [007 — 两岸选择效应](007-cross-strait-selection-effects-information-talent-regulation.md)：2002大陆作为台湾低成本研发腹地、2010s后大陆高薪反向虹吸台湾人才；台湾早期日本/欧美信息先发也单独审计。
- [中国016 — 大陆末代单机能力退出](../china/016-mainland-last-pc-capability-exit-1998-2003.md)：避免把“大陆后来网游强”误写成“大陆此前单机能力不足”。


1. **追回MIC 1998—2004的原始统计表/报告目录**，定义「网游代理80%」的分母；并审查2003年预测74.3亿元两种冲突口径。此处为P0/原始统计最大缺口。
2. **追回1995左右制作公司名单与生存轨迹**：哪些消失、改名、被并购、转做代理/网游、跨海峡合作？避免把报刊对“消失”的修辞当正式退出统计。
3. **个体命运**：宇峻施文进、昱泉项目负责人、退出业界的原单机开发者的教育/家庭/技能积累/收入/职务权利；避免只有CEO口述。
4. **产品型反例**：2000—2005持续推出单机新作、独立小团队作品、代理失败、自研网游失败等；用同年份同资金规模比较。
5. **大陆镜像**：2000—2004渠道合同、代理韩游与自研团队人员资料，明确是大陆公司净获得能力，还是跨境公司在两地配置同一能力。
6. **观察口径**：团队、项目、发行作品、收入、盈利、玩家数与贡献者的单位及缺失率分开记录。

**目前可作的结论**：同期报道足以确认台湾产业从1990年代末起出现本土原创项目减少、发行/融资困境、2000年代初大规模在线代理竞争及跨地区业务扩张；尚不足以确定「台湾原创衰退」的单一主因、普通创作者的遭遇比例，或制度与人才创新力之间的因果效应。
