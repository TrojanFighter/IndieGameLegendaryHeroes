# 005 — 台湾独立游戏资本梯子：奖励、项目投资、众筹、平台验证与种子资本

- Status: SOURCE AUDIT / PRE-CLAIM
- Program: C Taiwan comparator + A case finance context
- As of: 2026-10-07
- Core question: 台湾独立游戏团队在什么生产阶段可以接触何种外部资金；资金买走什么权利、要求什么验证、是否改变全职投入与市场接口？
- Restriction: “政府支持”“投资”“奖励金”“众筹”“发行预付”“平台合作”不得混称为补助，也不得把名义金额直接等同总开发预算。

## 0. 第一轮结论

目前公开证据支持的不是“台湾政府会给独立游戏免费钱”，而是一套逐渐加层的资本与验证接口：

1. 早期独立游戏开发奖励：用公开评审给公司化团队提供研发奖励金；
2. 项目收益分成型投资：以未来作品收入换早期现金，目标之一是购买全职开发时间；
3. 群众募资：同时承担现金、市场验证、传播和预售/履约义务；
4. 产品化/商业验证支持：在已有原型和公司基础上，把平台、发行、用户测试、营销和收入分成绑定到一起；
5. 种子阶段股权/机构投资：2025以后进一步把“first check”、公司设立与海外发行放入专业投资机制。

这是“资本梯子”假说，不代表所有台湾团队都能顺利走完，也不代表该体系的选择公平、规模足够或结果有效。

# 4. 2025：支持金也可以带明确平台、发行和收入分成条件

Team9的后续轨迹提供了一个很好的“同团队、不同资本工具”比较。

## TW-CAP-E09｜2025 VR商业验证计划

TAICCA 2025-07-14公布：
- 11件合格申请；
- 3件入选；
- 每件获得NT$1.2m制作支持金；
- 烴奈股份有限公司《A Black Climbing Dog LITE VR游戏开发计划》入选。

https://taicca.tw/latest_news/plan_bulletin/detail/362?industrys%5B0%5D=5

计划与法国发行商Astrea、Meta平台连接，目的包括上架、用户/游戏测试、国际市场和商业模式验证。

## TW-CAP-E10｜支持金不是“无条件免费钱”

计划规则：  
https://future.taicca.tw/programs/2025VRgame-opencall

- 每案支持金最高NT$1.2m；
- 申请人自备资金不得低于NT$600k；
- 申请人需拥有原创游戏IP；
- 项目必须可立即进入Early Access开发；
- Astrea投入制作跟踪、测试、上架、产业链接和营销。

收入结构：
1. Meta先取销售总额30%；
2. Astrea优先回收营销成本；
3. 之后六个月：Meta 30%、TAICCA 14%、Astrea 14%、申请团队42%；
4. 第七个月起：Meta 30%、Astrea 21%、申请团队49%。

因此这类“支持金”在经济上更像：

production support + mandatory co-investment + publisher/platform access + timed commercial validation + revenue-sharing contract

而不是传统意义的纯non-dilutive grant。

这对跨国比较很重要：只比较“政府给了多少钱”会漏掉市场接入和权利成本。

TAICCA与烏杉资本于2025-11宣布推动“数位游戏基金”：
- 聚焦seed stage；
- 希望成为新创团队的first institutional check；

这明显不同于独立游戏开发奖励：

- seed investment：进入公司资本结构与治理；

## 不能从这张表推出的东西

- 台湾普通开发者获得这些资金的概率；
- 获资助团队平均存活率；
- 台湾资金环境一定优于大陆；
- 获资助导致项目成功；
- 所有创作者都愿意接受分润/治理成本；
- 《九日》或其他明星项目必然使用了上述支持。

目前对《九日》的本轮官方资料检索没有找到可直接确认的TAICCA/独立游戏奖励记录；只能记为“本轮未发现”，不能写成“没有政府支持”。

# 7. 对两岸比较真正有用的变量

后续不要做“台湾有补助、大陆有没有”的粗比较，而要逐层编码：

1. eligibility：个人能否申请？必须公司化多久？国籍/所在地要求？
2. selection denominator：多少件申请、多少获选？
3. money timing：prototype前、可玩Demo后、发售前还是成功后？
4. capital type：奖励/补助、股权、项目分润、发行预付、贷款、众筹？
5. creator cash match：是否强制自备资金？
6. decision rights：谁能改变scope、发行日期、平台、地区发行权？
7. recoup/revenue share：谁先回收，比例和期限？
8. market interface：是否带平台、发行、展会、营销、测试？
9. failure downside：项目失败是否还款、失股、停权、影响后续资格？
10. access inequality：是否要求已有公司、Demo、英语提案、海外伙伴，从而先筛掉最早期开发者？
11. conversion：钱是否真的把兼职变全职、把prototype变vertical slice、把本地作品带到海外？
12. counterfactual：没有这笔资金时项目会停止、缩scope、延迟，还是照样完成？

Team9的“投资使业余成员转为全职”是目前第11项最清楚的一条机制证据；《活侠传》奖励金额已核但对实际runway贡献仍UNKNOWN。

# 8. 下一轮优先级

1. 找到2021独立游戏开发奖励的完整作业办法/拨款阶段，解决《活侠传》52→78万口径。
2. 查天使放大《文字游戏》的具体投资额、分润/回收期限与是否持股。
3. 追2024后4家获得国发基金投资的独立游戏团队，建立reward→institutional investment真实转化案例。
4. 从历年独立游戏奖励全部获奖名单建立固定起点队列，追踪发售、停更、公司存续和下一作；这会比只研究《活侠传》更能判断政策效果。
5. 建立大陆同阶段资金工具的同口径表，不以政策名称比较，而以cash timing / control / recoup / selection / conversion比较。
