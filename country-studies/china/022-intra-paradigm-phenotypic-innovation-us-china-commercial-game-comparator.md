## 0. 为什么需要这个概念

游戏创新讨论经常被压成错误二分：

```text
原发性范式创新
vs.
抄袭 / 微创新
```

这个二分漏掉了一类对成熟商业游戏公司尤其重要的创新：

> **在保留一个已验证范式的宏观识别结构时，通过若干相互耦合的系统重构，使玩家行为、体验曲线、性能边界或竞争方式发生显著变化。**

作者将其命名为：

# `同构异性创新`

本篇采用工作英文：

# `INTRA-PARADIGM PHENOTYPIC INNOVATION`（IPI）

暂不直接使用 `isomorphic innovation`，避免与组织社会学中的 institutional isomorphism 混淆。

作者原始例子包括 Watt 对蒸汽机的改进，以及 PUBG → Apex。这里不预设两者在技术史上的严格同类性；它们只共同提示一个问题：

> **“没有第一次发明母范式”不等于“创新强度低”。**

## 1. 定义：什么才算“同构异性”

### 1.1 Paradigm Skeleton / 范式骨架仍可识别

玩家仍可调用既有类型知识理解大框架。

例如 BR 中仍可存在：
- 大地图；
- 搜集 / 装备；
- 安全区收缩；
- 淘汰；
- 最后存活。

如果核心目标、风险结构、空间组织和主要决策已经全部换掉，则可能已接近新的范式，而不是 IPI。

### 1.2 Coupled Reconstruction / 变化必须耦合

单个 feature 不够。

高等级 IPI 通常表现为：

```text
新的 design thesis
→ 多个子系统被迫一起变化
→ 玩家必须学习新的决策函数
```

例如 team-first BR 如果成立，可能连续要求：
- 更低沟通成本；
- 队伍互补；
- 死亡后的恢复结构；
- 重新定义风险；
- 新的信息系统；
- 新的移动 / encounter cadence。

### 1.3 Behavioral Phenotype Shift / 玩家行为发生变化

这是最重要的门槛。

不能只问：
- 有多少新武器；
- 地图大了多少；
- 角色多了多少；
- 画面是否升级。

必须回答：

> **玩家现在为什么要以不同方式行动？**

如果旧游戏高手只需要“把原来的策略做得更好”，而无需学习新的风险、信息、协作、空间或构筑决策，则更可能只是优化。

### 1.4 Performance Frontier Shift / 性能前沿发生移动

IPI 不要求所有维度同时提高，但至少应在一项关键性能上产生明显变化：
- accessibility；
- strategic depth；
- social coordination；
- combat tempo；
- death / recovery structure；
- expression；
- platform reach；
- session structure；
- content cadence；
- production / service model；
- audience breadth。

## 2. 四档工作编码：C / O / T / P

为避免把“不同”都写成创新，商业项目先使用四档：

### C — COPY / TRANSFER
母范式和主要行为函数基本继承。主要变化是：
- 平台迁移；
- IP / 美术 / 题材；
- 内容量；
- 商业模式移植；
- 高质量复刻。

### O — OPTIMIZE / RECOMBINE
存在真实改进或高强度重组，但玩家表型仍大体连续。

### T — TRANSFORM / IPI
保留母范式识别骨架，但产生显著新行为表型。

### P — PARADIGM ORIGINATION
形成新的 dominant design / 类型骨架，或将此前散乱实验凝固成后来被行业识别的新范式。

这四档不是价值排名。一个 O 产品可以商业上远胜一个 T；一个 P 也可以彻底失败。

## 3. 第一条硬规则：存在性绝不等于数量级

任何国家 / 公司比较必须分开至少五层证据：

| 层级 | 能证明什么 | 不能证明什么 |
|---|---|---|
| EXISTENCE | 至少有人做得到 | 能力普遍 |
| ABSOLUTE COUNT | 有若干案例 | 与产业规模相称 |
| RATE | 单位可比项目中发生多少 | 能否长期复现 |
| ORGANIZATIONAL REPEATABILITY | 同一组织跨项目再次做到 | 整个生态密度 |
| ECOSYSTEM DENSITY | 多个独立组织都能重复做到 | 国家级强因果机制 |

因此：

> **能举出《永劫无间》、Auto Chess 或《原神》，只能证明能力存在；不能证明中国商业体系的 T 发生率与美国头部商业组织相当。**

反方向也一样：

> **能举出 Riot / Respawn / Epic，也不能证明美国所有商业游戏公司普遍具有高 T-rate。**

中国产业基数很大，因此孤例的解释力必须受 denominator 约束。

## 4. 第二条硬规则：国际成功 ≠ T，但高等级商业 T 需要全球压力测试

商业游戏的高等级 IPI 还应加入：

# `GLOBAL VALIDATION`

原因不是“海外天然更高级”，而是：

> **如果一个新表型只能在本土渠道、支付结构或信息隔离中成立，它尚未证明自己能在已有成熟竞争者和高经验玩家的开放市场里成立。**

暂用：

- **G0**：主要本土成立；
- **G1**：海外有收入，但集中于相邻市场 / 特定人群；
- **G2**：可在美国、日本、欧洲等成熟市场长期正面竞争；
- **G3**：成为全球头部、迫使国际同行响应，或形成明显模仿 / 新模板。

但必须保持两个轴独立：

```text
Global success ≠ phenotype innovation
Phenotype innovation ≠ global success
```

例如全球成功的 4X / SLG 仍可能主要体现成熟商业化、投放和运营，而不是 T。

## 5. 第三条硬规则：区分 studio capability 与 portfolio capability

### Studio-level
同一核心设计组织能否跨项目重复 T。

### Publisher / Group-level
集团能否：
- 发现；
- 孵化；
- 收购 / 保留；
- 赋权；
- 配置资源；
- 放大全球发行

具有 T 能力的不同团队。

EA、NetEase 等更适合同时用这两层分析。

不能把集团收购来的全部能力自动算成总部自己的设计能力。

同理，Riot 虽为腾讯全资子公司，不能因此把 Riot 的美国研发组织产出直接编码为腾讯中国自研能力。

## 6. 美国商业组织：当前最强 comparator

### 6.1 Riot：IPI 的显式制度化样本

Riot R&D 公开采用：

```text
Opportunity → Thesis → Audience
```

并明确区分：
- inside-out opportunities：从已验证 design loop 出发，通过 thoughtful improvements 扩大受众；
- outside-in opportunities：从未满足的市场 / 受众需要出发。

Riot 明确举例：
- DOTA → League；
- EverQuest → World of Warcraft；
- King of the Kill → PUBG / Fortnite。

其公开表述是，这类 inside-out opportunity 很有吸引力，因为母结构已证明潜力，团队可以把创新资源集中到真正关键的部分。

Riot Incubation 流程还公开记录：
- 约 10% pitch 进入 Prototype；
- Prototype 前要求较清楚 thesis；
- 原型阶段优先 de-risk 关键创新，而不是平均改很多小 feature。

这提供了少见的 **institutionalized IPI** 直接证据。

Source:
https://www.riotgames.com/en/news/r-d-foundations-opportunity-thesis-and-audience  
https://www.riotgames.com/en/r-and-d-office/incubation-exploration-with-a-plan

#### TFT

Riot 后来回顾，TFT 的起点就是办公室大量员工沉迷 Dota Auto Chess；团队据此快速调人、调资源，并在约六个月内推出产品。

Source:
https://www.riotgames.com/en/news/choosing-our-lane-2022-so-far

这不是 P；它更适合研究：
> 已验证范式出现后，大公司怎样快速吸收、重组和长期运营。

#### VALORANT

暂作为 T 强候选，但需另建产品级 evidence ledger 后再定档。

### 6.2 Epic / Fortnite：从外部范式到新表型

Epic 在 2017 Battle Royale 公告中直接承认喜欢 PUBG 等 BR 游戏，并把 Fortnite 的 building skills / destructible environments 与 BR 结合。

Source:
https://www.fortnite.com/news/announcing-fortnite-battle-royale

这是一份很干净的 contemporaneous evidence：
- 母范式明确来自已存在 BR；
- 差异化不是隐藏来源；
- Fortnite 原有能力成为新的系统耦合点。

后续 Zero Build / UEFN 又说明同一产品内部可以反复重写自己的 phenotype；但各阶段应分别编码，不把整个 Fortnite 历史压成一个 T。

### 6.3 Respawn / Apex：小 N、高密度 comparator

Respawn 的两周年回顾确认：
- Titanfall 2 后先做多种 prototype；
- 两位设计师做了 Survival BR prototype；
- 公司级 playtest 后逐步演化为 Apex。

Source:
https://www.ea.com/games/apex-legends/apex-legends/news/two-years-of-apex-legends

Apex 是否为 T 的核心不是“有英雄”，而是：
> team-first BR thesis 是否迫使 communication / squad composition / death recovery / movement / encounter structure 一起变化。

这需要后续产品级 ledger 继续拆。

### 6.4 COD：大 denominator 下周期性出现 T

COD 是特别重要的长期样本，因为它避免“只有小创新团队才能 T”的偏见。

研究重点不是把每代 COD 都判为创新，而是：

> **在巨大续作分母、极高商业连续性压力下，是否仍周期性出现显著 phenotype shift。**

候选节点：
- COD4：persistent progression / Create-a-Class / perks / killstreak；
- Advanced Warfare：exo movement；
- MW2019 / Warzone：COD gunplay × BR / F2P / recovery / economy；
- Black Ops 6：Omnimovement（长期行业影响仍待观察）。

COD 的核心研究价值是：
# `T under continuity pressure`

即成熟商业公司怎样兼顾：
- 熟悉认知接口；
- 已验证赛道；
- 商业连续性；
- 局部高强度重构。

### 6.5 Blizzard：组织能力会衰退

Overwatch 是强 T 候选，但 2015–2025 不能据此把 Blizzard 写成持续高 T-rate 公司。

它用于提醒：

> **过去能产生 T 的组织，并不自动永久拥有这种能力。**

因此研究需要时间窗，而不能给公司固定“创新型 / 保守型”本质标签。

## 7. 中国商业组织：当前第一版压力测试

### 7.1 miHoYo / HoYoverse

最值得研究的不是“原神成功”，而是：
- 《崩坏3》；
- 《原神》；
- 《崩坏：星穹铁道》；
- 《绝区零》

是否说明同一公司可以在多团队、多品类中重复提出新的 product thesis。

- 《原神》：T 强候选 / 全球 G3 验证；

### 7.3 Papergames / Infold

《恋与深空》《无限暖暖》提供两次很强的 phenotype thesis：
- 乙女 / romance 的 presence 与共同战斗；

但公司整体全球验证广度仍低于 miHoYo / NetEase。当前更适合：

> **垂直赛道高 T-density + G2 / vertical G3。**

### 7.4 Hypergryph

《明日方舟》《终末地》目前显示高 T-density，但大型主要作品 N 过小。

必须保留：

> **2/2 不能支持长期组织成功率估计。**

国际验证目前更偏东亚成熟市场。

### 7.5 Lilith

莉莉丝是重要反例：

> **全球竞争力可以很强，但 T 强度仍需单独证明。**

Rise of Kingdoms / AFK Arena 等全球成功不能自动升级为 IPI。

它用于防止把 `G` 当成 `T`。

### 7.6 Tencent China in-house

腾讯必须受到最大 denominator 约束。

优点：
- 项目数巨大；
- 工业 / 平台 / 运营 / 迁移能力极强；

- 2024 战略开始强调自研与新玩法。

Source:
https://www.reuters.com/technology/tencents-next-level-up-fewer-big-foreign-franchise-games-more-in-house-2024-03-21/

但：

> **Absolute T count 可能不低，不代表 PTR 高。**

Tencent China in-house 必须把普通、失败、跟随项目全部放入分母，且不能把 Riot / Supercell / Digital Extremes 等海外子公司产出混入中国自研分子。

## 8. 当前最重要的中美比较假说

### H1 — T-producing organization density

> **2015–2025 的全球商业游戏领域，美国头部设计生态中，能够重复产生全球有效 T 的独立组织密度，高于中国大陆商业游戏生态。**

Status:
**SUPPORTED AS DIRECTIONAL H / DENOMINATOR NOT COMPLETE**

支持信号：
- Riot；
- Epic；
- Respawn；
- COD 多工作室体系；
- Blizzard 历史样本。

中国当前最硬：
- miHoYo；
- NetEase；
- Papergames（垂直）；
- Hypergryph（小 N）；
- Lilith 的 T 仍待审；
- Tencent China in-house 的 PTR 仍待算。

禁止升级为：
> “美国商业公司普遍创新、中国公司普遍抄袭。”

### H2 — Organizational repeatability gap

> **美国最强商业设计组织更早把 phenotype transformation 从偶发天才事件变成可重复的组织能力。**

Status:
**PROMISING / R&D PROCESS EVIDENCE STRONG FOR RIOT / CROSS-FIRM GENERALIZATION OPEN**

Riot 的公开 R&D 流程是当前最强制度证据；COD 提供长时段重复产出；Respawn 提供小 N 高密度样本。

中国：
- miHoYo 已有明显复现信号；
- NetEase 显示 portfolio-level replication；
- 2021–2026 可能正在快速收敛。

### H3 — China convergence since 2021

> **中国头部商业游戏组织的 T-attempt density 在 2021 后、尤其 2024 后出现上升。**

Status:
**PLAUSIBLE / COHORT AUDIT NEEDED**

不能因为 Naraka / Genshin / Marvel Rivals / FragPunk / Delta Force 等连续出现，就直接声称产业整体已追平。需要固定 cohort。

### H4 — Paradigm origination is not the right commercial KPI

> **成熟商业游戏公司的核心创新能力不应主要用“发明了多少新品类”衡量，而应看其能否持续识别外部新范式、理解 invariant，并把它推进成新的全球有效表型。**

Status:
**THEORETICAL FRAME / STRONGLY CONSISTENT WITH RIOT PUBLIC R&D MODEL**

原发范式创新往往高方差、低发生率、依赖技术 / 人物 / 社区 / 偶然窗口。公司可以提高 mutation surface area，但很难按年度 KPI 稳定生产 Carmack / Auto Chess 级事件。

### H5 — Resource scale is insufficient

> **资本、人数、工业成熟度可以提高执行和放大能力，但不会自动产生高 PTR。**

Status:
**SUPPORTED AS ANTI-SUFFICIENCY CLAIM**

Tencent China in-house 是重要压力测试：若巨大资源和项目量不能产生相应高 PTR，则“资源越大→创新越多”的单因果模型应被拒绝。

## 9. 组织机制：为什么美国最强样本更容易制度化 T？

当前只列机制假说，不升级强因果。

### 9.1 THESIS BEFORE FEATURE
是否在 feature list 前先明确：
- Opportunity；
- Thesis；
- Audience；
- 需要被推翻的默认假设。

Riot 有直接公司公开材料支持。

### 9.2 PROTOTYPE AS FALSIFICATION
原型是不是为了尽快证明 / 证伪核心 innovation risk，而不是为了证明团队“做了很多功能”。

### 9.3 AFFORDABLE FAILURE CAPACITY
失败项目被砍后：
- 团队是否还能继续；
- 作者是否有第二次提案机会；
- 人才是否被整个组织吸收。

与 [014 DeepSeek](014-liang-wenfeng-deepseek-positive-deviant-innovation-organization.md) 共用变量。

### 9.4 GLOBAL-FIRST COMPETITION
项目是否从立项起就回答：
> “已经有 CS / PUBG / COD / Overwatch / Genshin，全球成熟玩家为什么要换到我这里？”

这比“先在本地渠道获得优势，再国际化”产生不同的产品选择压力。

### 9.5 SELF-CANNIBALIZATION
组织是否敢：
- 删除自己的招牌机制；
- 与自家旧产品争用户；
- 推翻上一个成功答案。

Epic / Fortnite 提供很强候选；中国需寻找同等级内部自我侵蚀案例。

## 10. 数量级审计指标

暂不把它们机械合成为一个总分。

### PTAR — Phenotypic Transformation Attempt Rate

```text
T-attempt projects / comparable major projects
```

回答：
> 公司有多常真正尝试重写表型？

### PTR — Phenotypic Transformation Rate

```text
validated T projects / comparable major projects
```

回答：
> 尝试中有多少真正形成新表型？

### ORR — Organizational Repeatability Rate

```text
organizations with >= 2 validated T / organizations sampled
```

回答：
> 创新是人物彩票，还是组织能力？

### GVR — Global Validation Rate

```text
T projects reaching G2/G3 / validated T projects
```

回答：
> 新表型有多少经得住全球成熟市场压力测试？

### IIR — Industry Imitation / Response Rate

记录：
- 直接模仿；
- 竞品加入类似机制；
- 同行公开承认参考；
- 新子类型 / 标签形成。

它是高等级影响证据，不是必要条件。

## 11. 分母规则

2015–2025 第一版审计必须固定：

### 项目纳入
- 正式发布的大中型新产品；
- 公开进入大规模市场测试的主要新产品；
- 明确独立预算 / team / thesis 的大型新模式可单列。

### 项目排除
- 普通资料片；
- 单纯内容 season；
- 没有独立设计 thesis 的端口；
- 小型营销活动；
- 纯技术 demo。

### 失败项目
不能只统计赢家。

至少建立：
- shipped failure；
- killed / cancelled R&D（资料足够时）；
- pivot；
- market exit。

### 组织归属
分别记录：
- studio；
- parent group；
- founder / key creative leadership；
- team continuity；
- acquisition timing。

## 13. 什么证据会推翻当前中美差距假说？

至少以下任一结果都应显著削弱 H1 / H2：

1. 固定 2015–2025 项目分母后，中国头部组织的 PTR 与美国 comparator 接近；
2. 中国拥有相近数量的独立 T-producing organizations，只是西方媒体曝光较少；
3. 美国看似高 T-rate 主要来自只挑成功明星，而加入 Anthem、失败 live-service、大量普通续作后差距消失；
4. 中国项目在全球成熟市场已形成大量 G2/G3 T，只是当前分类漏计手游 / 女性向 / 东亚市场；
5. 组织层复现消失：所谓“美国公司能力”其实主要由少数核心个人迁移解释，而不是制度。

## 14. 当前最小结论

截至 2026-10-08，最稳妥的表述不是：

> “美国负责原创，中国负责抄。”

而是：

> **在 2015–2025 全球商业游戏领域，美国最强的一批设计组织显示出更长的“成熟范式 → 新行为表型”重复历史，并且 Riot 等已将这类创新显式制度化。中国并非缺少 T：miHoYo 与 NetEase 已构成强压力测试，Papergames / Hypergryph 等也出现高密度信号；但目前尚未看到与美国头部设计生态同等厚度的 T-producing organization layer。**

同时必须保留时间变化：

> **2021 后中国 T-attempt 的可见密度明显上升，因此“今天仍差一个数量级”不能在分母审计完成前写成定论。**

真正要回答的下一题不再是：

> “中国有没有创新案例？”

而是：

> **在相同项目分母、全球验证和组织归属口径下，中美到底有多少组织能连续两次、三次把成熟赛道推成世界玩家必须重新学习的新表型？**

这才是数量级问题。
