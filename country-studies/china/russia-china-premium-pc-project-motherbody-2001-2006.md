## 一、编码规则

每个项目尽量记录：
year / team / location / parent-ownership / product-mode / project-state / publisher / previous-project / next-project / people-retained / problem-domain / evidence-level。

边界：
1. 中国大陆团队与港台母公司分开编码；上海软星属于“中国大陆开发团队 + 台湾母公司”。
2. 俄罗斯本土与乌克兰/白俄罗斯分开；后苏联比较可扩展，但不能把乌克兰Best Way/GSC直接计入俄罗斯本土。
3. “转网游”不等于能力消失；要追技术、人员、IP与设计问题域分别留存多少。
4. 本表当前是“可核第一批”，不是完整枚举。

## 三、中国项目链的关键机制证据

### 目标软件：不是失败后才转，而是成功项目也转
2002年《秦殇》主创采访明确承认：国内正版销量虽领先，但盗版拿走更多收入；网络游戏是把流失资金收回来的现实办法。
https://games.sina.com.cn/newgames/0212/120515201.shtml

2004年目标近百名开发者，已有《傲世三国》《秦殇》全球发行经验；《复活》仍能售出约10万套，但公司同时投入预算更高的《傲世Online》。
https://news.17173.com/content/2004-2-10/n416_332359.html

**判定**：online pivot不是“Premium作品完全卖不动以后才发生”，而是预期回报/反盗版/持续营收共同作用。

### 像素：官方公司史直接记录转向
像素官方史：
- 2002《刀剑封魔录》；
- 2003-1“大量吸收研发力量，将研发方向由单机电脑游戏转移至网络游戏”；
- 2003-7《上古传说》仍作为尾部单机项目交付；
- 2004《刀剑Online》测试、收费。
https://www.pixelgame.net/pixelsoft/site/history

**判定**：这是一条几乎实验室级的 whole-firm pivot 时间线。

### 上海软星：重要反例
2003《仙剑三》→2004《问情篇》→2005《阿猫阿狗2》→2007《仙剑四》，说明大陆并非绝对无法维持Premium团队。
https://games.sina.com.cn/y/n/2006-01-16/1049139910.shtml

但其母公司、IP、发行体系来自台湾大宇，不能直接视为“大陆本土资本市场自然支持Premium”的纯样本。应把它作为：
**mainland production capability + external/parent refuge**。

## 六、第一版项目母体产生的三个新结论

### 1. 中国的Premium尝试不是线性退化，而是“谱系改道”
目标、像素、祖龙的案例显示：
**shipped Premium → reuse people/IP/engine → online product**
比“工作室直接死亡”更常见于当前核心样本。

所以不能用“单机产量下降”推断“人才消失”；应计算 **problem-domain migration**。

### 2. 俄罗斯发行生态在同一窗口仍同时买多种问题域
1C/Buka的公开项目管线同时存在：
- RPG/strategy hybrids
- tactical simulation
- experimental RTS
- authorial narrative game
- MMO/F2P/online
- licensed/imported products

这至少说明当时没有形成“中国2005那种Premium本土新品近乎归零”的单一产品生态。

### 3. 核心比较应改成“项目选择函数”
不是问：
“中国/俄罗斯哪个国家更有创意？”

而是问：
**给定100支已经会做游戏的团队，两套发行/资本/渠道体系分别让多少团队继续Premium、多少转online、多少取消、多少裂变、多少五年后仍研究原问题域？**

## 八、当前阶段判词

**SUPPORTED**
- 2003—2005中国大陆Premium本土项目供给快速接近枯竭；
- 同期中国优秀Premium团队大量直接把既有人员/IP/技术迁移到online；
- 同期俄罗斯发行生态仍能持续资助并发行多类Premium项目，同时也在发展online；
- 中国差异不能用“缺开发者/缺创业意愿”解释。

**HYPOTHESIS**
- 中国发生的是更强的 **problem-domain migration + whole-firm pivot**；
- 俄方更厚的多发行商Premium市场让非共识项目具有更高的“继续尝试概率”；
- 这比民族性、F2P有无或单纯盗版率更能解释长期产出差异。

**UNKNOWN**
- 两国2001—2006每百支团队真正的Premium尝试率；
- 项目取消率；
- spin-off率；
- 5年后问题域留存率。
