## 0. 方法纠偏：此前把 Reference Set Poverty 放得太下游

前面028主要把 reference-set poverty / scale-down deficit / hacker-mode socialization deficit 连接到商业游戏训练。
这遗漏了用户一开始提出的三层框架中的第一层：**教育**。

更完整的因果链：

```text
EDUCATION / FAMILY / EAST-ASIAN DISCIPLINE
→ time allocation + legitimacy hierarchy + answer-seeking habits
→ reference repertoire / uncertainty tolerance / self-authored curiosity
→ hobby prototype opportunities
→ COMMERCIAL INDUSTRY SELECTION
→ industrial grammar reinforcement
→ observed creator behavior
```

> **行业不是所有问题的起点。很多“商业反训练”首先是在一个已经偏窄的认知底盘上继续强化。**

## 1. 三分法应按因果层级重排

用户原先把“老中问题”分成：教育、行业版本现状、社会版本意识。

更准确的关系是：
- **Education / Socialization**：塑造知识输入、时间配置、对“有用/无用”的判断、非功利兴趣、质疑习惯、不确定容忍与 reference repertoire；
- **Industry Regime**：选择并强化 benchmark、specialization、resource allocation、execution、data-driven optimization；
- **Social-Version Legitimacy**：解释什么是成熟、现实、正经、有用、不务正业、负责任。

因此三者更像：
```text
FORMATION → SELECTION / REINFORCEMENT → LEGITIMATION / REPRODUCTION
```

## 2. “不广泛阅读”和“游戏阅历窄”是同一上游机制的两个版本

# `NON-EXAM SELF-EDUCATION SUPPRESSION / 非考试型自我教育压缩`

> **学生把大量认知时间投入被明确评分、排名和升学认可的输入，而不能立即兑换成绩的广泛阅读、游戏、制作、探索承担更高机会成本与合法性成本。**

截图中的“也要看对拿分有用还是没用”尤其典型：即使在支持阅读，仍把 **SCORE LEGIBILITY** 当最高裁判。
问题因此不只是“读得少”，而是阅读是否合法仍需通过考试收益证明。

游戏承受的阻力更大：除“对考试有没有用”外，还经常被编码为娱乐、浪费时间、成瘾风险与需要设备控制的活动。

## 3. `UTILITY-JUSTIFICATION TAX / 有用性证明税`

> **个人兴趣必须先证明对成绩、升学、职业或收入有可见帮助，才获得时间、设备与家庭支持。**

这会压缩：
- curiosity-driven reading；
- remote reference acquisition；
- intellectual wandering；
- hobby making；
- game-reference accumulation；
- self-authored problem formation。

教育竞争越强，越可能出现一种合法性梯度：
```text
exam study > credential activity > curriculum-related reading > broad reading > hobby making > games > game-making
```
这只是研究H，不是全国统一排序。

## 4. 应试教育：不能粗暴写成“应试=没创造力”

华东师大教育科学2023论文明确反对用总体创造力作简单国别断言，但提出：应试教育对拔尖/高创造力学生可能存在更明显负面影响，机制包括知识宽度和深度受损、冒险与质疑精神下降、对不确定性的容忍下降、内在学习动机减弱。

Source:
- https://xbjk.ecnu.edu.cn/EN/10.16382/j.cnki.1000-5560.2023.04.006

这与独立作者形成所需的 broad repertoire / non-consensus judgment / uncertainty tolerance / intrinsic curiosity 高度重合。

因此值得检验：
# `TOP-END CREATOR SUPPRESSION RISK`

> **机会成本最高、成绩期待最高的潜在异类创作者，是否反而更容易被导向可评分输入，从而损失远端知识与兴趣探索？**

这是H，不是已证明的全国结论。

## 5. 东亚比较：自主探索时间可能被课外学业继续占用

2025年一项覆盖新加坡、香港、韩国、台湾16,893名学生的研究发现：校内课外活动正向预测 creative thinking，校外学业活动与 creative thinking 负相关，家庭和同伴支持有正向作用。

Source:
- https://www.sciencedirect.com/science/article/pii/S1871187125001865

因此可定义：
# `DISCRETIONARY-TIME CAPTURE / 自由时间捕获`

> **名义上的课外时间，被考试准备、补习、作业与家长监管继续占用，降低自主构建 reference repertoire 和 maker identity 的机会。**

中国关于中考竞争和家庭课外教育投入的研究也显示，升学竞争会显著提高家庭课外教育投资。

Source:
- https://qks.shufe.edu.cn/J/CJYJ/Article/Details/eef51b5f-a039-4e74-a816-91ff6d59f03f

## 6. 广泛阅读本身也受同一机制约束

2026一项中国高中 extensive-reading 研究指出，在 exam-driven secondary context 中，广泛阅读项目会因为时间限制、考试压力和 curriculum competition 而变得脆弱。

Source:
- https://pubmed.ncbi.nlm.nih.gov/42735655/

所以“不广泛阅读”与“不广泛玩游戏”可能共享同一上游：
```text
high-stakes evaluation
→ discretionary time becomes scarce
→ only legible-return activities survive
→ broad repertoire narrows
```

区别是游戏还额外遭遇娱乐污名、设备门控与成瘾话语。

## 7. `GAME-REFERENCE ACQUISITION TAX / 游戏参照获取税`

> **年轻人在形成广泛游戏参考系时，需要额外承担的时间、设备、家庭冲突、道德污名、成绩机会成本与合法性解释成本。**

家庭研究里，游戏经常以“耽误学习”的形式进入亲子冲突，没收设备、训斥等限制方式真实存在。

Source:
- https://pmc.ncbi.nlm.nih.gov/articles/PMC11042478/

2026关于中国2021未成年人网络游戏限制的研究发现：政策显著降低游戏参与与总上网时间，但短期内没有观察到清晰的学习时间或考试成绩提升。

Source:
- https://www.sciencedirect.com/science/article/abs/pii/S0304387826000957

这不能证明游戏必然有益，但至少说明“拿掉游戏时间会自动转成学习收益”不是可以直接假设的替代关系。

## 8. `DEFERRED AUTONOMY MODEL / 延迟自主模型`

一种典型教育想象是：
> 未成年人阶段先完成正确路径与筛选，成年/毕业以后再谈自主思考。

问题是很多作者能力不是22岁后开关式出现：
- hobby depth；
- game repertoire；
- curiosity；
- maker confidence；
- self-generated problem formation；
- peer subculture；
- failure tolerance。

它们都存在形成窗口。若18–22岁前长期缺训练，毕业后又立刻进入高工时大厂与家庭ROI阶段，补课成本更高。

## 9. `STANDARD-ANSWER EPISTEMOLOGY / 标准答案认识论`

潜在连续链：
```text
school: problem is given → recover expected answer
→ company: benchmark is given → execute validated solution
→ project: category is given → optimize within template
→ startup: investor-legible answer is given → reproduce known grammar
```

这并不是说所有应试生都会如此，而是需要研究是否形成：
# `ANSWER-SEEKING CONTINUITY`

它正好连接028的两种默认反射：
- industrial mode：specification → resource allocation；
- hacker mode：constraint → rewrite problem。

## 10. 东亚规训不能成为万能解释

如果“东亚规训”足以解释作者生态薄弱，日本就很难解释。
日本同样拥有高规范、高教育压力与组织从众，却形成漫画、同人、游戏导演、circle和长期 craft identity。

所以真正变量应是：
# `DISCIPLINE × ESCAPE INSTITUTIONS`

> **规训提高偏离成本；社会是否同时建立足够强的合法偏离通道，决定异类能否持续存在。**

日本的 doujin / manga / game circles 等可能提供补偿；台湾、韩国也必须作为东亚内部压力测试。

因此禁止写：`EAST ASIA = NO CREATIVITY`。

## 11. 教育为什么必须放在行业之前？

行业只能训练已经入行的人，但入行之前已经发生：
- 谁接触PC/主机；
- 谁玩过多少 genre；
- 谁能买游戏；
- 谁能用周末做 mod/jam；
- 谁广泛阅读；
- 谁能把兴趣公开；
- 谁为了高考停掉几年兴趣；
- 谁被家庭在报考前筛掉。

所以行业看到的是：
# `SELECTED CREATOR INPUT`

而不是原始人口。

若不研究教育/家庭，就会把“入行者本来 reference narrow”误写成“行业后来让他们 reference narrow”。两者可能同时存在，但贡献率不同。

## 12. 商业反训练必须拆成两阶段

### Stage 0 — `PRE-INDUSTRY REPERTOIRE FORMATION`
教育/家庭阶段：reference breadth、maker habit、self-authored curiosity、uncertainty tolerance。

### Stage 1 — `INDUSTRIAL GRAMMAR REINFORCEMENT`
入厂后：benchmark、specialization、resource reflex、metrics、department logic。

于是：
```text
narrow Stage 0 × strong Stage 1 reinforcement = very high ontology lock
```

反过来：
```text
rich Stage 0 authorial substrate + industrial capability = possible selective capability retention
```

这解释为什么同样进大厂，有的人带走能力，有的人主要带走语法。

## 13. `SELF-EDUCATION SOVEREIGNTY / 自我教育主权`

> **年轻人有多少时间和合法性，可以不为考试、证书或他人要求，自行决定“我想理解什么”。**

它包括：广泛阅读、游戏、mod、coding、drawing、music、niche community、wandering research。

这是 `SELF-AUTHORED ENDS` 在教育阶段的前身。

如果长期缺失：
```text
no self-chosen learning
→ weak self-chosen questions
→ weak self-chosen projects
```

作者性不是毕业后突然发生的。

## 14. 方法审计：为什么此前没优先归因教育？

# `PROXIMAL-MECHANISM BIAS / 近因机制偏差`

行业访谈、项目履历、公司组织、融资数据更容易观察，因此研究容易把最近、可测的变量误当成最重要的上游变量。

同时存在：
# `EVIDENCE-AVAILABILITY BIAS`

学校/家庭中的“没读、没玩、没做、被禁止”属于 non-event，比“加入某公司”更难留下公开记录。

未来老中研究强制问：
> **这个行业行为在进入行业前已经形成多少？**

并优先通过：CEPS等人群调查、学校课程、家庭访谈、学生队列、课外时间、设备/阅读/游戏经历恢复上游分母。

**机制延伸（2026-10-08）：** [034 认识论规训、遗制权威与知识载体污染](034-epistemic-discipline-authority-legacy-and-knowledge-aversion.md) 将本篇的 `STANDARD-ANSWER EPISTEMOLOGY` 推进到权威代替论证、历史判断技能与评价权限代际脱钩，以及说教可能降低自主接触原始材料意愿的三个 H 级研究问题；不把儒家或党史教育直接写成单因果。

## 15. 当前最小结论

> **“中国从业者游戏阅历窄”不应只作为行业能力缺陷研究。它可能是更早的教育—家庭—社会规训链条的结果：高风险考试与家庭投资把课外时间持续转化为可评分活动，广泛阅读都需要证明“对拿分有用”，而游戏还额外面对娱乐/成瘾污名、设备控制与职业不可见性。由此形成的Reference Repertoire Poverty会在进入商业游戏工业前就限制Solution-Space Visibility；商业组织随后再通过benchmark、specialization和resource allocation把局部解强化成Production Grammar。真正的比较变量不是“东亚人是否更听话”，而是SELF-EDUCATION SOVEREIGNTY、GAME-REFERENCE ACQUISITION TAX、DISCRETIONARY-TIME CAPTURE，以及社会是否提供足够强的ESCAPE INSTITUTIONS来抵消规训。**
