## 0. 研究入口：不能把“参加过大作”直接兑换为“能够创办Warhorse”

流行提问是：中国游戏业既有在海外大厂工作的资深人员，也有维塔士、育碧上海等本地国际制作团队；为什么没有按相应规模长出更多《天国：拯救》式的原创组织？

这需要拆成至少五个不同结果：

1. `TASK DELIVERY`：在确定设计方向下完成3D资产、UI、引擎、移植、QA、系统或关卡；
2. `PRODUCTION INTEGRATION`：把多人、多工作室和跨技术栈协作变成可交付作品；
3. `AUTHORIAL PROBLEM FORMATION`：自主识别玩家需求、界定体验、提出游戏核心并持续修正；
4. `DECISION-RIGHTS CONTROL`：实际持有 prototype、greenlight、scope、kill/continue、IP、发行与后续资本的相应权利；
5. `REPRODUCIBLE STUDIO`：完成产品后保留团队、需求关系与第二次尝试的能力。

**前两层强，不足以推出后三层弱，也不足以推出后三层强。** 不同层次要找不同证据，禁止用“Lead某技术岗位”“参与某著名游戏”代替作者权证明，也禁止以作品失败反推具体员工是“伪专家”。

另须将 `OVERSEAS_EMPLOYMENT→CHINA_RELOCATION`（本人实际迁回）与 `CHINESE_CAPITAL→OVERSEAS_STUDIO`（中国投资方海外招聘）、`ALUMNI_LANDING`（老兵跳槽）和 `CHINA-BASED_GLOBALLY_NETWORKED_PRODUCTION`（在中国工作的国际协作团队）分开；否则既无法统计“海归”，也无法判断知识外溢。

### 0.1 比较对象锁定与反例有效性门禁（2026-10-09修订）

**本研究要评估的不是“中国资本能否成功经营外国制作团队”。把网易投资波兰Rebel Wolves的成功，拿来反驳“中国本土游戏从业者的原创创作核心供给不足”，是一次明确的比较对象偷换；这种反驳无效。** 同理，腾讯旗下美国Riot、芬兰Supercell的长期业务成功说明中国资本可以拥有和经营由外国既有组织开发的全球产品，**不能算中国本土培养原创游戏主创的分子**。腾讯2025年年度报告将Riot列为美国开发运营企业、Supercell列为芬兰开发运营企业 [S16]。

不能从资本来源推定开发者来源，也不能从工作室注册地推定核心成员出生地。研究的实际观察单位应为 **创作核心（核心人物+其成长路径+彼此合作史+设计/立项权）**，并对每个团队分别编码：

| 维度 | 必须记录 | 禁止推断 |
|---|---|---|
| 投资/持股主体 | 中国/外国/混合、股权、控制权 | 中国资本参与→中国创作者表现 |
| 创作核心成长经历 | 国内/海外训练与关键项目、实际原型/产品决策经历 | 华人姓名/国籍→中国游戏教育与职业制度培养 |
| 实际工作和人才迁移 | 工作地点及何时实际回国/赴海外/远程 | 中国企业海外招聘→海归成功或回流 |
| 作品成果 | 项目是否发售、玩家与收入证据、二作及权益归属 | 集团收入/海外子公司产品→国内创作核心产出 |

适当的主要比较是：**中国本土培养或海外回流的创作核心** vs **捷克/波兰/乌克兰在当地成长的完整原创团队**，统一考察共同创作前史、专业岗位之外的全局判断、做原型与独立立项的实践、项目范围和商业结果。需要对具有中国背景但完全在海外完成创作训练的人员单独分类，不能简单按身份计入某一制度。

**反例资格规则**：只有来自相同分析层级、测量相同结果变量的案例才可以反驳数量级命题。一个不同投资者来源的外国工作室成功，最多否定“某资本不会投资好游戏”这种额外命题；如果原命题从未讨论资本能力，就不能构造该命题再反驳。一个中国本土原创团队成功，只证明该机制有非零案例，不能单独证明其与欧洲相同的团队密度。

## 1. 维塔士：在中国的全球生产能力学校，但不是稳定的原创工作室孵化器

### 1.1 2011年的职业能力与分工结构（同期可证）

2011年 Game Developer / Gamasutra 对创始人 Gilles Langourieux 的采访披露：公司约600名员工，其中约95%为本地员工，已有成熟的跨平台重制、移植和国际客户流程；他把公司的强项明确表述为可靠的项目管理、流程和成熟技术负责人。[S01]

**可以推得：** 中国本土已经存在规模化参与全球主机/PC高规格生产的组织，不能把国内主机技术人才史从《黑神话》才开始计算。

**不能推得：** 600人都是原创策划、国内员工都拥有产品最终决定权；也不能从公司参与名单把客户游戏的所有设计与收益算到中国。外包、联合开发、全项目重制应分别编码。

### 1.2 2023—2024：公司主动建立“从专业服务到面对玩家”的新课程

2023-06-14，Game Developer采访维塔士业务负责人Philippe Angely，记录 `Virtuos Originals`：提案人原则上有至少10年从业经历；入选后约六个月原型资助，目标是制作可以向发行伙伴展示的Demo；负责人报告约五分之一提案进入原型阶段。《Mahokenshi》是这一计划下已上市的策略卡牌游戏，由旗下法国团队生产，而**不能直接算成中国原创团队成果**。[S02]

2024-07-29，A9VG采访中国区负责人田立和成都《唐传奇：琵琶行》制作人胡涛、肖骥。田立说公司约2015—2016年起已逐渐承接整包研发，但开展自研的一个目标仍是让团队**走完对终端玩家负责的完整产品周期**；并回顾了早期《吸血牙妹》市场反响不佳的实践。胡涛披露：2024 ChinaJoy的小型试玩关卡既用于检验目标潜行玩家，也用于学习问卷、现场观察、市场接触；有策划承认亲眼看玩家操作改变了自己的判断。[S03]

这组一手同期自述很重要：

- `END-TO-END CONTRACT`（替客户整包开发）与 `OWN-MARKET FULL CYCLE`（自己定义产品并负责玩家、发行、市场结果）不是同一回事；
- 开发人员能完成系统与关卡，不等于此前已训练过用户研究、需求发现、产品定位及市场接入；
- 该团队有明确的品类选择逻辑：相较当时大量中国题材魂类作品，尝试把第一人称潜行体验结合唐代题材。**这是有意识的产品差异化尝试；商业可行性需待正式上市和销量数据验证。**

2024年的公开试玩报告提供了可玩的局部验证，但**试玩好评≠完整作品交付≠商业盈利**。[S04]

### 1.3 必须同时记录2025年的裁员事实

维塔士2025-07-17公告：约7%的全球岗位受到调整影响，包括亚洲约200个、欧洲约70个岗位，解释为部分地区产能利用不足与客户需求变化，同时强调向高价值联合开发转型。[S05]

所以专业服务模式并不天然隔绝全球裁员与预算周期。维塔士是否相比原创IP公司更能分散风险，需要公司的合同集中度、利润、员工流失与跨周期存续数据，现不可直接定论。

## 2. 中国3A人才训练与完整原创团队形成：把中国创作者作为统计主体

| 路线与案例 | 可观察的中国本土或海归人才贡献 | 2026-10-09时能验证的结果 | 结论边界 |
|---|---|---|---|
| **在华国际生产服务**：维塔士上海/成都等 | 中国本地技术、美术、制作管理与部分自研人员积累 | 持续承接国际项目；成都《唐传奇》公开试玩；2025全球裁员 | 员工数量并非中国原创游戏导演数量；法国《Mahokenshi》不能算中国团队原创产出 |
| **内部作者型训练**：腾讯NExT | 在中国建立原型发起、评审和淘汰机制，逐项目赋予权利 | 见已有中国010 / CASE-041，含已上市与已停运作品 | 需要固定所有立项起点和最终成果，不能只看媒体最关注的项目 |
| **中国本土市场原创成功**：《枪火重生》与游戏科学 | 本土团队自己形成设计主张，再组织技术与资金完成产品 | 已完成全球PC/主机市场验证，详见已有CASE-039及中国013 | 证明非零成功，不自动等于有与波兰/捷克可比的团队密度 |
| **海外专项技能回国**：弋振中参与《原神》主机版本 | 技术人才回国对明确的跨平台任务负责 | 主机版随产品上市；个别岗位成果可归因 | 不能将整个原创IP成功归因于某一海归，或把技术交付记成创意主导 |
| **海外创意岗位回国**：杨佳阳参与NExT《重生边缘》 | 曾有海外研发经历的资深创意人才加入中国原创项目 | 《重生边缘》上市后停止运营，详见CASE-041 | 失败的完整产品不等于某单一人的能力为零；需核具体立项/预算/方向决策权 |

**目前上述样本不是固定起点队列，不能计算海归或中国主创成功率。** 更重要的是先把同一类人作为比较分子和分母，而不是为了反对一个评价不断搬出不相关的外国项目。

### 2.1 对照背景（不是中国创作人才命题的反例）

中国资本确实可以支持优秀的海外本土团队：腾讯旗下Riot（美国）和Supercell（芬兰）是典型已成熟资产 [S16]。网易对波兰Rebel Wolves的少数股权投资，保留了原创团队的IP与创意控制权；该波兰团队的《The Blood of Dawnwalker》2026-09-03全球上市，2026-09-05宣布跨平台销量超过100万份 [S09–S11]。**这属于中国资本配置国际创作资产的成功，而非中国本土创作核心的成功，也不是对“中国创作人才再生产不足”假说的反例。**

腾讯支持的TiMi Montréal、Uncapped《Battle Aces》，网易支持的Fantastic Pixel Castle等海外第一方项目则在2025–2026年经历关停或终止开发 [S06–S08]。它们可以用来研究**资本组织方式、研发费用与原创项目风险**，但由于这些工作室人员来源混合或偏海外，并不能直接记入“中国游戏从业者的原创能力失败”分子。以中国母公司归类这些外国开发人员，同样是资本与人才的偷换。

因此这组资本成功与失败案例只构成**独立背景维度**：它能说明中国投资者未必缺少购买或持有优秀海外游戏资产的能力；不能回答中国培养了多少同等级原创主创。

## 3. 斯拉夫/捷克对照：不是“欧洲天然允许原创”，而是前史、组织和融资顺序

### 3.1 Warhorse：创作主张先于完整大预算，但融资并不轻松

2014-01-22 Warhorse推出《Kingdom Come: Deliverance》Kickstarter，明确提出不靠魔法的写实中世纪RPG。同期发行声明：项目此前已获约150万美元投入，主要来自一名非游戏行业投资人；**£300,000众筹目标是向此投资人证明存在需求、以触发继续投入的条件，而不是全项目预算**。众筹最终有35,384名支持者，合计约£1,106,371。[S12–S13]

创作团队拥有《Mafia》等既往经验，但不应写成“完全不用外部资本”“先攒钱再自然成功”。《Kingdom Come: Deliverance II》截至2026-02取得逾500万份销量，证明系列有第二次产品成绩；也不能借结果倒推出2011年成功概率已高。[S14]

### 3.2 GSC→4A：能力资本不是简单复制著名项目名字

GSC→4A的创办前史、公司内部冲突、早期主要人员、技术与玩法能力迁移已在 [SLAVIC-002](../../sister-projects/slavic/evidence/SLAVIC-002-gsc-4a-studio-schism.md)登记；不在此重建一份孤立的权威账本。现有资料支持这是一种有既往组织合作与能力资本的集体重组，而非2006年突然雇人组成一支完美团队。

其反压力测试是乌克兰Reburn：《La Quimera》由《Metro》相关专业成员参与开发，2025-04临时延期，2025-05-07以Early Access上线，说明资深团队经验也不自动保证新原创作品发布顺利。公司自行表示遇到了首次独立开发的困难，同时有战争条件这一重大混杂变量；不能由一款作品的评价推断乌克兰原体系“失去创造力”。[S15]

### 3.3 对照真正显示什么

Warhorse、4A及由波兰团队创办的Rebel Wolves共同支持一种**可能的非中国创作核心形成机制**；其案例只用于测量波兰/捷克/乌克兰团队前史，**不因网易投资而改写为中国创作者成功**：

```
pre-existing creator judgment / collaboration network
  → named product thesis
  → organizational recombination
  → funding and distribution
  → prototype / market validation / full-cycle delivery
```

但不能倒过来说所有好公司都必须先有单一天才，或只有这样的先后顺序才可能成功。维塔士与NExT提供另一种路线：**现有大组织可以为员工建立可用的原型入口与市场责任训练。** 其效果要按进入原型、完成产品、形成第二次尝试的同一队列验收。

## 5. 回流统计为何仍不能计算

必须建立 **individual-level longitudinal cohort** 而非剪贴社交平台“求收留”帖子：

| 必填字段 | 编码 |
|---|---|
| 基线 | 2022-01-01时的雇主、实际工作地、岗位、任职年限；国籍/华人身份不明一律UNKNOWN |
| 裁员事件 | 发生日期、主动离职/被裁/部门关闭、可核来源 |
| 流动结果 | `RETURN_TO_MAINLAND / RELOCATE_OTHER / STAY_ABROAD / REMOTE_FOR_CHINA_FIRM / UNKNOWN` |
| 能力 | `SPECIALIST / TECH_LEAD / PRODUCER / DESIGN_AUTHORITY / FOUNDER`，允许多选且按项目核实 |
| 决策权 | prototype、product thesis、greenlight、scope、IP、资金与项目终止权，逐项可核/UNKNOWN |
| 24/36月结果 | 具体已上市产品、贡献边界、创业/再就业、第二次尝试；观测日期与右删失 |
| 分母 | 起点必须固定雇员或受影响岗位 cohort；不能用小红书和媒体曝光者做分母 |

可先构建“公开可验证最低下限”，绝不能把无法观测者当作失败或回流者。中国资本拥有海外公司、同事搬去另一个国家、海归留在海外远程就职，均不能偷换成“回国”。

## 6. 下一轮最有价值的证据，而不是继续增加漂亮传记

1. **维塔士 cohort**：2010–2015年上海/成都/西安项目负责人名单→2026创业/流向，分别记外包资深领导、实际全周期产品主创与二次创业；维塔士2025裁员人员去向不能从公告推断。
2. **中国主创形成与密度**：围绕维塔士、育碧上海、海外回国开发者、NExT和本土创业公司，建立连续、可追溯的完整创作核心队列；记录从资深专业人员→原型作者→完整产品负责人→二作团队的转化率，优先于再做外国投资组合成绩榜。外国团队仅作为独立的同定义对照组。
3. **海归固定队列**：从2022年以前可公开的工作室员工名单/同一个被裁部门出发，追踪不同去向，不优先挑选媒体高薪名人。
4. **中国内部反例**：复用NExT、枪火重生、游戏科学、Sultan、Boundary等已有档案：国内产生的原创团队与海归专才同一计量口径对比，避免所有成功被算给海归或所有失败被算给中国。
5. **两次机会**：区分项目取消、工作室注销、IP留下、人员再组队、下一作被资助和完成发售；不能把“不再在原公司”直接记成职业失败。

## 8. 2026 Transfer Gate

- **DURABLE（机制）**：岗位专业资历≠全周期作者权；将人员迁居、资本跨国和实际作品归因分开；可用原型与玩家验证产品问题。
- **CONDITIONAL（策略）**：先有特定游戏构想再融资、少数股权保留创意控制权、服务业务反哺原创。这些策略在2011–2026不同融资/市场/劳动周期的效果未确定；**海外持股结果仅供资本治理比较，不可当中国本土主创能力的正反证据**。
- **HISTORICAL（具体操作）**：2014 Warhorse的Kickstarter募集效果、2011维塔士劳动力成本与职位结构不能不加换算移植到2026。
- **UNKNOWN**：2024–2026中国籍海外3A实际迁回比例；中国相对捷克/波兰“完整作者型团队”真实发生率与影响因素系数。
