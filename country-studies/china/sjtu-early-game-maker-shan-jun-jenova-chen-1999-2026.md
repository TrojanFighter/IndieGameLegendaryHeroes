# 上海交大早期游戏创作者：单隽—陈星汉的共同起点、出走与反复失败（1999—2026）

- Program：C 中国国情研究／独立作者职业史；对照 B 斯拉夫创作者生命史和现有 CASE-057 thatgamecompany。
- Type：双人物配对 Evidence Ledger + 制度假说；**非正式人物 Profile，不是因果识别成功的自然实验**。
- Intake：2026-10-07；证据分层 P1（本人当时或同期采访）、P0（平台官方公告）、S1（具名记者深访/现场记录）、H（待检验机制）。
- 索引边界：本篇处理1999—2003交大早期原型制作同伴及不同人生轨道；[2005—2026 SJTU／StudioGM／二次元社群](sjtu-acg-peer-network-career-histories-2005-2026.md) 是另一段部分相交、**不得合并为单一正式校社团**的谱系。
- 主要问题：同校、同年代且有早期游戏制作关系的两名作者，为什么一人走向盛大/MMO、XBLA、自筹/国内发行和多次未成功收束；另一人赴美后进入USC/Sony/VC等体系？要比较**谁提供学习机会、谁出资容忍非共识原型、谁为延期/渠道/团队成本买单，以及谁最终持有产品权利**，不能把结果简单归咎国籍、品味或毅力。

## 1. 真实交集与早年原型：二游时代以前已存在作者型实践

**S1 2015具名深访**：单隽1981年出生上海，家庭空间窄小、父母早离异，绘画/漫画创作早于电脑制作；高中编程课及家中购置电脑成为转折。1999年入上海交大美术系，在校利用计算机课程、图书馆和同伴资源制作游戏。为使旁观者也能享受游戏而设计“机器人战队”：玩家提前写入战术程序，现场由AI自行对战，校园活动吸引观众，比赛中的意外愚蠢行为形成观看乐趣。**这不是仅会模仿海外商业品类的早期人才**，设计目标已经涉及玩家—观众互动、系统涌现、可观察反馈。

**P1 2015单隽公开分享**：大学阶段做约4—5个原型，机器人游戏校内比赛和社团活动，个人明确说这种影响他人的感觉超过考试成绩；约2001—2002便尝试将个人作者能力转化为商业游戏能力，故加入盛大。他本人亦把《风卷残云》的格斗原型追溯到大学时代。

**S1 2015深访、S1 2018触乐采访**：单隽大三时由校友胡岭邀请加入交大游戏制作团队，陈星汉亦在其中；2015报道编辑写两人为校友和社团好友，2018报道援引陈称单隽为“死党”。**不应擅自写成正式注册游戏社团、共同创立公司，或认定两人合作过特定已发表作品**。2003前共同项目署名、陈在团队的具体分工仍缺原始记录。

陈星汉于1999年前后进入交大计算机培养体系、2003赴美国USC互动媒体专业，2006与Kellee Santiago等创建thatgamecompany，随后与Sony合作；这条海外成熟路线与单隽在国内的职业路线开始分叉。**共同起点减少了“只是中国本来没有原创设计人才”的解释空间，但个体对照不具备统计因果识别力。**

## 2. 单隽：从原型快手到必须为团队负责的制作人

### 2003—2006｜盛大：观众成长与系统公平的冲突，包含他自己的失败

**P1单隽2015自述**：进入盛大先做《传奇世界》，后来主持战棋项目《三国豪侠传》，偏爱兵种配合、低数值成长和策略性；项目商业失败。他承认自己忽视当时本土玩家的成长/累积需求，还影响其他希望凭项目取得奖金及期权的同事。这不能只写成“资本迫害追求平衡的天才”；原始财务、留存数据和具体运营建议仍待核。

**S1长访补充**：据回忆他曾在会议中拒绝陈天桥简化设计的建议，后来离开/被开除；不将记者重构的对话当同期录音，更不把其职业失败判定为单一制度原因。其后在灵禅外包/协作项目中学习项目管理与协同利益。

### 2007—2013｜自费做《风卷残云》，仍需资本与国际平台门票

**P1 2015开发者分享**：《风卷残云》2007开始开发，最初两人，计划约9个月，实际三年以上；前期约三年靠个人积蓄。获奖和优秀demo不能证明发行商相信两人团队能交付持续运营；到第三年资金紧张。经ChinaJoy、媒体传播及可下载demo触达潜在发行人，扩为约10人交付并登陆XBLA、Steam。

**S1 2015深访**：老友胡岭负责引擎工具，单隽核心逻辑，美术音乐外包；2009已几乎无以为继，同伴面临孩子出生与迁移家庭决策。报道称盛大18基金给予“千万级、三年期”资金，但缺合同和支付记录，**资金金额和精确时间不得当作P0**；Xbox/海外发行关系使作品被渠道方纠纷牵连下架，第二个项目因基金停止遭资金断裂。文章宣称XBLA首月约8000份，须与其他时间/平台PC首发数字分开，不合并为总销量。

**分析边界**：中国资本并非从未提供支持；单隽确实曾得到公司资金和全球发行门路。然而靠平台准入/发行商背书的风险集中到小团队身上；不能由此证明这些风险在美俄不存在。

### 2013—2018｜进入商业手游，并不等于抛弃原创

**P1 2016单隽给玩家的信**：《快斩狂刀》从短周期动作demo起步，他主动想做“原创核心玩法+成熟商业外围”；研究各种中国商业模式之后意识到细分、留存与付费设计比自己想象复杂，遂向心动求助。心动负责《神仙道》运营的刘义峰反而反对照抄成熟套路，提出外围系统也需新意。这是**专业商业合作者可能推动原创**的正面反证，必须与“不懂行资方指令复制成功品类”区分。两方探索动作深化、实时PvP和大服/小额用户优先机制。

**P0运营方公告**：《快斩狂刀》2018-04-17停止充值、2018-04-30停服。因此即使商业专业化合作和作者对核心玩法的选择得到尊重，也不必然换来可持续商业成果。需要销量、留存、成本、发行结算数据才可诊断失败因由。

### 2019—2026｜《不当英雄》与失败作品的部分再生

**P1 2019单隽独白**：自述《风卷残云》短暂高光、《魂斗士》《快斩狂刀》失败、未立项的《Magus》挫折；多年来为成熟网游商业模式作保守决定却仍未取得期待的成果；明知可以去找“好工作”，仍因团队还在而继续坚持。他批评行业只放大成功者、把成功包装成可复制方法；设计《不当英雄》苟雄这种落魄反英雄角色，直接投射了创作者自己的挫折和恐惧。**这是人物写作的中心一手史料，不能写成单纯“励志成功学”。**

**P0 Steam商店，截至2026-10-07检索**：《不当英雄 ROGUELIKE HERO》仍显示“即将推出（Coming soon）”，无正式发售记录。**P0 2026-07《派对之星》官方更新公告**：明确把来自“从未发售的幻之游戏《龙套英雄》”的苟雄作为新英雄。TapTap官方活动同步称作品未正式发售；这与2019《不当英雄》主角苟雄对应，但“《龙套英雄》”究竟是项目后期更名还是活动别称须核。**不得仅凭二手推测断言单隽本人当前从事何职位、团队已经解散、具体亏损或版权转移条款**。可确认的是**未正式发售的原创角色被后续商业项目利用**；作者能力/资产可能部分留存，即便原作没有收束。

## 3. 陈星汉：移居美国获得不同的试错通道，但未脱离权利与现金流约束

### 2003—2012｜USC、Sony合作与情感体验游戏

**P1 2007年陈星汉接受Gamasutra原始访谈（新浪同期中文译本）**：他明确说在中国毕业后难找到同时结合工程、艺术和设计的工作；当时国内工作室偏重外包和在线游戏、很多管理者希望设计师复刻竞争品类。他同时承认自己已经约四年没回国，该评论并非中国2007行业统计，却是**同期当事人的明确离开动机和对本土职业机会的观察**。

**P1 2025-09-09 Gaming Founders Podcast本人回忆**：父亲倾向让他继续计算机博士/成为教授，反对艺术道路；他最初申请USC动画/电影是希望进入Pixar，起初根本不认为做游戏是体面的职业目标；交大学生作品主要是在模仿流行游戏。他回忆家里动用了几乎全部积蓄、包括卖房支持第一年赴美读书，赌其后来拿到奖助。**此为本人20余年后的回忆，金额/房产交易未见独立档案，不能估算家庭净资产**。这纠正了“出走就是单纯逃离国内游戏圈”和“赴美完全没有家长阻力”的双重误判：保守父亲后来仍以重大财务牺牲支持其子女非标准路径，而这同时造成极强的家庭回报压力。

**P0/S1 USC 2012校方报道**：USC提供约2万美元支持学生游戏《Cloud》；陈谈及作品触达用户后的回信及情感游戏目标。2006与Kellee Santiago等创立thatgamecompany；Sony发行《flOw》（2007）、《Flower》（2009）、《Journey》（2012）。USC校内奖助、同伴网络与Sony独占投资形成不同于盛大MMO的原型验证、发行与观众评价环境；不是一次性“美国有人投资天才”的简单故事。**赴美并非无需成本：其具体家庭阻力、家庭资金牺牲及USC早期非稀释支持均有新的一手材料，见下节。** 学生作品及同学首次合作credits仍需进一步核。

**P1 Jenova Chen 2013 GamesBeat深访**：《Journey》超期，员工约半年领取半薪，完工时现金耗尽，部分人员离开；Sony承担资金和推广、同意部分延期，但并未无限追加资金。发行回款首先偿还Sony投资、销量报表/版税结算有滞后。**产品获奖≠团队当期现金正流入**。

**P1 Chen 2013 Engadget访谈**：Chen明确称Sony拥有该三款作品的权利及主要经济收益，thatgamecompany需等回本后取得分成；同时他说Sony在前所未见的玩法上干预创意并不重。即**创作决策权高，但IP/现金归属独立性低**。这是“赴美自由”的必要反证，不得将未披露合同全文当已核验。

### 2012—2026｜VC、全球市场与《Sky》的长周期商业化

**P0/P1 2012 GamesBeat**：Benchmark投资550万美元，结束Sony三作独占合作后，团队寻求多平台自主发行/扩展受众。2014追加约700万美元资金；资金性质、股份与具体批准权须另查CASE-057与文件证据。

**P1 2019 Famitsu与2022 PocketGamer访谈**：《Sky》面向更大的移动受众，选择F2P和长线运营，而非永远停留在买断艺术小游戏。Chen强调不希望依赖掠夺性付费情绪，试图用送礼、通行证等设计让商业模式与情感体验一致；也承认研发移动触屏操控曾耗费约一年半、未识别真正用户习惯。这证明“海外成功者”也在不断犯产品判断和scope错误，且有意识适应商业模式。

**P1 2026-07 4Gamer 20周年访谈**：陈星汉称自己20年前的目标——让社会将游戏尊重为艺术形式——尚未完全达成；报道转述《Sky》全球累计下载超过3亿，属于报道/公司对外口径，不能误当审计用户或收入。20年后仍在同一设计问题域持续迭代是有效长线能力证据。

## 3.5. 必须增加的家庭内部对照：单隽与哥哥单晖（非交大同学组）

**S1 2015年单隽传记**：提到其哥哥单晖（与单隽讨论过机器人战术游戏）后来任《天天酷跑》制作人；这是**兄弟关系证据，尚未核两人在父母离异后的实际同住、经济支持与职业成长环境**，不能假定二人有完全相同家庭待遇。

**P1 2014-12《天天酷跑》团队现场采访**：制作人单晖明确说，即使完全去掉奖励、成长线和单局回报，也应验证基本操作手感和玩法闭环的独立乐趣；团队据腾讯数据迭代。最初约13—14人，2013年3—8月完成约5个月可上线版本，长期运营时扩至40多人。运营负责人同期承认腾讯社交平台是启动扩散和付费能力的关键，并否认作品脱离平台也必然取得相同成绩。**作者懂核心玩法、利用既有品类benchmark与平台流量成功，在同一个案例中可以同时成立**，不应把商业设计者全写为不懂游戏的资本傀儡。

**S1 2025年天美组织调整新闻**：单晖出任整合后的天美T1工作室负责人，项目能力和组织权力持续积累；需进一步核官方组织文件、本人从2006入腾讯至2025的真实职务履历及具体作品署名。

**理论价值**：除了单隽—陈星汉跨制度配对，现在还有**单隽—单晖同家族、不同组织轨道**：一个追动作原创与海外买断，几次创业仍遭发行/现金/收束问题；一个在腾讯大平台利用跑酷benchmark、核心手感、社交分发与长线组织获得成绩。这降低了将所有命运差异直接归结于出生国/家庭性格的诱惑。但兄弟亦有个性、时间、专业技能与资源差异，不能当严格家庭控制实验。后续应研究兄弟关系在具体职业机会/工具/项目建议上的真实互助是否存在。

## 4. 配对比较：谁替作者承受试错的损失？

| 维度 | 单隽在国内/国际平台路径 | 陈星汉在USC/Sony/VC路径 |
|---|---|---|
| 形成期 | 校园原型、机器人AI战术、格斗Demo、游戏社团/比赛 | 交大计算机、同期制作同伴→USC跨学科互动媒体 |
| 初始职业/制度入口 | 盛大MMO/运营、灵禅外包→个人创业 | USC学生作品与同伴→Sony资助独占项目 |
| 核心作者题目 | 战斗对抗、动作系统、系统公平与观赏性 | 情感、关系、非暴力、可普及的社交体验 |
| 项目超支谁先垫付 | 本人/合作者积蓄，后商业投资和发行支持，团队工资风险 | Sony项目资助+团队现金储备，最终仍减薪/人员流失 |
| 创作权与经济权 | 每次项目、投资/发行关系待证；有商业方鼓励创新的记录 | Sony期创意干预低，但据Chen本人说平台持主要IP和利润 |
| 商业化选择 | 由premium/主机转向国内mobile运营化，仍追求特色动作 | 由Sony买断小品转向mobile F2P/social，仍追求情感题目 |
| 至2026可核结果 | 原作《不当英雄》未正式发行，角色苟雄2026进入《派对之星》；个人去向待核 | 《Journey》完成并获奖，《Sky》长线运营；财务可持续性与股权成本仍需分年核 |

比较不是“只差一个国家”或统计自然实验；两人的艺术目标、选择、团队、平台、教育经历、时机、资本条件都不同。**这是具有真实早年社会关系的 matched life-history pair，适于发现机制，不适于计算制度净效应。**

## 5. 提出的新问题：Failure Carrying Capacity（失败承载能力）

先前ARC（Authorial Refusal Capacity）只问能否拒绝不合适的投资/渠道要求并继续原型验证；本双人物档案显示更高层问题：**作者可以失败几次而不退出职业？损失由个人积蓄、亲属、同伴、公司、发行商、平台还是投资人吸收？失去一个项目后哪些能力、IP、合作关系能转入下一作？**

为避免误判，暂分四个指标：
1. **ARC / 决策权**：谁能在方向冲突时否决，否决代价何在；
2. **Product Closure / 交付能力**：从短期Demo到可发售、可维护产品的范围与生产判断；
3. **FCC / 失败承载能力**：几轮试错/延期/失利后团队还能留下多少成员、技能、资金和选择；
4. **Rights/Capability Recirculation / 权利与能力再生产**：失败项目的机制、引擎、角色或团队知识能否转入后继项目，并由谁享受收益。

**两个反例必须同时保留**：盛大与心动都曾支持单隽，不能把中国商业资本写成纯粹破坏者；Sony的资金并未免去陈星汉团队的破产危机，也没有将IP经济权全部留给作者，不能把美国体系写成创作乌托邦。市场筛选与作者自己的产品收束错误必须进入解释。
