## 0. 结论先行：两国都不是“普遍个人主义社会”，关键差异可能是**破格发生在哪里**

日本研究的新修正表明，日本游戏黄金时代不能解释成“日本社会宽容怪人”。传统组织同样存在年资、先辈—后辈和高同调压力；但电子游戏作为新产业，曾在部分公司内部创造出**低资历者提前取得完整项目权**的孔洞：

```text
Japan historical hypothesis:
enter established firm
→ encounter new-industry frontier / patron / prototype channel
→ gain unusually early project authority
→ remain inside organization
→ accumulate craft for decades
→ possibly become long-lived director / producer
```

中国游戏史也反复出现新边疆和破格人物，但现有材料更常显示另一条路径：

```text
China historical hypothesis:
enter school / commercial studio / old regime
→ accumulate capability
→ current objective function does not price author's preferred problem
→ exit / found / split / rebuild small team
→ obtain authorial control outside the old organization
→ face market + financing + household risk directly
```

因此当前最值得检验的不是“China less individualist”，而是：

> **日本黄金时代的 `FRONTIER_PERMEABILITY` 较常发生在企业内部；中国的完整作者权较常集中在创始人层、创业层、离职重组层或新组织层。若这一差异成立，中国普通专业人员从“有能力”到“拥有完整产品问题主权”之间，需要支付更高的 `AGENCY_TAX`。**

Status: **H / strong case convergence, denominator not yet established.**

## 1. 统一比较单位：不是“自由不自由”，而是作者权经过哪几道门

以后中日案例都统一拆以下变量，不再用“公司鼓励创新”概括：

- `PROBLEM_ORIGIN_RIGHT`：谁能提出“我们应该做什么”；
- `PRE_GREENLIGHT_RESOURCE`：正式立项前能否拿到带薪时间、工具、人手、服务器/算力；
- `PROTOTYPE_RIGHT`：能否先做出可玩物，再要求组织判断；
- `GREENLIGHT_RIGHT`：谁允许项目进入更高资源级别；
- `KILL_RIGHT`：谁有权终止项目；
- `RESCOPE_RIGHT`：项目有问题时，作者能否缩回小队继续，而不是连人一起清零；
- `PARENT_BUDGET_RIGHT`：工作室之外谁可以撤销整个创新制度的预算；
- `FAILURE_SHELTER`：一次失败后人是否还在、工资是否还在、能否再试；
- `SECOND_ATTEMPT_CAPACITY`：项目失败/首作结束后是否有现实条件再做一次；
- `TEAM_CONTINUITY`：能力和默契是否随项目失败而保存；
- `CREATOR_REPLACEMENT`：成功一代掌权以后，新人是否仍能持续获得同等级作者权；
- `EXIT_TO_RECOMBINATION`：离开旧组织后能否在市场、平台、发行、投资或社区中重新组成生产单位。

这组权利与[010 NExT](010-next-studios-greenlight-rights-governance-lifecycle-2017-2024.md)已有decision-right matrix兼容，不另造互相冲突的schema。

## 2. 中国不是没有“边疆豁免”，而是至少经历过四次不同的边疆窗口

### 2.1 第一窗口：1990s—early 2000s 国产PC单机——作者跨度大，但市场庇护极薄

早期国产单机团队本身就具有今天所谓“小团队作者制”的很多特征：
- 工种分工粗，程序、美术、策划经常跨界；
- 小核心承担完整作品；
- 主策 / 主美 / 主程对产品形态有很高直接影响；
- 因产业尚年轻，二十多岁的开发者能够很早承担完整功能甚至整款产品。

《刀剑封魔录》制作人刘坤2022年回顾尤其适合作为机制个案：
- 离开目标软件后，先自己做偏好的动作玩法原型；
- 多位《秦殇》旧同事因demo加入；
- 核心团队约10人、开发不到一年；
- 团队没有专门策划工种，设计由美术和程序直接协商；
- 但公司几乎没有现金安全垫，只能发很低的生活费；
- 产品发售后又因发行/结算问题没有得到可持续收入，最后转向网游才形成企业生存。

Source:
- GCORES / 刘坤访谈, 2022-03-14: https://www.gcores.com/articles/148493

这说明第一代不是“没有作者权”，而是：

> **`AUTHORIAL_SPAN` 高，`FAILURE_SHELTER`、`MARKET_INTERFACE`、`SECOND_ATTEMPT_CAPACITY` 低。**

同时，目标软件2002年接受采访时已直接把转向网络游戏和避免盗版、回笼资金联系起来。优秀单机并非没有需求或制作能力，而是持续经营的回报函数迅速偏向在线服务。

Source:
- 新浪游戏 / 目标软件刘豫斌访谈, 2002-12-05: https://games.sina.com.cn/newgames/0212/120515201.shtml

因此中国第一代单机的历史失败不能写成：
> “作者不够强，所以被网游淘汰。”

更接近：
> **作者制已经出现，但没有形成让作者型团队反复试错、稳定现金回流和长期留存的产业壳。**

### 2.2 第二窗口：2001—late 2000s 在线游戏——真正巨大的商业边疆，但前沿权力被重新定义

盛大等公司首先解决的是支付、服务器和全国触达问题。同期SEC材料显示，盛大早期建立了覆盖数十万零售点 / 网吧的支付与分发体系；在线服务能够把盗版环境中的大量玩家转化成可持续现金流。

参见：
- [中国商业制度谱系003](../../book/research-notes/china-game-commercial-regime-lineage-003.md)

这一阶段当然存在极强创业与产品创新，并不能写成“网游=不创新”。真正改变的是**哪些问题获得最高价值**：
- server / account persistence；
- social structure；
- economy；
- continuous update；
- payment；
- retention；
- live operations。

因此边疆豁免仍然存在，但越来越集中在：

> **能够定义新的在线商业 / 社交 / 服务系统的创业者和项目领导层。**

普通员工则随着企业扩大、岗位专业化进入更长的组织链条。

单隽提供了一个很清楚的个人级转折。他自述学生时代已做过多款游戏；毕业后因大环境进入网游公司，在盛大主导原创《三国豪侠传》，但商业失败使他认识到长期黏着、成长和社交对当时在线市场的重要性。后来他与同事离职，以个人积蓄承担风险，通过XBLA等新数字平台重新进入单机/小团队制作。

Source:
- 新浪游戏 / 单隽访谈, 2012-04-28: https://games.sina.com.cn/o/n/2012-04-28/0953609876.shtml

这条人生路径非常重要：

```text
已有作者倾向
→ 商业网游内部获得项目权
→ 市场证明目标函数错配
→ 学到online production / commercial reality
→ 退出组织
→ 新平台降低market-interface cost
→ 重新取得完整作者权
```

它既反驳“大厂经验全是负资产”，也说明作者权经常要靠**退出后重组**重新取得。

### 2.3 第三窗口：2010s 移动/F2P/渠道时代——创业边疆很强，普通雇员作者权未必同步扩张

智能手机和F2P又创造了一次真正的新产业边疆。大量年轻创始人、旧网游从业者和小团队获得暴涨的市场机会；《刀塔传奇》等产品本身也包含真实玩法重组，不能把这一代写成“纯抄袭”。

但随着Android渠道、发行、买量和高LTV模型成熟，收入接口会持续奖励：
- retention；
- ARPU / LTV；
- monetization；
- event cadence；
- UA；
- channel negotiation；
- large-scale live ops。

[商业制度谱系003](../../book/research-notes/china-game-commercial-regime-lineage-003.md)已用同期财务资料证明渠道可以拿走很高比例的gross billings，开发商与发行方因此被强烈激励去优化可量化商业函数。

这一阶段可能形成中国区别于日本黄金期的关键结构：

> **`FRONTIER_EXEMPTION` 在“新公司创始人 / 项目负责人”层非常强，但并不会自动向普通雇员扩散成同等级 `PROBLEM_ORIGIN_RIGHT + GREENLIGHT_RIGHT + SECOND_ATTEMPT_CAPACITY`。**

2026潘竹涛 / 吴桐雨对42名中国游戏从业者的民族志与访谈提供了当前最直接的劳动现场证据：组织会吸纳玩家身份、创作热情和高投入意愿，但模块化劳动中某些人的高投入比其创作主体性更稳定地被调用；部分人试图通过晋升换取更大创作范围，另一些转向side projects。

详见：
- [009 中国游戏雇员创造性劳动](009-china-gameworker-creative-subjectivity-fieldwork-2017-2026.md)

这仍是定性样本，**不能写成“中国大厂员工普遍没有创意”**。更合理的命题是：

> 中国成熟商业工业已经非常擅长生产高水平专业能力，但`PRODUCTION_CAPITAL`的扩张速度可能快于`PRODUCT_PROBLEM_RIGHTS`向普通成员扩散的速度。

### 2.4 第四窗口：mid-2010s—2026 Steam / 全球premium / 主机——作者权重新外溢到小团队

Steam、主机数字商店、全球支付、通用引擎和creator network逐渐把“离开大组织以后还能不能找到玩家”改写。

当前中国出现的不是简单“独立游戏突然繁荣”，而是：

> **旧商业工业积累的能力被重新组合、重新定价。**

典型路径已有：
- Game Science：腾讯PC MMO核心班底 → 创业 → 手游现金流/适配 → 2018以商业线+5–6人单机试作的双轨结构降低战略转型风险 → premium大项目；
- Double Cross /《苏丹的游戏》：旧商业手游组织衰退后，长期合作老兵缩成小核心，按剩余能力重构scope，让原本被大组织分工切碎的能力获得更宽ownership；
- 《枪火重生》等提供“商业工业能力 + premium完整产品”的正向转移样本；
- NExT则是重要的**公司内部反例**：普通员工确实曾获得小组Demo入口、100人日试作和回炉机会，证明中国大组织并非只能通过离职创业释放作者性。

详见：
- [能力重新定价013](../../book/research-notes/china-capability-repricing-black-myth-sultan-013.md)
- [010 NExT](010-next-studios-greenlight-rights-governance-lifecycle-2017-2024.md)

2025年中国官方产业报告同时显示：
- 国内游戏市场实销 **3507.89亿元**；
- 移动仍占 **73.29%**；
- 客户端收入 **781.6亿元**、同比+14.97%；
- 主机收入 **83.62亿元**、同比+86.33%。

Source:
- 中国音像与数字出版协会，《2025年中国游戏产业报告》: https://www.cadpa.org.cn/3277/202512/41770.html

因此不能再把2020s中国描述成“仍然只有手游”。更准确的是：

> **旧F2P/GaaS超级工业仍然占据主体，但premium PC / 主机市场接口已形成显著上升的第二生产生态。**

问题转成：这个新生态能不能留下足够多的**第二次尝试团队**，而不只是出现一批首作和少数爆款。

## 3. 第一版中日结构对照：不是“谁自由”，而是作者权的空间位置不同

| Dimension | 日本黄金时代假说 | 中国历史上更常见的模式 | Current status |
|---|---|---|---|
| 新人早期作者权 | 部分大公司内部可破格快速取得project lead / prototype权 | 普通雇员内部机会存在，但完整权利更多见于创始人、项目高层、离职/重组 | H / case convergence |
| 工艺积累 | 长期雇佣、师徒、稳定团队可形成深厚tacit craft | 大型商业工业同样形成很强专业能力，但人员/项目/商业regime切换更快 | SUPPORTED descriptive |
| 资历约束 | `SENIORITY_TAX`显性较强 | 传统年功较弱，但职级/KPI/商业成功路径会形成另一种`STATUS/REGIME_TAX` | H |
| Patron作用 | 强高层可绕过等级为异端开闸 | NExT等也显示负责人保护重要；patron离场后预算/组织存续仍可能变化 | SUPPORTED cases |
| 退出后的作者生态 | doujin / circle等长期旁路 + 商业公司 | Steam / indie / startup旁路近十余年快速变厚，早期历史较薄 | strong descriptive / denominator open |
| 首次失败后的保存 | 长期组织可能保留人，但具体分母待核 | 早期单机市场壳薄；现代大厂/独立均有回炉与清零两种案例 | OPEN |
| 创作者代际更新 | 大师长寿，需检验新人replacement是否下降 | 大厂内代际作者更新缺统一统计；创业/新团队不断产生但连续性薄厚待核 | OPEN |
| 市场接口 | 日本早期本土主机/街机/出版生态较成熟 | 中国经历单机回款弱→在线服务→渠道租→全球数字直达的多次重写 | STRONG lineage |

最重要的暂定判断：

> **中国未必比日本更缺“怪人”；中国更可能长期缺少的是：让普通专业者在不退出整个组织、不自担全部家庭/融资/市场风险的情况下，也能逐步升级到完整作者权的稳定职业阶梯。**

NExT是这个命题的重要正向反例，因此必须继续研究它为何能成立、哪些环节依赖沈黎/集团预算，以及后来的组织变化意味着什么。

## 4. 中国的特殊问题可能不是 `SENIORITY_TAX`，而是 `REGIME_TAX / 产业版本税`

日本的典型约束是：
> 你可能很有能力，但先熬资历。

中国游戏业更值得检验的约束可能是：
> 你可以很快升职，但你的升职建立在某一套已经被市场证明的objective function上。

2010s高回报制度持续奖励：
- 既有品类benchmark；
- retention / LTV；
- 数值与活动；
- 渠道适配；
- 发行/买量；
- 大组织协调。

这会产生：

### `REGIME_TAX / 产业版本税`

> **一个人想把在旧收入制度中积累的职位、收入、团队和声誉兑换成新范式作者权时，需要损失多少既有职业资本？**

它与`SENIORITY_TAX`不同：
- 日本型：晚辈可能必须等待；
- 中国商业游戏型：强者可以很快上升，但越成功越可能被旧目标函数高价绑定。

因此中国的“成功者陷阱”可能比简单新人压制更重要。

[016 追赶成功 / 前范式创作者](../../book/research-notes/china-catch-up-success-pre-paradigm-creator-016.md)已经把这一问题定义为`Success-Path Version Lock`；本文件只把它接入中日比较，不另立平行理论。

## 5. 为什么早期中国单机人的命运对今天特别重要：有作者权但没有市场壳，也会死

日本案例容易把我们带向“只要给作者自由就行”。

中国1990s—2000s单机恰好提供反证：
- 小团队；
- 多面手；
- 强主创；
- 真实原创；
- 甚至能出口海外；

但仍可能没有：
- 可靠支付；
- 数字分发；
- 可执行发行合同；
- 稳定现金流；
- 第二次失败预算。

《刀剑封魔录》案例尤其清楚：约10人团队拥有极宽设计权，但发售后的分成/发行并未形成足够现金，最后仍靠网游项目让公司延续。

因此正式模型必须是：

```text
AUTHORIAL AUTONOMY
×
MARKET INTERFACE
×
FAILURE SHELTER
×
SECOND ATTEMPT
×
TEAM CONTINUITY
→
durable creator ecology
```

缺任何一项，都可能只留下“天才作品”，留不下“下一代作者产业”。

## 6. 中国当前最值得关注的改善，不只是“国产单机卖得更好了”

### 6.1 `EXIT_TO_RECOMBINATION` 显著改善

和2002相比，今天离开大公司的人拥有更多：
- Steam / 主机平台；
- 数字支付；
- Unity / Unreal / Godot等通用工具；
- 远程协作；
- 社交媒体 / creator discovery；
- 国内外publisher；
- demo / Next Fest / wishlist等较早市场信号。

这让“退出”不再自动等于职业自杀。

但退出改善仍不能替代**公司内部作者阶梯**。如果完整作者权几乎只能靠离职获得，社会仍会向个人收取高额：
- household risk；
- salary opportunity cost；
- insurance / housing risk；
- financing risk；
- failed-project reemployment risk。

即 `AGENCY_TAX` 仍然存在。

### 6.2 `CAPABILITY_REPRICING` 已经发生

Game Science、《苏丹的游戏》等证明：
- 旧大厂/商业项目经验可以转化成premium生产资本；
- “被旧制度训练过”不等于被永久锁死；
- 真正关键是能否重写objective function、scope和market interface。

### 6.3 但 `FULL_CYCLE_TEAM_DENSITY` 仍是核心未决

[012](012-full-cycle-authoring-team-supply-proxy-china-vs-comparators.md)的Steam Top200 wishlist国别代理显示，中国绝对产品并不少，但相对其巨大人口、市场和从业基础，高关注全球PC产品管线仍显得偏薄；与韩国、波兰、瑞典等比较存在数量级压力信号。

这不是作者型团队数量的直接测量，因此核心命题仍保持OPEN：

> **中国能否按产业规模持续生产“自己定义产品 → 完整交付 → 接受市场结果 → 核心团队不散 → 再做一次”的团队？**

这比“国产游戏有多少爆款”重要。

## 7. `CREATOR_REPLACEMENT`：中国研究下一步最缺的分母

日本线已经迫使我们问：
> 宫本茂之后还有没有下一位年轻宫本？

中国也必须问同一个问题，而且不能只数创业明星。

### 大组织版本
对腾讯、网易、米哈游、莉莉丝等，不只问：
- 哪个项目成功；
- 哪个制作人有名；

而问：
- 每年多少2–10人原型组；
- 发起者首次担任完整项目主创时的年资；
- 多少项目被砍但人获得下一次原型机会；
- 同一个负责人是否长期占据作者权；
- 普通策划/程序/美术能否从craft authority升级为product problem authority；
- patron离职以后制度是否继续。

### 小团队版本
不只问Steam首作数量，而问固定首发cohort的：
- 3年 / 5年第二项目尝试率；
- 第二款实际发售率；
- 核心团队保留率；
- 首作失败后回到大厂 / 转行 / 新组队的比例；
- publisher / investor是否把失败团队当作能力资产继续投资。

这就是`CREATOR_REPLACEMENT + SECOND_ATTEMPT_CAPACITY`的真实分母。

## 8. 中国为什么会显得“每一代都重新创业一次”？

当前产业史允许提出一个新假说：

### `AUTHORIAL_CONTINUITY_GAP / 作者连续性缺口`

中国并非没有持续出现强创作者，而是每次收入/平台regime重写时：
- 单机 → MMO；
- MMO → F2P；
- PC/页游 → mobile/channel；
- channel mobile → global/content；
- mobile industrial talent → premium / console；

旧团队、旧作品权、旧市场入口和旧职业声望的可迁移性都不完整。

结果可能是：

> **人才连续，但作者身份和完整团队连续性不足；每一代人需要重新证明“这种游戏值得做、这种人可以当作者”。**

这与日本长寿公司 / 长寿director形成很值得检验的反差。

但这个命题必须有失败队列和人员迁移数据才能升级；当前状态：**H**。

## 9. DeepSeek为什么成为非常重要的中国内部反例

如果把问题写成“中国文化缺乏个人主义，所以年轻人不会原创”，DeepSeek会直接击穿它。

[014](014-liang-wenfeng-deepseek-positive-deviant-innovation-organization.md)中的创始人采访至少说明一种可能的中国组织结构：
- 年轻、本土培养的人才；
- 自下而上提出问题；
- 正式大规模greenlight之前能调用真实算力和同事；
- idea有潜力后再集中资源；
- 允许一定浪费和失败。

所以更加可检验的命题不是：
> 中国教育没有怪人。

而是：
> **什么组织能让中国已有的高基础能力者，在足够早的时候获得 `FRONTIER_PROBLEM_OWNERSHIP + PRE_GREENLIGHT_RESOURCE + FAILURE_CAPACITY`？**

这也是游戏业该与AI时代比较的真正接口。

## 10. AI：可能开启第五次边疆窗口，但目前只能记H

生成式AI / coding agents / content tools可能降低：
- prototype cost；
- specialist coordination cost；
- translation / content / test成本；
- 小团队把judgment变成playable artifact的距离。

因此一个重要H：

> **AI可能让中国过去更多依赖“离职组齐一支完整团队”才能获得的作者权，部分前移到个人 / 2–5人小组。**

但当前不能写成“中国已经因此获得第四次工业革命优势”。仍需观察：
- 谁真正用AI产出可发行完整产品；
- AI降低的是现金burn还是只提高scope；
- 新工具是否反而让更多团队把错误想法做得更大；
- 平台、版权、品质和市场发现是否成为新瓶颈；
- 大公司是否把AI用于扩大普通成员的prototype right，还是主要用于提高既定任务产能。

AI真正值得测的不是“用了多少”，而是：

> **有没有改变`decision rights`和`time-to-player-truth`。**

## 11. 当前最强比较结论与禁止外推

### SUPPORTED / strong descriptive
1. 中国游戏业并不缺新产业窗口；单机、网游、手游和premium/global都曾重写生产函数。
2. 早期国产单机已经存在强作者、小团队、多面手和原创产品；其衰退不能仅用创作能力解释。
3. 在线/F2P/渠道时代产生了极强且真实的专业能力资本，同时改变了最有回报的问题类型。
4. 中国今天的PC/主机市场接口正在变厚，旧商业人才也已发生能力重新定价。
5. 中国大组织内部存在NExT等真实prototype/孵化反例，因此“完整作者权只能创业获得”不能写成全称事实。

### H / still to test
1. 日本黄金期比中国更常把frontier exemption放在公司内部；
2. 中国更常要求潜在作者通过exit / founding / spinout获得完整问题主权；
3. 中国的主要约束可能从`SENIORITY_TAX`转为`REGIME_TAX + AGENCY_TAX`；
4. 中国真正短缺的不是idea或执行力，而是`FULL_CYCLE_TEAM_DENSITY × SECOND_ATTEMPT_CAPACITY × CREATOR_REPLACEMENT`；
5. 中国存在`AUTHORIAL_CONTINUITY_GAP`：人才连续性高于作者身份 / 完整团队连续性。

### 禁止写成
- “日本公司尊重天才，中国公司压制天才”；
- “中国人缺个人主义所以做不出原创”；
- “大厂经验必然摧毁作者性”；
- “独立团队天然更自由 / 更创新”；
- “早期国产单机如果没有盗版一定会形成日本式产业”；
- “AI必然解决中国作者权问题”。

## 12. 下一轮优先验证

### P0 — 中国大厂内部 `CREATOR_REPLACEMENT`
找3–5家公司建立：
- 首次director / producer年资；
- prototype→greenlight真实制度；
- 被砍项目后的第二次尝试；
- 同一资深主创长期占权 vs 新人进入。

### P0 — 1995–2005“单机作者去哪了”
不要只写公司转网游；追具体核心人：
- 留公司转网游；
- 离职创业；
- 转行业；
- 海外；
- 继续单机；
并记录其旧作者权是否保留。

### P1 — 中国“退出取得作者权”是否真比日本高
构建公开人物样本：
- 中国：单隽、刘坤、Game Science核心、Double Cross、更多普通失败者；
- 日本：首次project lead仍留公司者 + 离职创业者；
统一编码`EXIT_REQUIRED_FOR_AUTHORSHIP`。

### P1 — 失败后是否还有第二次
重点不是成功者，而是：
- 被砍项目主创；
- 首作商业失败团队；
- 组织调整后普通成员；
- 三年 / 五年后是否仍在提出自己的产品。

### P2 — AI-native cohort
固定2025–2027首次公开prototype/首作的一批中国2–5人团队，追踪：
- AI工具实际使用；
- 首个playable所需时间；
- 外包 / 专职岗位减少多少；
- 第二次尝试；
- 是否真正提高作者密度。
