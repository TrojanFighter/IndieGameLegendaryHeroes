## 0. 结论先行：2026年的中国不能再简单描述成“没有旁路”

当前公开证据已经能确认中国至少存在：业余社区、Game Jam、学生作品、独立比赛、大厂创作赛、平台扶持、主机平台加速、publisher、公司内部prototype、大厂能力外溢创业，以及Steam/global direct market等多条路线。

所以真正的问题已经不能是“中国有没有第二条路”，而应该是：这些路是否足够老、足够稳定、能互相切换，而且第一次失败之后仍能保留作者身份和生产能力？

当前最强工作假说：ROUTE_COUNT 已显著增加；ROUTE_DEPTH / ROUTE_DURABILITY / ROUTE_REVERSIBILITY / AUTHORIAL_PORTABILITY 仍是主要未知。

## 1. 中国其实很早就存在自己的 hobbyist 创作者生态：66RPG

2026年Sunny Jie Yang发表的开放获取研究，基于档案、数字民族志、66RPG创始人访谈及25份核心成员有效问卷，重建了中国最重要的早期业余游戏社区之一。

Paper: https://journals.sagepub.com/doi/10.1177/20594364251413750

研究显示：社区2005建立，2006–2009快速增长，2013后衰退，2017关闭；关闭前档案记录860,000+ users / 3.29 million posts。其成员在2000年代已经大量使用RPG Maker制作原创/同人作品；社区发布系统化中文教程，累计教程时长超过1,000小时；用户通过发布作品、教程、素材、答疑获得社区声望和内部奖励。2006–2012年度短篇比赛通常37–54件，2010达116件，2012达152件。

这说明：中国2000年代并不缺“玩家→制作者”的草根转换。而且其创作模式不是西方式孤立auteur，而包括共同答疑、共享素材、联合活动、众包式协作，把做游戏本身变成一种集体游戏。

## 2. 66RPG最重要的不是成功者，而是它暴露了“旁路为什么会断”

同一研究记录了多重衰退原因：

1. 技术/审美代差：RPG Maker低门槛曾是优势，但到2013前后RTP资产同质化，玩家开始把业余RM作品直接和商业3D游戏比较。
2. 开放共享的产权困境：教程/script/asset/project files的开放交换后来遭遇盗卖与低成本搬运，创作者逐渐转向加密。
3. 商业化桥梁没有稳定建立：2011 premium games section、发行/营销合作、联合公司、素材/工具商业化都没有形成长期稳定的creator→market接口。
4. 平台化替代：橙光以更低门槛工具和平台分发吸收部分创作人口，但把开放commons变成platformized creator economy。
5. 监管与发布要求增加：研究把2016后出版许可、2017实名要求等视为66RPG最终关闭的重要因素之一。

因此不能写成“监管单一摧毁社区”，因为审美升级、产权冲突、商业化失败与平台化同时发生；但可以确认：大型公开分发社区会承担个人circle不需要承担的合规与运营成本。

## 3. 梁其伟 / 《雨血》说明中国早期旁路不是纯业余死胡同

66RPG研究记录：梁其伟2006大学期间通过RPG Maker进入制作，2007完成初版，2010公开发布后获得大规模下载，随后做英文版，进入Big Fish Games、GamersGate等海外商业渠道，并继续形成商业系列。

所以中国早期也存在：HOBBYIST COMMUNITY → PERSONAL AUTHORSHIP → PUBLIC DISTRIBUTION → GLOBAL COMMERCIAL MARKET。

真正值得比较的是：这种转换有多普遍、是否有稳定publisher/marketplace承接、普通作品能否获得小额持续收入，以及失败后还能不能继续。

### 5.2 CUSGA：学生作品直接进入行业展示

## 6. 所以“中国路线少”已经不准确；真正差别可能是三层深度

### Layer A — ROUTE EXISTENCE
截至2026，中国不缺比赛、Jam、学生赛事、展会、平台扶持、publisher、主机accelerator和全球Steam市场。这一层差距已明显缩小。

### Layer B — ROUTE CONVERSION
真正未知的是：800个Game Jam demo里多少进入正式项目；500个CUSGA作品里多少形成商业团队；indiePlay入围后多少拿到资金；Spotlight扶持后多少ship；被拒绝一次后能否换bridge。大多数机构仍主要披露成功项目，缺固定cohort。

### Layer C — ROUTE DURABILITY
日本部分基础设施有几十年连续历史：Comiket从1975持续至今，Enix外部作品竞赛可追到1982，doujin→commercial跨多代创作者。

中国更曲折：66RPG 2005–2017后转形/关闭；IGF China 2009起但未成为长期主轴；GGJ 2011起增长；CiGA/indiePlay 2015起；China Hero 2016起；TapTap Spotlight 2023起。

因此新增：
- ROUTE_HALF_LIFE：一个创作者基础设施能持续服务多少代人？
- BRIDGE_CONVERSION_STABILITY：第一批成功后，机构有没有形成稳定下一批？
- SECOND_GENERATION_CREATOR_PRODUCTION：受益于第一代生态的人，是否又开始投资、教学、发行、扶持下一代？

## 7. 当前最强历史假说：生态断裂 vs 生态累积

这不是已证实国别定论，只是需要验证的结构模型：

Japan hypothesis: ROUTE CREATION → SURVIVES → ACCUMULATES → SPAWNS NEW ROUTES.

China hypothesis: ROUTE CREATION → GROWS → REGIME/PLATFORM/MARKET SHIFT → PARTIAL BREAK OR TRANSFORM → NEW ROUTE REBUILT.

66RPG是典型压力样本：社区、教程、关系和作品大量积累，商业桥没有完全跑通，随后遇到平台化与制度变化，Project1保存档案、橙光吸收部分创作人口，但原“开放RM hobbyist commons”没有连续保留。

这不是中国没有传统，而更像传统经常被产业版本切换重新编码，与015的REGIME_TAX高度一致。

## 8. 中国还存在一个很重要的“证明前置成本”

很多现代扶持不是有想法就给钱：China Hero需要vertical slice/GDD/团队审查；TapTap成熟项目要页面、实机、Demo、团队介绍；indiePlay要求一定开发度和Demo。

因此新增 EVIDENCE_BEFORE_RESOURCE_GAP：创作者必须先自费做出多少证据，才有资格进入真正资金/发行/平台资源？

日本也有同类门槛——Enix竞赛需要作品、Comiket也要求先制作内容，所以不能先断言中国更差。但现代高规格3D项目的证明成本远高于1980年代PC投稿、同人漫画或RM作品，谁承担这段gap会显著影响作者人口。

## 9. side project：路线存在，但权利边界比“下班做就行”复杂

008已确认：中国法律并非所有下班软件归公司，也不是下班做的一定归个人；职务软件权属取决于任务、资源、职责等，真正公司政策、员工理解与执行仍缺全国调查。

NExT OWO案例则证明员工私人时间Demo可以被组织吸收并转为正式项目。这与ZUN/Taito不同：ZUN保持PARALLEL_AUTHOR_IDENTITY，OWO是PRIVATE DEMO → CORPORATE INTERNALIZATION。

所以中国必须继续研究PARALLEL_AUTHOR_IDENTITY，而不是只问有没有side project。

## 10. 中国当前路线拓扑第一版

PLAYER/HOBBYIST → community making / Game Jam / TapTap challenge / self-learning
STUDENT → CUSGA / Tencent contest / school project / internship
PUBLIC PROTOTYPE → indiePlay/WePlay / GWB / Spotlight / publisher outreach / social media
RESOURCE BRIDGE → publisher / platform funding / equity / founder savings / China Hero
FULL-TIME AUTHOR TEAM → Steam/global premium / domestic licensed distribution / console / mobile
FAILURE OR FIRST SHIP → return to employment / outsourcing / second project / new publisher / new company / dissolve / unknown

最薄的目前不是前半张图，而是最后一段：failure/first ship → second authorial attempt。这与011–013的SECOND_ATTEMPT研究一致。

## 12. 对“老中不行”框架的进一步修正

已经可以排除三个粗暴解释：
- 没有人想做：66RPG、GGJ、CUSGA、indiePlay、TapTap Jam反驳。
- 没有创作社区：66RPG早在2005前后就形成大规模hobbyist culture。
- 今天没有扶持路径：China Hero、Spotlight、CiGA/GWB/publisher反驳。

仍可能成立的结构性命题是：中国长期的问题更可能是“创作人口 → 稳定作者团队 → 可持续第二次尝试”的转化效率，而不是创作冲动或单次原型供给不足。

另一个历史性命题是：中国创作者基础设施经历更频繁的产业regime切换和制度重写，能力可以高速迁移，但组织/社区传统更难连续累积。两条都需量化。

## 13. 下一步最值得做的实证

P0 — Bridge Conversion Cohort：固定2024 CUSGA / Tencent Creator Competition / TapTap Spotlight Game Jam / indiePlay，追到2026/27，看继续开发、资金、公司化、ship、团队连续和作者权。

P0 — Side-project Rights Survey：直接问中国游戏雇员副业游戏是否允许、是否报备、IP归属、公司设备/同事使用、被拒后是否受惩罚，与日本ZUN型PARALLEL_AUTHOR_IDENTITY比较。

P1 — Route Durability History：重建66RPG → IGF China → GGJ → CiGA/indiePlay → TapTap/Steam/China Hero，每个节点记录寿命、资金、用户关系、关闭原因、数据迁移和是否培养下一代机构。

P1 — Failure-to-Reentry：以首作失败/停更/未发售项目为frame，跟踪回大厂、继续独立、外包、换publisher、解散和第二项目，直接测ROUTE_REVERSIBILITY。

## 14. Verdict

中国和日本当前最有解释力的差异，不再是“日本有创作者路，中国没有”。更可能是：日本部分路线经过数十年连续累积，形成了更成熟的“路→桥→下一条路”；中国也很早拥有草根创作共同体，并在2015后快速补齐比赛、平台、发行、主机扶持和全球数字市场，但多条桥梁仍年轻，历史上也发生过明显断裂与平台化重写。

接下来真正要测的是：一条创作者路线能活多久？它能把多少人送到下一条路线？失败以后是否还能回来？而不是继续简单统计有多少独立游戏。
