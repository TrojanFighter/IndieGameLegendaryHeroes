## 1. 不可混淆的五种“存活”：先定义指标

| Survival unit | 事件可以证明什么 | 什么不属于该单位 |
|---|---|---|
| **IP / service continuity** | 《Royal Quest》2012→2023→2024产品继续服务，新公司取得特定区域运营/开发权 | 不能说原Katauri那45名开发者一直负责 |
| **Company legal entity** | 同一个注册法人继续运营 | 名称相同、商店原开发者署名、原游戏继续销售均不是法人证据 |
| **Core employee continuity** | credits/同期具名访谈证明某员工跨项目工作 | 创始人名字或工作室宣传图不能代替全体留业率 |
| **Authorial problem-domain continuity** | 原主创带着新的独立产品思想继续成功或失败地开发可玩原型 | IP依然赚钱不是作者能力再生产 |
| **Commercial self-sufficiency** | 开发商持续确认净回款和交付下一作所需资金 | Steam仍上架、销量估算、融资网页单条线索都不是利润证明 |

- **关键研究判断**：商业产品的长期存续可以同时伴随原作者离职、游戏开发权跨法人及跨国资本链。未来对俄罗斯“长寿作品”统计必须核原始作者现在何在，不能用2024现运营产品为Katauri原团队作者连续性加分。

## 2. Katauri核心年轻开发者真正的跨组织继承：Mitrofanov 与 Yazynin → Red Winter

**RU-02 P0 2013-12-26本人专访**：Dmitry Mitrofanov 说离开前先在.dat参与《Disciples III》、后Katauri《Royal Quest》，认识美术主管/共同参与者Alexander Yazynin，两人构成Red Winter的**两个常驻核心工作者**：Mitrofanov程序+系统设计，Yazynin美术，**两人常年异地合作**；项目有外包与熟人美术帮助。Mitrofanov明确说从入职商业公司起就公开表达愿望：将来自己做游戏。
- 来源 Mail.ru Hi-Tech，《Интервью с Red Winter Software, часть I: про игру Dungelot 2 и не только》，2013-12-26，https://hi-tech.mail.ru/review/16993-interview_dungelot_2/ 。
- 本人透露父亲也是玩家，曾自国外带回SNES，其游戏参考既有Mario、Zelda、Lost Vikings、Illusion of Time、Secret of Evermore，又有PC《Settlers 2》《Civilization》，此外2013喜欢《Rogue Legacy》。这是**一人的跨平台游戏阅历与家庭技术接入**；不可从一位父亲推俄罗斯家庭文化常态，也不能证明这些游戏导致其职业路线。
- **重要劳动归因**：第一次《Dungelot》的美术部分由熟人付费或非现金方式协助，后来高级美术Yazynin全职核心加入；“单人开发”描述需加外包与非正式贡献者，编导/程序技能与美术技能互补。

**RU-03 P0 2014-02-24本人财务/组织后见与制作回顾**：App2Top主持Aleksandr Semenov直接问Mitrofanov：他在《Royal Quest》开发中离开Katauri，原本就想做自己的游戏（**非因Gusarov离开而自动集体分裂**，具体时间需核）。他说首款《Dungelot》制作**8—9个月**，期间做其他零碎工作维持生计；估“舒适一点”的小团队需要**最低约1万美元的生活与轻外包资金**，**不是已经投入的实际预算**；自发行、TouchArcade论坛与编辑/版主/意见领袖交往是早期推广渠道。两人异地制作《Dungelot 2》，明确选择保持灵活的2核心/4—5人外部合作模式。
- 来源 App2Top《Интервью с Red Winter Software》，2014-02-24，https://app2top.ru/industry/interv-yu-s-red-winter-software-37477.html 。
- **F2P设计事故第一人称**：二作由买断→F2P，主导者承认严重低估持续运营所需程序、客服、经济/付费设计和大规模打磨，对付费机制思考让其难同时思考游戏；游戏初始版本因bugs/IAP经济/UX差，在苹果商店**约24小时后**主动下架。本人还反思曾忽视付费机制玩家不同认知、自己拒绝找F2P专家帮助。不可据此说俄国整体会运营或不会运营。
- 上述同一专访记录许多未采用机制、功能迭代。**设计实验与玩家接受度**会导致玩法裁剪，不能把“玩家没接受而撤方案”按模式抄袭判无创新。
- Steam等游戏上架之前不存在确证收入额；“初代收入对一个人不错”是创作者主观回忆而非审计。

**RU-04 S1+P0公司声明 2014—2016 产品后续**：

## 4. 2014中俄“双停售”：匹配到什么，不能匹配什么

| 项目 | 俄Red Winter《Dungelot 2》 | 中云游《新剑侠传奇》 |
|---|---|---|
| 年份与商业模式 | 2014 iOS **F2P+真IAP** | 2014 PC **买断+弱联网账号/活动币，官方明确无直接充值** |
| 开发者起点 | Katauri大型MMO经历→**两核心**、业余/外包小队 | 上一代Premium资深制作人+顾问+音乐人，真正同时全职团队人数**UNKNOWN** |
| 主动撤市 | 2014-02因bugs、IAP/UX、持续运营负担，主动撤下 | 2014-07因上线bug、激活、任务、技术、QA暂停销售 |
| 恢复日期 | 2014-05-21以调整经济和UX的F2P二版重新上架 | 2014-08-12以2.0版重上架且开放销售 |

| 硬证据边界 | 两核心不代表独自完成美术发行；返工不等于盈亏已核 | 三位名人不代表三人全职制作；2014售价/奖池与净利润未核 |

**错误因果需要清楚排除**：
- 双方失败并不证明“中俄游戏产业在平均水平没有差别”；是刻意选择两起有撤市新闻的负面事件，不是随机sample，也没有总项目母体。
- 《新剑侠传奇》有账绑定的黑市币，但明确无直接充值，不允许将之判为现金IAP或P2W；而《Dungelot 2》的F2P付费压力有开发者本人和商业版本证据。
- F2P问题不是俄罗斯完全不会做GaaS；2013年开发者在俄MMO经验丰富与2014年2人F2P执行失败可同时成立，商业组织能力**不可从大公司自动转移到单人**。
- 李兰云有强历史原创意愿、却在Unity/3D时代QA与封闭/半联网配套交付出现缺陷；这不证明其本人“无能”，也不证明其2014后来没有学习。
- 俄方小组走买断与国际发行成功**不等于财务盈利**；2016游戏仍在Steam售卖不证明工资/团队长青。

## 5. 解释性问题与下一轮可证伪审计

**H01: Structural asset separation**：新公司的**IP寿命**可与原作者创作生涯脱钩，跨公司转移甚至使IP价值续存；相反原作者的游戏经验也可脱离原IP以新作品延续。应采用两套credits+business asset追踪，不以Steam页面显示“持续运营”计算首创作者人年。

**H02: Microteam service-economy mismatch**：熟悉大规模商业MMO的人仍可能无法以2名全职核心维持一个小F2P game-as-a-service；原因不仅数值/程序，还涉及付费经济、QA、用户支持、内容更新与玩家信任。2014 Mitrofanov亲身证据很强；比较样本仍需小F2P成功者作反证。

**H03: Product-closure bottleneck is orthogonal to authorship**：两国同年撤市团队都能提出项目，但未满足各自平台QA；中俄平均原发创新率和人效无法从两起事故计算。若有团队原始人力/费用/bugs-by-severity资料可测试生产边界。

**H04: Player reference breadth / family access as enabling inputs**：Mitrofanov自述父亲是玩家、早期从境外接入任天堂SNES和多平台作品，结合TouchArcade国际论坛，可见其个人的丰富需求和社群机会；**仅是可观察的1人社会化条件，不得用于“俄国家长都支持”或“游戏阅历必定导致原创”**。

**H05: Format contamination without false cash-gacha attribution**：成熟online运营的产品语法可能渗透到2014中国PC premium的弱联网与奖品促销，而俄Red Winter同时试用F2P后撤回。但“黑市币”没有充值，不等于成熟商游P2W输出；需要真正的预算/玩家数据才能判断“促销分散战斗QA资源”。

### P0研究缺口
1. **Katauri 2009—2014正式员工/研发credits全人名，Gusarov与Mitrofanov/Yazynin去向**，公司离职名单和Royal Quest自2012→2023是谁在做具体更新；不能按一个采访推全队迁移率。
2. **Royal Quest 2023 Lesta地区授权合同范围、转让价、Royal Quest IP全球/俄罗斯分拆、2024新旧引擎与代码继承**，和Tencent/Fulqrum之间的真实融资方式。
3. **云游2010—2018工商历史股权、各年员工社保基数、2015/16投资方原始公告、Xbox/手游上线证据、2014价格/实际退款/真实销量/净利润**；36氪项目数据库只作线索。
4. **Red Winter 2016以后团队与系列商业结果、2014 IAP争议用户反馈全母体**；不能从第二代失败和第三代上线定义必然学习成功率。
5. 查2014中国实体单机市场其它5—10款《新剑侠》同年/相邻发行产品的预算、游戏品质、售后修复，俄2014买断/免费小团队同样本，比较QA和外部发行支持，不以两起有名事故外推两国。

### Time-bound Transfer
2014 iOS App Store/F2P、2014大陆实体买断/账号激活/渠道奖池、2023俄国地区权利划拨属**HISTORICAL**；“一个项目同时包含人物/公司/IP/现金流四种生存”“小队重组后服务型生产能力不自动可携带”“合同区域权利/预算与媒体估价分离”属**DURABLE**通用审计。无私人项目应用建议。
