## 0. 为什么已经有031/032，仍需要这一篇？

031解释“哪些知识、兴趣与参照系在入行之前就被挤出”；032解释“封闭题域训练如何不恰当地迁移到开放决策”；028解释“成功者声望如何替代原创问题的判别”。

本篇补充尚未充分拆开的三个社会—认识论环节：

1. **EP-01 `EPISTEMIC-AUTHORITY SUBSTITUTION / 认识论权威替代`**：以社会身份、道德正确、成功结果或“标准答案”代替具体证据和因果论证。
2. **EP-02 `JUDGMENT-RIGHTS DECOUPLING / 判断能力与评价权力脱钩`**：后继组织继承历史成功者的评价权、术语与合法性，但未必继承其最初创造结论的判断、纠错与改题能力。
3. **EP-03 `KNOWLEDGE-CARRIER AVERSION / 知识载体厌恶`**：若有价值的历史、经典、人物材料长年与强制说教绑定，学习者可能对其载体本身产生逆反，降低主动接近一手材料的意愿。

三条均为**H级待证假说**。它们不自动构成单向强因果链，也不能用几张社交媒体截图推算发生率。

## 1. EP-01：权威替代了证据，人生箴言变成免检判断

### 1.1 同构而非等同

公开励志故事中的“伟人小时候便有异常预兆”、关系成功学中的“服从某一方意见所以必然成功”、人物表彰中“因为品德高尚所以决策正确”、课堂中的“标准中心思想”，表面内容不同，却可能共享一个步骤：

```text
复杂事件 / 多种行动方案 / 非确定后果
→ 提取一个符合预设价值的表征
→ 宣布该表征具有普遍正确性
→ 跳过原始材料、备选方案、反证与适用边界
```

但“尊重伴侣”“重视秩序”“坚持理想”可以具有独立的伦理价值；批评的不是道德本身，而是**把伦理主张偷换为无需检验的经验因果**。若一项主张是规范性价值判断，应公开说明价值前提；若声称“这样做就会成功”，则须拿出结果证据与比较样本。

### 1.2 可识别的四种错误

- `MORAL-TO-CAUSAL LEAP`：从“应当如此”跳到“必然有效”。
- `OUTCOME-TO-CHILDHOOD MYTH`：成功后筛选早年逸事，反推其少年言行已注定未来成就。
- `AUTHORITY-AS-PROOF`：用身份、官方认证或人物荣誉豁免对事实和推论的检查。
- `RUBRIC-AS-TRUTH`：把“符合评分细则”误认成“已经掌握对象世界的真相”。

**反例与边界**：权威并非完全无信息价值；在无法直接核验时，领域专家与可靠机构可以是合理的启发式信号。真正需要测试的是，权威标签是否压倒独立证据、能否接受有证据的异议，以及当权威判断错误时系统怎样修正。

## 2. EP-02：超人遗制陷阱的认识论版本

本篇仅保留“超人遗制陷阱”作为**组织知识继承的抽象分析隐喻**，不援引任何私人创作设定。

```text
第一代通过调查、实践、试错与冒险形成有效判断
→ 后继者整理其经验、提炼原则
→ 经验被转为教条、岗位权限、考核与身份认证
→ 继承者获得判断别人“对不对”的权力
   却未必持续具备自行发现、改写、纠正原则的能力
```

研究关键不是“后代一定无能”，而是**决策能力的实际再生产率**与**评价权力的制度继承率**可能脱钩。

工作表述：**创造正确答案的能力不必然伴随判定答案的权力而代际继承。**

与[028](028-imitation-of-greatness-prestige-copying-and-authorial-judgment.md)的`ACHIEVEMENT-TO-EPISTEMIC-AUTHORITY TRANSFER`、`JUDGMENT OUTSOURCING`连接：不仅是模仿可见的成功表征，也可能由权威继承体系奖励更像前人的方案、削弱新问题的合法性。

与[032](032-exam-overfit-routine-expertise-open-domain-transfer.md)的`MEETING-AS-EXAM`、`COMPETENCE-LEGITIMACY OVERFIT`连接：优秀答题能力、合规管理能力和前沿问题定义能力分别测量。

**不得以历史上的儒家制度、某一政治组织或一家大公司作为不需核证的“天然正例”**。组织存在经典、制度化或等级结构，不足以证明它已失去自我纠错能力。研究须比较其思想异议机制、独立试验通道、真正的决策权与重复成功/失败表现。

## 3. EP-03：说教可能污染知识的入口，而非知识本身

工作机制：

```text
高价值原始材料（史书、书信、组织文件、人物传记）
→ 被反复摘编为价值结论与考试任务
→ 学习者将“学习该领域”与被迫接受结论关联
→ 对传达方式的抵触可能泛化为对知识对象的回避
→ 更少自发阅读、多源比对与主动探究
```

- 需要区分 `AVERSION-TO-PREACHING`（厌恶说教方式）、`AVERSION-TO-SOURCE DOMAIN`（厌恶该知识领域）与`LOW ACCESS / LOW LITERACY`（资源或阅读能力不足）。
- **外部间接锚点**：*Message effects on psychological reactance: meta-analyses*（*Human Communication Research*，2025-06-30在线发表；33项研究）发现高自由威胁语言与愤怒/反对性认知增加有关，且这些反应与劝服效果下降相关。它检验的是劝服语言，**没有直接检验中国历史教材、长期党史学习或成年人的学术阅读回避**。https://academic.oup.com/hcr/article/52/1/38/8178818
- **真正待证问题**：对相同的史料与人物主题，采用“标准道德结论”“多文献比较”“决策节点重建”三种呈现方式时，自愿继续阅读、选择原始材料、长期保留兴趣的比例是否不同？
- **相反可能**：价值教育同样可能引发真实兴趣；有些学生因正式课程首次接触史料，之后走向自主研究。不能先验规定政治教育必然使人疏远历史。
- **二次风险**：拒斥一种权威，并不自动形成证据意识；它也可能导向另一种自信但无证的网民成功学或阴谋叙事。

## 4. 儒家规训、现代考试与意识形态教育：只能提出可检验的制度连续性

作者指出伦理权威、师道等级、科举式答案、现代应试与现代媒体成功学可能共享“正确答案先行”的形式。然而**“形式相似”不等于证明中国思想史存在单一、连续、充分的因果谱系**。

最小研究要求：

1. 区分原始经典中的争辩/反思传统、历史官僚与考试制度的选择性使用、当代教育实施三层；
2. 将“规范性目标（培养何种公民/组织成员）”与“经验事实（历史具体发生了什么）”分开评价；
3. 在政治与革命史中同时检查胜利、失误、争论、权力关系、制度成本与当时未知；
4. 比较日本、韩国、台湾等东亚体系及欧美具有强教条/英雄崇拜的组织，避免“中国性”自动归因；
5. 区分历史课本中的人物台词、作者叙述、课后习题和评分标准，不能只凭裁剪截图判定编者意图。

## 5. 正向替代：历史决策教育，而非更换一套伟人偶像

作者提出重要的正向设想：真实领导者的同期文件、传记、军事与组织历史，可被重组为**目标形成与决策训练材料**，而不只是道德榜样传记。尤其中国近现代革命史跨越组织规模、通信/后勤、战争与政治条件的变化，具有很多可供追问的材料；**“潜在教育价值高”不是“其教材效果已被实证证实”**。

两种可复核的外部教学参照：

- **Harvard Business School Case Method**：用决策者当时能看到的信息将学生置于决策节点，不预先给出真实选择。HBS官方说明：https://www.hbs.edu/case-method-project/about/Pages/case-method-teaching.aspx
- **Digital Inquiry Group / Reading Like a Historian**：运用来源核验（sourcing）、情境化（contextualization）、交叉印证（corroboration）和细读（close reading），对多份原始文献作证据判断。官方课程：https://www.inquirygroup.org/history-lessons

### 一份合格的历史决策教学案例至少要有

| 字段 | 问题 | 常见伪装 |
|---|---|---|
| `DECISION-TIME` | 明确截至哪天，禁止引用尚未发生的后果 | 事后把结局倒填为主角早已知道 |
| `ACTOR-TELOS` | 人物为何设定目标？谁反对？ | 预设目标天然正确 |
| `KNOWN / UNKNOWN` | 当时实际获取哪些信息、遗漏哪些？ | 用后来史家知识代替同期情报 |
| `OPTIONS / NO-ACTION` | 至少两条可执行方案及不行动的成本 | 只给胜者当年的方案 |
| `RESOURCE / RIGHTS` | 组织、资源、授权、协调限制是什么？ | 用个人天才遮蔽团队/制度 |
| `EX-ANTE RATIONALE` | 在不知胜败时，判断的质量如何？ | 只用结果给领导者打分 |
| `OUTCOME / COUNTERFACTUAL` | 真实结果与可信反事实分别是什么？ | 把另一个选择的结局编造为必然 |
| `ETHICAL COST` | 谁承担人员、公共与政治成本？ | 用“胜利”豁免一切手段 |
| `SOURCE-GRADE` | 同期一手、回忆、研究与传说如何分级？ | 把后出宣传改写为同期决定 |

**历史案例并非必须拥护任何政治行动**；教学需要让学习者可以质疑目标本身、判断过程和伦理代价。军事组织的强制权或战争手段也不能被自动移植为企业及公民教育规范。

### 防止决策教育再次“考试化”

如果仅将上述表格改成新的标准话术，让学生背“要有目标、要善于决策”，旧问题就原样重现。应测量学生能否选择新的史料、提出不同方案、公开不确定性、修订判断，并为自己的选择提供证据；允许合理异议，不用“是否与历史胜利者相同”评分。

## 6. 将三项机制转为可证伪研究，而不是增加口号数量

| ID / 当前状态 | 最小可检验命题 | 支持所需材料 | 反证或控制 |
|---|---|---|---|
| `H-EP-01 / UNVERIFIED` | 相同论证因权威/身份/德性标签而更易获得采信，且标签加成超出相关专业信息 | 随机匿名/标注的文本评审实验，测证据质量与意见变化 | 控制真实专业信誉后效应消失 |
| `H-EP-02 / UNVERIFIED` | 后继组织对异端试验的否决权增加，但纠错能力没有同步增加 | 连续数代的决策权、可见失败、异议处理、试验通过/拒绝档案 | 组织保留持续纠错、作者更新与可反对机制 |
| `H-EP-03 / UNVERIFIED` | 说教式呈现使同主题原始材料的长期自发阅读率下降 | 三组教学方式随机/准实验、课外阅读长期追踪、学习基线控制 | 兴趣保持或增强；效应由阅读能力等解释 |
| `H-EP-04 / UNVERIFIED` | 可自定目标并审查史料的课程，比结论背诵更促进跨情境决策 | 同年龄、初始知识与教学时间匹配的延迟测验、开放问题迁移任务 | 仅在史料记忆上变化，跨情境技能无提升 |
| `H-EP-05 / UNVERIFIED` | 若教育上游效应存在，进入游戏行业前就能观察到独立出题与原型尝试差异 | 入行前的固定起点队列、非入行者、家庭与教育指标 | 产业选拔、经济条件与市场接口完全解释观察差异 |

**测量纪律**：

- 不把民族、国家人口、个别大师、热帖点赞当作机制分母；“有一例”不证明频率和强因果。
- 区分教育效果、家庭约束、产业激励、社会地位继承与互联网传播，每一条箭头单独核验。
- 反向纳入：高考试表现且长期保持自主创造的人；正式思想教育后主动转向史料研究的人；没有强规训但照样崇拜权威/做出差决策的环境。
- 不把官方教材的全部内容概括为“只有训诫”，也不把民间反官方叙事当作天然真实；两者都必须受证据规则约束。
- 观察期主要是2020年代教育与创作者生态；跨百年的制度连续性仅H级，不从古代文本直接推现代数量级。

- **社会版本意识**：回链[028 声望鉴别外包](028-imitation-of-greatness-prestige-copying-and-authorial-judgment.md)、[029 正统倒置](029-orthodoxy-inversion-chundeng-farmer-inventor.md)。
- **人生决策读者入口**：承接[全书架构](../../book/BOOK-ARCHITECTURE.md)的“你是否学会自己出题？”；不要把本文未经案例验证的命题直接写成正式人物传记结论。
- **后续实证优先级**：①逐页教材/教师用书/考试评分细则抽样；②不同教学呈现方式的史料学习实验；③真实领导者同期文件重构的盲化决策案例；④学校→原型社区→职业作者的固定队列。
- **2026 transfer status**：`DURABLE`（区分证据与权威，独立复盘）；`CONDITIONAL`（教学方法效果须实测）；`UNKNOWN`（跨国普遍性、产业影响的效应量）。

**最小暂定结论**：社会对正确答案的传递，不等于社会对“产生并修正答案”的能力再生产。反对说教的目标也不应是寻找新的免检偶像，而应恢复原始材料、问题主权、证据比对、合理异议和实际行动反馈。此结论目前是研究方向，不是已完成的中国人群调查。
