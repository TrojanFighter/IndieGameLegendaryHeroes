## 1. 第一阶段已经可以下的结论

**A / 有公开反例支撑：**“中国玩家不爱复古”“中国玩家不爱外国老游戏”“中国玩家不接受低规格/像素画面”都是过强断言。传统日式动作 RPG、RPG Maker 恐怖和极简策略均存在较高的简中 Steam 购买评价参与。

**B / 本样本成立：**不同复古游戏传统的简中评论构成存在悬殊差异；“复古游戏”不应被当作一个整体市场品类。此处的“简中参与”不是中国大陆销量份额。

**C / 待检验：**中国游戏文化的代际传承存在选择性：有些传统经兼容机、网吧、汉化、实况、同人等渠道长期延续；另一些传统虽曾进入中国，却可能没有形成规模相当的后续独立创作与消费社群。

**D / 待检验：**庞大消费市场、广泛游戏阅历、原创规则实验和可持续作者回款，是不同能力层次，不会自动互转。中国发行商商业化外国独游的成功，不等于该作品在中国被原创孵化。

**E / 待检验：**部分商业游戏工业训练可能强化既定 benchmark、专业执行和资源扩张，弱化跨品类学习与小规模原创实验；这是价值网络与职业能力迁移假说，不可由评论语言数据单独证明。

## 3. 重要反例：The Roottrees Are Dead 的官方汉化后市场变化

**E42-06 / P0，当事人公开自述：**该作 2025-12 上线简中后，开发者在 **2026-04-09** 的官方更新中称，简体中文上线后的两周之内，其语言版本销售已超过英语之外的每种语言版本；还宣布免费更新普通话配音，并表示下作 The Incident at Galley House 会首发简中。[开发者公告（SteamDB 保留更新原文）](https://steamdb.info/patchnotes/22714051/)；[Steam 官方新闻入口](https://store.steampowered.com/news/app/2754380)。

这比评论语言的间接代理更强，直接削弱“中国玩家天然不喜欢文字密集的非传统推理/搜索游戏”的强断言。

但它**没有**公开逐语言的原始销售数量、净收入、定价/曝光控制组，不能推断“翻译独立造成了百分之多少的销售提升”，也不能推断任何小众作品只要汉化就一定成功。语言、创作者传播、既有口碑、文本谜题可解性、发行时点可能共同起作用。

## 4. 到底“复”什么古？至少拆成四个维度

1. **视觉年代**：FC/8-bit、16-bit、DOS/旧 PC 精灵、PS1 低多边形/纹理抖动、CRT/模拟录像、现代像素复古。画面并不对应唯一规则体系。
2. **规则谱系**：JRPG、动作 RPG、RPG Maker 恐怖、老式资源探索生存恐怖、Quake/Blood/DOOM 系单人关卡 FPS、CS 系多人竞技、RTS/塔防/经济建造、街机动作、MMO/刷宝等。历史接触不同，不可一概而论。
3. **怀旧入口**：亲历原作和硬件；非正式盗版/模拟器/网吧；后来通过汉化、UP 主、同人、MOD 和现代致敬作品重新学会欣赏旧样式；以及以《烟火》《三伏》为候选的旧时代**社会生活记忆**，并非旧游戏机制本身。
4. **需求回声**：观看、试玩、买外国作品、给国产作者付费、自己做游戏与下一代再生产，分别需要 ACCESS / INTERPRETATION / LEGITIMATION / PRACTICE / TRANSACTION / MEMORY（定义和 Owner 在[中国019](019-taste-institutions-player-literacy-creator-selection.md)）。

因此不应将“中国人玩过 CS”推出“中国已充分继承 Quake 式单人关卡 FPS”，也不应将“玩过生化危机”推出“中国自然会购买所有独立 PS1 生存恐怖新作”。反过来，不应将少数独立作品简中占比低推出“中国玩家不喜欢 FPS/恐怖”。

**E42-07 / P0：** [Crow Country 官方商店](https://store.steampowered.com/app/1996010/)有简中并以 1990s/Survival Horror/Retro 标签定位。[E42-08 / S2：中文玩家评测](https://steamcommunity.com/app/1996010/reviews/?browsefilter=toprated&l=schinese)可以看到“老生化”怀旧者，也能看到谜题本地化抱怨，故“有没有中文”应升级为“何时有中文、翻译是否有效”。

## 5. “不玩”不一定是没有接触，而是没有形成相应的谱系传承

**两条路径（H）：**
- **亲历式怀旧**：玩家曾参与某个时代的机器、游戏或玩法共同体。
- **再习得式复古**：玩家不必拥有 PS1/老 PC 的亲身回忆，也可能经视频、汉化、同人和现代作品获得审美与规则知识。

中国历史上的 FC 兼容机、街机、网吧 PC、主机水货/盗版、模拟器及 Steam 均是不同接触通道。强调某项主机政策而忽略真实接触渠道，不能解释整个文化谱系。尤其日本 RPG Maker 恐怖可研究早期 B 站实况与汉化形成新一代受众的过程。

另一个反压力是 **Beyond Citadel**：2025-01 中文 Steam 评论中有人提供自己制作的简中补丁，并说明 B 站公开发布。这是[玩家社区直接介入可接近性](https://steamcommunity.com/app/3371240/reviews/?browsefilter=toprated&l=schinese)的 S2 线索，不等于该作已有官方完整本地化，亦不能根据少量帖子给出国别销量。

**神之天平的跨国分工反例：** 日本开发者 KEIZO 的长期个人制作，在中国发行商 WhisperGames 的翻译/宣发/反馈支持下形成中文市场回声。[2024 开发者讲座报道](https://az-line.jp/index.php/2024/01/01/idc-astribra/) 是回顾性一手主张的二手整理（P1 路径）。中国有发行与消费能力，不等于由此证明本土拥有同等的创作起始生态。不同环节需分别审计。

## 6. 从游戏本身到能否被发现：冷启动弱线索

此前讨论的独立小型卡牌/接龙作品引出三个值得观测的变量：**实际玩到以后的乐趣**、**试玩前能否看出乐趣**、**进入乐趣前的学习成本**；再加上社群信任、短视频解释能力和 demo/曝光渠道。

- 玩法难以第一眼解释，不证明游戏不有趣；许多策略、推理玩法的乐趣恰恰在学会规则后。
- 不能把低销量全部归因于“玩家素质”，也不能把设计问题全部外包给市场传播。
- “有了销售和用户基础以后能放大、从零到早期认可特别难”的说法来自未公开的聊天观察，只是 H，不是已经做过中外对照的市场规律。
- 未核实的“买量推动短期榜单表现但项目未获净回报”传闻**不作为 Evidence**，但已经在 [SIG-001](../../sources/research-intake/signals/SIG-001-paid-acquisition-chart-vs-profit-20261103.md)按未经证实的行业 Signal 保存。
- 私人参与者、原始截图和私人项目不公开；去身份的行业推断已在 [AC-011 作者立场](../../author-corpus/AC-011-laozhong-buwan-selective-retro-and-authorial-game-literacy-20261103.md)与 [SIG-002 冷启动观察](../../sources/research-intake/signals/SIG-002-cold-start-and-social-proof-china-indie-20261103.md)保留。

本段可能检验的变量包括：试玩→愿望单、看视频→试玩、首次有效理解时间、客观首次游玩成功、折扣/推广前后购买、国区社区内容覆盖；若没有可信分母，不估概率。

## 7. 从复古市场回到原创人才：四种资本不自动转化

作者提出的“消费资本 / 阅历资本 / 创作资本 / 产业资本”作为本次**分析速记**保留，但不另造全库分类法。严格对照既有 [中国001](001-experience-capital-demand-discovery-hypotheses.md)、[中国019](019-taste-institutions-player-literacy-creator-selection.md)、[研究047 七道门](../../book/research-notes/experience-capital-creator-conversion-gates-047.md)：

- 很多人购买游戏 ≠ 有广泛的游戏设计参考集；
- 多样阅历 ≠ 能准确解释玩法差异；
- 会解释玩法 ≠ 能自己做原型与修正；
- 买外国成功作品 ≠ 在本土培养同等的创作者；
- 执行能力与大厂履历 ≠ 自然具有立项、削减 scope、定义问题与原创决策权。

这与作者“应试教育过拟合”“商业训练可能是微型独游负迁移”的主张可连接，但不能由本研究的 Steam 表格直接确认教育→原创新人数量的因果链。对应判断继续由[中国032](032-exam-overfit-routine-expertise-open-domain-transfer.md)及商业训练的既有 Owner 审计。

## 10. 遗漏审计补录（2026-11-03）：首轮对话的鉴赏与传播对照

本节补足 2026-10-27 起首轮“老中不玩”讨论中遗漏的研究问题。属于 Lane B 的**有限事实和可检验比较方案**，不建立新理论 Owner，不把聊天里未经统一核验的百分比升级为 Evidence。

### 10.1 陌生作品的四道市场门槛（H / 诊断工具）

| 阶段 | 待回答的问题 | 要取得的观测 |
|---|---|---|
| DISCOVERY / 发现 | 目标玩家是否真正看到了作品？ | 曝光、搜索、视频覆盖、推荐路径 |
| TRIAL / 尝试 | 看见后是否愿意实际试玩？ | 店页→demo、愿望单、试玩/购买、语言与价格 |
| COMPREHENSION / 理解 | 玩进去后能否识别规则创新和乐趣？ | 首次有效理解时间、玩家访谈、留存与具体批评 |
| PROPAGATION / 传播 | 理解价值的人能否再介绍给其他玩家？ | 讲解视频、社群转发、口碑、转介绍时序 |

这不是对[中国019](019-taste-institutions-player-literacy-creator-selection.md)六类基础设施重命名，而是**单产品冷启动诊断**。不能由某作品中文销量低，直接断言玩家不喜欢该机制；也不能因已玩玩家好评，就断言陌生受众一定能主动发现它。

## 12. 2026-11-04 数量级问题的可核旁证与人物机制

### 12.1 作者观点（A0/H）不应被孤立反例冲淡

作者明确强调，中国具有巨大消费市场和成熟游戏就业体系，但类似巨鸟多多这样能够从游戏阅历出发、独立试验并产生国际玩法影响的人，在**数量级上很少很少**。这不是“国内不存在任何创新者”的存在性判断，而是**原创机制作者的密度、可复制的生成路径以及商业就业体系训练迁移**的数量级比较。论断见 [AC-011第7节](../../author-corpus/AC-011-laozhong-buwan-selective-retro-and-authorial-game-literacy-20261103.md)，按A0完整保留，未获得同口径国别比率前不得擅自提升为已证实统计结论。

### 12.2 新统计：国际可见度不等于原创发明率

- **E42-09 / P1：** 波兰企业发展局《[The Game Industry of Poland – Report 2025](https://www.parp.gov.pl/storage/publications/pdf/The_Game_Industry_Poland_2025.pdf)》第29页表2，2025年7月 Steam 全球愿望单Top200按开发来源折算：中国8、波兰12、美国33.25、加拿大17.25、日本15、瑞典14.75、德国14、俄罗斯5。小数为多国归属分摊。它统计**全球关注度席位**，不是销量、发行总量、独立发明者数或原创度。
- **E42-10 / P1：** [广东游戏产业协会2025年行业报告解读](https://www.gegia.cn/newsinfo/10936533.html)：2025年国内游戏用户6.83亿，国内市场实际销售收入3507.89亿元。这反映消费规模，不能与Steam Top200席位简单相除得出原创效率。Steam品类、平台、语言、国内外市场分配和宣传是重要混杂变量。
- **有界用途：** 中国游戏市场极大、在该Steam特定国际关注度榜单中份额未相称突出，支持进一步调查**海外可见度／人口和产业规模错配**；尚不能定量证明“国际玩法发明者比波兰少几倍”，更不能用俄罗斯本次仅5席位反证其游戏设计传统。

### 12.3 新的同期人物证据：不只是玩得多

- **E42-11 / P0：** [AUTOMATON 2021-03-14 KEIZO本人采访](https://automaton-media.com/articles/fp/20210314-154803/)：2D动作RPG供给减少促使自己开发；希望较长流程和由成长替代高难精确操作；初期对编程、计算机不熟，项目两次中断；装备熟练度来自连载期间玩家论坛反馈。这一案不能被套进“广泛玩过更多品类才能原创”的单一公式。
- **E42-12 / P0：** [TouchArcade 2024-02-12 KEIZO本人采访](https://toucharcade.com/?p=318833)：他有正常公司工作、业余开发；个人网站大致每两年更新一章，2021免费发布；许多早期素材作者无法联系，难以合法商业化，后来WhisperGames出资帮助素材替换。该生计和授权限制不得从传记删除。

- **E42-14 / P0：** [PCGamesN 2019同期访谈](https://www.pcgamesn.com/dota-2/dota-auto-chess-artifact)记载团队两年开发、第一年后大幅降低上手负担；[Red Bull 2019采访](https://www.redbull.com/int-en/dota-auto-chess-interview-drodo-studio)则强调五人借已有Dota引擎及素材避免全栈独立开发。

**下一步问题和止损：** 在研究047的G0-G6与研究052的固定起点原型队列中，比较同年代、同入口、同成熟门槛的中国/外国原创机制作者、可玩作品与持续创作的比率。看见单个国内英雄只证明可能性；缺少可比较分母不能宣布“国别差异不存在”，也不能凭主张造出精确国别倍率。
