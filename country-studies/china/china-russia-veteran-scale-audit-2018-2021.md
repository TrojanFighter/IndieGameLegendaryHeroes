# 中俄游戏从业者老兵数量级审计（2018—2021）

- Type: Workforce scale audit / methodological correction
- Status: ACTIVE — SCALE FIRST
- Date: 2026-10-08
- Purpose: 纠正此前由少量主创案例推断“俄方老兵密度可能更高”的方法错误。先比较产业人口、经验分布与绝对数量级，再讨论Premium/系统型子行业的集中度。

## 一、必须先问数量级，而不是先看名人

此前目的性credits样本只能说明：
- 两国都存在长期hands-on的老兵；
- 一些俄方Premium/系统作品由资深者主导；
- 一些中国早期单机老兵转入Online/MMO后仍长期做产品。

它**不能**证明：
- 俄罗斯全行业老兵比例更高；
- 俄罗斯10年以上从业者绝对数量更多；
- 俄方核心决策位老兵密度高于中国；
- 俄方seniority pipeline整体更强。

这些命题必须有分母。

## 二、产业人口数量级

### 中国 2018
《中国游戏产业报告》口径：游戏产业从业者约 **145万人**。职位构成中：
- 游戏开发：20.4%
- 游戏设计：17.1%
- 游戏策划：11.4%
- 游戏运营：39.1%

若只把开发+设计+策划作为一个非常宽的“生产相关”代理，则约占 **48.9%**，对应约 **70.9万人**。

来源：
https://www.jiemian.com/article/2731103.html
https://tech.sina.com.cn/i/2019-01-04/doc-ihqhqcis3156875.shtml

**边界**：145万是中国游戏产业广义从业口径，70.9万是研究者按职位占比构造的宽口径，不等于“核心游戏开发者”。

### 俄罗斯 2021
PwC Moscow gaming study的媒体转述：截至2021年10月，俄罗斯约 **250—300家**游戏开发/发行公司，共约 **1.7万名员工**；其中莫斯科约150家公司、1万人。

来源：
https://app2top.ru/analytics/v-proshlom-godu-moskovskij-ry-nok-videoigr-zarabotal-119-5-mlrd-rublej-e-to-80-dohoda-vsego-gejmdeva-rossii1-194498.html

**边界**：年份不同（2018 vs 2021）、行业定义不同，因此不能把70.9万/1.7万当成精确人员倍率；但它足以说明中国的绝对游戏劳动池远大于俄罗斯。

### 数量级敏感性
用上述宽口径：
- 中国广义生产相关约70.9万人；
- 俄罗斯整个游戏公司就业约1.7万人；
- 前者约为后者 **42倍**；
- 中国全部游戏产业就业则约为俄罗斯2021游戏公司就业 **85倍**。

这不是同口径正式比率，只是数量级警报。

即使假设俄罗斯1.7万人里有 **20%** 是10年以上老兵（3400人；20%仅是假设，不是俄罗斯实测），中国70.9万宽口径生产人员里只需要约 **0.48%** 为10年以上老兵，就能在绝对人数上达到同样3400人。

因此：
> **“俄罗斯拥有更多老兵”作为绝对数量命题，在没有极端比例差异证据前不具可行性。**

真正可能成立的只能是：
> 某些俄罗斯Premium/模拟/CRPG子行业中的老兵**集中度**更高。

## 三、经验分布：现有广义调查并不显示俄罗斯明显更老

### 俄罗斯 / 俄语圈
2019 Values Value调查：负责人称**接近一半**受访者游戏行业经验不足3年。
https://dtf.ru/gameindustry/52977-issledovanie-mediannaya-zarplata-v-rossijskom-gejmdeve-sostavlyaet-tysyachu-dollarov-v-mesyac

2020 Talents in Games / App2Top调查：
- 1379名俄语圈从业者，其中1021人在俄罗斯；
- 19.8%低于25岁；
- 63.9%在25—34岁；
- 45岁以上仅略高于2%；
- 只有16.2%在当前公司工作4年以上；
- 专业经验分布没有单一压倒组，低经验组同样很大。
https://wnhub.io/news/other/item-18350

2021 Values Value / InGame Job：
- 2413名俄语圈从业者，56.2%来自俄罗斯；
- 年龄中位数29岁；
- 56.1%从业超过3年，也就是约43.9%不超过3年；
- 86%自报Middle及以上，但seniority标签不能等同于10年以上工龄。
https://boost.ingamejob.com/ru/bolshoj-zarplatnyj-opros-gejmdeva-2021g/

### 中国
2019腾讯IEG为主的750人调查：
- 平均年龄29.66岁；
- 游戏行业平均经验 **5.8年**；
- 0—3年占 **34.7%**；
- 31岁及以上占48.9%。
https://games.sina.cn/cyfw/cyxw/2019-07-03/detail-ihytcerm1042679.d.html

**边界**：腾讯样本是中国头部公司员工，不代表中国全行业；俄方调查是自愿参加的俄语圈/俄罗斯样本，也有明显自选择偏差。

但至少：
> **现有调查完全没有支持“俄罗斯广义从业者经验显著高于中国”的证据。**

相反，俄罗斯2019/2021调查中的≤3年新人比例约44%—50%，并不低。

## 四、招聘需求也不能当老兵存量

中国2018游戏岗位招聘要求中：
- 1年以下10.5%
- 1—3年35.0%
- 3—5年23.3%
- 5—10年5.4%
- 10年以上0.1%
- 不限25.7%

来源：
https://qccdata.qichacha.com/ReportData/PDF/3b848217fcd9ee01fcc8a97189642208.pdf

这说明企业公开招聘极少直接要求10年以上经验，但它是**岗位需求分布**，不是在职人员经验分布，不能拿0.1%当中国老兵占比。

俄罗斯2021招聘市场也以Middle需求为主；同样不能由招聘广告推回存量年龄结构。
https://boost.ingamejob.com/ru/obzor-rynka-truda-gejmdeva-kakim-byl-2021-god/

## 五、此前方法错误：从“存在”又跳成了“密度”

错误链条是：
1. 找到Maddox/Kislyi/Yudintsev/Mishulin等资深者；
2. 发现其长期hands-on；
3. 将其解释成“俄方旗舰项目老兵密度可能更高”；
4. 但没有先问俄方总从业者多少、中国总从业者多少、10年以上各占多少、Premium子行业分母多少。

这和此前用少数《戴森球计划》/Gamera反驳中国结构性问题是同一种量词错误：
> **存在量词 ≠ 频率 ≠ 密度 ≠ 绝对数量 ≠ 因果。**

今后国别比较强制按以下顺序：
1. population / workforce / project denominator；
2. distribution；
3. standardized rate；
4. subgroup concentration；
5. case mechanism；
6. only then causal interpretation。

## 六、真正应该测的命题

### 命题A：绝对老兵数量
中国10+年游戏从业者绝对人数 vs 俄罗斯/后苏联。
**当前：UNKNOWN；但中国巨大劳动池使“俄罗斯绝对更多”非常不可信。**

### 命题B：全行业老兵比例
10+年经验 / 全部游戏从业者。
**当前：UNKNOWN；现有调查不支持俄方明显更高。**

### 命题C：核心研发岗位老兵比例
10+年经验的programmer/designer/producer/artist leads / 同类岗位总数。
**当前：UNKNOWN。**

### 命题D：Premium/系统型子行业老兵集中度
10+年经验核心人员 / Premium PC、模拟、CRPG、复杂系统项目核心人员。
**这是最可能与用户直觉一致、也最值得验证的命题。当前仅有selected cases。**

### 命题E：老兵经验配置
两国10+年老兵的人年分别投入：
- Premium/买断；
- Online/MMO；
- mobile；
- live ops；
- engine/tools；
- management；
- original core mechanics。

**这是当前最可能解释产品差异的变量，但必须先获得人数分母。**

## 七、下一步抽样设计必须按数量级做

不再“每国挑7个人”。

### 第一层：公司/项目母体
- 中国：2003 cohort 7个核心组织 + 2010/2015代表性Online/Premium公司；
- 俄罗斯：1C 2005完整本土项目集 + 2010/2015 Premium/Online公司。

### 第二层：全credits抽样
每个项目按固定规则取：
- producer/design lead；
- technical lead；
- art lead；
- 随机普通programmer/designer/artist若干。

禁止按“谁容易查到”选人。

### 第三层：标准化输出
至少报告：
- N；
- 10+年人数；
- 10+年比例；
- 每千名开发者老兵数；
- 每百个项目老兵数；
- Premium/Online/mobile分布；
- 5年后留存/转域/退出率。

### 第四层：绝对规模
把样本率乘以可信的行业/子行业人口范围，只给区间，不给虚假精确值。

## Verdict

**RETRACTED / NOT ESTABLISHED**：
- “俄罗斯核心决策层老兵密度更高”目前没有数量级证据；
- “俄罗斯seniority pipeline更强”目前没有数量级证据。

**SUPPORTED**：
- 俄罗斯存在一批长期hands-on的Premium/系统型资深主创；
- 中国也存在大量长期hands-on老兵，且中国游戏劳动力绝对规模远大于俄罗斯；
- 现有广义调查没有显示俄罗斯从业者整体更资深。

**NEXT TEST**：
只检验一个更窄命题：
> **俄／后苏联Premium/模拟/CRPG子行业中的10+年老兵集中度，是否显著高于中国同类Premium子行业，并且在控制公司年龄、项目预算、岗位和年代后仍成立？**
