# 中国游戏职业价值网络锁定与国际市场自主权（2026-10-11研究增量）

- 区域：中国国情；对照俄罗斯/俄语圈的国际市场机会与职业迁移。
- 类型：Evidence/Hypothesis Ledger，**非正式国别判决、非人口调查、非书稿**。
- 关联：[俄中制度十维矩阵](russia-china-game-industry-regime-comparison-1995-2026.md)；[ARC / FCC](russia-china-game-industry-regime-comparison-1995-2026.md#2026-10-07-核心比较概念authorial-refusal-capacityarc与自主能力的局限)；俄作者动机材料 [PR #340](https://github.com/TrojanFighter/IndieGameLegendaryHeroes/pull/340) 尚属独立研究 intake。
- 用户观察（AUTHOR THESIS，不等于全行业事实）：中国一些商业游戏从业者虽反感本地工作/社会环境，其技能、工资、职业阶梯和关系资本却由特定商业化价值网络定价；经过多年局部最优决策后，可能失去在其他市场以自主作者身份生存的现实选项。概括为「被成功的商业化套路成功收买了人生路径」，不得改写成对个人道德/能力的整体评判。

## 职业价值网络锁定（Career Value-Network Lock-in）机制：H

渠道/商业模式持续盈利 → 对应专项职位获得高薪与晋升 → 本网络定价的特定技能深度累积 → 跨入陌生市场/原创作者路径时既有履历不能全部定价，且需放弃薪酬/稳定性 → 更多人选择保留既有岗位 → 旧网络进一步拥有资深人才和执行优势。

该机制不要求资本方故意剥夺创造力；不要求从业者主观赞同环境；甚至每一步都可能是个人合理选择。**它是一个待检验的锁定机制，不是对多数中国游戏员工实际处境的已证统计结论。**

### 至少分清四种不等价的“可以离开”

- **跨国就业可迁移性**：能否被境外F2P公司/PC公司直接雇佣，与语言、签证、作品集、网络和市场经验有关；
- **跨品类可迁移性**：数值、买量、渠道管理专业化，不会自动变成具原创PC/买断项目定义能力；反之全球F2P技能在海外相似公司可能高迁移；
- **作者/企业自主权**：是否掌握IP、资金、核心策划否决权、Demo与发行/社区接入，参照本库ARC；
- **实际迁居选择**：人身安全、家庭、居住偏好、签证等不由市场竞争力单一决定。“没迁居”不证明“没能力”，“不想离开”也不证明认同所在网络。

**要点**：中国已创造可观海外收入，且约九成为移动；这说明跨境商业化能力现实存在，但不能证明其收益已广泛转化为个人在国际PC独立游戏网络的原创决策权。中俄双方都有成熟商业化，区别须按职业、项目、客户市场、国际收入暴露与决策权逐组比较。

## 证伪与下一轮研究设计

- **分母**：中国从业者按职业 (系统/经济/关卡/技术/UA/发行/制作)、入行年份、平台、是否有本人主导项目、公司是否出海、城市/收入层级分层；俄罗斯用同职类、同年代、同类型公司配对。
- **纵向节点**：毕业/入职、首次自选原型、首次拥有产品方向否决权、首次外国玩家真实付费、首次境外公司录用或境外发行合作、退出/未退出原因；不得由成功者现状倒推早年动机。
- **实际能力而非意愿**：能否以个人/小团队发布可玩Demo并获得非熟人用户；是否有外币收入、海外Offer、海外消费者社区、跨国可复用工具/引擎经验；与作者自主权/项目完成能力单列。
- **反例**：中国全球F2P/引擎/美术等技能可跨境高迁移，俄国本土F2P及被动外迁人员，国内买断独游的自选路径，高薪商业团队成员自愿选择稳定岗位；以上均需按抽样分母计量。
- **不能宣称**：多数中国游戏人“没有本事离开中国”、某国创作者天性更自主、境外收入占8%、俄罗斯人出口率统一75%、收入比例等于个人国际可迁移率。

### 书写接口

避免道德化通篇谴责；用具体主策/开发者的**两难选择场景、收入及机会成本、作品失败后替代机会**写人生路径。原作者的“收买人生路径”表述保留为醒目的评论性论点，事实叙述与证据等级分开。


## 2026-10-11 具名职业生命史增量：从组织资本到作者资本

### A01｜王妙一（网易→《WILL: A Wonderful World》），2018同期证言

- 自述离职理由：国内商业游戏越来越像「互联网产品」，且继续在网易的未来十年路径高度可预测、缺少个人兴趣；**同时正面承认网易引擎研发、稳定性管理、产品质量及多人协作经验有助后来自主开发**。日本发行方采访，不应只摘反网易段。
- 2017 Steam发行，2018日本/主机发行；创始人2018回顾累计开发成本约人民币200万元，销售收入大体覆盖成本，**不足以长期支持原公司人员/开销**，故缩回较小规模。收入具体数字及「利润」表述有媒体转译歧义，保留采访原文，不能直接推出现金净利润。
- 来源：AUTOMATON JP 2018-12-28，当事人一手访谈 https://automaton-media.com/devlog/interview/20181228-82392/
- H：离职产生作者资本，但产品交付≠企业再生产；规模过快扩张推高失败承载门槛。

### A02｜《孤星猎人》LONESTAR（两位大厂策划→两人独立创业），2025同期证言

- 2021离职，约4年制作；制作人2025-04称已售6万余份，工资成本约为原大厂收入的**50%-60%**，按当时成本尚未完全回本（采访时EA，2025-04-03转正式版）。
- 核心可玩循环仅数月形成，后续大幅时间消耗在内容制作、美术自学/返工；2人都是策划，自学程序与美术分工。主创认为独立开发经验也可能增加未来重返大厂的竞争力；**“可回去”是其预期，非已验证成功回流**。
- 当事人引用“首作回本5%、二作50%”没有可靠抽样统计口径，**不作为本库统计事实**。
- 来源：游戏陀螺2025-04-08 https://www.tuoluo.cn/article/detail-10121164.html
- H：独立创业可能积累外部市场可定价能力，但制作范围收束（Product Closure Competence）是独立瓶颈；机会成本和工资实际损失分开计量。

### A03｜魏嘉 Loka（腾讯NExT/《疑案追声》→独立《声探疑云》），2026采访

- 2019《疑案追声》已具玩家长期声誉；后在腾讯大型项目做叙事策划，认为单一岗位标签不能解释自己希望承担的完整创作。公开讲述：高职级主策也可能没有能被本人认领的作品（仅当事人转述，不可推所有大厂主策）。
- 2025-03启动4人工作室，2026访谈说由自己出资以确保产品方向否决权；原作玩家、老同事试玩、原NExT转发行朋友的支持形成**已经存在的可携带职业网络**。项目尚在制作，不能提前宣布商业成功或正式交付。
- 当事人仍向家人隐瞒从腾讯离职，父母重视福利稳定；可作为制度性声誉的个人案例，不作一般心理人口结论。
- 2026对具体设计的阐释：关卡谜题先行，剧本和配音都需配合非线性时间轴；靠大量试写、删掉约2/3关卡草稿及试玩迭代筛选。说明个人作者资本由**可验证的特定玩法问题域与制作方法**构成，而不仅是署名/行业地位。
- 来源：《游戏葡萄》2026-08-09访谈转载于TapTap https://www.taptap.cn/moment/835782571051713477
- H：曾经拥有可归属产品成果、直接玩家社区与可信合作者，更容易把组织声望转换为独立作者选择权。

### A04｜胡烽与于洋（MadGoat，《幸运市长》《冥界契约》），2025同期访谈

- 胡烽2023年底在AI游戏项目被砍/遭裁后，与同事于洋转独立开发。受访者认为经历多年风口项目，制作正经游戏的能力未必增强；同时其企业技能并非毫无价值。

### A05｜月下 林夏（腾讯《王牌战士》执行制作人→《铸仙之境》），2025同期访谈

- 同人创作起点→大厂就业→2021创业；获悠星和游戏扳机合计超千万投资，早期选择非腾讯资金为了避免第二轮融资排他，事后本人认为误判；原计划约4000万元成本及第二轮资金未到位。

### 反向研究设计：将锁定拆成四个可比结果

1. **Cross-firm employability（换雇主能力）**：外部Offer、薪酬、岗位要求，国内与海外分开。
2. **Portable craft and public proof（可携带技艺及可核实作品）**：本人决策/代码/设计录像/玩家直接付费，IP归属与口碑不等同。
3. **Authorial refusal capacity（对不喜欢的方向说不）**：存款Runway、股权及IP、发行备选、愿意持续合作的核心团队。
4. **Failure carrying/production closure（失败承载与完成能力）**：Demo→1.0时间及成本偏差、首作现金流、下一作存活，哪怕回大厂也可积累新技能。

**建议假说测量**：在同一批可观察大厂员工入职后的第1/3/5/10年，评估组织职位与薪酬上升是否伴随可独立展示原创作品下降；不能用作者选择辞职者作为唯一分母。公司外部就业机会和本土生活偏好须独立记录，不以仍在中国境内直接判“无迁移能力”。
