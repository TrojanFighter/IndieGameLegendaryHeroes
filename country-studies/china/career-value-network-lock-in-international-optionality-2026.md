# 中国游戏职业价值网络锁定与国际市场自主权（2026-10-11研究增量）

- 区域：中国国情；对照俄罗斯/俄语圈的国际市场机会与职业迁移。
- 类型：Evidence/Hypothesis Ledger，**非正式国别判决、非人口调查、非书稿**。
- 关联：[俄中制度十维矩阵](russia-china-game-industry-regime-comparison-1995-2026.md)；[ARC / FCC](russia-china-game-industry-regime-comparison-1995-2026.md#2026-10-07-核心比较概念authorial-refusal-capacityarc与自主能力的局限)；俄作者动机材料 [PR #340](https://github.com/TrojanFighter/IndieGameLegendaryHeroes/pull/340) 尚属独立研究 intake。
- 用户观察（AUTHOR THESIS，不等于全行业事实）：中国一些商业游戏从业者虽反感本地工作/社会环境，其技能、工资、职业阶梯和关系资本却由特定商业化价值网络定价；经过多年局部最优决策后，可能失去在其他市场以自主作者身份生存的现实选项。概括为「被成功的商业化套路成功收买了人生路径」，不得改写成对个人道德/能力的整体评判。

## 直接可核的数据与口径纠错

1. 中国音数协《2025年中国游戏产业报告》2025-12-19，**P0机构当期报告**：国内自研收入 2910.95 亿元人民币；海外自研 204.55 亿美元；海外自研移动 184.78 亿美元；海外自研收入约 **90.33% 为移动游戏**；海外收入TOP100自研移动游戏中策略（含SLG）收入比重 **49.96%**（仅TOP100手游，非全出口）。https://www.cadpa.org.cn/3277/202512/41770.html
2. 以研究库既有2025年约7.19 RMB/USD参考换算，2025海外自研收入约1470.7亿元，构造的**海外收入近似权重**约33.6%（海外/[国内自研+海外自研]）；若海外按约1440亿元折算为33.1%，差别来自汇率选择。统计归类/定价并非严格同口径，**非协会直接发布的比例**。中国境外收入“仅8%”暂找不到全行业权威出处，不得采信或写入主结论；8%可能系企业/局部品类或不同分母，找到原表再复核。
3. 俄裔跨国企业 MY.GAMES 2020国际（俄国及独联体之外）收入约75%（公司口径）；同年集团年报表示MY.GAMES营收约98%来自F2P。它证明俄裔企业也可大规模依赖移动/商业化运营，绝不能将俄国塑造成非商业化纯作者生态。**俄罗斯企业个例不能代表俄罗斯全国收入比率**。https://vk.company.ru/ru/investors/ir_blog/10907/ ; https://corp.vkcdn.ru/media/files/mail.rugrouparfy2020.pdf
4. 1991年 James G. March《Exploration and Exploitation in Organizational Learning》：组织提高现有实践效率时，短期利用收益可能压倒新探索。**外部理论，不是中国游戏业数据**。https://pubsonline.informs.org/doi/abs/10.1287/orsc.2.1.71
5. 1992年 Dorothy Leonard-Barton《Core Capabilities and Core Rigidities》：核心能力也可构成新产品开发障碍。**外部理论，应用到个人职业为本研究推论**。https://sms.onlinelibrary.wiley.com/doi/10.1002/smj.4250131009

## 职业价值网络锁定（Career Value-Network Lock-in）机制：H

渠道/商业模式持续盈利 → 对应专项职位获得高薪与晋升 → 本网络定价的特定技能深度累积 → 跨入陌生市场/原创作者路径时既有履历不能全部定价，且需放弃薪酬/稳定性 → 更多人选择保留既有岗位 → 旧网络进一步拥有资深人才和执行优势。

该机制不要求资本方故意剥夺创造力；不要求从业者主观赞同环境；甚至每一步都可能是个人合理选择。**它是一个待检验的锁定机制，不是对多数中国游戏员工实际处境的已证统计结论。**

### 至少分清四种不等价的“可以离开”

- **跨国就业可迁移性**：能否被境外F2P公司/PC公司直接雇佣，与语言、签证、作品集、网络和市场经验有关；
- **跨品类可迁移性**：数值、买量、渠道管理专业化，不会自动变成具原创PC/买断项目定义能力；反之全球F2P技能在海外相似公司可能高迁移；
- **作者/企业自主权**：是否掌握IP、资金、核心策划否决权、Demo与发行/社区接入，参照本库ARC；
- **实际迁居选择**：人身安全、家庭、居住偏好、签证等不由市场竞争力单一决定。“没迁居”不证明“没能力”，“不想离开”也不证明认同所在网络。

**要点**：中国已创造可观海外收入，且约九成为移动；这说明跨境商业化能力现实存在，但不能证明其收益已广泛转化为个人在国际PC独立游戏网络的原创决策权。中俄双方都有成熟商业化，区别须按职业、项目、客户市场、国际收入暴露与决策权逐组比较。

## 证伪与下一轮研究设计

- **分母**：中国从业者按职业 (系统/经济/关卡/技术/UA/发行/制作)、入行年份、平台、是否有本人主导项目、公司是否出海、城市/收入层级分层；俄罗斯用同职类、同年代、同类型公司配对。
- **纵向节点**：毕业/入职、首次自选原型、首次拥有产品方向否决权、首次外国玩家真实付费、首次境外公司录用或境外发行合作、退出/未退出原因；不得由成功者现状倒推早年动机。
- **实际能力而非意愿**：能否以个人/小团队发布可玩Demo并获得非熟人用户；是否有外币收入、海外Offer、海外消费者社区、跨国可复用工具/引擎经验；与作者自主权/项目完成能力单列。
- **反例**：中国全球F2P/引擎/美术等技能可跨境高迁移，俄国本土F2P及被动外迁人员，国内买断独游的自选路径，高薪商业团队成员自愿选择稳定岗位；以上均需按抽样分母计量。
- **不能宣称**：多数中国游戏人“没有本事离开中国”、某国创作者天性更自主、境外收入占8%、俄罗斯人出口率统一75%、收入比例等于个人国际可迁移率。

### 书写接口

避免道德化通篇谴责；用具体主策/开发者的**两难选择场景、收入及机会成本、作品失败后替代机会**写人生路径。原作者的“收买人生路径”表述保留为醒目的评论性论点，事实叙述与证据等级分开。
