# 016 — 大陆“末代单机”能力退出：1998—2003技术追赶、海外产品化与市场回报断裂

- Program: C / 中国国情研究 × 台湾比较线
- Status: SOURCE-AUDIT / CAPABILITY-EXIT / PRE-CLAIM
- As of: 2026-10-07
- Taiwan comparator: ../taiwan/007-cross-strait-selection-effects-information-talent-regulation.md
- Core question: 大陆单机团队转向网游，究竟是因为“做不出好单机”，还是因为已经长出的能力没有得到足以维持组织的市场回报？

## 0. 当前结论

1998—2003不能再简单写成“大陆单机仍明显落后台湾，随后靠网游才追上”。

现有同期/公司资料至少支持：

1. 大陆头部公司已经能制作较长周期、高投入、系统复杂的RTS/ARPG/FPS/3D项目；
2. 《傲世三国》《秦殇》等已经进入E3、全球多语种发行、欧美发行商合作；
3. 大宇2002公开承认大陆与台湾研发差距快速缩小，并决定台北不再另做3D引擎，采用北京软星成果；
4. 多家公司明确把盗版、正版回收不足或硬件基数不足列为单机商业困境；
5. 这些能力随后大量迁入MMORPG/网络游戏，而不是“消失”。

因此更准确的机制是：

CAPABILITY GROWTH
+ WEAK PAID-COPY CAPTURE
+ PIRACY / HARDWARE LIMIT / SMALL ADDRESSABLE PAYING BASE
+ ONLINE MONETIZATION OPPORTUNITY
→ CAPABILITY EXIT FROM PREMIUM SINGLE-PLAYER.

# 1. 《傲世三国》：2000年前后大陆已经出现全球产品化

## CN-LASTPC-E01｜正式进入E3与多语种全球发行

目标软件官方历史：
https://object.com.cn/incident.html

记录：
- 2000年《傲世三国》成为首个正式参加E3展出的中国大陆游戏；
- 2001年推出英文、法文、日文、德文、意大利文、韩文等16种语言版本；
- 进入美国GLOBAL 100榜单。

目标公司历史回访：
https://games.sina.com.cn/guancha/object/huayu.shtml

公司受访者称：
- 1999与EIDOS签全球代理；
- 《傲世三国》国内发行约12万套；
- 海外发行约26万套。

这些销量为公司/人物自报，不等于审计sell-through，但足以支持：
**大陆头部单机已经具备全球发行接口，不是只在国内做低成本作品。**

# 2. 《秦殇》：高投入ARPG与“正版不能养活原创”的直接当事人证词

## CN-LASTPC-E02｜开发近3年、投入巨大、进入国际发行

2002《秦殇》主创访谈：
https://games.sina.com.cn/zhuanqu/qin/qinliao.shtml

张淳称：
- 开发总时长2年10个月；
- 投资/投入“非常巨大”；
- 盗版对原创制作公司伤害最大。

目标公司历史同时记录：
- 北美由Strategy First发行；
- 日本版由Capcom代理；
- 2002 E3参展。

https://object.com.cn/incident.html

## CN-LASTPC-E03｜转网游的原因由团队自己明确说出

2002-12目标软件《天骄：秦殇世界》访谈：
https://games.sina.com.cn/newgames/0212/120515201.shtml

策划刘豫斌直接称：
- 《傲世三国》《秦殇》的正版销量在国内已属前列；
- 但与盗版相比，更多收入仍流向盗版；
- 对厂商而言，运营网络游戏是避免盗版、让流失资金回笼的现实方案。

这是非常强的CAPABILITY-EXIT证据：

> 团队并不是因为单机产品能力失败才进入网游；他们明确把“商业价值无法被正版捕获”作为转型理由之一。

# 3. 《自由与荣耀》：技术领先本身也可能错配市场

## CN-LASTPC-E04｜3D技术领先，但硬件基数不足导致产品化失败

2005产业复盘：
https://games.sina.com.cn/o/n/2005-03-14/89004.shtml

报道评价：
- 《自由与荣耀》是当时大陆少见的全3D RTS；
- 技术能力位于国产前列；
- 但产品定位超前，当时大量用户PC无法顺畅运行；
- 故事/内容也相对简单；
- 最终滞销。

同文还指出洪恩随后《自由与荣耀2》《大秦悍将》等继续展现强技术能力，并判断这些技术转向3D网游并非困难。

这说明：

TECHNICAL FRONTIER
≠ PRODUCT-MARKET FIT.

在低硬件普及率市场中，技术领先甚至可能降低addressable market。

# 4. 《刀剑封魔录》：高质量单机能力直接迁移成在线产品

## CN-LASTPC-E05｜单机之后公司正式转向MMORPG研发

新浪游戏厂商资料：
https://games.sina.com.cn/biz/gamedata/netgames/company/949.shtml

但“单机→网游研发”本身由公司资料可核。

# 4.5. 北京软星：两年内从“低成本研发基地”走向核心技术输出

## CN-LASTPC-E05B｜2000成立时：人才便宜、台湾资本先进入

《仙剑奇侠传5前传》官方站转载姚壮宪人物回顾：
https://pal5q.cubejoy.com/pal5q/2502001858e.html?mlid=5782

记录：
- 2000年北京软星成立，一个多月内招聘20多人；
- 当时约RMB2,000/月可招聘美术、RMB3,000/月可招聘程序、RMB1,000+/月可招聘策划；
- 前期投入/注册资本约USD500k；
- 大宇明确把北京软星定位为研发基地。

这说明大陆游戏研发在2000年仍同时具备：
- 相对于台北显著较低的人力成本；
- 大量高校/技术人才供给；
- 台湾资本、IP和管理输入。

它是一个“低成本承接”起点。

# 5. 到2002，大陆头部工程能力已经反向进入台湾公司

## CN-LASTPC-E06｜大宇决定台北不再另做3D引擎

2002蔡明宏新浪访谈：
https://games.sina.com.cn/newgames/0203/03018133.shtml

蔡明宏回答大陆/台湾研发差距时明确表示：
- 差距“越来越小”；
- 北京开发人员3D引擎效果已经很好；
- 大宇决定台北不再自行开发3D引擎，准备采用北京软星开发的3D引擎。

这是目前最重要的两岸能力节点之一：

> 到2002，大陆不再只是台湾游戏的下游消费市场或低成本制作基地；在3D引擎等核心工程环节，已经开始向台湾母公司反向输出能力。

这与2000北京软星早期“低工资研发基地”的状态形成快速变化。

# 6. 台湾作品仍然是大陆第一代开发者的重要启蒙来源

这并不与“大陆技术追上”矛盾。

2004金山/智冠合作现场，求伯君公开回忆：
- 早年玩智冠《三国演义》受到强烈震撼；
- 后来《仙剑奇侠传》进一步促使自己产生做游戏的想法；
- 台湾作品是其游戏启蒙的重要部分。

Source:
https://games.sina.com.cn/newgames/2004/06/061726024.shtml

因此两岸历史更像：

Taiwan product / information lead
→ mainland player-developer learning
→ mainland engineering scale-up
→ partial technical catch-up/overtake
→ online-game capital regime pulls capability away from premium PC.

而不是两个互不连接的国别产业。

# 7. 不能说“大陆末代单机整体远超台湾”

用户提出的方向在若干维度成立，但需要分维度。

### 当前证据支持大陆头部在这些方向至少出现追平/局部领先：
- 3D engine / rendering engineering；
- RTS规模与系统复杂度；
- ARPG技术与网络化过渡；
- 部分海外产品化；
- 大团队工程野心。

### 台湾同时仍有长期优势：
- 华语RPG叙事与角色资产；
- 已形成的品牌/IP；
- 更成熟的PC发行/营销传统；
- 某些类型的内容生产持续性。

因此正式命题：

> **1998—2003大陆头部单机团队已在若干工程、3D与系统复杂度维度追平甚至超过台湾传统PC厂商，但其正版单机市场未能为这些能力提供稳定的组织回报；网游因此成为技术、人力和资本的更高回报迁移方向。**

Status: STRONGLY SUPPORTED AS MULTI-CASE MECHANISM / NOT A TOTAL-QUALITY RANKING.

---

# 8. 这对“老中不行”框架的关键修正

如果只看2005以后，会得到：

大陆商业网游强
→ 单机原创弱
→ 中国创作者不会做premium原创。

末代单机证据却说明：

**高水平原创能力曾真实出现。**

真正应该追问：
- 为什么能力没有留在premium PC单机组织？
- 哪些人才转入网游并因此获得更好薪酬/职业路径？
- 哪些人离开游戏业？
- 哪些设计能力在网游商业目标中被保留、重定价或淘汰？

也就是：

“有没有能力”
与
“什么制度持续购买这种能力”

必须分开。
