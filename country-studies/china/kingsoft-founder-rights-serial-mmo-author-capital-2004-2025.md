# 2004—2025 金山—心游—剑心：从作者否决权到同问题域超高回报的连续人才谱系

- **Type**: China canonical longitudinal evidence / Russia—China comparison hook。仅公开资料，不入正式Case/Profile/Claim；与[Apeiron—心游](apeiron-yading-xinyou-authorial-closure-finance-1999-2024.md)、[中俄渠道十维矩阵](russia-china-game-industry-regime-comparison-1995-2026.md)互链。
- **Observed**: 2004—2025；核验日期2026-10-09。**核心问题**：作者有股权、实际经营权、专业团队和资金后，是否就会产生跨核心交互品类的新作者？未必；仍要观测创作者**选择的效用函数**与新问题域探索、产品内优化两个维度。
- **Method**: 一条出色职业谱系只能证明 EXSITS。**《金山“黄埔军校”18位创业者》是2024媒体主动策划选出知名者，混有非游戏行业及高管，不是18人总母体，不用于计算金山离职创业成功率/原创率。**

## 2. 西山居MBO≠现金买断；有杠杆、有母公司利润权约束

**RIGHT-01 — P0香港证券交易/年报**：
2011-01-24股份认购协议、2011-04-08实施：WestGame（26名创办员工参与的持股公司）以约**HKD189.344m**购买Westhouse增发的**20%**股份；母公司维持**80%**。其中约**HKD151.475m（约80%认购价）系金山体系借款**，以认购的128m股股份抵押；利率首期**HIBOR+1.3%**，一年期满足条件可延长。**不能写成26人独立现金收购整个西山居。**
- 2011-01-24港交所公告（中文原始条款）：https://www.hkexnews.hk/listedco/listconews/sehk/2011/0124/ltn20110124251_c.pdf
- 2014金山年报关联贷款记录：https://www.hkexnews.hk/listedco/listconews/sehk/2015/0421/ltn20150421446.pdf
- 2011-04-12完成公告转载：https://jingji.cntv.cn/20110412/104592.shtml

**RIGHT-02 — 带有维持盈利压力的融资条款，不是玩法命令**：
2011港交所公告写明，若Westhouse不能维持上一年经审计合并税后净利超过**RMB90m**，贷款方可依约决定**提前终止贷款**（具体通知与到期时间见原公告）。另外员工需提交最低服务期、竞业限制、退出机制等书面方案。
=> 这说明股份激励仍可对团队形成**年度商业目标**和退出/资金纪律。**不能推出“金山因此干预了某个具体玩法/设计审查”**；利润条款只能证明贷款条件与商业约束。
=> 西山居20% MBO与心游后来的外部创业是两种法律经济形式，不能叠加或混为“金山把公司交给员工”。

## 3. 2012外部投资人对同一心游项目前瞻分歧：证明投资判断不是统一评分答案

[2012新浪《一起创业吧》](https://games.sina.com.cn/dreamclub/29/xinyou.html) 同时刊登多名风险投资人点评：
- 一位更肯定大厂经验、强团队与成熟商业项目（作为有利信号）；
- 另一位担忧《逍遥江湖》仍保留很强金山原有产品影子，游戏体验和运营竞争需要改进。
这是一份**ex-ante前瞻分歧**，不是知道2015结果后的后验事后故事；但同期现场点评不保证其预测的统计准确率。
=> 比较创业融资需要对项目提案、原型新颖性、交付经验、经理人CV分别赋权；**专业投资人之间也可能对同一游戏有根本分歧**。

## 4. 重检作者2023长文图片：认知模型与实际审批权要分开

- **A0 作者旧原稿**：《正在到来的中度数值通胀率游戏设计革命》pp.17—22；对中俄“开发者—市场—资方”三角、行业“执行主策”招聘图片、历史销售数据代替开放式判断的图片，属于作者自己的思想史材料。**2026本轮从用户保留PDF原稿核对其图和段落，未直接取得其他聊天上传的每一张截图，不能声称逐张复核过。**
- 原稿pp.19“执行主策”JD截图标题为执行主策，要求较长行业经验；**其具体职责又包含制定产品方向、确定核心规则与跨部门管理**。图片单独支持该岗位名称和职责同时出现，**既无法证明拥有产品最终否决权，也不能单凭标题证明必定无否决权**。统计“执行主策化”须追**谁第一个定义立项、谁有最终批准权、谁能砍掉老板喜欢的规则、谁承担后果**，而不是招聘标题/职级取代制度。
- 原稿pp.20材料描述某知名决策者“不玩游戏但相信数据”，这是作者收集的具名传播材料；**未经独立抽样，不证明国内投资者中多少百分比不玩游戏**。需当事完整录音/原文及同期对照，而不能从图片为行业分布下定论。
- **H：历史结果过拟合**：数据可靠地描述过去现有产品样本，但不能观察尚未形成的全新类型需求。出题能力/做题能力区分必须再加入“提出自己的需求”与“能建立并验证可玩原型”两次独立检验；品牌/渠道语境下“卡牌”“SLG”等既可能是营销市场分组，不一定每位说话人都不懂国际玩法分类。
- **新增第四维：Experience-conditioned Choice Set（经验条件化的选择集合）**：作者从前作失败总结的战略目标与自我风险约束，会在缺外部强迫时主动收窄下一作。现金流保护既可以构成合理判断，也可能削减后续原发探索槽位；用本人同期语言、真实产品预算与外部替代机会验证。
- “个人主义”操作化区分至少四种自主：**职业离职意愿、公司治理/股权自主、对产品立项的实际否决权、跨问题域发现并自主验证新体验**。前三者均不能自动推出第四者。

## 6. 强制反证与下一轮

1. 选择**2011—2021所有可发现西山居/金山研发者裂变样本**，至少同时追王屹、湛振阳、裘新、李兰云、罗晓音、尚进；2004入行者与1990s开发者区分，并加入已失败、未入媒体18人榜者。媒体成功名单只是**线索**。
2. 追2015“剑心”实际股东结构、母公司资金、腾讯分成/IP许可，不能从**130亿玩家流水**推算研发团队ROI或人效。日期2015-01内部立项 vs 2015-05公司注册两套资料的差异保留。
3. 后续《封神再临》2024宣布，需追正式发行与玩机反馈，比较从武侠IP切换神话IP是否真跨越核心玩法领域，而非仅美术题材迁移。
4. 做对照：“已具有创造自由但选择旧问题域”的中俄双边样本，和“高收入团队主动拨资源试新问题域”的双方样本。**拒绝用这条中国商业成功者谱系否定相对俄的创新形成率差距，也拒绝用俄一条作品链判其全国创新更多。**
5. 招聘JD采样必须对应版号时期、公司、职级、项目立项前/后，配真实离职主策本人证言或采访，而非截图数量。
6. 必须控制每人**第一次跨行业创业失败**经历如何改变其下一次风险判断，不能都归于教育/资本；比较家庭支持、储蓄/跑道和已有网络，避免反向从幸运样本推全民心理。

**Temporal validity**：2011员工杠杆MBO/2016微信QQ流量渠道 = HISTORICAL制度条件；“过去成功经验如何收窄或扩大新问题域选择”“经济控制权≠创作探索权”“终端流水≠工作室利润”“职位描述≠真实决策权” = DURABLE研究方法。
