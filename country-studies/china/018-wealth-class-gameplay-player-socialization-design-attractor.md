## 0. Author-origin

作者旧稿《正在到来的中度数值通胀率游戏设计革命》提出了三条在本项目中继续保留、但需要研究化拆解的母题：

1. 传统低数值通胀竞技/零售游戏经常把现实财富排除在主要胜负规则之外，以相对平等起点 + 技巧差异分配结果，可被作者概括为“中产阶级游戏性”；
2. 《征途》式高数值通胀 / F2P 允许现实财富持续换取数值能力、地位与相对优势，作者称之为“富豪阶级游戏性”；
3. 游戏类型与玩家并非单向“需求先存在、产品来满足”，而会发生 **genre → audience → genre** 的长期互相塑造；现存主流类型本身带有幸存者偏差。

旧稿里的阶级术语是一套**游戏需求模型**，不是现实阶层身份的直接分类。正式研究中不把“富豪阶级游戏性”理解为“所有富人都喜欢P2W”，也不把“中产阶级游戏性”理解为人口统计学意义上的中产。

## 1. `RESOURCE_CONVERSION_RIGHT / 外部资源转换权`

核心问题：

> **现实世界的哪些差异，被游戏规则允许转换成游戏内稀缺能力？**

可比较：
- chess / competitive FPS：主要允许时间、知识、技巧、认知等转成胜率；
- subscription / boxed game：现实财富主要决定“能否进入”，进入后对直接战斗优势的转换受限；
- 《征途》式高数值F2P：现实财富可持续转换为战力、装备、地位、组织影响和相对压制能力。

因此“富豪阶级游戏性”的研究定义：

> **一种允许现实财富通过游戏规则被高效率、可重复地转换为游戏内稀缺能力、地位、可见权力与相对优势，并由这种转换本身构成重要正反馈的体验制度。**

边界：
- cosmetic-only purchase ≠ 富豪阶级游戏性；
- subscription ≠ 富豪阶级游戏性；
- 有抽卡 ≠ 自动构成完整富豪阶级游戏性；
- 关键在于财富能否稳定购买**相对效用 / 相对支配关系**。

## 2. `PLUTOCRATIC_DEMAND_WEIGHTING / 财富加权需求`

Premium 的收入投票通常较有界：

```text
one buyer → one/few bounded purchases
```

高付费深度 F2P 则允许：

```text
revenue voting weight ∝ willingness/ability to spend
```

因此《征途》的制度创新不只是“找到whale”，而是：

> **取消“一个玩家最多贡献有限收入”的市场上限，使少数高支付能力用户的偏好在收入函数中获得远高于普通玩家的权重。**

这不是民主/政治类比的价值判断，而是需求权重结构描述。

研究后果：
- “大多数玩家喜欢什么”与“收入最奖励什么”可能显著分离；
- product roadmap 可能围绕高边际收入玩家而不是人数多数优化；
- 玩家舆论的音量与资本接收的收入信号可以相反。

## 3. `CLASS_COMPLEMENTARY_PLAY / 阶级互补型游戏性`

《征途》式结构中，不同付费能力玩家并不只是并列 cohort，而可能互相生产彼此的体验：

```text
large free / low-pay population
→ population density
→ opponents / followers / audience
→ visible hierarchy / social comparison
→ higher value of purchased status

high-pay players
→ revenue
→ guild/kingdom power
→ social events / conflict
→ activity and spectacle for the broader population
```

因此免费用户的价值不只来自未来 conversion，还可能来自：

### `SOCIAL_CONTENT_VALUE / 社会内容价值`

> **玩家作为其他玩家的对手、部下、观众、比较对象、社交节点和动态事件来源，本身构成可消费的游戏内容。**

此机制解释“养100个人陪1个人玩”式商业逻辑，但后续引用必须回到 CASE-033 的公开史玉柱来源，不能把口号本身当完整因果证据。

## 4. 商业化不是附层：`WEALTH → DESIGN POWER`

当收入高度集中于高支付能力玩家时，现实财富可以沿以下链条继续转换：

```text
WEALTH
→ in-game spend
→ revenue signal
→ roadmap priority
→ channel preference
→ capital allocation
→ hiring / promotion
→ next-generation design grammar
```

因此“富豪阶级游戏性”不仅把财富带进游戏世界，还可能把财富差异进一步转换成**对未来设计方向的经济投票权**。

这给 [017](017-demand-side-creator-selection-player-veto.md) 的 `DEMAND_WEIGHTING` 增加一个更精确的子型：
- `BOUNDED_DEMAND_WEIGHTING`
- `PLUTOCRATIC_DEMAND_WEIGHTING`

## 5. 为什么这会改变创作者的职业位置

如果收入主要奖励：
- novel interaction；
- authored design；
- coherent world / narrative；
- balanced combat；
- identifiable creator taste；

那么 `AUTHORIAL_JUDGMENT` 本身更容易成为稀缺资产。

如果收入主要奖励：
- conversion；
- retention；
- spend depth；
- progression pacing；
- virtual economy；
- event cadence；
- UA / channel fit；

组织更容易把高价值岗位定义为：

```text
objective-function optimizer
rather than
problem-originating auteur
```

因此本项目新增机制H：

> **《征途》式高数值商业制度不仅改变中国游戏“做什么”，也改变“什么人才最值钱、谁更容易获得资源和晋升”。**

这与 commercial-regime lineage 的既有结论兼容：
> 收入接口筛选能力；能力再筛选下一代项目。

禁止外推：
- monetization skill = low skill；
- F2P = no creativity；
- premium = auteur by default。

## 6. `PREFERENCE_SOCIALIZATION / 偏好社会化`

不能把玩家偏好视为完全外生。

当前模型：

```text
latent preference
× institutional affordance
× repeated reinforcement
→ observed demand
```

一个游戏制度可以：
1. **发现**此前未被满足的欲望；
2. **赋权**这些欲望，使其成为合法、可重复的游戏行为；
3. **训练**玩家形成新的默认预期。

因此：
- 传统技巧游戏会筛掉长期得不到正反馈的一部分玩家；
- 高数值 / F2P 可以重新吸纳其中部分人；
- 玩家长期生活在一种规则语言中以后，可能把该语言内化成“游戏本来就应该这样”。

这不是“厂商洗脑”，也不是“玩家天生如此”，而是长期产品—用户共演化。

## 7. `GENRE ↔ AUDIENCE CO-EVOLUTION / 类型—受众共演化`

作者旧稿的重要方法论保留为：

> **现存主流游戏类型不是人类需求空间的无偏样本；它们是历史上成功进入“玩家付费 → 资本跟进 → 更多供给 → 玩家被训练 → 更稳定需求”正反馈循环的幸存类型。**

因此不能从：
> “今天核心玩家都喜欢X”

直接推出：
> “所有潜在玩家天然都更喜欢X”。

需要区分：
- population latent preference；
- available genre set；
- skill barrier / access barrier；
- who churned before becoming visible “players”；
- industry investment after first validation。

## 8. `DESIGN_ATTRACTOR / 游戏设计吸引子`

定义：

> **当玩家偏好、商业模式、渠道、人才结构、媒体评价和资本配置形成相互强化的稳定反馈时，产业会进入一个使相邻产品不断向某套设计语法收敛的吸引子。**

中国2010s一个待检验强吸引子：

```text
F2P
+ high progression / numerical inflation
+ social status
+ whale monetization
+ live ops
+ channel / UA optimization
```

它不是民族属性，而是历史形成的制度—商业均衡。

其他市场也可存在不同吸引子，例如：
- premium + novelty + creator identity + direct storefront；
- console craft + IP + full-price packaged product；
- hardcore PC + mod/community + simulation depth。

这些只是 comparator H，不可当国别本质。

## 9. `SELECTION_EXTERNALITY / 选择外部性`

一次成功商业创新不会只影响创新者自己。

```text
successful product
→ investors update beliefs
→ channels allocate visibility
→ studios copy objective function
→ hiring changes
→ workers accumulate different skills
→ players see more of the same grammar
→ demand becomes more legible
```

因此史玉柱的历史意义不应缩成：
> “做出一款赚很多钱的游戏。”

更值得研究的是：
> **一次成功的需求发现是否改变整个产业的适应度地形。**

这也解释为什么 pioneer 与 imitator 要分开评价：
- pioneer = exploration / latent-demand discovery；
- followers = exploitation / validated-function optimization。

## 10. `ATTRACTOR_ESCAPE_COST / 设计吸引子逃逸成本`

当产业已围绕某套语法积累：
- 高薪岗位；
-成熟团队；
- benchmark；
- 渠道关系；
- 数据系统；
- 玩家池；
- 投资模型；

创作者想验证非共识产品，需要承担额外成本。

这与 [015](015-japan-comparator-frontier-permeability-author-rights-and-creator-replacement.md) 的 `REGIME_TAX` 相连：

> `REGIME_TAX` 更偏个人/团队从旧成功制度转向新范式时损失的职业资本；  
> `ATTRACTOR_ESCAPE_COST` 更偏整个产品假说要离开既有产业均衡时需要克服的资源、市场与认知阻力。

## 11. AI / Steam / direct-to-player：可能降低逃逸成本，但只记 H

当前H：

> **AI、通用引擎、Steam demo、全球支付与creator discovery可能降低“把非共识判断变成playable market test”的最低资本门槛，因此增加脱离既有Design Attractor的试验数量。**

但这不等于自动提高创新：
- prototype变便宜也会产生更多低质量项目；
- discovery可能成为新瓶颈；
- AI也可能被成熟组织用于更高效复制既有吸引子；
- 玩家attention仍稀缺。

真正要测的是：
- `TIME_TO_PLAYER_TRUTH` 是否下降；
- 非共识 prototype 数量是否上升；
- prototype→second attempt 的转化是否上升；
- 新需求是否能形成自己的 audience / market interface。

## 12. 下一轮研究：设计吸引子怎样被打破

### 12.1 `ALTERNATIVE_SELECTION_STACK / 替代性鉴定栈`

旧Design Attractor真正被打破，通常不只是“出现一个更有才华的人”，而是出现一套让旧守门人失去垄断的替代基础设施：

```text
CHEAPER CREATION
+ NEW DISTRIBUTION
+ DIRECT PLAYER SIGNAL
+ LEGITIMATION / TASTE INSTITUTION
+ MONEY / REPEATABILITY
→ hidden demand becomes financially legible
→ old gatekeeper can be bypassed
```

2007–2017西方独立游戏运动提供一组强机制锚点：

- Microsoft 2007披露XNA Game Studio下载量已超过40万，并被近200所教育机构采用；2008进一步允许XNA Creators Club成员通过Xbox LIVE Community Games把作品出售给数百万用户，官方直接以“democratized game distribution”描述该路径；
- 2008 Xbox LIVE Arcade官方阵容把Braid、Castle Crashers等独立作品放入平台重点发行，独立工作室已占其原创游戏库的重要部分；
- Unity 2013把此前收费约800美元的基础移动发布工具免费开放给独立开发者和小工作室，明确以降低creative / fiscal门槛描述这一变化；
- Steam 2012推出Greenlight，让社区参与决定哪些游戏获得Steam发行；Valve 2017回顾时明确表示，推出Greenlight的重要原因是其内部小团队发现自己无法可靠预测玩家究竟对哪些新游戏感兴趣；
- Steam Direct 2017进一步把进入Steam改成更透明、直接的开发者注册 / 单品申请路径；
- IGF长期承担另一种功能：不是直接支付所有研发成本，而是提供open submission、专业评审、奖项、媒体/行业可见性和“这种怪作品值得被认真看待”的合法化。

这里最重要的不是“digital distribution好”，而是：

> **旧publisher / platform buyer不再是唯一的市场鉴定者；prototype、社区、平台数据和独立奖项共同形成另一套选择制度。**

### 12.2 `PLAYER_TRUTH_INTERFACE / 玩家真相接口`

定义：

> 一个非共识产品在获得大预算以前，能否以足够低成本直接接触真实潜在玩家，并让其行为形成可信信号？

可包括：
- shareware；
- playable demo；
- Greenlight / wishlist；
- Early Access；
- open-source / mod community；
- festival playable；
- crowdfunding；
- small paid release；
- F2P live test。

这使“谁判断产品值得做”从单一老板 / publisher，变成多层市场发现。

Valve的Greenlight回顾尤其重要，因为它提供了一个罕见的守门人自证：
> **平台自身承认其内部编辑判断不能可靠预测玩家兴趣，因此把发现功能外移给玩家。**

这正是 `CREATOR_SELECTION_CAPACITY` 从舆论变成基础设施的例子。

### 12.3 《征途》与西方indie：价值观相反、范式革命结构同构

```text
《征途》
old regime: 点卡 / bounded spend
new interface: F2P + item sales + live data + ground marketing
hidden audience: 高支付能力 / 传统技巧体系未充分服务的人群
proof: huge revenue
effect: capital/channels/talent imitate

Western indie wave
old regime: publisher/retail/AAA gate
new interface: cheap tools + XBLA/Steam + festival/community
hidden audience: 愿为小规模、怪异、作者型体验付费的人群
proof: Braid / Castle Crashers / World of Goo / etc.
effect: platform support / indie publishers / creator careers
```

因此“范式革命”的共同结构可能是：

> **不是先证明新产品符合旧体系的评价标准，而是让另一套受众通过另一套交易/分发/鉴定制度，证明旧评价标准漏掉了真实价值。**

这一点与“中国玩家审美 vs 资本”争论直接相关：改变产业不只需要教育旧玩家或说服旧资本，也可能需要建立**另一套让不同玩家能够被看见、被计价的选择制度**。

### 12.4 吸引子破裂的五个必要/促进条件（H）

当前整理为：

1. `OLD_ATTRACTOR_RENT_DECAY`：旧模式边际收益下降、竞争过密或成本上升；
2. `PRODUCTION_COST_SHOCK`：工具/AI/引擎降低prototype与production门槛；
3. `NEW_MARKET_INTERFACE`：出现新的支付、分发、社区或平台；
4. `ALTERNATIVE_LEGITIMATION`：媒体、奖项、社群、主播、festival等让旧体系眼中的“怪东西”获得可理解身份；
5. `ANOMALY_PROOF`：至少一个项目把隐藏需求变成足够强的收入/用户/声誉信号，使资本更新先验。

这五项不是已证充分条件；下一步要找“条件齐全却没有形成新生态”的失败反例。



统一比较四类转折：

1. **《征途》：旧点卡/低付费深度 → 免费人口 + 财富加权需求**
2. **欧美indie 2008–2015：AAA/出版商控制 → digital storefront + cheap tools + direct audience**
3. **日本新IP/异端项目：成熟公司内部通过 prototype / patron / frontier exemption 打孔**
4. **中国premium 2015–2026：Steam/global market + old-industry capability repricing**

每个案例记录：
- old attractor；
- first anomaly；
- enabling technology；
- new distribution/payment interface；
- hidden audience；
- first commercially legible proof；
- capital imitation lag；
- talent migration；
- whether a durable new ecology formed。

## 12.5 `MINORITY_DEMAND_FINANCING / 少数需求如何养活创作者`

中国《征途》与西方indie wave还可被统一成另一个问题：

> **当愿意为某种体验持续付费的人只是总人口中的少数时，怎样把这部分需求变成足够大的生产预算？**

当前提出两种理想型：

### A. `INTENSIVE_MARGIN_MONETIZATION / 强度边际变现`

```text
small / heterogeneous payer base
× very deep spend per high-value user
→ viable revenue
```

典型方向：
- F2P；
- whale monetization；
- 富豪阶级游戏性；
- social/status goods；
- long-lived live service。

它通过**提高单个高价值用户的收入权重**让少数需求养活大系统。

### B. `EXTENSIVE_NICHE_AGGREGATION / 广度边际小众聚合`

```text
geographically dispersed niche audience
× digital global reach
× bounded price
→ enough buyers to sustain small creators
```

典型方向：
- Steam / XBLA / digital storefront；
- global niche premium；
- indie publisher；
- festival / community discovery；
- long-tail sales。

它不是让少数人每人花无限多钱，而是把原本彼此隔离的少数玩家跨地区聚成一个经济上足够大的市场。

### 为什么这可能解释中西路径差异（H）

2000s中国：
- premium回款弱；
- 盗版和支付摩擦高；
- 本土高品质零售核心受众相对有限且需与海外成熟作品竞争；
- 在线服务首先解决收费；
- 于是“把少数高支付者的ARPPU做深”成为极强商业解。

2007–2017欧美数字indie：
- XNA / Unity降低制作门槛；
- XBLA / Steam等降低分发门槛；
- IGF /社区/媒体帮助识别怪作品；
- 全球商店允许一个小众作者直接聚合跨地域购买者；
- 因此“小团队 × bounded premium price × worldwide niche”可以成为另一种可持续解。

这不是已证“国民偏好导致模式”，而是一个待检验的政治经济H：

> **不同市场基础设施会改变小众需求最容易被货币化的边际：一边可能走向“每个高价值用户付更多”，另一边可能走向“把全世界更多同好聚过来”。**

其设计后果可能非常不同：
- intensive margin 更容易奖励 retention / status / progression / spend depth；
- extensive niche aggregation 更容易奖励 distinctiveness / creator identity / category novelty / word of mouth。

后续必须寻找反例：
- premium小众聚合仍走高度公式化；
- F2P高变现仍产生强作者型玩法；
- 中国早期/现代存在广度聚合成功案例；
- 欧美/日韩存在典型富豪阶级游戏性与whale-driven attractor。

## 13. 当前最小结论

> **“富豪阶级游戏性”不是简单的P2W贬义词，而是一种现实财富—游戏效用转换制度；《征途》的关键创新，是把免费人口、异质支付能力、阶级化数值和社会关系整合成一个可持续商业系统。该系统一旦获得巨大收入，会通过需求权重、渠道、资本和人才筛选形成选择外部性，并可能构成稳定Design Attractor。玩家偏好既是这个系统的输入，也是长期社会化后的输出。**


## 14. Design Attractor 的文化层：谁训练玩家识别另一种游戏？

`DESIGN_ATTRACTOR` 不能只由收入函数解释。一个新吸引子要持续存在，还需要一套文化基础设施反复告诉新玩家：

- 这种作品存在；
- 为什么它值得玩；
- 如何比较它与主流产品；
- 谁做了它；
- 去哪里买；
- 如何进一步自己创作。

因此 [019](019-taste-institutions-player-literacy-creator-selection.md) 的 `TASTE_INSTITUTION STACK` 是 `ALTERNATIVE_SELECTION_STACK` 的文化/认知层。

尤其是 `EXTENSIVE_NICHE_AGGREGATION` 必须同时满足：

```text
distributed niche demand
+ discovery / interpretation
+ direct transaction
+ memory / reputation
→ repeatable creator market
```

只有全球商店、没有解释/合法化机构，怪作品可能淹没在供给里；只有评论/媒体、没有交易接口，则可能形成高鉴赏但低作者回流。
