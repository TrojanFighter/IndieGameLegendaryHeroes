## 0. Author-origin

作者旧稿《正在到来的中度数值通胀率游戏设计革命》提出了三条在本项目中继续保留、但需要研究化拆解的母题：

1. 传统低数值通胀竞技/零售游戏经常把现实财富排除在主要胜负规则之外，以相对平等起点 + 技巧差异分配结果，可被作者概括为“中产阶级游戏性”；
2. 《征途》式高数值通胀 / F2P 允许现实财富持续换取数值能力、地位与相对优势，作者称之为“富豪阶级游戏性”；
3. 游戏类型与玩家并非单向“需求先存在、产品来满足”，而会发生 **genre → audience → genre** 的长期互相塑造；现存主流类型本身带有幸存者偏差。

旧稿里的阶级术语是一套**游戏需求模型**，不是现实阶层身份的直接分类。正式研究中不把“富豪阶级游戏性”理解为“所有富人都喜欢P2W”，也不把“中产阶级游戏性”理解为人口统计学意义上的中产。

## 1. `RESOURCE_CONVERSION_RIGHT / 外部资源转换权`

核心问题：

> **现实世界的哪些差异，被游戏规则允许转换成游戏内稀缺能力？**

可比较：
- chess / competitive FPS：主要允许时间、知识、技巧、认知等转成胜率；
- subscription / boxed game：现实财富主要决定“能否进入”，进入后对直接战斗优势的转换受限；
- 《征途》式高数值F2P：现实财富可持续转换为战力、装备、地位、组织影响和相对压制能力。

因此“富豪阶级游戏性”的研究定义：

> **一种允许现实财富通过游戏规则被高效率、可重复地转换为游戏内稀缺能力、地位、可见权力与相对优势，并由这种转换本身构成重要正反馈的体验制度。**

边界：
- cosmetic-only purchase ≠ 富豪阶级游戏性；
- subscription ≠ 富豪阶级游戏性；
- 有抽卡 ≠ 自动构成完整富豪阶级游戏性；
- 关键在于财富能否稳定购买**相对效用 / 相对支配关系**。

## 2. `PLUTOCRATIC_DEMAND_WEIGHTING / 财富加权需求`

Premium 的收入投票通常较有界：

```text
one buyer → one/few bounded purchases
```

高付费深度 F2P 则允许：

```text
revenue voting weight ∝ willingness/ability to spend
```

因此《征途》的制度创新不只是“找到whale”，而是：

> **取消“一个玩家最多贡献有限收入”的市场上限，使少数高支付能力用户的偏好在收入函数中获得远高于普通玩家的权重。**

这不是民主/政治类比的价值判断，而是需求权重结构描述。

研究后果：
- “大多数玩家喜欢什么”与“收入最奖励什么”可能显著分离；
- product roadmap 可能围绕高边际收入玩家而不是人数多数优化；
- 玩家舆论的音量与资本接收的收入信号可以相反。

## 3. `CLASS_COMPLEMENTARY_PLAY / 阶级互补型游戏性`

《征途》式结构中，不同付费能力玩家并不只是并列 cohort，而可能互相生产彼此的体验：

```text
large free / low-pay population
→ population density
→ opponents / followers / audience
→ visible hierarchy / social comparison
→ higher value of purchased status

high-pay players
→ revenue
→ guild/kingdom power
→ social events / conflict
→ activity and spectacle for the broader population
```

因此免费用户的价值不只来自未来 conversion，还可能来自：

### `SOCIAL_CONTENT_VALUE / 社会内容价值`

> **玩家作为其他玩家的对手、部下、观众、比较对象、社交节点和动态事件来源，本身构成可消费的游戏内容。**

此机制解释“养100个人陪1个人玩”式商业逻辑，但后续引用必须回到 CASE-033 的公开史玉柱来源，不能把口号本身当完整因果证据。

## 4. 商业化不是附层：`WEALTH → DESIGN POWER`

当收入高度集中于高支付能力玩家时，现实财富可以沿以下链条继续转换：

```text
WEALTH
→ in-game spend
→ revenue signal
→ roadmap priority
→ channel preference
→ capital allocation
→ hiring / promotion
→ next-generation design grammar
```

因此“富豪阶级游戏性”不仅把财富带进游戏世界，还可能把财富差异进一步转换成**对未来设计方向的经济投票权**。

这给 [017](017-demand-side-creator-selection-player-veto.md) 的 `DEMAND_WEIGHTING` 增加一个更精确的子型：
- `BOUNDED_DEMAND_WEIGHTING`
- `PLUTOCRATIC_DEMAND_WEIGHTING`

## 5. 为什么这会改变创作者的职业位置

如果收入主要奖励：
- novel interaction；
- authored design；
- coherent world / narrative；
- balanced combat；
- identifiable creator taste；

那么 `AUTHORIAL_JUDGMENT` 本身更容易成为稀缺资产。

如果收入主要奖励：
- conversion；
- retention；
- spend depth；
- progression pacing；
- virtual economy；
- event cadence；
- UA / channel fit；

组织更容易把高价值岗位定义为：

```text
objective-function optimizer
rather than
problem-originating auteur
```

因此本项目新增机制H：

> **《征途》式高数值商业制度不仅改变中国游戏“做什么”，也改变“什么人才最值钱、谁更容易获得资源和晋升”。**

这与 commercial-regime lineage 的既有结论兼容：
> 收入接口筛选能力；能力再筛选下一代项目。

禁止外推：
- monetization skill = low skill；
- F2P = no creativity；
- premium = auteur by default。

## 6. `PREFERENCE_SOCIALIZATION / 偏好社会化`

不能把玩家偏好视为完全外生。

当前模型：

```text
latent preference
× institutional affordance
× repeated reinforcement
→ observed demand
```

一个游戏制度可以：
1. **发现**此前未被满足的欲望；
2. **赋权**这些欲望，使其成为合法、可重复的游戏行为；
3. **训练**玩家形成新的默认预期。

因此：
- 传统技巧游戏会筛掉长期得不到正反馈的一部分玩家；
- 高数值 / F2P 可以重新吸纳其中部分人；
- 玩家长期生活在一种规则语言中以后，可能把该语言内化成“游戏本来就应该这样”。

这不是“厂商洗脑”，也不是“玩家天生如此”，而是长期产品—用户共演化。

## 7. `GENRE ↔ AUDIENCE CO-EVOLUTION / 类型—受众共演化`

作者旧稿的重要方法论保留为：

> **现存主流游戏类型不是人类需求空间的无偏样本；它们是历史上成功进入“玩家付费 → 资本跟进 → 更多供给 → 玩家被训练 → 更稳定需求”正反馈循环的幸存类型。**

因此不能从：
> “今天核心玩家都喜欢X”

直接推出：
> “所有潜在玩家天然都更喜欢X”。

需要区分：
- population latent preference；
- available genre set；
- skill barrier / access barrier；
- who churned before becoming visible “players”；
- industry investment after first validation。

## 8. `DESIGN_ATTRACTOR / 游戏设计吸引子`

定义：

> **当玩家偏好、商业模式、渠道、人才结构、媒体评价和资本配置形成相互强化的稳定反馈时，产业会进入一个使相邻产品不断向某套设计语法收敛的吸引子。**

中国2010s一个待检验强吸引子：

```text
F2P
+ high progression / numerical inflation
+ social status
+ whale monetization
+ live ops
+ channel / UA optimization
```

它不是民族属性，而是历史形成的制度—商业均衡。

其他市场也可存在不同吸引子，例如：
- premium + novelty + creator identity + direct storefront；
- console craft + IP + full-price packaged product；
- hardcore PC + mod/community + simulation depth。

这些只是 comparator H，不可当国别本质。

## 9. `SELECTION_EXTERNALITY / 选择外部性`

一次成功商业创新不会只影响创新者自己。

```text
successful product
→ investors update beliefs
→ channels allocate visibility
→ studios copy objective function
→ hiring changes
→ workers accumulate different skills
→ players see more of the same grammar
→ demand becomes more legible
```

因此史玉柱的历史意义不应缩成：
> “做出一款赚很多钱的游戏。”

更值得研究的是：
> **一次成功的需求发现是否改变整个产业的适应度地形。**

这也解释为什么 pioneer 与 imitator 要分开评价：
- pioneer = exploration / latent-demand discovery；
- followers = exploitation / validated-function optimization。

## 10. `ATTRACTOR_ESCAPE_COST / 设计吸引子逃逸成本`

当产业已围绕某套语法积累：
- 高薪岗位；
-成熟团队；
- benchmark；
- 渠道关系；
- 数据系统；
- 玩家池；
- 投资模型；

创作者想验证非共识产品，需要承担额外成本。

这与 [015](015-japan-comparator-frontier-permeability-author-rights-and-creator-replacement.md) 的 `REGIME_TAX` 相连：

> `REGIME_TAX` 更偏个人/团队从旧成功制度转向新范式时损失的职业资本；  
> `ATTRACTOR_ESCAPE_COST` 更偏整个产品假说要离开既有产业均衡时需要克服的资源、市场与认知阻力。

## 11. AI / Steam / direct-to-player：可能降低逃逸成本，但只记 H

当前H：

> **AI、通用引擎、Steam demo、全球支付与creator discovery可能降低“把非共识判断变成playable market test”的最低资本门槛，因此增加脱离既有Design Attractor的试验数量。**

但这不等于自动提高创新：
- prototype变便宜也会产生更多低质量项目；
- discovery可能成为新瓶颈；
- AI也可能被成熟组织用于更高效复制既有吸引子；
- 玩家attention仍稀缺。

真正要测的是：
- `TIME_TO_PLAYER_TRUTH` 是否下降；
- 非共识 prototype 数量是否上升；
- prototype→second attempt 的转化是否上升；
- 新需求是否能形成自己的 audience / market interface。

## 12. 下一轮研究：设计吸引子怎样被打破

统一比较四类转折：

1. **《征途》：旧点卡/低付费深度 → 免费人口 + 财富加权需求**
2. **欧美indie 2008–2015：AAA/出版商控制 → digital storefront + cheap tools + direct audience**
3. **日本新IP/异端项目：成熟公司内部通过 prototype / patron / frontier exemption 打孔**
4. **中国premium 2015–2026：Steam/global market + old-industry capability repricing**

每个案例记录：
- old attractor；
- first anomaly；
- enabling technology；
- new distribution/payment interface；
- hidden audience；
- first commercially legible proof；
- capital imitation lag；
- talent migration；
- whether a durable new ecology formed。

## 13. 当前最小结论

> **“富豪阶级游戏性”不是简单的P2W贬义词，而是一种现实财富—游戏效用转换制度；《征途》的关键创新，是把免费人口、异质支付能力、阶级化数值和社会关系整合成一个可持续商业系统。该系统一旦获得巨大收入，会通过需求权重、渠道、资本和人才筛选形成选择外部性，并可能构成稳定Design Attractor。玩家偏好既是这个系统的输入，也是长期社会化后的输出。**
