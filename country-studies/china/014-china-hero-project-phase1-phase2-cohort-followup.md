## 0. 为什么这一队列重要

台湾2021独立游戏开发奖励已经有一个完整8案的selected-winner follow-up。大陆最接近的可比公开框之一不是某个地方补助，而是Sony Interactive Entertainment Shanghai自2016年启动的China Hero Project。

它不是政府补助，也不是纯现金投资。当前PlayStation官方说明，该项目同时提供开发、发行、营销支持；开发侧包括Epic/CRIWARE中间件、Digital Hearts QA、音频、Virtuos开发支持、Richtap、代码审查及专业指导；重点项目还可获得开发资金，并获得全球发行伙伴对接。

官方当前入口：https://www.playstation.com/zh-hans-cn/china-hero-project/

因此本队列检验的是：

> 被一个高强度平台加速器筛中的中国游戏项目，之后究竟有多少真正发售、延期、改变产品形态、发售后停服，或长期失去可靠公开进展？

它不能回答普通大陆独立开发者的成功概率。

这意味着第一期大约是“400+公开申请入口 → 10 selected titles”，具有极强选择效应。即使10案最后全部发售，也不能把结果外推为普通项目概率。

这里最重要的方法论修正是：第一期并非10个同成熟度、同起点的新创项目。2017同期报道已经说部分作品接近完成，而Lost Soul Aside等处于不同阶段；Tiger Knight/War Rage还是既有商业产品或产品谱系。

所以第一期不能机械计算一个“China Hero发售率”。

### 描述性结果

第二期可以安全写：

> 2019固定7个selected titles中，截至2026-10有6个可核公开发售，1个仍未发售且项目关系存在公开争议。

不能写：
- China Hero让85.7%的团队成功；
- Sony资金造成了6款发售；
- Convallaria失败完全由Sony或开发商任何一方造成。

## 6. 与台湾2021奖励队列的真正可比点

台湾2021奖励队列：8个已公司化年轻企业，7个公开发售、1个Steam仍Coming Soon。

China Hero第二期：7个被平台筛中的项目，6个公开发售、1个仍未发售/争议。

数字表面非常接近，但制度完全不同：

| 维度 | 台湾2021独立游戏奖励 | China Hero Project |
|---|---|---|
| 资金/机构性质 | 公共奖励体系 | 私营全球平台加速器 |
| 申请主体 | 必须台湾公司、成立未满5年 | 当前规则审查公司/团队；2016首期允许从plan/demo筛选 |
| 选样成熟度 | 明显偏公司化和可交付 | vertical slice/GDD/团队能力；首期成熟度高度混杂 |
| 支持内容 | 奖励金，后续逐渐接产品化/投资 | 资金 + middleware + QA + audio + code review + dev support + publisher matching + marketing |
| 平台目标 | 不限单一主机生态 | PlayStation导向并面向全球 |
| 主要selection bias | 公司化门槛、评审成熟度 | 400+→10的极强平台筛选、技术/主机适配 |
| 失败形态 | 长期未发售项目 | 长期未发售、争议、发售后服务停止等均存在 |

因此比较不能落到“台湾政府 vs Sony谁成功率高”，而应该问：

> 不同资本/平台接口在项目的什么成熟阶段进入，买下了什么生产能力，项目失败时又留下哪些可恢复资产？

## 7. 一个更有价值的新结论：平台扶持解决的是能力缺口，不是项目风险本身

China Hero当前官方支持范围很深：资金、中间件、QA、声音、开发协力、代码审查、发行伙伴和营销。

即便如此，固定队列仍出现：
- 超长开发周期（Lost Soul Aside）；
- 正式发售后服务中止（Boundary）；
- 长期缺少公开闭环（Pervader / Project X）；
- 未发售且合作争议（Convallaria）。

所以更准确的命题是：

> 强平台中介可以显著补足生产和市场接口，但不能消除scope、组织、治理、合同、市场和长期交付风险。

这也反过来压力测试台湾资本梯子：TAICCA、发行商和平台服务的存在同样不能被直接视为项目成功原因。

## 8. 下一步

1. 回收第一期Pervader / Project X最后可靠一手开发记录，必要时保留RIGHT-CENSORED而不是硬判取消。
2. 分开Tiger Knight、War Rage的“既有PC产品”与China Hero PlayStation交付承诺，不把历史商业发布计为计划后转化。
3. 对第二期6个已发售项目补入选时团队规模、prototype成熟度、实际资金/服务使用，避免仅有ship outcome。
4. 对Convallaria收集Sony回应、合同/司法/仲裁等可公开材料；在此之前维持CONTESTED而不归责。
5. 第三期另建队列，不与一二期混算；2022以后计划规模、资金下限和平台策略已发生明显变化。
