# 上海交大与周边同人游戏网络：人物人生抉择与跨公司能力流动（2005—2026）

- Program: C 中国国情／游戏产业与青年创作者形成；跨区与《斯拉夫游戏英雄传说》Gusarov/Krank/Klimov等职业生命史对照。
- Type: 人物关系／命运分叉 Evidence Ledger；**不是单个完整Case，也不是已经定稿的人物传记**。
- Status: ACTIVE，2026-10-07第一轮；P0 同期证券文书/校方材料/亲历者发言 + P1 当事人回忆 + S2 人物圈层历史梳理；存在未证实成员关系。
- 核心问题：在中国2010年代渠道为王／资金重视成熟商业模型的环境下，**什么样的同伴网络、早期原创实践、外部收入与创始人角色互补，能够让少数作者型游戏小组存活**？研究院系、游戏社群、人生冲突、退场者、资金，不能把最后成功者自动当成群体常态。

## 一、先禁止一个方便但可能错误的传奇
“上海交大游戏社团走出米哈游、鹰角、悠星”是**过度单线化**叙述。当前可确认两条相交但不等同的谱系：
1. **交大研究生宿舍／ACG技术兴趣（米哈游）**：蔡浩宇、刘伟、罗宇皓、第四原始股东靳志成及早期美术张庆华等；不是已证实都出自名为“StudioGM”的同一官方校内游戏社团。
2. **2007年前后独立同人制作社群（StudioGM、云母组／MICA、艺术家社群）**：姚蒙、陈开以及据2021二手研究称参与StudioGM的黄一峰/林书茵等；后来关联悠星、散爆、鹰角、蛮啾／勇仕。《明日方舟》海猫是**钟祺翔**，而交大校友鹰角CEO**黄一峰不是海猫**。
3. 连接两者的**可确认跨组关系**：悠星CEO姚蒙2020年亲口说**2014年刘伟给姚蒙和陈开介绍投资人**；不只是“同城圈子”，而是具体现金流进入路径。
4. **正式交大校友与独立社团成员分开记**：交大2023官方材料确认鹰角黄一峰（15届）与樊润冬（14届）为校友；2021交大机构报道记载袁理与乐俊伟为鹰角合伙人。袁理/乐俊伟及陈开的交大学历，目前有二手文本，个人原始学历档案待核；姚蒙是否交大校友不可推定；StudioGM是否正式上交大注册社团未核。
5. 也不把米哈游三位剩余创始人当“起步就各自天才/志同道合”简单成功故事：**技术合伙人分裂、非技术角色有意互补、稳定工作退场、2012现金融资**都能追踪。

## 二、人物的真正人生选择（逐项证据）

### 1. 刘伟：成绩规训 → 2008留学落空 → 接触“非标准学生” → 深圳失败 → 非技术互补合伙人
- **L01 P1**：刘伟2026-04在交大40分钟自述，经游戏葡萄编辑摘录：https://wallstreetcn.com/articles/3770005 （访问2026-10-07，演讲场合为交大130周年校庆相关活动，主观记忆，文章注明为方便阅读有所删节）。
- 出生农村，自述早期只重高GPA与出国；2005入交大，英语/专业计算知识落后于城市背景同学，数学分析首次未及格；2008国际金融危机后申请国外学校未拿到offer，选择本校直研。
- 2009—2010研究生阶段转变：发现自己不喜欢/不擅长科研，完成论文要求后主动接触非标准的电商创业同学、计算机系做金融服务的创业型学生、跑虫俱乐部成员，重新认识“优秀”的定义；生活费约600—1000元/月（2026追忆数，不可换算成2010人人平均）。
- 随交大学长前往深圳尝试创业，约3—4个月在出租屋未能形成项目，2010年前后返上海；先前曾认识正在创业的蔡浩宇，回沪后获其邀入新团队。**注意：口述中同时用“2010年底结识交大学长”和“2010年12月底回沪”描述经历，与三四个月跨度存在内部顺序冲突；未拿到同期记录前只写2010年前后，不能推确切月。**
- 刘伟问蔡为何找技术能力不强的自己，刘伟回忆蔡说自己此前2—3次全部技术人员合作的项目失败，认识到需要有人负责管理及技术以外工作。**这是2026刘伟对蔡观点的追述，不是蔡本人同期原话**。
- **研究价值**：职业起点不是玩法天才，而是从单一路径考试与学历评价转向同伴创业网络；“技术强者识别自己缺少经营能力，主动招募非技术互补者”与Krank/K-D LAB团队分工构成职业抉择对照。
- **需要补**：出生家庭教育资源与父母反对/支持的直接证据；“创业失败两次”细节及原合伙人反方；2010深圳同伴团队名单（注意非公众私人信息不采集）。

### 4. 姚蒙与陈开：愿意做Steam单机 → 投资人要求改手游 → 失败 → 卖房继续 → 国际发行＋投资别人
- **L05 P1**：2020-05-27 姚蒙CEO采访（GameRes转载《手游那点事》与Google合作栏目），https://www.gameres.com/868199
- 姚与陈开毕业后经营小团队，进行独立游戏开发和软件外包；2014刘伟介绍投资人后创建悠星；原想做Steam单机，**投资人告知应转手游，于是他们把单机项目改成手游，设计做了多处重大修改**，《诺诺来自异世界》表现不佳，损失资金。这是**具体涉及发行/资金对作者产品方向干预的当事人一手回忆**，不能说只存在抽象资金筛选。
- 2016下半年，公司资金不足，姚自述卖掉家乡房产救公司，将资金一半用于代理《碧蓝航线》日本市场，另一半投资支持鹰角与《明日方舟》；过去的同人开发者关系与提前筹备的日本发行队伍使该转换有实际可行性。
- **因果边界**：《诺诺》失败由姚归因于产品原始定位与商业模式不匹配，但未验证若保留Steam单机一定成功。未查投资方同期解释，不能道德判决；他自称“投资参与成立鹰角”，但公开股东工商登记入股时点可能晚于创立，分开“合同资助/运营关系/法定股东日期”，不能用一个词完成三种事实。
- 重大创作者角色转变：姚从想亲自做游戏的创作者，转为依赖创作社群和产品判断、在海外运营与发行上高度专业化的组织者。**与Krank→KranX、Klimov→Snowball功能比较**，但三人公司时代/游戏类型与财务不可硬等价。

## 三、同一环境里至少有五种完全不同的职业与风险路径

| 人物／节点 | 最初能力与目标 | 被迫决策 | 走向 | 需比较的俄罗斯职业模型 |
|---|---|---|---|---|
| 蔡浩宇 | 技术与ACG游戏志趣 | 早期技术团队合作失败，转向管理互补 | 自主作品系列与大型公司 | Krank早期团队/技术强但需要product integration |
| 刘伟 | 成绩导向/科研焦虑，非研发核心能力 | 留学不成、深圳创业无成果、改选管理 | cofounder经营/运营/客服 | Klimov类型的制作/组织判断，不同于“同样天才程序员” |
| 靳志成 | 软件工程职业选择 | 2012稳定工作offer vs 十分年轻无盈利团队 | 退出创业入Cisco | **必须保留的早退/非成功者**，不能事后施加股价机会成本 |
| 姚蒙/陈开 | 独立作品/外包 | 投资人要求Steam单机转手游→失败；资金耗尽 | 卖房+投资/日本发行→悠星 | Krank/KranX及Klimov/Snowball的转换 |
| 海猫/黄/樊/袁等 | 艺术世界观、技术、玩法互补 | 小预算与3D产能限制 | 2D角色+3D空间可玩验证并商业化 | Gusarov能力塑造项目+团队组合；严禁由后果推出必然成功 |

**系统性分析入口**：不是只看这些人“终于成功”，而是看一群年轻开发者在**相似时间、相同城市、同类兴趣和部分相同社交网络**条件下，谁能够获得作者权限、谁主动放弃、谁被迫转型、谁因为项目失败转入发行、谁仍在社群中但从未成为创始人。建立同源网络内部对照可能比随意比较上海与莫斯科成功名人更严格。

## 四、与“渠道—外行资本—执行主策”研究的最硬接口

已有 [渠道资本账](channel-capital-cognitive-asymmetry-2013-2019.md) 记录发行商干预收费点，但“真实开发者被要求改品类”的一手记录稀缺。**姚蒙2020访谈明确提供投资方改变Steam单机→手游、导致实质改动并商业失败的当事人叙事**。新增一条 P1“authorial project redirection”重点线：
`original Steam-premium thesis → investor preference for mobile monetization/distribution → redesign → commercially unsuccessful launch (per founder) → founder capital liquidation → reconfiguration into publisher & angel investor`。
这条链有亲历者本人陈述，但需寻找投资方版本、当时BP/合同以及诺诺的上线版本证据。**不能假定投资者必然外行**；“有资金方向权”与“从未玩过游戏”是不同命题。

米哈游的反例亦重要：早期**杭州斯凯**确为移动互联网/发行有经验的资本方，而非“纯外行”投资者；取得100万元天使资金、15%股权不等于主创丧失IP/设计权。公司亦借用了二次元社区的高度定向用户反馈。对此需要与被要求改做手游的悠星形成**同年投资对象内部对照**，研究的是合作权力而非资本是否来自中国。
