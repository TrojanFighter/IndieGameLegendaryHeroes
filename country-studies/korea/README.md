本区主要研究**韩国网络游戏技术先发优势减弱后，企业如何通过国际人才识别、国外作品/技术获取、跨国组织整合与海外市场反馈延续竞争力**。不要把这个问题偷换成“韩国人比中国人更原发创新”；也不要拿少数成功并购代替两国整个产业的数量级比较。

### 研究禁令

1. “海外收入”“海外并购金额”“国外作者被雇佣”“韩国本土作者能力成长”四者不能互代；
2. 韩国正例与中国反例都必须计入；不要把中资国际收购抹掉；
3. 发现得早还是晚要标注当时已存在的Mod/社区/市场数据；
4. 公司国籍起源、上市/总部所在地、工作室生产所在地与作者国籍应分开编码；
5. 失败收购、治理权冲突与非续作同样是研究样本；
6. 不能以几位知名创始人的故事建立全国发生率结论。
