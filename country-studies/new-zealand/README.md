## 研究问题

用户/作者2024年知乎原文及2026-10-11连续研究提出：
> 一个只有约五百多万人口的国家，为什么能涌现出跨越如此多品类、制作水准与原创性相当高的游戏？这种人均产出与芬兰、丹麦、挪威、捷克、波兰、瑞典等国相比究竟处于什么位置？

同时把“被媒体看见的名作”与“已有能力但商业表现较弱的作品”分别统计，反对只挑成功者。此处不是预设“新西兰是第一”的证明档。

## 统计协议（必须同时出两个以上榜单）

1. **国际成名/高质量作品**：2010—2025统一时期，以Steam评价数与比率、媒体/奖项、销量/收入、平台下载分别报告；同系列与续作另列；付费单机、F2P、Roblox和移动不可混合一条阈值。
2. **创作者形成率**：首次以独立产品决策权完成原型/商业发行的团队；从游戏Jam、协会/平台的固定起点全部候选名单向后追踪，寻找没有成名的参与者。
3. **第二作/再生产率**：某届/某年的全部初创主体，3/5/10年后是否持续创作；区分继续做游戏、成功商业化、独立持有IP、员工spinout和母公司继续经营。
4. **跨国归属**：创作者受教育/形成地、原型起源地、实际生产地、融资/IP控制地、市场所在地分别登记；海外发行和少数股权投资不自动改变原创归属。
5. **分母**：当年人口、同年FTE和累积开发者人年分别提供；多年的作品存量不能除以单年FTE并宣称“人效”。
6. **反证**：若同口径芬兰/捷克/丹麦表现接近或更强，应直接记录，不把其它小国当衬托。
7. **重复与独立性**：同家公司多个IP与不同创始主体必须分别计；Steam策展推荐数、GDSR开发中游戏数、CODE申请数均非“新创公司数”或“全球知名作品数”。

## 首批优先样本（候选，不等于已立Case）

- 独立形成：Mini Metro / Dinosaur Polo Club、Poly Bridge / Dry Cactus、DREDGE / Black Salt、Abiotic Factor / Deep Field、Umurangi Generation、Cryptmaster。
- 长周期IP：Path of Exile / GGG、Bloons / Ninja Kiwi、PikPok/Into the Dead。
- MOD和技术社群：AMID EVIL / Indefatigable、Depth / Digital Confectioners、RocketWerkz/Stationeers/Icarus。
- 新增或重算：Ashen/A44、Automation/Camshaft、Labyrinth of the Demon King、It's Only Money、Agent Intercept、PICO-8创作者谱系、Chopper、SPARX、Roblox作品。
- 失败/未发售对照：Wandering Monster的Space:1969、Dinosaur Polo Club取消的Magic School、未签约/未上市CODE申请者（目前大部分不可公开核验）。
- 不能把所有海外共同开发产品视为新西兰“原发”，也不能把低Steam评测数自动等同于低全平台收入。
