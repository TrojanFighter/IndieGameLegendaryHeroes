# 研究术语 / Research glossary

用于翻译一致性，不代替 Case / Claim 的精确定义。新术语先讨论含义，再扩表。

| 中文 | English | 使用边界 |
| --- | --- | --- |
| 能力资本 | capability capital | 包含项目开始前的训练、工作、工具与关系积累 |
| 生存资金与可支撑时间 | runway | 金额与持续时间分别记录，不能只等同预算 |
| 范围控制 | scope discipline | 不是泛称降低质量 |
| 市场接入 | market access | 包含平台、媒体、社群与发行路径 |
| 核心开发团队 | core development team | 不等于全部 contributors 或 credits |
| 峰值团队 | peak team | 注明统计时期与全职 / 外包口径 |
| 表现成本 | representation cost | 承载体验所需的资产与技术成本 |
| 可迁移的生产决策 | transferable production decisions | 仍需适用条件与跨案例验证 |
| 不可轻易复制的条件 | context-specific / non-transferable conditions | 不把成功者路径写成普遍处方 |
| 同期一手证据 | contemporaneous primary evidence (P0) | 以说话人、时间、角色判断，不以媒体形式判断 |
| 回顾性一手证据 | retrospective primary evidence (P1) | 明示回忆及自我叙事局限 |
| 假说 | hypothesis (H) | 不得改写为已证实事实 |
| 尚未知 | UNKNOWN | 翻译不得凭常识补齐 |
| 产品驱动扩张 | PRODUCT_LED_SCALING | 通用分析概念，保留原标识 |
| 组织驱动扩张 | ORGANIZATION_LED_SCALING | 通用分析概念，保留原标识 |
| 能力邻接 | CAPABILITY_ADJACENCY | 通用分析概念，保留原标识 |
